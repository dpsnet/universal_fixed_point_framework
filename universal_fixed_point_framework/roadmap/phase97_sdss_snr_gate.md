# Phase 97：SDSS SNR 门槛化测量（Phase 94 登记的远期项闭合）
**关联**：Paper 48 §4.9 中场全样本段（v0.25）；闭合 Phase 94 登记的"SNR 门槛化测量远期"项
**日期**：2026-10-08
**状态**：规划 → 执行

## 1. 目标

Phase 94 诚实发现：SDSS 老光谱"无线率"被 SNR 混杂（弱场无线 52% vs DESI 弱场 0%）。本 Phase 对 Phase 94 的 142 中场 + 99 弱场 SDSS 光谱**估算 SNR、加门槛后重做有线星 d_pure 对照**——检验支持性结论（缺失 37%）是否在 SNR 门槛下稳健。

## 2. 判据

- SNR 估算：从 SDSS 光谱 flux 噪声（相邻像素差法）估算 Balmer 区 SNR/像素
- 门槛：SNR ≥ 5（弱）、≥ 10（中）、≥ 20（严）三档
- **若 SNR 门槛后 d_pure 对照（中场 vs 弱场）仍保持缺失方向 → SDSS 支持性结论加固**
- **若门槛后样本锐减或方向改变 → 诚实标注：SDSS 支持性证据失效/降级，主证据仍为 DESI**
- 诚实边界：SDSS get_spec 的 ivar/err 可用则用精确 SNR；不可用则相邻像素差法近似并标注

## 4. 执行记录

### M97-1（✅ 2026-10-08）：SNR 估算（241 颗全成功）
- 相邻像素差法（Balmer ±50 Å 外连续谱窗 4000–6800 Å）
- 弱场 SNR 中位 8.2 vs 中场 16.8——**SNR 不对称确认**（弱场系统性偏低）
- 数据：`paperX_wd_linelevel_mid_full_snr.json`、`paperX_wd_linelevel_weak_sdss_snr.json`

### M97-2（✅ 2026-10-08）：门槛分档对照——关键诚实发现
| SNR 门槛 | 中场（有线 n、d_pure） | 弱场（有线 n、d_pure） |
|---|---|---|
| ≥0 | 55、0.036 | 48、0.057 |
| ≥5 | 38、0.035 | 23、0.037 |
| ≥10 | 24、0.031 | 8、0.044 |
| ≥20 | 14、0.006 | 2、−0.036 |
- **SNR≥5 后差异消失（0.035 vs 0.037）——"缺失 37%"不稳健**
- 弱场无线率随 SNR 升高反增（52%→68%→77%）——无线判定与 SNR 非单调（温度混杂，无线星偏冷 9561 vs 14070 K）
- 原因：SDSS 老光谱 SNR 不对称（弱场低 SNR）→ d_pure 对照基线不对称

### M97-3（✅ 2026-10-08）：落盘 + 降级
- Paper 48 v0.28：SDSS 全样本"缺失 37%"**降级为方向性提示**（不作定量支持证据）；主证据链（DESI −63%、Kepler+2013 −49%）不受影响
- 登记远期：SNR 匹配的新观测（LAMOST/4MOST）做正式中场扩样对照
