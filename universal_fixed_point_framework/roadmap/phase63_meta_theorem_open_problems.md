### 第二阶段：体制间态理论深化（2–4 周）

**目标**：将体制间态从草案 v0.1 推进至可发表的理论框架。

#### 3.2.1 $\epsilon_\mathrm{hex}$ 可计算性（C1）

- **问题**：$\epsilon_\mathrm{hex} = \sup_{X,Y,Z} \frac{\|b_{X \otimes Y, Z} - \cdots\|}{\|b_{X \otimes Y, Z}\|}$ 在无穷维中不可计算
- **推进方案**：
  1. 发展有限维截断逼近：$\epsilon_\mathrm{hex}^{(N)} = \sup_{\dim X, \dim Y, \dim Z \leq N} \cdots$
  2. 研究 $\epsilon_\mathrm{hex}^{(N)}$ 的收敛速率与渐近行为
  3. 寻找替代判据：如伪谱剩余（pseudospectral residual）或条件数渐近
- **交付物**：逼近方法 + 收敛性定理

#### 3.2.2 $\theta$-$C$ 独立性的理论解释（D1）

- **问题**：理论预测 $\theta$（局部纠缠度量）与 $C$（全局正交性度量）独立，但数值模拟得 $r = -0.53$
- **推进方案**：
  1. 分析随机矩阵耦合对 $\theta$-$C$ 关系的影响
  2. 区分"理论独立性"（数学定义层面）与"数值相关性"（有限样本耦合效应）
  3. 构造解析反例证明独立性，或修正理论预测
- **交付物**：理论分析 + 修正后的数值实验

#### 3.2.3 体制间态拓扑分类（C2）

- **问题**：体制间态是连续参数空间，是否有有意义的拓扑不变量？
- **候选不变量**：
  - $\epsilon_\mathrm{hex}$ 的渐近增长率（幂律 $\alpha$ / 指数 $\beta$ / 对数 $\gamma$）
  - 退化方向 $\theta$ 的拓扑性质（是否为流形上的连续函数？）
  - 弱辫子范畴的等价类（Drinfeld 联结子形变分类）
- **推进方案**：
  1. 对三类渐近行为（幂律/指数/对数）构造具体算子实例
  2. 验证不同渐近类对应的物理场景（临界动力学/非厄米随机矩阵/Kerr QNM）
  3. 建立渐近类与辫子等价类的对应关系
- **交付物**：拓扑分类定理草案

#### 3.2.4 谱静默与体制间态关系（C3）

- **问题**：体制间态中 D 有定义但辫子部分失效，是否对应"半静默"？
- **推进方案**：
  1. 定义"方向静默"（directional silence）：D 在某些辫子方向上静默，其他方向非静默
  2. 建立方向静默与弱辫子结构的对应
  3. 与已有的谱静默判定（S1–S4）衔接
- **交付物**：方向静默定义 + 与体制间态的等价定理

### 第三阶段：盲区 2–5 的形式化推进（1–3 月）

**目标**：将五个盲区从概念分析推进至形式化定义。

#### 3.3.1 盲区 2：无界算子域问题（B2）

- **核心挑战**：$A_\mathrm{sa}$ 和 $A_\mathrm{anti}$ 的定义域可能不交，交换子无定义
- **推进方案**：
  1. 引入 von Neumann 代数 $\mathcal{M}$，在代数层面定义自伴/耗散分解
  2. 用 KMS 态或 Tomita-Takesaki 理论替代直接算子分解
  3. 将 Rec 范畴从"算子范畴"推广为"算子代数范畴"
  4. D 函子从"谱映射"推广为"谱空间的代数同态"
- **依赖**：Mathlib 的 von Neumann 代数基础设施（可能需要自主开发）
- **交付物**：`UnboundedOperatorBlindSpot.lean` 骨架 + 数学定义文档

#### 3.3.2 盲区 3：临界体制 $C^*$（B3）

- **核心挑战**：$C = C_\mathrm{crit}$ 时辫子六边形公理可能半瓦解
- **推进方案**：
  1. 精确定义"弱辫子"（weak braiding）：$\|b_{X \otimes Y, Z} - \text{标准六边形右端}\| < \delta$
  2. 建立弱辫子与 Drinfeld 联结子形变的对应（已有推导，需严格化）
  3. 研究临界体制 $C^*$ 的稳定性：微扰下 $C^*$ 是流入 B2、C 还是体制间态？
- **交付物**：`CriticalRegimeCstar.lean` + 定理文档

#### 3.3.3 盲区 4：$C_\mathrm{crit}$ 连续化（B4）

- **核心挑战**：辫子交叉数 $k$ 随 $C$ 连续增大，不存在离散 $C_\mathrm{crit}$
- **推进方案**：
  1. 将 $C_\mathrm{crit}$ 从常数推广为函数 $C_\mathrm{crit}(\theta)$
  2. 参数 $\theta$ 的数学含义：与谱类型（纯点/绝对连续/奇异连续）的关联
  3. 引入"体制纯度"概念：系统在多大程度上属于某一体制
  4. 或者承认过渡带系统的存在，与体制间态理论合并
- **交付物**：连续化判据 + 与体制间态的统一框架

#### 3.3.4 盲区 5：Koopman 提升推广（B5）

- **核心挑战**：时变/混沌/随机系统的 Koopman 算子不落入标准 Hilbert 空间
- **推进方案**：
  1. 将 Rec 范畴推广到"算子代数范畴"（与盲区 2 共享基础设施）
  2. D 函子推广为 Gelfand 对偶意义下的"表示函子"
  3. 处理算子丛/算子族的谱化问题
  4. 定义"弱三元组"（weak triple）：Rec/Sp/D 三元组部分存在的情况
- **依赖**：盲区 2 的 von Neumann 代数框架
- **交付物**：`KoopmanLiftingBlindSpot.lean` + 推广定义文档
