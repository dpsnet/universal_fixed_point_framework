# Phase 86：绝对流量守恒对账——Gaia 绝对 SED 标定与振子求和上限

## 1. 研究问题（Phase 85 的升级）

Phase 85（§4.7）已用形状代理（D_B/slope/归一化基底残差）建立连续谱守恒检验：slope 残差随 B 显著偏移（ρ=−0.350, p=0.001），量级约为线缺失的 15%（10–20kK 档 23%）。**遗留口实**：形状代理非绝对能量——评阅人仍可主张"连续谱被 4 阶多项式归一化抹掉抬升，46.9% 缺失是归一化伪影"（§4.7 res_b3 已部分证伪该主张，但未封死绝对流量）。

**本阶段目标**：把守恒检验从形状代理升级为**绝对能量对账**——
- 检验 A：Gaia DR3 视差 + G/Bp/Rp 测光 → 绝对 SED → 跳变区（λ<3646 Å）绝对吸收积分；
- 检验 B：强磁场氢原子束缚-连续跃迁振子求和理论上限（线翼窗口 ±80–320 Å 内连续谱注入 f 的积分上限）；
- 检验 C：守恒对账——绝对吸收增强能量 vs 46.9% 线缺失能量，判定残差方向与量级。

## 2. 判定矩阵（延续 §4.7 四路，新增绝对流量区分力）

| 结局 | 绝对流量观测 | 振子求和理论 | 判定 |
|:---|:---|:---|:---|
| **A1 传统胜出** | 跳变区绝对吸收增强 ≈ 线缺失能量（对账闭合） | 理论注入上限覆盖观测增强 | 拓扑禁戒在白矮星现象降级为等价描述；常规强场物理论文 |
| **B 等价翻译** | 增强部分闭合 + 线序模式（§4.3.3） | 传统工具独立推导出 46.9% | 两个框架收敛同一物理；拓扑禁戒获传统背书 |
| **C 传统失败** | 绝对吸收未增强（排除归一化伪影）且理论注入上限远低于缺失（>3σ） | 求和规则违反（Sum Rule Violation） | 硬异常确立；第三约束维度夯实 |

## 3. 检验设计

### 检验 A：Gaia 绝对 SED 标定（绝对流量对账）

- **标定链**：Gaia DR3 parallax → 距离 d；G/Bp/Rp 测光（及 GaiaXPy 合成通量）→ 绝对星等/绝对流量；DESI/SDSS 光谱零点交叉校准（合成测光 vs 光谱带通积分）；Koester 表面流量 F_surf（缓存，erg/cm²/s/Å）× (R/d)² → 模型地球处绝对流量——R 来自质量-半径（§4.2.5 口径），d 来自视差。
- **测量量**：跳变蓝端（3600–3640 Å）绝对流量观测 vs 模型，跳变绝对吸收深度 ΔF_abs（erg/cm²/s）；积分 → 缺失能量 E_abs。
- **对账**：E_abs（连续谱增强）vs E_line（46.9% 线缺失，§4.3.1 总 EW 残差 0.384 对应）——单位统一为等效振子强度/能量。
- **误差传播**：视差（近距白矮星一般 <5%）、Gaia 测光（~1–2%）、Teff/logg 表面流量（模型网格最近点）、红化（白矮星近距 E(B-V) 小，必要时 Gaia 视差/颜色约束）。

### 检验 B：振子求和理论上限（强场原子数据对账）

- 数据源：Zhao (2021, ApJS 254, 21) 23.5–2350 MG 截面（adiabatic-basis + coupled-channel）；A&A (2026, arXiv:2603.07679) RWA 图 3/4 数字（T=20000 K 吸收系数 vs λ，B=0.019–235 MG）；Fano 共振线型参数（n=2 态 Landau 能级底部浸入）。
- **计算**：B=10–100 MG（中场域），Balmer 线系 n=2 束缚-连续跃迁在 ±80–320 Å 线翼窗口内的振子注入积分 $\int \Delta f_{\mathrm{cont}} d\lambda$——即"传统可解释的连续谱注入上限"。
- **对账**：理论上限 vs 观测 slope 偏移（−0.042 dex）对应的等效注入；若观测 ≤ 上限 → A1 可解释；若观测 > 上限 → 超额（B/C）。

### 检验 C：守恒对账与阈值

- 对账方程：$E_{\mathrm{line}}^{\mathrm{missing}} = E_{\mathrm{cont}}^{\mathrm{enhance}} + E_{\mathrm{residual}}$；E_residual 归因于拓扑禁戒（B）或模型缺陷（C）。
- 阈值：E_residual/E_missing < 20% → A1 闭合；20–80% → B 中间态；>80% 且理论注入上限 < 20% → C 硬异常（求和规则违反）。

## 7. 风险与诚实边界

1. **Gaia Bp 低分辨率（~30 Å）**不能分辨 3646 Å 跳变细节——但 G 波段整体通量 + 蓝端光谱交叉可标定绝对零点；跳变深度仍由光谱测（S/N≈3 限制保留，诚实标注）
2. **视差精度**：近距白矮星一般 <5%，个别星（12/137 未解析）用坐标匹配；parallax_error 大者剔除或加权
3. **红化**：白矮星近距 E(B-V) 一般 <0.05；用 Gaia 视差/颜色约束，必要时施密特消光修正
4. **模型表面流量误差**：Koester 网格最近点（Teff/logg 步长）→ 传播进对账
5. **振子求和数据可用性**：Zhao 2021/RWA 数字表需下载/数字化——网络受限时登记为量级估算（RWA 已给出定性"substantial <10 MG"与方向）
6. **诚实原则**：若绝对流量标定误差 > 缺失量级（>10%），明确声明检验能力不足，不强行结论

**四路判定更新（R4b 后）**：
- **A1 传统解释：完整闭合候选**——RWA 全渠道预测的正是观测现象（吸收下降→流量增强），方向+带间分布+量级全部一致；"纯振子转移上限不足"仅指单一渠道，全渠道 RWA 定量支持 A1
- **C 求和规则违反：撤下**——全渠道上限不再悬置：传统框架预言中场连续谱吸收下降，观测增强与之一致——无硬异常
- **B 保持降级**——连续谱响应已由 A1（RWA）完整解释；但线缺失主体（79% 缺口）RWA 不涉及（RWA 处理连续谱，EW 缺失是线的问题）——B 作为线缺失的解释仍与 A1 竞争
- **缺口重定义**：连续谱响应（21%）已归 A1；线缺失剩余 79% 的归因 = B（拓扑禁戒）vs 线级机制（Zeeman 线拼接/Stark）——需线级建模区分
