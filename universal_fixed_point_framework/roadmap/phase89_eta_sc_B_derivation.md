## 2. 内生机制假设（待验证）

η_sc(B) 的"平段→陡升"应源于 **Landau 能量与库仑能量的交叉标度**：
- 弱场（B≪B*）：ħω_c ≪ 库仑能 |E_n|~1/n²——谱以库仑规则区为主，Landau 扰动小 → η_sc 低平
- 中场（B≈B*）：ħω_c ~ |E_n|——束缚态与 Landau 态混合、浸入连续谱底部——谱奇异化 → η_sc 陡升
- 强场（B≫B*）：Landau 主导——束缚态塌缩为 Landau 基态系（态数剧减）——η_sc 饱和或回落（谱趋于纯点+绝对连续）
- 相变点 B* 解析预估：ħω_c = |E_1| → B* ≈ (2E₁)²/(2m)·(2/ħe)·… 数值检验对照陡升区间（0.05–0.1 a.u.）
- Harper 映射：B<B* ↔ λ<2（绝对连续）、B≈B* ↔ λ=2（临界/奇异连续）、B>B* ↔ λ>2（局域化）——与 §3.2.3 第 3 条对应，需定量化

## 4. 风险与边界

- 2D 重算口径：η_sc 从 D_q 多分形估计——论文未给 D_q→η_sc 公式——用报告数值（B=0.2 → D₂=0.752、η_sc=0.496）做校验锚点；若无法同口径复现，改用 IPR/态密度口径并诚实标注口径差异

- 3D 绝热近似有效性：中场（B~0.1-0.4 a.u.）Landau 能级间距 ~ 库仑能，绝热分离近似误差需评估——若不可靠，标注 2D 为"模型层面预言"，3D 为远期
- 抑制因子→线深连接：τ∝f·N_n 线性层近似（§7.1 已用同假设）；严格需模型大气集成（已登记遗留项）——对照为"量级+斜率形态"而非绝对 EW 预言
