## 一、战略定位

### 为什么这个推广重要

谱丛理论目前是 Kerr QNM 的"专有几何解释"。但推广分析揭示了一个更深层的事实：**任何以连分数形式出现的物理响应函数，都等价于一个三对角谱丛**。这意味着：

- **Leaver 连续分数法的全部谱丛工具**（§4 剪枝算法、§3 单值群分析、§6 分支点预警）可跨领域迁移
- **数值互惠**：引力 QNM 的谱丛剪枝可加速流变学参数反演；NRG 的 Wilson 链经验可反哺高自旋 QNM 的截断策略
- **理论统一**：三类看似无关的"非物理解"问题（非物理根、非物理弛豫模、非物理谱权重）是同一几何现象（谱叶间跳跃）的不同物理表现

### 推广优先级

**验证结果**（2026-07-25）：

| 测试 | 验证内容 | 结果 |
|:---:|:--------|:----:|
| T1 | Mori 连分数参数合理性 (Δ_n 衰减, γ_n 正定) | ✓ |
| T2 | 三对角谱丛矩阵结构 (对称、带宽、虚数 off-diagonal) | ✓ |
| T3 | 连分数 vs 三对角矩阵求逆交叉验证 (偏差 < 1e-10) | ✓ |

| T5 | 光导率 Kramers-Kronig 一致性 | ✓ |
| T6 | det(A_M)=0 分支点定位 (6 个实轴投影点) | ✓ |
| T7 | 条件数与谱叶 CV 联合分析 | ✓ |
| T8 | 三系统 (rheo/NRG/mem) 结构统一性验证 | ✓ |

**关键设计**：
- 三对角矩阵 off-diagonal 使用纯虚数 $i\Delta_n$（非实 $\Delta_n$），保证与 Mori 连分数"+"约定一致
- 当 $b_n = i\Delta_n$ 时，Jacobi 矩阵公式 $[A^{-1}]_{11} = 1/(a_1 - b_1^2/(a_2 - b_2^2/(...)))$ 中 $-b_n^2 = +\Delta_n^2$，自然匹配 $M(\omega) = \Delta_1^2/(i\omega+\gamma_1 + \Delta_2^2/(...))$
- 行列式递推相应使用 $d_n = a_n d_{n-1} + \Delta_n^2 d_{n-2}$（+号），匹配 $(i\Delta)^2 = -\Delta^2$ 的符号效应

**分支结构观测**：
- 小阻尼小体系 (N=6)：det(A)=0 在实轴上找到 6 个分支点投影 (±0.159, ±0.576, ±1.123)
- 条件数尖峰方法在该体系灵敏度有限（κ_max=12.1 远低于 10×中位数阈值），因 γ 阻尼使矩阵远离真正奇异
- CV 方法在分支点投影处有局部极大值（最大 CV=4.8×10⁻³），与 det(A)=0 定性一致
- 经验规律：体系阻尼越大，分支点投影的数值可检测性越低（适合大 N 低阻尼体系）
