## 核心假说（H78）

**假说 H78**：符号判据场（块和符号配置 → A 符号）是部分共线配置流形上的**层（sheaf）**——即：
1. **胞腔结构**：部分共线配置 = 块相等约束的胞腔分解（蜂窝）——胞腔 = 块和符号配置（有向图/复形节点）
2. **符号场单值性**：同一胞腔（同一块和符号模式）→ 唯一 A 符号（除跨 seed 稀有冲突 = 层奇异点）
3. **退化区 = 孔洞**：A=0 区域 = 流形上的零值胞腔簇（多孔）
4. **翻转 = 层过渡**：符号翻转 = 跨胞腔边界的层转移（S3/S4 静默挂靠）
