# Phase 88：Kepler 独立目录线级交叉验证（跨仪器确认 B）

## 0. 目标

Paper 48 §4.9 的 B（拓扑禁戒）判定基于 **DESI 单一仪器**（8–25 kK：弱 59/中 16）。本阶段用 **Kepler+ 2013 目录（M83d）**——独立目录 + 独立仪器（SDSS 光谱）——对"线变浅不变宽"做**跨仪器交叉验证**：若 Kepler 样本也显示深度随 B 下降、线宽相对模型不变/变窄 → B 判定升级为"双仪器独立确认"；若不一致 → 仪器混杂调查。

## 1. 事实基础

- Kepler+ 2013 全表 539 颗（B 1–773 MG），10–300 MG 域候选 60 颗（全采，无选择）、**32 颗有效**（B 10–105 MG，Teff 8000–40000 K）——EW 层面已确认负梯度 ρ=−0.722（§4.4）
- 光谱源：SDSS（`v10.get_spec`，plate-mjd-fiber，无本地缓存，需重新下载 32 颗）
- SDSS 波长 3800–9200 Å：Hβ/Hγ/Hδ 全可测，Hε（3970）在蓝端边缘（SNR 低，视质量取舍）
- Koester 模型谱：fid 表已有（891 网格点），Kepler 星 Teff/logg 取目录值 → nearest 网格 → 缓存或下载
- 仪器差异：SDSS R~2000（σ_inst~1.6 Å @4861）vs DESI R~2500（σ_inst~1 Å）——**两目录各自用 R_sig（模型比值）口径，不直接合并 σ 绝对值**

## 3. 判据

- **B 预言（跨仪器复现）**：Kepler 中场 depth_pure 显著低于弱场对照、R_sig 不随 B 增（不变/变窄）
- **展宽机制预言**：σ 随 B 增——若 Kepler 也观测到 σ 增 → 与 DESI 相反 → 仪器混杂警告
- 弱场对照：Kepler 目录自身 <10 MG 星（若可测）+ DESI 弱场 59 颗（跨目录对照，仅方向性对比）

## 4. 风险与边界

- SDSS 蓝端 SNR 低于 DESI——弱线（Hδ 以上）可能无法线级拟合（登记 n_lines 分布）
- 仪器 σ 不同：σ 绝对值不可跨目录比较；只用 R_sig（模型比值，各自口径）
- 样本量：32 颗中预计线级有效 15–25 颗（弱场+中场分档需平衡）——若中场有效 <8 颗，判据改为"方向一致性"而非"统计独立确认"
- 诚实边界：若 Kepler 有效样本不足，如实标注"跨仪器方向性支持，统计独立确认留待更大样本"

## 7. 状态与结果（2026-10-08）

- [x] M88-1/2：Kepler 32 有效 → SDSS 光谱下载 + 线级测量 → **26 颗中场有效**（B 10–53 MG；目录内弱场仅 1 颗——Kepler 为强场补充目录，弱场对照缺失）
- [x] M88-3 回归与跨目录对比（结果）：
  - **跨目录复现**：Kepler mid 纯线深 0.066±0.051 vs DESI weak 0.128±0.078——**缺失 −49%（t=−3.13, p=0.003）**；与 DESI mid（0.047±0.041）同量级（t=3.01）——"中场线浅"跨仪器（SDSS/DESI）独立复现
  - **场内梯度不显著**（Kepler 26 颗 B 10–53 MG 窄范围）：depth_pure β=−0.066 t=−0.99；σ β=−1.0 t=−0.6；R_sig β=−0.075 t=−0.28——与 DESI 同构（显著性由"中场 vs 弱场"跨组对比驱动，非场内连续梯度）
  - **无增宽证据**：场内 σ 梯度不显著、R_sig 为负——展宽预言（10→53 MG σ 应显著增）不成立
- [x] M88-4 落盘：Paper 48 v0.17（§4.9 交叉验证段 + 结论第 8 条 + 变更记录）

## 8. 判定

- **B（拓扑禁戒）获独立目录+独立仪器量级复现**：Kepler 2013（SDSS）中场线深相对弱场对照缺失 −49%，与 DESI（−63%）同量级同方向；无展宽证据（σ/R_sig 不增）
- **诚实分级**：跨仪器"方向 + 量级复现"= 支持性证据；独立统计确认仍以 DESI 内部对比（n=75，t=−6.5）为主——Kepler 弱场对照缺失 + 场内 B 范围窄（10–53 MG）限制其独立性
- 遗留：Kepler 目录 <10 MG 星（448 颗）可作为未来弱场对照扩容源（EW 层面已排除域外——需另采样）；高分辨分量级终审（远期）
