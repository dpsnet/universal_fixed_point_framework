## 1. 目标

§7.6 第 5 项（反常发射线系统研究 + NMLO 定量拟合）深化，两条腿：
1. **发射翻转发生率量化**：系统性扫描全部 518 样本（非仅 3 颗标记星）的 Balmer 负 EW——发射翻转是孤例还是中场/强场普遍现象
2. **η_sc(n) 量子标度（第一性原理）**：用 §3.2.4 氢原子模型逐主量子数 n 计算束缚态衰减——检验 NMLO 拟合参数 `|EW_n|=A_s n^m`（m=3.39）是否有量子数值支持

## 2. 判据

- 发射翻转发生率：弱场 0%（预期，验证无系统伪影）vs 中场/强场显著 >0 → 发射翻转是场强相关现象
- η_sc(n)：高阶 n 束缚态衰减更快（n 高 → 束缚能小 → 更易 Landau 化）→ η_sc(n) 单调增 → 支撑 m>0 线序标度；若量子 m 与观测 m=3.39 同量级 → NMLO 拟合获第一性原理支持

## 4. 诚实边界（预设）

- 负 EW 可能含噪声/邻线污染（Hδ 邻线）——扫描需 SNR 门槛 + 多线一致判据
- η_sc(n) 量子标度若与观测 m 不同量级 → 发射增强机制需另寻（布居泵浦/荧光）——登记为开放项，不强行调和
- 3 颗发射星样本量小——发生率结论限定"场强相关现象"范围
