# Phase 74：Zeeman 截断窗口扫描实测排除（Paper 48 口实闭合）

> 状态：**已完成（2026-10-07）** | 创建：2026-10-07 | 主线归属：Paper 48（拓扑禁戒频率观测验证）
> 目标：将 §4.4/§4.5 中"高场 Zeeman 分裂超出 80 Å 测量窗口导致 EW 截断、斜率陡化可能部分反映截断"的诚实标注，升级为**窗口扫描实测检验**——若扩展窗口后斜率 β(W) 收敛到 0，则截断有贡献；若保持显著负，则截断不解释梯度（实测排除）。

## 0. 背景与动机

- Paper 48 诚实边界（M83d/M83e 原文）："强场斜率陡化可能部分反映 Zeeman 分裂超出 80 Å 测量窗口的非对称截断（理论与观测同窗口，但归一化基线对分裂形态敏感）"。
- 用户提问："高场 Zeeman 截断的情况能否通过扩展观测窗口来覆盖分析"——即窗口扫描检验。
- 物理预期：弱场星分裂 ≪ 线宽 → EW 随窗口不变（对照基线）；高场星（B>50 MG）分裂达 50–100+ Å → W=80 截断 → EW 应随窗口明显恢复；若截断主导梯度，β(W) 应向 0 收敛。

## 1. 方法与步骤（全部复用已缓存数据 + SDSS 重取）

### R1 窗口设计（2026-10-07，完成）
- 窗口集 W = {80, 160, 320} Å（对数步进）。
- **half-gap 保护**：每线窗口受"到最近相邻 Balmer 线半距 − 1 Å"截断——Hα 850 / Hβ 260 / Hγ 119 / Hδ 66 / Hε 66 / Hζ 40 / Hη 27——消除相邻线翼重叠污染（Hδ/Hε 间距仅 132 Å）。
- 理论 EW 同窗口重算（Koester 无磁场谱扩展窗口 EW 变化很小——残差变化主要由观测侧驱动，机制清晰）。
- 口径：与已发布 v0.7 完全同源（v10.normalize + v10.measure_ew 参数化 window；检测 ew>0.5 且 depth>0.03）。

### R2 DESI 91 颗多窗口（完成，零新下载）
- 输入：`_desi_spec/{gaia_int}.npz`（116 颗全波长缓存）→ 49 颗有效残差（同 v0.7 样本）。
- 回归（protect）：W=80: log10B=-0.468 (t=-9.55) ρ=-0.735 p=1.9e-9；W=160: -0.406 (t=-8.77) ρ=-0.708 p=1.2e-8；W=320: -0.445 (t=-9.17) ρ=-0.759 p=2.7e-10。
- 逐星窗口效应：B<10 MG 70 颗 EW(320) 相对 80 中位 −3.1%（对照基线近不变）；B=51 MG +20.4%、B=172 MG +63.5%（高场 EW 确实随窗口恢复）；B=211 MG −56%（分裂形态 × 归一化基线交互，个体异常）。
- **尽管高场 EW 恢复，斜率不消失**。

### R3 Kepler 32 颗多窗口（完成，SDSS 重取）
- 输入：M83d 有效 32 颗（B 14–212 MG，Sp-ID → SDSS.get_spectra，astroquery 重取，34/34 成功）→ 32 颗有效残差。
- 回归（protect）：W=80: log10B=-1.343 (t=-4.08) ρ=-0.702 p=7.4e-6；W=160: -1.431 (t=-4.10) ρ=-0.713；W=320: -1.440 (t=-4.11) ρ=-0.709——**中场/强场段斜率窗口扩展后完全稳定**。
- 高场星明细：B=53 MG 仅 Hε/Hζ 检测（tew=21.7 全窗口恒定）；B=105 MG 仅 Hη 1.92 恒定；B=212 MG 无检测（tew=0）——**Zeeman 展宽确实存在且严重**（高场星大部分 Balmer 线无法单峰检测），但全样本梯度不受影响。

### R4 合并 81 颗统一回归（完成）
- DESI 49 + Kepler 32 = 81，统一"每星最近网格点 Koester 谱 + 同窗口 EW"口径，目录固定效应 + 目录×log10B 交互：
  - W=80: log10B=-0.507 (t=-5.71) ρ=-0.513 p=9.8e-7；Kepler×B=-0.936 (t=-3.89)
  - W=160: log10B=-0.442 (t=-4.78) ρ=-0.440 p=4.0e-5；Kepler×B=-1.080 (t=-4.32)
  - W=320: log10B=-0.484 (t=-5.17) ρ=-0.379 p=4.8e-4；Kepler×B=-1.055 (t=-4.17)
- **判定：斜率完全不收敛到 0；强场端交互稳定 ≈-1.0；截断不解释 B-残差负梯度——实测排除。**

### R5 落盘（本文件 + Paper 48 v0.8 + 变更记录）

## 2. 结论与诚实边界

- **结论**：窗口扩展（80→160→320 Å）后，B-残差负梯度在 DESI（p<1e-8）、Kepler（p<1e-5）、合并 81 颗（p<5e-4）三层次全部保持显著；强场端斜率（Kepler 交互）稳定 ≈-1.0 不减。Zeeman 截断作为"斜率陡化的替代解释"被实测排除，方向性结论（高 B → 观测 EW 系统性低于理论）获窗口鲁棒性验证。
- **保留边界**：(1) B=211/212 MG 个体星 EW 受分裂形态×归一化交互影响大（单星残差不确定度升高，方向性结论不依赖单星）；(2) 窗口上限受相邻 Balmer 线距物理限制（Hδ/Hε 66 Å），"无限扩展窗口"不可行；(3) 高场星（>100 MG）有效检测线数少（1–2 线），统计功率受限——样本层面结论稳健，个体层面需 Zeeman 多分量拟合（Paper 48 §7.6 第 4 项，未来工作）。
- **遗留**：Zeeman 多分量拟合（非单峰积分）仍是高场端最终解——窗口扫描已排除"截断假说"，拟合则消除个体残差不确定度。
