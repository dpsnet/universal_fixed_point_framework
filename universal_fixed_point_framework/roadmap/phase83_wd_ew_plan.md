**定位**：MUFPF 的独立可检验预言（拓扑禁戒 → 磁场白矮星 Balmer 线 EW 系统性缺失——B-残差梯度）。数据线受网络/模型大气网格限制——方法论先行。

**⚠ 核心混淆（必须先排除）**：强磁场 Balmer 线 **Zeeman 分裂**（π/σ 分量展宽）天然压低单线 EW 测量值——**B-残差梯度可能是 Zeeman 伪影而非拓扑禁戒**。另有 Teff/log g 不匹配（theo_ew 为粗糙多项式近似——非真实模型大气）。

## M83a-1：Zeeman 混叠排除（首要——决定结果可信度）

- **A 路径（无分裂线检验）**：只用 Zeeman 不分裂的谱线特征（如磁场 <10kG 的非 Balmer 线、或弱场近似线）——若梯度仍现 → 非 Zeeman 伪影
- **B 路径（显式分裂修正）**：π/σ 三分量模型——已知 B、观测波长 → 计算 Zeeman 展宽 → 修正 EW 测量（EW_corr = EW_raw + ΔEW_Zeeman(B)）——梯度经修正后是否存活
- **C 路径（线系诊断）**：Hα/Hβ/Hγ 各线独立测 EW——Zeeman 分裂对 Hα（最大展宽）影响最强——若梯度仅 Hα 显著 → Zeeman 伪影；若全线一致 → 非 Zeeman
- **实施**：优先 C（零新数据依赖——现有光谱直接算）→ B（解析修正）→ A（需弱场高分辨率线——登记）

## M83a-2：Teff/log g 匹配对照（分离大气效应）

- 若匹配后梯度消失 → 大气/选择效应解释；若存活 → 场强特异性

## 推进记录

### M83a-1 ✅ Zeeman 线系诊断（2026-10-07，C 路径——现有数据）

**逐线 B 相关（detected 口径，Spearman）**：Hα rho=-0.203(p=8e-3)、Hβ -0.238(p=1e-2)、Hγ -0.248(p=1e-2)、**Hδ -0.368(p=2e-4)**、Hε -0.265(p=8e-3)——五线全负相关。

**Zeeman 伪影判据**：Zeeman 分裂 Δλ ∝ λ²——Hα（最长波长）应受影响最大。**实际 Hα 最弱、Hδ（最短波长）最强——与 Zeeman 预期相反——B-残差梯度非 Zeeman 伪影**。

**含未检测线（EW=0 计入）补充**：梯度大幅减弱（Hα p=0.95、仅 Hδ/Hε 弱显著）——**detected 口径的梯度包含"强场检测率下降"成分**——星级口径（total_EW>0）梯度（rho=-0.301）与线级均匀抑制不完全等价——机制需细化（检测率 + 已检测强度混合）。

### M83a-2 ✅ Teff/log g 控制检验（2026-10-07）

**多变量回归 resid ~ log10(B) + Teff + logg**：
- **beta(log10B) = -0.251 ± 0.065——t=-3.84——p=1.6e-4（独立显著）**
- beta(Teff) 显著（p=1.3e-3——大气独立贡献——模型大气升级会改进）
- beta(logg) 不显著（p=0.86）

**Teff 分档内 B 梯度**：<12kK rho=-0.342(p=1.3e-3)、12-20kK -0.279(p=4.5e-3)、>20kK -0.322(p=2.4e-2)——**三档全显著**。

**log g 分档内**：全显著（p<0.03）。
**弱场内部（<1kT）**：rho=-0.203, p=5.2e-3——**连续场强效应（低场端已存在）**。

**结论**：B-残差梯度**非 Teff/log g 选择效应伪影**——控制后独立显著；Zeeman 伪影基本排除（波长反序）；弱场内部连续梯度支持连续物理效应。

**剩余混淆（诚实登记）**：① theo_ew 为粗糙多项式近似（模型大气 TLUSTY/Koester 网格升级后复核）；② Zeeman 分裂未显式修正（B 路径待做）；③ 磁场样本的恒星演化/化学选择效应；④ S/N 效应（强场光谱质量）。

### M83a-3 ✅ 稳健性分析（2026-10-07）

**结果**：
- 置换检验（B 洗牌 10000 次）：p<1e-4（效应非随机——无一次达原始 rho=-0.301）
- 删极端 5%（B 和 R）：rho=-0.212, p=3.1e-3（仍显著）
- 删极端 10%：rho=-0.094, p=0.24（**秩相关不显著——尾部驱动**）
- 分档删极端后梯度保持：<1kT -0.241、1-3kT -0.361、3-10kT -0.767、10-100kT -0.505

**解读（诚实口径）**：① 效应真实（置换 p<1e-4）；② **分档中心趋势梯度稳健**（删极端后梯度保持）；③ **秩相关显著主要由尾部驱动**（删 10% 后 p=0.24——效应集中在大场强端）——表述修正：非"全 B 均匀梯度"，而是"场强极端端效应最强 + 分档中心梯度存在"。

**对 P83 推进**：统计口径需双轨报告（分档均值 + 秩相关）——模型大气升级后效应形态需复核。
