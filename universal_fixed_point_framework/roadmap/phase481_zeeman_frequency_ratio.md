## 2. 理论基准线（已立，标准量子力学，无框架特异性）

一阶 Zeeman 分裂（MNRAS 485, 5050 §3.1，Aggarwal et al. 2017）：

- 频率位移：ΔE_ik(n) = μ_B (g_i·m_i − g_k·m_k)，选择定则 m_i − m_k = 0, ±1
- 分量波长：λ_n = (1/λ₀ + ΔE_ik(n)/10⁸)⁻¹
- Landé 因子：g = 1 + [J(J+1)−L(L+1)+S(S+1)]/[2J(J+1)]（L-S 耦合）

**核心结构**：g、m 均为（半）整数量子数 → 各分量频率位移 = 有理数 × μ_B B/h → **同一谱线全部分量频率比 = 量子数决定的精确有理数，与 B 无关**。

偏离源（使频率比偏离有理结构）：
1. **二次 Zeeman 效应**（∝B²，>100 MG 显著；J135141 500–773 MG 恰在显著区）
2. 禁戒分量（高场选择定则放宽，Phase 100 拓扑禁戒理论相关）
3. 抗磁项、QED 微扰（可忽略级）

## 4. 检验设计

**A 级（基线验证）**：实测各分量频率比 vs 标准有理预言（量子数计算）——吻合 = 标准 Zeeman 确认 + B 测量交叉校验（无框架特异性，但建立频率比提取管线）。

**B 级（框架对照，预注册候选）**：频率比偏离标准有理值的**残差结构**（二次 Zeeman 修正主导）——残差比值是否落框架量族（M12 框架量比、扩展素域分数族，协议 v1.0 口径）：
- 预注册 → 命中 = 预注册命中（强证据，通道③）
- 事后发现 → 候选（弱证据，通道②）

**C 级（禁止项）**：不以残差小整数/简单有理命中为证据（标准二次 Zeeman 本身产生有理近似结构——无框架特异性）；须偏离质量与数量级分离（证据通道④）。

## 5. 判定协议

- 数据到达后：提取分量频率 → 比 A 级有理预言（残差 = 二次修正）→ 残差结构对框架量族。

### 预注册判据

1. **π 分量 = 纯二次 Zeeman 探针**：一阶位移 ≡0（教科书），完整位移 ∝B²（20-300 MG 实测指数 1.93-2.0 ✓）。判据：实测 π 位移指数须 ∈[1.9, 2.1] 且 ≤300 MG 无变号。
2. **σ 分量残差比 r_σ(B) ∝ B**（20-200 MG）：斜率 A(B)=r/γ 从 1.43 单调降至 1.24（三次项污染）。判据：实测 r_σ(B) 若在 ≤200 MG 偏离 A·γ 线性 ≥3σ（按实测精度）→ 框架签名候选；若全符合 → 标准 QM 无异常（B 级判"无框架签名"）。
3. **300 MG 变号 = 跨带耦合**（非微扰起点）：>300 MG 一律禁用"残差比"作判据，只对照分量谱型（24 分量）。

### 结论与下一步

- **B 级初检主数据不在 NADC**；NADC 可补目标清单扩展（LAMOST WD 星表已下载至 obs_data/）。
- 执行管线（FITS 到手后）：蓝/红窗谱 → σ 一阶 → ⟨|B|⟩ 当场定标（判据①可行性由实测裁决）→ Hβ π 定位（≤~125 MG 窗内余量 ~13 MG）→ π 位移指数 vs 预注册 [1.8, 2.1]（Hβ 2.005±0.01）。
- 获取方式（Web 通道已排除后更新）：**C1 ING 档案正式请求（邮件）**——官方政策渠道（联系 jma@ing.iac.es，附项目号 P10 19A / P8 19B + 目标 + 三夜曝光清单含 2018-09-23）；**C2 论文通讯作者索取**（stefano.bagnulo@armagh.ac.uk，Open Access 论文，通常可提供降谱，最快路径）；**D 备选**：Fig.B.15 数字化 A 级锚（已落盘 obs_data\g227_fig_G227var_p1.png）。邮件草稿（已含 2018-09-23 补登）：roadmap\phase481_email_C1_ING.md / phase481_email_C2_Bagnulo.md。
- **外部资料证伪记录（2026-10-22）**：用户转来一份"SDSS/SIMBAD/VizieR 获取 G227-35 光谱"指引材料，声称 G227-35 已被 SDSS 收录光谱。实测证伪：① SDSS DR18 Explore 在精确坐标（277.5855, +54.7909）返回 **"object does not exist / does not have SDSS imaging"**——该天区无 SDSS 成像、更无光谱（与蒙特利尔库"无 SDSS 谱记录"一致）；② 即便存在，SDSS R≈1800-2200 与 LAMOST 同级，测不了 π 分量；③ 材料中的 astroquery 脚本为通用样板，无对象针对性；④ VizieR 现处 Anubis 反爬 PoW 拦截，自动化取表不可行；P&J 1995 / Angel 1975 只发表谱图、无开放 ASCII 流强表（其谱图即已数字化的 Fig. B.15 来源）；Greenstein 1990（ApJ 360, 662）为 CCD 测光论文、无谱线轮廓、对 π 位移无用。**结论：材料不改变 C1/C2 主路径，不追加任何新渠道。**
