## 1. 目标

将数值验证推广到**三维氢原子**（圆柱坐标，含 z 连续自由度）：
1. **3D η_sc(B) 束缚态衰减曲线**——与 2D 曲线对照（验证 2D 截断的 η_sc 是否稳健）
2. **奇异连续谱直接检测**——z 方向连续自由度提供真实连续谱舞台（Landau 带×库仑势混合）——IPR 盒子标度 D2 谱维数

## 2. 模型

3D 圆柱坐标（m 固定，Landau 规范）：
$$H = -\frac{1}{2r}\frac{\partial}{\partial r}\left(r\frac{\partial}{\partial r}\right) - \frac12\frac{\partial^2}{\partial z^2} + \frac{(m+Br^2/2)^2}{2r^2} - \frac{1}{\sqrt{r^2+z^2}}$$

- 径向：半偏移网格（同 2D，j+0.5 dr）+ 离心/Landau 项
- z：均匀网格 z_k∈[-Lz/2, Lz/2]，3 点差分
- 库仑：-1/√(r²+z²)
- 稀疏矩阵：Kronecker 和 + 对角势；eigsh shift-invert

## 4. 判据

- 3D η_sc 与 2D 同量级 → 2D 截断 η_sc 稳健（束缚态衰减是维数无关效应）
- 3D 正能态 0<D2<2 → **奇异连续谱实在性确认**（3D 舞台）——§3.2 机制获直接证据
- D2=0 局域化 → 奇异连续谱仍不可测（登记方法边界）
