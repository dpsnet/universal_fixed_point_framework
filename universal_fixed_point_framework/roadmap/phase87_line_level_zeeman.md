# Phase 87 线级建模：B（拓扑禁戒）vs 线级机制（Zeeman 分裂/展宽）——79% 线缺失归因决战

## 0. 背景与动机（承接 Phase 86 R4b）

- Phase 86 R4b（RWA 全渠道）已把连续谱响应（≈线缺失 21%）完整归于 A1 传统解释（吸收下降→流量增强）
- **遗留缺口重定义**：线缺失主体（79%，0.217 dex）的归因 = **B（拓扑禁戒）** vs **线级机制**（Zeeman 线分裂/展宽/检测阈值效应）
- 本 Phase 目标：用中场 DESI 谱的**线轮廓定量建模**区分二者——可证伪判据，非口舌之争

## 1. 判据设计（核心，可证伪）

| 机制 | 预言 | 可测指标 |
|---|---|---|
| **线级：Zeeman 展宽** | 线半宽 σ 随 B 增大（Δλ_Z ∝ λ²B）；EW 展宽守恒（缺失只来自窗口截断/检测阈值——Phase 74 窗口扫描已排除截断） | σ(B) 斜率 > 0；depth 基本不变 |
| **线级：检测阈值** | 高序线弱→低于检测线→n_det 减少、EW 缺失集中于弱线 | n_det(B) 下降；缺失集中于 Hε/Hζ |
| **B：拓扑禁戒** | 线深度随 B 减小而**宽度不变**（单位宽度变浅=辐射通道关闭）；σ(B) 平或负 | σ(B) 斜率 ≈ 0 且 depth(B) 斜率 < 0 |

**判定**：
- σ(B) > 0 显著 → 线级展宽成立（B 降级，79% 归线级）
- σ(B) ≈ 0/负 + depth(B) < 0 → B 成立（线级机制排除，拓扑禁戒坐实）
- 混合 → 分线序看：低序线（Hβ/Hγ）σ 平 + 高序线（Hε/Hζ）缺失 → 双机制并存（B 主打高序、线级仅贡献检测）

## 2. 技术方案

- 数据：DESI 91 ok 星（`_m83e_desi_ew.json`），10–20kK 主档（弱场 n=45 vs 中场 n=11，与 Phase 86 同批）
- 线系：Hβ 4861 / Hγ 4340 / Hδ 4102 / Hε 3970 / Hζ 3889（DESI 3600–5800 覆盖；Hα 6563 不可见）
- 连续谱归一化：复用 v10.py normalize 口径（局部线性/多项式，线翼 ±60 Å 外锚点）
- 轮廓拟合（每星每线）：
  - **模型 A（零场单高斯）**：F(λ) = 1 − d·exp(−(λ−λ₀)²/2σ²)，拟合 {d, σ, λ₀}
  - **模型 B（Zeeman 三分量）**：π 分量（λ₀，权重 w_π）+ 2 个 σ 分量（λ₀±Δλ_Z，权重 w_σ），Δλ_Z = 4.67e-13·λ²·B·g_eff（正常 Zeeman g_eff≈1）；拟合 {w_π, w_σ, σ, λ₀}
  - 比较：Δχ²（A vs B）；B 的分量权重 vs 理论 π:σ=1:2（平均场球）
- 回归：σ 与 depth 对 log10B（中心化 OLS，Teff 控制同 Phase 85/86 口径）；bootstrap 5000
- 输出：`paperX_wd_linelevel.json`（逐星逐线 σ/depth/χ²）+ 回归表 + 判定

## 8. 判定（2026-10-07 初版 → 2026-10-08 扩容强化）

**核心结果**（DESI 主档 10–20 kK：弱场 n=45 vs 中场 n=11；模型谱子集 n=35）：

| 判据 | 结果 | 统计 |
|---|---|---|
| depth(B) 线心深度斜率 | **β=−0.272 dex/decade** | t=−7.48，p<0.0001，CI(−0.327, −0.209) |
| depth 分组中位 | weak 0.419 → mid 0.198（**−52.9%**） | 深度减半 |
| R_sig = log10(σ_obs/σ_mod) ~ B | **β=−0.41** | t=−2.43，p=0.021，CI(−1.01, −0.03) 不含 0 |
| R_sig 分组 | weak 0.000 → mid −0.631 dex | 观测线宽相对模型**变窄** |
| 分线序 depth | Hβ −60% / Hγ −45% / Hδ −73% | 全线序深度下降 |
| EW vs depth 缺失 | EW −46.9% ≈ depth −52.9% | 缺失≈线深变浅，宽度效应小 |

**扩容强化（2026-10-08，主档放宽 8–25 kK）**：

| 判据 | 扩容版（弱 59 / 中 16） | 统计 |
|---|---|---|
| depth_pure(B) 纯线深 | **β=−0.138** | **t=−6.49**，p<0.0001（中场 −63%）；含背景对照 −52.6%——非背景伪影 |
| **Teff 双档交叉验证** | 8–16kK：−79%（t=−5.2）｜16–25kK：−48%（t=−2.8） | **两档均显著——排除 Teff 混杂** |
| R_sig | β=−0.54 | t=−4.53，p<0.0001（**Koester 补齐后模型子集全量 n=62**，中 16） |
| 分线序纯线深 | Hβ −45% / Hγ −84% / Hδ **−98%** | 高序线几乎消失——禁戒特征 |

**判定**：
- **B（拓扑禁戒）：成立（扩容强化）**——中场 Balmer 线"变浅不变宽"（深度显著降 + 相对模型 σ 不变/变窄）——辐射通道部分关闭特征，与 MUFPF 拓扑禁戒预言一致；新样本（含强中场 40.9–51.0 MG）下 t 从 −7.5 升至 −8.9，双 Teff 档独立确认
- **线级 Zeeman 展宽机制：排除**——展宽预言 σ 增 depth 不变，实测相反（R_sig 负）；Zeeman 分裂（Δλ~0.1–1.1 Å）远小于 DESI 仪器 σ（~1 Å），卷积展宽若存在必使 σ_obs 增——未观测到
- **79% 线缺失缺口归因：B 主因确立（扩容加固）**

**诚实边界**：
- weak 组拟合 σ 大量撞物理上限 3 Å（censored）→ σ 绝对值不可信；R_sig 比值口径干净（weak=0.000 校验通过）
- FWHM 半高直测全 nan（跳变曲率下翼区未低于半高）→ EW 分解用总缺失 vs depth 缺失近似（46.9% vs 52.9%）
- 模型谱子集中场仅 6 颗（Koester 缓存缺口 5/11）——R_sig 基于小样本，效应大但需扩容复核
- 低分辨率（R~2500）下 Zeeman 分量不可分辨——"不变宽"为卷积层面结论；高分辨（VLT/Keck）可做分量级终审
