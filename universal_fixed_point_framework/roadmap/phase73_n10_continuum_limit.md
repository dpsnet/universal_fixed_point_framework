# Phase 73：n=10 极限边界 · 连续量依赖机制

**锚定主线（防追丢）**：将 n=10 极限边界（4 个跨集冲突模式、符号基座内跨集一致性不可闭合）从数值事实升级为**解析机制**（找到模式外连续量依赖形式），或确认为**非结构性边界噪声**。两者都产出落盘结论，不扩展旁支（静默层几何、Bott 塔封闭形式、判定表完备性证明均挂起）。

**上游事实（Phase 72 收官）**：
- 49 因子基座（46 尾部 + 3 头部补）主样本 40000 闭合（38801 模式、0 非决定、判定表导出）
- 2×15000 独立复核（seed 77/211）暴露 **4 冲突模式**：主表值 {0,0,0,−1} vs 独立值 {−1,−1,+1,0}，频次全 =1（跨 70000 样本密度 ~1/70000）
- 诊断判据单样本退化：候选 ~100 因子全盖 4 模式 → s1_2 假候选（补入后冲突同批保留）
- **数据缺口**：diag_violations.json 未存 4 冲突模式的因子投影向量（只存值/频次/seed）——定向采样前置

## M1 冲突模式投影捕获（前置，~10–30 min）

- 重跑 seed 77 / seed 211 独立复核（verify2 逻辑），**捕获 4 冲突模式的完整 49 维因子投影 + 几何参数**
- 产物：`scripts/paperX_n10_conflict_vectors.json`（4 模式 × {投影, 主表值, 独立值, 采样几何}）
- 验证：投影计算与 diag_violations 主/独立值一致（同一模式 → 同一值）
- **回查锚**：投影捕获是 M2 定向采样的唯一入口，不得跳过
- 失败判据：重跑后 4 冲突模式不再出现（不可复现）→ 直接转 M4 结局 B（浮点噪声勘误）

## M2 定向重采样：固定投影 × 连续量扫描（~1–2h）

- 新脚本 `scripts/paperX_n10_targeted_sampling.py`：
  1. 对每个冲突模式，**固定 49 维符号投影**（在退化族扫描 gen_partial_collinear 家族中按投影筛选）
  2. 在该投影约束的几何流形内**变化连续参数**（ω、z̄、比例、退化极限方向），每模式 ≥10 万样本
  3. 统计 A_BG 分布（round 6 位）
- 成功判据：任一模式出现 ≥2 个 A_BG 值（主值 + 新值）→ **连续量依赖实证**（极限边界机制化入口）
- 失败判据：10 万级固定投影样本全部单值 → 冲突为跨集浮点/边界伪影 → 转 M4 结局 B
- **回查锚**：只回答"模式内是否多值"，不扩散到全模式空间

## M3 连续量依赖形式识别（~2–4h，仅 M2 实证多值时执行）

- 收集 (连续几何参数, A_BG) 配对，尝试解析拟合：
  - ω/z̄ 组合（如 |ω|²/|z̄|²、相位差）
  - 退化极限行为（半共线/全共线方向的渐近符号）
- 产物：依赖形式假设 + 数值验证（≥6 组随机残差 1e-8 全 0 标准）
- 成功 → M4 结局 A：连续量增强判据设计（符号基座 + 连续量函数因子）
- **回查锚**：拟合必须可复现、可证伪，禁止"形式同构"式强附会
