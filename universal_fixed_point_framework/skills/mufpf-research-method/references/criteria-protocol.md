# 判据体系完整规格（MUFPF 研究方法）

本文档是 generative_chain_map.md §10 判据协议区的操作规格。σ_dev 为命中唯一权威（用户裁决）。

## 1. P1：dev → dev/σ

命中判定用 dev/σ（dev 除以观测不确定度），非 dev%。

**四档判定**：

| σ 档 | 判定 | 例子 |
| --- | --- | --- |
| ≤0.5σ | 兼容无分辨力（观测精度粗，无法判别） | κΛ −0.003（Λ_QCD 0.14%）、m_t/m_b +0.12 |
| ≤3σ | 候选级 | g_p/2 −1.49、g_n/2 +1.66 |
| 3–5σ | 需解释的偏差 | — |
| >5σ | 真实偏差（排除） | α 路径 B −1.7e6、1/α 137.028 σ_dev≫5 |

**表列三件套**：dev、σ_dev、不确定度来源。无不确定度来源的 σ 数不可信。

**算术放大陷阱**：小误差/大值可显示为表面高精度（如 m_p/m_e 合并闭式 dev 8e-10），必须用 σ 数穿透——8e-10 vs CODATA 1.6e-10 → 4.99σ 未达命中。

## 2. P2：状态五阶梯

⬜ 未溯源 → 🟡 拟合候选 → 🟢 链内唯一（已计搜索空间）→ 🔵 先验预言已确认 → ✅ 推导（机制+唯一+独立预言）。

- 唯一状态源：同一量在不同文档/表格的状态必须一致。
- 预注册判据转移：🟡→🟢 需协议下先验命中或用户裁决；事后唯一性（负控通过但未预注册）停于 🟡（如 44/23）。
- **当前证据下无物理常数达 ✅**（104az-200 裁定）。
- 状态标注过期是常见失效模式：发现旧 ✅ 与后登记冲突 → 立即勘误降级（如缺失率谱 ✅→🟡）。

## 3. P3：负控基线

每个 ✅/🟢 行必须附六元组：表达式语法、原子集、深度上限、候选总数、命中数、容差。

- decoy 假阳性率：≥10 个 decoy 目标（随机数、已知错误组合），报告命中数；全零为通过。
- 判别力阶梯：自由参数越少判别力越高（T1 单参 > T2 双参 > T3 四参灾难性——T3 基线命中率 41%）。
- 精度孤岛（1e-8 级精度在族内消失）是正向证据；域内 17 个更优 = 唯一性失败。

## 4. 预注册检验协议 v1.0

- 族定义（如平方型族）：(a²−b)/(c²−d)，a,c∈M12、b,d∈M12∪{1}，24336 组合。
- 去重后值域、容差（3σ 绝对）、判定（族内唯一）。
- 升级条件：协议下未来新量/新 CODATA 值先验命中，或负控 ≥10 decoy 全零。
- **发现顺序 ≠ 证据强度**：事后扫描出的身份，负控通过也只能"候选特征描述"，不升格。

## 5. 证据通道 v0.5（四条）

1. 代数闭合链（机器证明，T1–T6）——最强结构证据。
2. 跨链交叉锁定（同一因子跨扇区复用）——弱证据。
3. 预注册预言（数据前注册的命中）——强证据。
4. 命中质量数量级分离——需与族内次优差出数量级。

## 6. 等价改写 ≠ 独立确证

同一整数的多重身份（σ=1/15 六通道、231 三重同源、65 四身份）是等价改写，不累加置信度。判据区分：等价改写（0 证据）vs 跨扇区同一因子复用（弱）vs 未测观测量先验命中（强）。

## 7. 链溯源判据（观测精度不足时）

Λ_QCD 0.14% 精度不支撑 σ_dev → 用链溯源（结构判据）：候选的独立生成链身份（如 231=S(8) + 全框架量素分解）唯一性排除 ±1 邻域竞争。此判据非观测确认，须注明。
