## 三、$d_H$ 相关预言的联动规则

P4、P6、P7 的数值均间接或直接依赖 $d_H$，构成**相关预言簇**。联动协议如下：

1. **公式形式冻结**：$\delta_{\text{CP}}^{\text{PMNS}} = (d_H/2)\pi$ 的函数形式不变；$d_H$ 的更新仅通过此公式传导。
2. **数值更新触发条件**：当任一实验（DUNE / Hyper-K / 中微子排序 / CMB-S4）以 $>3\sigma$ 给出与当前 $d_H=2.7095$ 不一致的约束时，启动联动更新。
3. **重新登记要求**：更新后的 P4/P6/P7 必须附带新的版本哈希、更新时间戳，并在 [RAP_勘误与立场声明.md](./RAP_勘误与立场声明.md) 中记录变更原因。
4. **证伪独立性**：即使 $d_H$ 更新，单个预言的证伪条件仍按表内列出的实验阈值执行；联动不削弱任何单项的证伪力。

## 四、各预言详细说明

### P2：IQHE 倾斜磁场跃迁（首选低成本测试）

- **物理背景**：量子霍尔体系在倾斜磁场下存在朗道能级交叉导致的态密度跃迁。
- **框架输入**：倾斜角临界值 $\theta_c = 75.6^\circ$ 来自 IFS 分形谱边界的标度关系。
- **推荐实验**：GaAs/AlGaAs 二维电子气，固定载流子浓度，改变面外/面内磁场比，测量纵向电阻率 $\rho_{xx}$ 的角依赖；寻找 $75.6^\circ$ 附近的非解析跃迁或标度行为改变。
- **证伪阈值**：在 1–3 年内，若系统倾角扫描至 $85^\circ$ 仍未观测到任何跃迁或标度指数突变，则视为证伪。

### P4：中微子质量排序

- **当前冻结值**：正序（Normal Ordering）。
- **证伪阈值**：DUNE（2028–2030）或 JUNO（2028 前后）以 $\geq 3\sigma$ 确定反序（Inverted Ordering）。
- **联动说明**：排序本身不直接含 $d_H$，但质量谱链 $m_i \propto c_i^{\alpha_\nu}$ 的标度解释与 $d_H$ 输入耦合。

### P5：无中微子双贝塔衰变有效质量

- **冻结区间**：$m_{\beta\beta} \in [0.6, 4.6]$ meV（正序假设下）。
- **证伪阈值**：nEXO / LEGEND 在 $>15$ meV 发现信号（远高于正序上限）。
- **注意**：区间内发现信号不构成证伪，反而证实正序；只有超出区间上限才证伪框架的当前参数组合。

### P6：原初张标比

- **冻结值**：$r = 0.0042$。
- **证伪阈值**：LiteBIRD / CMB-S4 测得 $r > 0.01$（5$\sigma$）。
- **联动说明**：$r$ 的标度链含 $d_H$ 导出的能标比；若 $d_H$ 更新，$r$ 同步更新。

### P7：PMNS CP 破坏相角

- **冻结值**：$\delta_{\text{CP}}^{\text{PMNS}} = (2.7095/2)\pi = 4.256$ rad。
- **证伪阈值**：DUNE / Hyper-K 以 5$\sigma$ 排除 4.256 rad。
- **联动说明**：该预言是 $d_H$ 最直接的实验约束，优先级高于 P4/P6 的间接约束。
