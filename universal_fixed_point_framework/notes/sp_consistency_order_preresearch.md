## 1 数值网：48 例谱型扫描

> ⚠️ **2026-11-10 效力更正（见 §13.11）**：本节的 `kA`（贪心可达阶）用「随机右端 ∈ im」构造层 3/4，与 Lean `HigherSpCategory.lean` L354/L370 不符——Lean 规定层 k(≥3) 的 condition 右端**恒 ∈ `ker(d_A)`**（结构恒等式）。故本节的**层数分布**（`4→11 / 5→5 / 6→2`、口径 B 的 `8→22`）不可用作 Lean 塔高；**两相分离本身**（`ker∩im = 0` 与 `> 0` 判然有别）方向正确，予以保留。

### 1.1 模型

对 `SpObj` 对 `(X, Y)` 定义缺陷算子

```
d_A(H) := A_X · H − H · A_Y
```

按 `vec_col(H)` 矩阵化为

```
M = kron(I, A_X) − kron(A_Yᵀ, I) ,    d_A 的解 ⟺ M x = b 可解
```

- 层 2：自由（存在即可）；
- 层 3：需 `d_A h₃ = h_β − h_α`；
- 层 4 的两种读法：
  - **口径 A（共享）**：两个 3-态射共享同一对 `(α, β)`，故差值 `h_β − h_α` 必在 `ker(d_A)` 内 ⇒ 层 4 可解 ⟺ `ker∩im ≠ 0`；
  - **口径 B（可换）**：允许两个 3-态射各带不同的 `(α, β)`，差可含 `im` 分量 ⇒ 可解 ⟺ `rank(M) > 0`。

层推进用贪心递推，并在 `ker` 内随机调整 50 次，上限 8 层。

### 1.2 网格

16 种谱型 × 3 类对象对 = **48 例**。

谱型（`D` = 对角、`N` = 幂零单块、`U` = 单位+Jordan）：

```
D2 diag(1,2)（谱互异）  D2 diag(1,1)（谱相同）  D3  D4  D6  D8
N2  N3  N4  N6  N8      N4 J2⊕J2      N6 J2⊕J2⊕J2
U2 I+J2     U3 I+J3     D3 平移 c=0.5
```

对象对（`same` / `similar` = `P A P⁻¹` / `shift+10` = `A + 10I`）。

### 1.3 主结果：两相精确分离

判据 `ker∩im = 0` 把整张网切成两半，无一例越界：

| 相 | 例数 | 相容阶 kA（口径 A） | 分布 |
|---|---|---|---|
| `ker∩im = 0` | 30 | **恒为 3**（除 2 例 `d_A ≡ 0` 记 0） | 3 → 28，0 → 2 |
| `ker∩im > 0` | 18 | **恒 ≥ 4**，无一停在 3 | 4 → 11，5 → 5，6 → 2 |

- `ker∩im > 0` 的全部是幂零 Jordan 与非正规上三角：`J2, J3, J4, J6, J8, J2⊕J2, J2⊕J2⊕J2, I+J2, I+J3`；
- `ker∩im = 0` 的全部是可对角谱型。

### 1.4 关键发现：默认状态下连层 3 都不存在

「层 3 随机可解」列（随机给两条 2-态射，看差值是否落在 `im` 内）：

| 结果 | 例数 | 构成 |
|---|---|---|
| 成功 | **16/48** | **全部**为 `shift+10`（此时 `d_A` 双射、`ker = 0`） |
| 失败 | **32/48** | **全部**为 `ker ≠ 0` 的实例 |

即：**随机给出两条 2-态射，层 3 不存在。** 三层不是默认结构，而是逐层挑「右端 ∈ `im`」才搭出来的。这与 `27cdf8d` 中三行「模式：」注释（写了条件、从未验证存在这样的 `(α, β, Σ)`）完全吻合。

### 1.5 假阳性复核

`diag(1,1) similar` 一格原显示 OK，复核判定为**病态假阳性**：

```
max|M| = 6.938893903907228e-17      （数值上恒零）
σ_min  = 9.955822326600304e-17 ,  全部奇异值 [9.96e-17, 9.96e-17, 3.04e-17, 3.04e-17]
‖x‖    = 1.1185484420754446e+17    （荒谬量级）
resid  = 1.3077560134122365e-15    （残差看似通过）
```

本质是 `d_A ≡ 0`，按 fail 记。故成功数为 **16 而非 17**。对照：`diag(1,2) shift+10` 的 `cond = 1.22e0`，是正常良态。

### 1.6 口径分歧：层 4 是可解性问题，不是存在性问题

同一批实例换口径：

| 口径 | 8 | 4 | 5 | 6 |
|---|---|---|---|---|
| A（共享 `(α,β)`，差 ∈ `ker`） | — | 11 | 5 | 2 |
| B（允许更换 `(α,β)`） | **22** | 17 | 5 | 2 |

口径 B 下大量实例能一路到上限 8 层。结论：**「三层还是四层」不是数学事实，而是「允不允许换下层态射」这个定义选择的结果。** 这也解释了两件事：(a) `SpFourMorphism` 为何晚 17 天（`ffc2b56`）才补；(b) 补上后为何无人再算层 5——口径一松，层数就随口径走。

### 1.7 判决与候选命题

按事先写死的三条：

| 判别 | 结果 |
|---|---|
| `k* ≡ 3` 覆盖所有非退化谱型 | **不成立**（18 例反例） |
| `k* ≡ 3` 仅某一相成立、非正规相另有值 | **成立**，正是这一支 |
| `k*` 同类谱型内随元素变化 | 部分成立（`ker∩im > 0` 相内 4/5/6 有波动） |

候选命题（讨论稿形态，非定案）：

> 设 `d_A(H) = A_X H − H A_Y`。若 `Hom_Sp(X,Y) ≠ 0` 且 `ker(d_A) ∩ im(d_A) = 0`，则缺陷塔的相容阶恰为 3；若 `ker∩im ≠ 0`，则相容阶 ≥ 4（存在反例）。

### 1.8 边界（必须与结论同时引用）

1. 层 4 可行性判据（`ker∩im ≠ 0 ⟺ 可解`）是精确线性代数结果，可信。
2. 5/6 层数字来自「贪心 + `ker` 内随机调整 50 次」，是**搜索可达阶**，不是存在性证明，也不是上界。
3. `Hom_Sp` 非平凡性用 `dim ker(M)` 间接代表，未逐例验证 `P` 存在且非零。
4. 网格为 16 个代表谱型，`n ≤ 8`，非全参数空间。

### 1.9 D1 回填：18 个反例的可持续性（2026-11-10 已跑）

判据约定：`A` 为 Sp 侧谱算子（`μ` 侧），`U = exp(−A)` 为 Rec 侧迭代算子，故 `|λ(U)| = exp(−Re μ)`。可持续取「`U` 幂有界」，等价于「全谱 `Re μ ≥ 0` 且 `Re μ = 0` 部分几何重数 = 代数重数」；数值侧以 200 步迭代交叉验证，**理论判据与数值判据 48/48 一致**。

**第一版判据写错（把 `max Re μ ≤ 0` 当条件，符号反了），导致可对角化例全被判不可持续。下表为修正后结果。**

| 分组 | 例数 | 可持续情况 |
|---|---|---|
| `ker∩im > 0` | 18 | **两个对象都不可持续：14 例**；**两个对象都可持续：4 例** |
| `ker∩im = 0` | 30 | 两对象都可持续 23 例；含不可持续对象 7 例 |

- 14 例不可持续者：`J2/J3/J4/J6/J8`、`J2⊕J2`、`J2⊕J2⊕J2` 的 `same` 与 `similar`（`μ = 0` 且临界非半单）。数值发散量级：`N2` 2.0e2、`N3` 2.0e4、`N4` 1.334e6、`N6` 2.668e9、`N8` 2.543e12、`N4 J2⊕J2` 2.828e2、`N6 三块` 3.464e2，且 `max‖U^k‖ = ‖U²⁰⁰‖`（到末步仍在涨，未衰减）。
- **4 例两对象都可持续：`U2 I+J2` 的 `same`/`similar`、`U3 I+J3` 的 `same`/`similar`。** 其 `μ = 1`（严格收缩，不在虚轴上），`‖U²⁰⁰‖ ≈ 2.77e-83 ~ 2.77e-85`，幂有界成立；但 `ker∩im = 1/2 > 0`、相容阶 `kA = 4`。
- 7 例「`ker∩im = 0` 但对象不可持续」全部是 `N* / shift+10`：`A_X` 为幂零 Jordan（不可持续），`A_Y = A_X + 10I` 严格收缩（可持续），`d_A` 双射 ⇒ 塔恒 3。

**判定（重要）**：

1. 18 例中**并非全部**落在「不可持续」——`I+J2`、`I+J3` 共 4 例既可持续、又 `ker∩im > 0`。
2. 因此 **「可持续 ⟹ 相容阶 3」为假**。路线 A 的四步链不能简化为「可持续 ⟹ 3」，必须保留「**临界**」这一条（`I+J2` 有 `Re μ = 1 ≠ 0`，不属临界）。
3. 反向也不成立：相容阶 3 不要求对象可持续（`N* / shift+10` 的 7 例）。

§3.6 预告的严格收缩相张力，在 D1 中被数值坐实为 4 个具体实例。

## 2 若 3 成为条件定理：对理论的影响

### 2.1 总述

`N_active = 3` 从「定义」变「条件定理」：**可信度上升、内生性下降**。下降部分正落在 MUFPF 最核心的宣称上——「纯内生」。

### 2.2 变强三处

1. **第一次可证伪**：3 从「写下的构造子数」变成有反例集划界的陈述。
2. **反例集是方法学资产**：48 例网格 + `ker∩im` 分相判据可复核，比任何「结构必然性」断言更经得起查。
3. **隐藏公设上台面**：「可对角化 + 同谱」原本埋在定义里，现成明写条件——藏着的公设才是「民科」指控的真正入口。

### 2.3 变弱与断裂四处

**(1) 内生性断裂。** 条件来自对物理系统的谱假设，不来自 `Rec`/`Sp` 范畴公设。链从「范畴公设 → 3」变成「谱公设 + 范畴公设 → 3」。

**(2) 语义错位。** 条件含「同谱」⇒ 三层数的是「同一谱类的两种表示之间的关系层数」，而非「生成了几层新东西」。而 `N_active` 命名、`Unified3Theorem` 的「主动生成层」、`BottTower` 的「翻倍由主动生成层数决定」全建立在「生成」上。语义一挪，`k_max = 2³ = 8` 的旋量维数解释失去依托——**为什么「表示关系层数」决定旋量维数？**

**(3) 内部自相矛盾（最致命）。** 3 的成立条件排除「非对角化」，而非对角化正是耗散/非正规系统的谱特征。而 paper1 自己把耗散系统当作核心对象：

|---|---|---|
| `§2.5` | 辫子幺半结构建立在 `Rec_diss` | 耗散 |
| `§5.7.5` | 辫子静默（B1–B3）专治 `Rec_diss` | 耗散 |

理论不能一边把耗散系统收进框架、一边用「排除耗散」保住 3。这是**内部一致性冲突**，反驳材料是论文自己写的。

**(4) 「不可能有第 4 层」须撤回。** `Unified3Theorem` L151–158 的原话是「不可能有第 4 个主动生成层」。现有 18 例能到 4–6 层，且是 `J2/J3/J4/J6/J8` 这类最标准的幂零结构。该句只能改写为「在可对角化相不可能」，而条件化后的「不可能」与原来的说服力完全不同。

## 3 候选路线 A：可持续性 → 谱准入

### 3.1 「可持续性」的可判定定义

优先采用**迭代幂有界**：

```
∃C, ∀k, ‖U^k‖ ≤ C
```

理由：有限维可判定；是纯存在性要求（系统不炸、不塌），不含结构偏好，故由它推出的结构结论不算外部假设。另两个候选（谱闭合、谱隙不塌）各有缺陷：前者只说不逃、不说不爆；后者是充分非必要。

### 3.2 四步链（每步可机检）

关键引理（二项式展开即可证，不需 Kreiss 定理）：

> 设 `A = λI + N`，`N` 幂零、`N ≠ 0`、`|λ| = 1`。则 `A^k = Σ_j C(k,j) λ^{k−j} N^j ⊇ k λ^{k−1} N`，故 `‖A^k‖ ≥ k‖N‖ → ∞`。

1. **幂有界 ⟹ 单位圆上的谱半单**（上引理反证：`size ≥ 2` 的 Jordan 块落在 `|λ| = 1` 则幂无界）；
2. **临界 + 半单 ⟹ 可对角化**（临界 = 全谱在 `|λ| = 1`，单位圆上部分即全谱）；
3. **可对角化 + 同谱 ⟹ `ker∩im = 0` ⟹ 相容阶 = 3**（§1 已给出精确判据）；
4. ⇒ **临界 + 可持续 ⟹ 相容阶 = 3**。

至此 `3` 不再是公设。

### 3.3 谱准入判据

```
Σ_adm := { σ ⊆ ℂ : Re σ ≤ 0 ，且 σ ∩ iℝ 上几何重数 = 代数重数 }
```

- `Re σ ≤ 0`：迭代不爆；
- 虚轴半单：不沿多项式增长；
- 两者合 ⟺ 幂有界 ⟺ 可持续。

可判定算法：算谱 → 查实部 → 对虚轴特征值查 `geom = alg`。这是「MUFPF 能容纳什么谱」第一次有明确答案。

### 3.4 18 个反例的重释

18 例全为幂零/非正规，谱落在单位圆上（临界）却带 Jordan 块 ⇒ 迭代必多项式发散（`‖A^k‖ ~ k^{m−1}`）⇒ **自己活不下来**。

区别很重要：同一组数据从「被物理域排除」变成「不可持续」。前者读起来像人为排除，后者是存在性判决。

### 3.5 代价

换了更好的公设：原「可对角化」是结构限制，难辩护；新「系统处于临界」是存在性要求——「递归要持续存在」近乎同义反复，「临界」是 `Rec` 侧「不塌到 0 也不发散」的唯一稳态位置，正合「不动点」本义。

三层语义变为：**递归在自己不动点上的临界层数 = 3**。

### 3.6 与 S625/S626 收缩线的冲突（必须先解决）

S625/S626 用**严格收缩**（`σ ≡ S₄`、`step` 满足压缩）。严格收缩下 Jordan 块无害、幂仍有界 ⇒ 可持续不再蕴含半单 ⇒ 三层不成立。

| 相 | 可持续 | 半单 | 相容阶 | 3 的地位 |
|---|---|---|---|---|
| 临界（`Re σ = 0`） | 要求半单 | 强制 | = 3 | 结构定理 |
| 严格收缩（`Re σ < 0`） | 不要求半单 | 可选 | ≥ 4 | 观测现象 |

两条线不能同时当普适前提。

### 3.7 可机检性评估

| 步骤 | 内容 | 难度 | 备注 |
|---|---|---|---|
| 1 | Jordan 链 ⟹ 幂无界 | 低 | 不需完整 JCF：只需「存在 `v`、`|λ| = 1`、`(A−λI)v ≠ 0`、`(A−λI)²v = 0`」，算 `A^k v` 首项系数 |
| 2 | 临界 + 半单 ⟹ 可对角化 | 中低 | 近定义展开，Mathlib 有 `IsDiagonalizable` API |
| 3 | 可对角化 + 同谱 ⟹ `ker∩im = 0` | **中** | 唯一真正数学内容：可对角基下显式分解 `ker(d_A)` 与 `im(d_A)` |

工作量：1 < 2 < 3。

### 3.8 D1 / D2 回填与四步链修正（2026-11-10 已跑）

**D2（全称检验，n = 2..6）**：每 `n` 四类构造 × 30 例，共 150 例，全部取同谱对 `(A, A)`。

| 构造 | `ker∩im` | 例数 |
|---|---|---|
| 可对角化、谱互异 | 0 | 40 |
| 可对角化、带重根（`n−1` 个 1 与一个 2） | 0 | 40 |
| 非对角化（`λI + J_n` 相似变换，`λ = 1`） | `n−1` | 35 |
| 纯幂零（`J_n` 相似变换） | `n−1` | 35 |

混淆矩阵：可对角化 & `ker∩im = 0` = **80**；可对角化 & `ker∩im > 0` = **0**；非对角化 & `ker∩im > 0` = **70**；非对角化 & `ker∩im = 0` = **0**。⇒ 双向等价在 `n ≤ 6` 范围内**无违例**。

**两条新精确规律**：

1. 单块 Jordan `λI + J_n` 时 `dim(ker∩im) = n − 1`（`n = 2,3,4,5,6` → `1,2,3,4,5`），与 `λ` 取值无关。
2. 可对角化时 `dim ker(M) = Σ_i m_i²`（`m_i` 为特征值 `i` 的代数重数）。§3.7 第 3 步的"显式分解"因此有闭式答案：`ker` 维数按重数平方计数，`im` 维数 `= n² − Σ m_i²`，两者指标集不相交。

**D1 对四步链的修正**：见 §1.9。第 4 步必须写成「**临界** + 可持续 ⟹ 相容阶 3」，不能写成「可持续 ⟹ 3」——`I+J2`/`I+J3` 是 4 个反例。换言之第 2 步的「临界」不是可省的修饰词，而是链条承重件。

**【D20 精确复查】块尺寸覆盖缺口（结论不变，覆盖已补）**：上表 150 例在**块尺寸维度只覆盖两端**——非对角化部分全部是单块 `[n]`（`λI + J_n` 与 `J_n`），可对角化部分全是 `[1,…,1]`，**`[2,2]`、`[3,2,1]` 等中间 Jordan 型从未被测**。故「非对角化 ⟹ `ker∩im > 0`」原只有单块证据支撑。

精确复查 `pr634r2exact.py`（`Fraction` 零浮点，107 例：n=2..6 全部整数划分 × {同谱, 异谱} + 部分同谱抽样）补齐：可对角 22 例交全为 0，非对角 85 例交全 > 0，**双向零违例** ⇒ 等价命题成立，缺口已补。

同批实测还给出两条修正：

1. **`dim(ker∩im) = n − 1` 只对单块 `[n]` 成立**（上表规律 1 必须带此限定）。中间型显著偏大：n=4 `[2,1,1]` → 5、n=5 `[3,2]` → 7、n=6 `[3,2,1]` → 11、n=6 `[2,2,1,1]` → 12（均 ≫ `n−1`）。
2. **`dim ker = Σ m_i²` 只是可对角特例**，一般 Jordan 型通式为 `Σ_λ Σ_i (2i−1) d_{λ,i}`（`d` 组内降序），精确算术 241/241（见结构结果清单 R3）。

**D2 的边界**：全部样本取 `A_X = A_Y`（同谱）。异谱情形另行检验（§11.3）：谱不交时 `M` 可逆，`ker∩im = 0`，与是否可对角化、是否自伴**都无关**。

## 4 候选路线 B：严格收缩相 × 静默破缺

### 4.1 为什么它是唯一的载体

严格收缩（`Re σ < 0`，`|λ| < 1`）下

```
‖A^k‖ ~ k^{m−1} |λ|^k → 0
```

两件事同时成立：**结构上 Jordan 块存在**（相容阶可 4、5）、**幅度上衰减到零**。这正是静默所需，而且**不需要任何判据**——衰减率本身就是静默。前面几轮关于「静默判据不带层索引、Lean 侧占位级」的困境，在这个相里根本不必出场。

### 4.2 但破缺方向是反的

paper1 命题 5.21 第 3 条（L935 原文）：

```
δμ_silent = 2πi k · Res(G, μ₀)      ⇒ 破缺与 k 成正比
```

`k` 越大破缺越强 ⇒ **高阶加倍显形**。

> **更正（2026-11-10 自检）**：上式中的 `k` 在 paper1 里是**辫子交叉次数**，不是层号。注 5.22（L939）原话："Kerr QNM 复谱的辫子交叉次数 `k` 在此框架下对应阻尼周期量子数——`k` 越大，静默破缺的量子效应越…"；定义 2.5.1（L230–232）给出 `k(R₁,R₂) = ⌊(ω_{I,1} − ω_{I,2})/2π⌋`，即两系统虚频差除以 `2π` 取整。
>
> 故「破缺 ∝ 层号」这一步**依赖一个论文未给出的等同：层号 `k` = 辫子交叉次数 `k`**。本分支此前的表述（含 §5 的 `δμ_k = k·ε`）隐含使用了该等同，须降级为条件式：
>
> *若* 层编号与辫子交叉次数一致，则破缺随层号线性增长；否则该推论不成立。
>
> 这是**语义滑移**，不是数学错误。凡引用本节结论，须先补该映射或明确标注为假设。

| 机制 | 随 k 的方向 |
|---|---|
| 指数收缩 `|λ|^k` | k 增 → 更隐形 |
| 静默破缺 `∝ k` | k 增 → 更显形 |

两条曲线交叉一次，交叉点之后高阶反而更可见。要变成「压制」只能改破缺方向——无依据，改了是凑答案。

### 4.3 三种口径互斥

| 口径 | 层数 | 依据 |
|---|---|---|
| 经典观测层 | **3** | 指数收缩 + `ℏ→0` 或有限分辨率 |
| 结构层 | **≥ 4**（耗散相合法） | 幂有界不要求半单 |
| 量子修正层 | **> 3 且更显** | 破缺 `∝ k` |

论文同时提「三层」与「静默破缺」必被问「既然破缺让高阶更显，为何只有三层」。

### 4.4 与路线 A 互斥（**异路**）

一旦物理相定在严格收缩（更符合 paper1 自己的 `Rec_diss` / 辫子静默 / 伪谱界），`3` 自动从结构定理降级为观测现象。A 与 B 是**异路**，不可同时当普适前提。

### 4.5 唯一不靠阈值的截断：峰值时间

`k^{m−1}|λ|^k` 极大值点

```
t_k ≈ (m − 1) / γ ,     γ = −log|λ|
```

含义：「层 k 的可见窗口越来越晚」⇒ 「观测时窗 `T` 内只数到前若干层」。优于设幅度阈值之处：`T` 是物理观测尺度，且**避开用户明令禁止的百分比容差**。

但仍是观测口径的定量版：能解释「为何看到 3」，不能证明「只有 3」。

## 5 候选路线 C：破缺尺度与抑制机制

### 5.1 抑制因子是 ℏ，而 ℏ 在单位制里是 1

命题 5.21 证明的逻辑是「`ℏ → 0` 时圈图贡献 `~ ℏ` 阶，故 `δμ → 0`」。而用户立牌「普朗克质量 = 推导链内部自然单位 1」⇒ `ℏ = 1`。

- 若 `ℏ = 1`，`O(ℏ)` 即 `O(1)`——**没被抑制**；
- 若 `ℏ` 确实小，则「内部自然单位 1」须修正。

**冲突比三层问题更根本：框架里到底有没有小参数可用。** 命题 5.21 默认有，单位制说没有。

### 5.2 退用标准圈因子也不叫「极度」

`1/(16π²) ≈ 6.3e-3` 是 0.6% 级相对修正。按 σ_score 口径（`>3σ` 否决），通常已属「显形」，而非「看不见」。

### 5.3 真正决定胜负的是相对幅度

```
可见度 ≈ max( e^{-γk}, δμ )
```

| 情形 | 静默幅度 | 破缺 | 主导 | 第 4 层 |
|---|---|---|---|---|
| `ℏ = 1`（本框架） | `e^{-γk}` | `O(1)` | 破缺 | **完全可见 → 三层崩塌** |
| `δμ = 6e-3` 且 `γk > 5` | `< 1e-2` | `6e-3` | 静默 | 仍隐（3 成立） |
| `δμ = 6e-3` 且 `γk < 5` | `> 1e-2` | `6e-3` | 原本可见 | 与破缺无关 |

即：能否被抑制，取决于 `δμ` 是否大于静默本身，而后者依赖 `γ` 与 `k`——相依赖，非全局常数。

### 5.4 缺口：模式分摊律

若破缺不是每模式各拿一份 `O(1)`，而是**总量守恒、按模式分摊**：

```
δμ_k ~ δμ_total / #modes     或     δμ_k ~ δμ_total · e^{-γk}
```

则高阶分到的随 k 单调降，`e^{-γk}` 重新占上风，三层可维持。**论文没有这条规则**：`δμ_silent = ∮ Tr G(p) dp` 对整个静默谱集积分，未说各模式如何分配。这是真缺口，也是「破缺 + 三层」共存的唯一补丁（路线 C-1）。

### 5.5 普朗克抑制作为天然屏障（路线 C-2）

圈积分天然带紫外截断：

```
δμ ~ (μ / Λ)ⁿ      （n 常见 2 或 4）
```

优点：**全局**（只给一个 `ε`，无逐层规则）、**层无关**（不改「破缺 ∝ k」，只压整体幅度）、有 EFT 传统支撑。

净效果：`δμ_k = k·ε`，可见度 `max(e^{-γk}, k·ε)`。翻转到破缺主导需 `k > e^{-γk}/ε`；若 `ε ~ 1e-17`，门槛落在 `k ~ 1e17` ⇒ 物理层数内够不到 ⇒ **「三层观测」与「破缺 ∝ k」可共存**。

### 5.6 门槛依赖耗散率 γ（数值已更正，见注）

要求 `δμ_8 = 8·(μ/Λ)² < e^{-8γ}` 时：

| γ | `e^{-8γ}` | 允许的 `(μ/Λ)²` 上界 | 允许的 `μ/Λ` 上界 |
|---|---|---|---|
| 1.0 | 3.35e-4 | 4.19e-5 | **6.5e-3** |
| 0.5 | 1.83e-2 | 2.29e-3 | **4.8e-2** |
| 0.1 | 4.49e-1 | 5.62e-2 | **2.4e-1** |
| 0.01 | 9.23e-1 | 1.15e-1 | **3.4e-1** |

> **注（自我更正）**：2026-11-10 对话中口头给出的 γ=0.1 行 ≈`2.1e-1`、γ=0.01 行 ≈`0.96` 两处估算有误，本表为复算后的正确值。γ=0.5 行口头取 `4e-2` 为保守值，精确值 `4.8e-2`。以本表为准。

读法：γ 越小门限越松，但静默本身也越无效（最后一行 8 层只衰减 8%，几乎没压住）。故**屏障不是独立外挂，与耗散率绑定**。

### 5.7 它搬家搬到了 hierarchy

立牌 `Λ = 1` ⇒ 「普朗克抑制」实际要求的不是 `Λ` 大，而是 `μ ≪ 1`，即标准模型的 **hierarchy 问题**。

| 原问题 | 现问题 |
|---|---|
| 缺「破缺按层分摊」规则 | 缺「物理能标 / 普朗克单位」比值 |
| 需新机制 | 需一条生成链 |
| 与纯内生冲突较小 | **与纯内生直接冲突**（若比值为外部输入） |

判定标准不变：**该屏障能否从生成链推出。** 若能，是加分项（导出 hierarchy 远难于导出 3）；若不能，纯内生链条断在此。

### 5.8 必须防的语义滑移

普朗克抑制只压圈修正的绝对幅度、不区分层。它能回答「破缺为何不显形」（观测口径），**不能**回答「第四层为何不存在」（结构口径）。拿它支撑「三层是结构定理」＝用观测结论冒充结构结论，正是「候选层不得轻升定案层」所防。正确用途：为「三层是可观测层数」提供机制解释。

### 5.9 D4 / D5 回填：屏障与分摊律都缺件（2026-11-10 已跑）

**D4（`μ/Λ` 锚点检索，全库 `.md` + `.lean`）**

| 层次 | 结论 | 证据 |
|---|---|---|
| 普朗克单位本身 | **已内生** | S106（2026-10-27）明文「链内 `M_Pl = 1`（定义——自然单位制）」；由 `G_N = 18(2+√3)Δλ_min² = 1` 谱定（paper49 §6.1），进而 `ln Δ_mod = −2π·M_Pl = −2π`。全库 241 处命中 `M_Pl = 1` 类表述 |
| `μ/Λ` 小比值 | **无锚点** | 全库显式 `μ/Λ` 写法仅 11 处：5 处为本笔记自身；`GaugeTopology.lean` L107 是外部 RG 跑动式 `α_s(μ) = 2π/(b₀ ln(μ/Λ_QCD))`；`spectral_T_category_riemann.md` L1074/L1084 的 `mu/Λ` 是 numpy 变量名（裸 `mu`），与物理 `μ` 无关 |
| 唯一相关量 `Λ_QCD/M_Pl` | **未闭合** | `roadmap\phase102b_full_endogenous_roadmap.md` L32 自陈「阶段 0：`Λ_QCD/M_Pl` 纯框架闭合（最大攻坚——**4.2 倍缺口**）」 |

判定：**标尺内生、小比值外挂**。路线 C-2 在「普朗克单位 = 1」这层有内生依据，但它需要的是 `μ ≪ 1`（§5.7 的 hierarchy），而该比值无生成链。采用 C-2 必须登记为公设，且属「小参数公设」型——正是用户立牌最排斥的一类。

**D5（分摊律文本核查）**

1. paper1 **不含**「按模式分摊 / 每模式 / per-mode」任何表述（全文检索为假）。
2. 定义 5.20（L927–929）为 `δμ_silent = ∮_{Σ_silent} Tr(G(p)) dp`，对**整个静默谱集**积分，是整体量；命题 5.21③ 只给**单个极点**的留数 `Res(G, μ₀)`，其系数是辫子交叉次数（见 §4.2 更正注）。
3. 因此「总量守恒、按模式分摊」既不在论文中，也不是已有结构的推论。路线 C-1 若采用，是**新增公设**而非推导。
4. 唯一可能的近似内生来源：把 `∮ Tr G` 按极点做部分分式，得到「各极点留数之和」——但那只是分解，不含「总量守恒后再分配」的语义，除非另设归一规则。

**综合判定**：路线 C 的两条下属机制**同时缺件**——C-1 缺分配规则，C-2 缺小比值。C 整支不能充当「3 的支撑」，只能在观测层作解释，且每一处都须标注公设。

## 11 D3 判别结论：`Sp` 的两套语义与 `3` 的可升格形态

> 本节是本分支**最重要的翻案项**。此前的 §1–§6 全部在 Lean 的 `SpObj` 语义下计算，而论文的定理写在另一个语义里。D3 把这个分歧定位了出来。

### 11.1 论文侧与 Lean 侧的 `Sp` 定义不一致

**论文侧**（`paper1` 命题 2.4.4，L207 与证明 L211）：

```
A_R := ½( −log U_R + (−log U_R)* )
```

证明原文：「`D(R)` 的算子 `A_R` 已取为 Hermitian（自伴），故 `D` 的像始终在 `Sp` 中」。即论文的 `Sp` 是 **`D` 的像**——只含自伴算子的范畴。

**Lean 侧**（`SpCategory.lean` L29–33）：

```lean
structure SpObj where
  n : ℕ
  A : Matrix (Fin n) (Fin n) ℂ
```

`SpObj` **只有 `n` 与 `A` 两个字段，无任何自伴字段**；`SpHom`（L37–39）只要求 `P * Y.A = X.A * P`。即 Lean 的 `Sp` 是**任意复矩阵**的范畴。

**后果**：`H³ = 0` 路线否证、18 例反例、§1 的 48 例网格，全部成立在 Lean 语义下；而论文的「三层」陈述写在自伴语义下。两者不是同一个命题。

### 11.2 D3 数值结论（同谱对 `(A, A)`，40 例，`n = 2..6`）

| 构造 | 自伴 | 可对角化 | `ker∩im` | 例数 |
|---|---|---|---|---|
| Hermitian，谱互异 | Y | Y | 0 | 10 |
| Hermitian，带重根 | Y | Y | 0 | 10 |
| 非 Hermitian 但可对角化 | N | Y | 0 | 10 |
| 非正规 Jordan（`λI + J_n`） | N | N | `n − 1 > 0` | 10 |

判定（**无违例**）：

1. **自伴 ⇒ `ker∩im = 0`**（20/20）。
2. **可对角化 ⇔ `ker∩im = 0`**（30/30 正向、10/10 反向）；前提是**同谱**。
3. **`dim ker = Σ_i m_i²`**（30/30 命中，只在可对角化时成立）。

**关键读法：真正的分界条件是「可对角化」，不是「自伴」。** 自伴只是可对角化最常见、最易验证的充分条件。

### 11.3 异谱（谱不交）是第二条独立通道

`J_n` 与 `J_n + 0.7 I`（谱不交）：`rank(M) = n²`，`n = 2,3,4` 全可逆。**与自伴、可对角化都无关。**

故「相容阶 = 3」有两条互不包含的来源：

| 支 | 条件 | 语义 | 门槛 |
|---|---|---|---|
| (a) 同谱支 | 同谱 + 可对角化 | 「同一谱类的两种表示之间的关系」 | 高，需挑 `(α,β)` |
| (b) 异谱支 | 谱不交（`d_A` 双射） | 「两个不同谱类对象之间的缺陷塔」 | 低，随机 `(α,β)` 即成立（§1.4 的 16/16 全在此支） |

物理上 `Sp` 的对象对是否允许异谱，决定 `3` 是**结构特征**还是**泛型上界**——若允许，(b) 支使 `3` 成为「任意不同谱对象对的上界」，理论意义被摊薄。这是 D6 之外**第二个需裁决的分叉**。

### 11.4 若采纳论文语义，`3` 可升格的候选定理

> **候选定理 PR-634-T1**。设 `A_X, A_Y` 可对角化（同谱或谱不交）。则 `ker(d_A) ∩ im(d_A) = 0`，缺陷塔相容阶 = 3。

证明骨架（三步，全部可机检）：

1. 可对角化 ⇒ 取特征基 `A_X = V Λ_X V⁻¹`，`A_Y = W Λ_Y W⁻¹`。
2. `M = kron(I, A_X) − kron(A_Yᵀ, I)` 在张量基下成为对角算子，块值 `λ_i(X) − λ_j(Y)`。
3. `ker` 的指标集 `{λ_i(X) = λ_j(Y)}` 与 `im` 的指标集 `{λ_i(X) ≠ λ_j(Y)}` **不相交** ⇒ 交集为 0。∎

若只取自伴（更强、更易证），第 1 步换成谱定理（正交特征基），其余相同。

**代价与边界（必须与结论同时陈述）**：

1. **前提来自定义，不来自范畴公设。** 「自伴」是 `Rec_D` 的定义内容（`A_R := ½(−log U + (−log U)*)`）。采纳 T1 等于**把 3 焊在定义上**，与「`N_active := 3` 写死在 `ActiveMorphismLayer`」地位相同——升格没有前进，只是换了定义位置。这一点与 §2.1「内生性下降」的判断方向相反，必须如实标注。
2. **18 例反例整体移出 `Sp`。** 它们在 `D` 之前，属 `Rec`/`Rec_diss`。从「否证」变为「边界刻画」：`D` 的自伴投影恰好消灭 Jordan 块。
3. **Lean 侧须改定义。** 给 `SpObj` 加 `IsHermitian A` 字段（或另立 `SpObjH`），属定义增强；`SpTwoMorphism.condition` 与 `spThree*` 的构造字面不变，但"自伴"语义须显式声明。
4. **`k_max = 2³ = 8` 仍悬空。** 采纳后 `3` 是 `Sp` 内的 universal 上界，不是"N 个生成自由度"；旋量维数解释仍缺支撑。

### 11.5 三种语义选择

## 12 Δ 与 `ker∩im` 是两条独立轴（D9，2026-11-10）

> 触发：D2 的双向一致性（`可对角化 ⇔ ker∩im = 0`）被问「是否意味着 Δ = 0」。本节给出否定答案，并指出被挑战的是 Lean 注释中的一处**语义指派**，不是机检定理本身。

### 12.1 Δ 的精确形式

`SpDelta2Cell.dev`（`HigherSpCategory.lean` L503–511）：

```
dev = A_X·(H_β·H_α′) − 2·(H_β·A_Y·H_α′) + (H_β·H_α′)·A_Z
```

即对 `K := H_β·H_α′` 的三项中心差。`spDelta2Cell_eq_homotopy_deviation`（L527）机检 `dev = 横向复合 homotopy − 竖向复合 homotopy`，故 `Δ := dev` 是**层 2 交换律偏差**。

注释把它定位为「Δ 是层 2 交换律的结构残余，位于 coherence 层（层 4），是层 4 coherence 内容的唯一载体」（L357–360、L471–473）；`delta_cell_dev_ne_zero_iff_swap`（L543）机检 `dev ≠ 0 ⟺ 横竖复合不等`，并附数值「2000 组随机谱算符 dev 非零 2000/2000」。

### 12.2 与 `ker∩im` 的独立性（同谱 `A_X = A_Y = A_Z = A`，`n = 2..6`）

| 构造 | `dim ker` | `dim im` | `ker∩im` | `‖dev‖max` | Δ = 0？ |
|---|---|---|---|---|---|
| `A` 对角互异，`H_β/H_α′` 随机 | `n` | `n²−n` | **0** | 4.89 … 47.63 | **否（0/5）** |
| `A = 3I` 标量，`H_β/H_α′` 随机 | `n²` | 0 | 0 | 5.0e-15 … 7.9e-15 | 是（5/5） |
| `A` 对角互异，`H_β = H_α′ = I` | `n` | `n²−n` | 0 | 0 | 是（5/5） |
| `A` 对角互异，`H_β` 对角（与 `A` 对易） | `n` | `n²−n` | 0 | 0 | 是（5/5） |

相对量级（随机可对角化同谱，`‖dev‖/(‖K‖‖A‖)`）：0.436（`n=2`）、0.349（3）、0.298（4）、0.222（5）、0.116（6）——**O(1)**，不是小量。

### 13.2 引理 PR-634-L1（逐分量论证，待 Lean 化）

设 `P, Q : X → Y` 均满足 `intertwine`（`P·A_Y = A_X·P`、`Q·A_Y = A_X·Q`）。逐分量看：

- `λ^X_i ≠ λ^Y_j` ⇒ `P_ij = Q_ij = 0`，故 `(Q.P − P.P)_ij = 0`；
- `λ^X_i = λ^Y_j` ⇒ `(ad_A h)_ij = (λ^X_i − λ^Y_j) h_ij = 0`。

于是 `ad_A(h) = Q.P − P.P` 逐分量给出：共享谱处要求 `(Q.P − P.P)_ij = 0`，非共享处自动成立。

**⇒ P = Q。** 即 `Q.P − P.P = 0` ⇒ `h ∈ ker(d_A)`。此时用 `A_X h_β = h_β A_Y` 与 `A_Y h_α′ = h_α′ A_Z`：

```
A_X·K  = A_X·h_β·h_α′ = (A_X h_β)·h_α′ = h_β·A_Y·h_α′
K·A_Z  = h_β·h_α′·A_Z = h_β·(h_α′ A_Z) = h_β·A_Y·h_α′
```

故 `A_X K = K A_Z = h_β A_Y h_α′`，代入 `dev = A_X K − 2 h_β A_Y h_α′ + K A_Z`：

**`dev ≡ 0`（精确恒等式，非数值近似）。**

**限定（2026-11-10 补，D14 后加）**：上述逐分量论证要求 `A_X, A_Y` **可对角化**（按各自本征基展开，`ad_A` 才对角化）。`A` 含 Jordan 块时本论证失效——`ker∩im ≠ 0` 使 `Q.P − P.P ≠ 0` 也可解，且 `dev = ΔP_β·h_α′ + h_β·ΔP_α′ ≠ 0`（§13.10 给出精确反例）。故 L1/C1 只在可对角化子类内成立。

## 20 下界：三相分离的最小层数（D24）

### 20.1 问题

## 21 「平凡」的定义勘误（D25）

### 21.1 触发点

§19、§20 与结构结果清单 R1 都用「层 k 平凡 / 非平凡」标注。核实 `pr634r1highn.py` 时发现：脚本判据是 `R != 0 且 R ∈ im(ad_A)`（L7、L99、L131），而 R1 表只写「平凡」，未写这一定义，存在两种误读：

- **误读甲**：该层没有态射 → **错**。A 相层 3 明明有态射。
- **误读乙**：该层右端恒为零 → **也不对**。A 相可构造非零右端（`diag` 的非零对角元素）。

### 21.2 正确定义

设 `d_A = ad_A`，层 k 的 condition 为 `d_A(x) = R_k`，其中 `R_k` 由上一层 datum 之差给出：

- **层 k 非平凡（defect 可穿越）** ⟺ `∃ R_k ≠ 0` 使 `R_k ∈ im(d_A)`；
- **层 k 平凡（defect 不可穿越）** ⟺ 任何非零 `R_k` 都 `∉ im(d_A)`。

关键：`R_k = 0` 时 `x` 可取 `ker(d_A)` 中非零元，但那是**层内 loop**，不承接上一层 defect，不延长链条 ⇒ 不计入塔高。

### 21.3 为什么该定义是唯一合理的

塔高衡量的对象是「**defect 传递链的长度**」，不是「态射数量」。

- 若把 loop 计入塔高：任何 `ker ≠ 0` 的相（含 A 相）塔高都会变成 ∞，三相全部塌缩成一个，R1 失去全部意义；
- 反之，`R_k ≠ 0 且 ∈ im` 精确表达「**上一层确实有个非零 defect 需要穿过这一层**」，这才是链条能否延续。

```
H : h ↦ A_X * h − h * A_Y        （A_X = 源对象矩阵，A_Y = 目标对象矩阵）
```

的核，**不是** `A` 自身的核 `ker(A)`。三相其实是同一个 `H` 的两个整数：`dim ker H` 与 `dim(ker H ∩ im H)`。

**为什么必须是跨对象**：层 3 的 condition 是 `β.homotopy − α.homotopy = X.A * secondHomotopy − secondHomotopy * Y.A`（`HigherSpCategory.lean` L244–249），右端天然是 `H` 对 `secondHomotopy` 的作用，源对象与目标对象各出一个矩阵，不可能写成单对象的 `ad_A = [A, ·]`。`ker H = 0` 的充要条件正是 `spec(A_X) ∩ spec(A_Y) = ∅`（Sylvester 方程：两谱不交 ⇒ `H` 可逆），这就是 R1 表「`ker = 0`（**谱不交**）」括号注的来源。

**误述更正**：§18.4 / §19.3 / §20.5 中把第一相简写为「`ker(A) = 0`」，与第二相的 `ker(ad_A)` 并列，读起来像在说两个不同算子。正确读法是三相共用 `H`：

| 相 | 判据（都用 `H`） | 塔高 |
|---|---|---|
| C | `ker H = 0`（谱不交） | 1 |
| A | `ker H ≠ 0` 且 `ker H ∩ im H = 0` | 2 |
| B | `ker H ∩ im H ≠ 0` | 4 / ∞ |

`A` 自身是否可逆**不参与**判据；参与判据的是 `spec(A_X) ∩ spec(A_Y)` 是否为空。

**对 Lean 侧的覆盖边界（已补齐）**：`SpLayerSeparability.lean` 的 `adLin A : X ↦ A * X − X * A` 是 `A_X = A_Y = A` 的**退化特例**（同对象 ⇒ 同谱），因此只覆盖 A 相与 B 相。本轮的补救是新增跨对象版 `adLin2 A B : X ↦ A * X − X * B`，并对 C 相代表（`A = diag(4,5,6)`、`B = diag(1,2,3)`）机检：

| 定理 / 引理 | 内容 | 相 |
|---|---|---|
| `adLin2` | 跨对象交换子 `X ↦ A * X − X * B`，ℂ-线性 | 工具定义 |
| `diag4_mul_apply` | `(diag4 * X) i j = e i * X i j` | C（工具引理） |
| `diag4Val_sub_diag3Val_ne_zero` | 任意 `i j`：`e i − d j ≠ 0`（谱不交的全部内容） | C |
| `diag4_diag3_ker_eq_bot` | `ker(adLin2 diag4 diag3) = ⊥`（层 2 无法承接 defect） | C |

⇒ **C 相（谱不交、塔高 1）也已机检**。至此 R5.1 三相（C/A/B）的层 2 判定全部有 Lean 依据，且判据统一落在同一个算子族 `{adLin2 A B}` 上（`adLin A = adLin2 A A`）。

**分级影响**：R5.1 的 A/B 两相不受影响（同谱设定下 `H = ad_A` 退化为 `adLin`）；C 相由「Sylvester 可逆（经典定理，未机检）」升为「机检」，故三相表整行现在都是 A 级机检。

### 21.16.2 为什么改走元素级判定

本来打算走矩阵共轭链：`A = Pᴴ C P` ⇒ 若 `A` 自伴则 `Pᴴ C P = Pᴴ Cᴴ P` ⇒ 左乘 `P` 右乘 `Pᴴ` ⇒ `C = Cᴴ` ⇒ 与 `cyclicSpObj_not_hermitian` 矛盾。这条链要 4–5 条辅助引理（`stepMatrix_equiv_conjTranspose`、两组 `stepMatrix_conjTranspose_mul`、sandwich 保自伴），每条都要在 `Matrix.conjTranspose` 与 `if` 分支上磨。

改走**元素级**：`SpCategory.lean` L53 已经有现成的 `isHermitian_iff_entries`

```lean
lemma isHermitian_iff_entries {E : SpObj} :
    IsHermitian E ↔ ∀ i j, E.A i j = star (E.A j i)
```

取两个具体指标 `i := e 0`、`j := e 1`（`e := Fintype.equivFin cyclicRec.T`），算得

```
A (e 0) (e 1) = 1        （因为 (e ∘ c ∘ e.symm) (e 0) = e (c 0) = e 1）
A (e 1) (e 0) = 0        （因为 (e ∘ c ∘ e.symm) (e 1) = e (c 1) = e 2 ≠ e 0）
```

⇒ 自伴要求的 `A (e 0)(e 1) = star (A (e 1)(e 0))` 退化成 `1 = star 0 = 0`，直接矛盾。

⇒ 只用了 `Equiv.symm_apply_apply`（由 `simp` 自动）与 `e.injective` + `decide`，**完全绕开矩阵乘**。

## §21.17 D41：塔高无界（判据口径）+ 审计口径复跑

### 21.17.1 先说口径为什么必须收窄

结构清单里「塔高无界」的原话是：

> 层 k ≥ 3 的右端恒属 `ker(d_A)`。因此层 k ≥ 3 的非平凡性由 `ker ∩ im` 是否非零决定：`ker = 0` 时塔高 1，`ker ∩ im = 0` 时塔高 2，`ker ∩ im ≠ 0` 时塔高无界。

「无界」在这里**不是**「层 k 的结构对每个 k 都存在」——库内层结构只到层 5（`HigherSpCategory.lean` 止于 `SpFourMorphism`，`SpFiveLayer.lean` 补 `SpFiveMorphism`），层 6 起没有结构，所以「层结构无限存在」是不可证的。

⇒ 所以 D41 只能、也只应在**判据层**落「无界」。

### 21.17.2 `LayerWitness`：把「有非零缺陷」定义出来

```lean
def LayerWitness {n : ℕ} (A : Matrix (Fin n) (Fin n) ℂ) : Prop :=
  ∃ R : Matrix (Fin n) (Fin n) ℂ, R ≠ 0 ∧ HasConditionForm A A R ∧ adLin A R = 0
```

三个条件合起来就是「`ker ∩ im ≠ 0` 的非零见证」：非零、具有层 condition 形态（`R = A * L − L * A`）、且在 `ker(adLin A)` 内。

**注意这里故意不放层号变量**——放进去就等于预设了 D37 的结论。

## §21.19 自伴化投影的边界：对象层可行、态射层不可行（第 1 项收口）

### 21.19.1 这一条从哪里来

「逐一推进」第 1 项原定的是「`SpHerm` 上的受限伴随存不存在」。而受限伴随能否成立，取决于一个前置判据：**`D` 的像 ∩ 自伴层是否够大**——若自伴像只占极少数，受限伴随无从谈起。

直接判「够不够大」是量化判断，不可机检。故转成一个更根本、可直接判真假的命题：

> 把 `A` 换成自伴化 `A' = ½(A + Aᴴ)`（论文命题 2.4.4 L207 的口径）之后，态射层的交织等式 `P · A'_Y = A'_X · P` 是否仍成立？

若成立，则自伴化是一个**函子**，受限伴随至少有了余定义域侧的候选构造；若不成立，则自伴化只能逐对象做，受限伴随连构造入口都没有。

这一转形把「程度问题」换成了「函子性问题」，后者可穷举、可机检。

### 21.19.2 数值先检（穷举，非抽样）

脚本 `pr634hermfun.py` / 结果 `pr634hermfun.txt`（pyenv 3.11.8 运行，EXIT=0）。按 `DFunctor` 定义逐字翻译：

- `A_of(step) = stepMatrix`：`A[i][step[i]] = 1`
- `T_of(f) = transferMatrix`：`T[i][f[i]] = 1`
- `herm(A) = ½(A + Aᵀ)`（实 0/1 矩阵下 `Aᴴ = Aᵀ`）

`n, m ∈ {1,2,3}` 全部 `step` 与全部 `f` 全枚举，筛出满足交换性 `step_Y ∘ f = f ∘ step_X` 的三元组：

| 量 | 值 |
|---|---|
| `CASES(commuting)` | **2166** |
| `ORIG_OK_ALL`（原像交织） | **True**（2166/2166 成立） |
| `HERM_VIOLATIONS`（自伴化后破坏） | **1789 / 2166 = 82.6%** |
| 首反例 | `n=1, m=2`，残差 `max|·| = 0.5` |

`ORIG_OK_ALL = True` 是**自检**：若我的 `A`/`T` 翻译与 `DFunctor` 不符，原像交织会先失败。它 2166/2166 通过，说明脚本口径正确——这样 1789 这个数字才是关于 `DFunctor` 的，而不是关于一个别的函子。

残差 `0.5` 是精确值，不是浮点噪声（元素取值为 `0`、`½`、`1`，`0.5` 恰在格点上）。

### 21.19.3 最小反例手算核验

`n=1`（`step_X=(0,)`，单点自环）、`m=2`（`step_Y=(0,0)`，两点均映到 0）、`f=(0,)`（把单点映到 `Y` 的 0 号点）。

- `A_X = [[1]]`（自伴）
- `A_Y = [[1,0],[1,0]]`（两行相同，非自伴）
- `T = [[1, 0]]`（`X` 一个点映到 `Y` 的 0 号点）
- 原像交织：`T·A_Y = [[1,0]] = A_X·T` ✔ 成立
- `symPart A_X = [[1]]`
- `symPart A_Y = ½([[1,0],[1,0]] + [[1,1],[0,0]]) = [[1, ½],[½, 0]]`
- 自伴化后：`(T · symPart A_Y)(0,1) = 1·½ + 0·0 = ½`，而 `(symPart A_X · T)(0,1) = 1·0 = 0` ⇒ **`½ ≠ 0`**

破坏的来源很直观：`A_Y` 是「把两点都送到 0」，它的转置 `A_Yᵀ` 是「从 0 出发送到两点」——两张完全不同的图。自伴化把这两张图平均，得到一张既不像前也不像后的矩阵；而 `P` 只忠实于原图的方向，平均之后就对不上了。

## 21.25 R2 单块特例（`jordan3`）：数值完全核实，Lean 化受阻于 tactic panic（第 9 批）

### 21.25.1 目标

`finrank (ker(ad_jordan3) ⊓ range(ad_jordan3)) = 2`（这是 R2 闭式 `n − #Jordan块 = 3 − 1 = 2` 在单块情形的实例）。

### 21.25.2 数值核实（三次，前两次的错都已排除）

**第一次（错，作废）**：用 `kron(I,A) − kron(Aᵀ,I)` 构造 `ad_A`，得 `dim(ker ∩ range) = 4`，与闭式冲突。
**错因**：该 Kronecker 公式是**列主序**的 `vec` 约定；行主序应为 `vec(AX) = (A ⊗ I)vec(X)` 的转置版。⇒ 该冲突是**假冲突**，不是闭式被证伪。

**第二次（显式逐元素 9×9，`pr634r2n3c.py`）**：

| 量 | 结果 |
|---|---|
| `rank ad_J` | 6 |
| `dim ker` | 3 |
| `[J, X] = I` | 残差 **1.732** ⇒ **不可解** ⇒ `I ∉ range` |
| `[J, X] = J` | 残差 4.6e-16 ⇒ 可解，`X = diag(-1,0,1)`（等价于库内 `diag(0,1,2)` 加 `cI` 平移，因 `I ∈ ker`） |
| `[J, X] = J²` | 残差 2.2e-16 ⇒ 可解 |
| `[J, X] = J + J²` / `2J − J²` | 残差 5.4e-16 / 1.0e-15 ⇒ 可解（线性叠加） |

**第三次（显式线性系统，12 未知 / 9 方程）**：`rank A = 7` ⇒ 解空间 5 维 ⇒ 减去 3 维「`X` 中心化子（`a=b=c=0`）」⇒ **非平凡维 = 2**，且非平凡解的 `(a,b,c)` 全部 `a = 0` ⇒ **`ker ∩ range = span{J, J²}`，维恰 2**。

⇒ 与 R2 闭式 `3 − 1 = 2` **完全一致**；闭式在 `n = 3` 单块下经独立方法（不用 SVD 秩、用显式线性系统）复核通过。


（越界项取 0）。我最初误写成 `X (i+1) j − X i (j+1)`，据此得出「`J ∉ range`」的**假结论**，
与库内已机检的 `jordan3_mem_range`（见证 `diag(0,1,2)`）直接矛盾。订正后：
`J ∈ range`、`J² ∈ range`（**纯 0/1 见证** `X = [[0,0,0],[0,0,1],[0,0,0]]`）、`I ∉ range`。

⇒ `I ∉ range` 是上界 `≤ 2` 的关键（`ker` 三维中只有迹零方向可能落在 `range`）。
