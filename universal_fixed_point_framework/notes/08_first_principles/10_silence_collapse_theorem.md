## 一、缘起：一个待严格化的直觉

用户在维度饱和讨论（`09_dimension_freedom_saturation.md`）后提出：

> "d ≥ 4 坍缩不稳定，也是其他四个类空维静默的一个直接因素。"

此前的表述是**并列**的：外部通道（场论侧束缚稳定性给出上界 d≤3）+ 内部通道（谱静默给出可见维=1+3、d=N_IFS=3）。两个通道恰好同时指向 3，被表述为"夹逼/巧合"。

本笔记的目标：把"巧合"提升为**因果充要关系**——**坍缩不稳定性 ⇔ 静默**。即：四个额外类空维的静默**不是**偶发不可见，而是 d≥4 坍缩不稳定的**强制性结构性后果**；反过来，坍缩不稳定性也正是静默维的判据。

**结论预告（充要定理 T2）**：在桥接公设 B1 下，对 MUFPF 框架中任一额外类空维 X：

> X 静默（不可观测） ⟺ X 坍缩不稳定（不承载稳定束缚态） ⟺ X 并入可见空间后维数 d ≥ 4。

## 二、记号与对象

- **d 维空间、库仑型（高斯律）势**：V_d(r) = −Z / r^{d−2}（d ≥ 3；d=2 为对数势，不属讨论范围）。这是 d 维中"点源电荷/等谱通量"的自然势形（见 Paper XXXV §5 球面稀释）。
- **定态薛定谔**（ħ=m=1）：[ −½ Δ_d + V_d ] ψ = E ψ。
- **s 波约化**：径向函数 f(r)，作 u(r) = r^{(d−1)/2} f(r)，得到一维径向方程

  −½ u″ + V_eff(r) u = E u,   V_eff(r) = (d−1)(d−3)/(8r²) − Z / r^{d−2},   u(0)=0,  u∈L²(0,∞)。

- **束缚稳定性判据** S(d)：径向算符 H_d = −½ d²/dr² + V_eff 存在正规化负能量本征态（束缚态）且下有界。

## 三、内层定理 T1：束缚稳定性 ⟺ d ≤ 3（已证）

**定理 T1**：对 d ≥ 3、Z > 0：

| d | 结论 | 数值验证（本笔记 §八） |
|---|---|---|
| d = 3 | H₃ 下有界，存在束缚态，E₀ = −Z²/2 | E₀ → −0.499（N→∞），收敛于 −0.5 |
| d = 4 | **临界维**：Z > Z_c = ½ 时无下界（坍缩）；0 < Z ≤ ½ 时无负本征值 | Z=1：E₀ 随网格细化 → −∞（−1091 → −4366） |
| d ≥ 5 | 对任意 Z > 0 无下界（坍缩） | d=5：E₀ → −3.7×10⁷；d=6：→ −7.7×10⁸ |

**证明**（缩放论证，充要）：

对 d 维径向问题引入尺度参数 λ 与归一化试探族 ψ_λ(r) = λ^{1/2} ψ(λr)。动能项按 λ² 缩放，势能项按 λ^{d−2} 缩放（因 V ∝ r^{−(d−2)}）。故缩放能量函数

  e_d(ρ) = 1/(2ρ²) − Z / ρ^{d−2}（ρ 为特征尺度）

的下界性决定了坍缩与否：

- **d = 3**：ρ^{−2} ≫ ρ^{−1}，动能主导，e₃ 有下界 min = −Z²/2；且标准氢原子解给出显式本征函数 ψ ∝ e^{−Zr}，E₀ = −Z²/2。⇒ S(3) 成立。✓
- **d = 4**：两项同为 ρ^{−2}，净系数 ½ − Z。Z > ½ 时净系数为负，e₄ → −∞（坍缩）；Z ≤ ½ 时下界存在但无负本征值（已知结果，见 §七）。⇒ S(4) 不成立（常规设定 Z=1 即坍缩）。✓
- **d ≥ 5**：ρ^{−(d−2)} 主导（d−2 ≥ 3 比 1/r² 更奇异），对任意 Z > 0 有 e_d → −∞。⇒ S(d) 不成立。✓

**充分性**（d≤3 ⇒ S(d)）由 d=3 显式解给出；**必要性**（S(d) ⇒ d≤3）由反证：若 d≥4，缩放族 ψ_λ 使 ⟨H_d⟩ → −∞，违反下有界性，任何束缚态 E = ⟨H⟩ 必须 ≥ inf spec > −∞，矛盾。∎

> 注：d=4 的临界耦合 Z_c = ½ 来自一维 Hardy 常数：算子 −½∂² + A/r² 下有界 ⟺ A ≥ −⅛，故 (d−1)(d−3)/8 − Z ≥ −⅛ ⟺ Z ≤ (d−2)²/8 = ½。Z=1（自然归一化）严格超临界。

## 四、桥接公设 B1（显式标注：公设，非定理）

**B1（可见性-束缚稳定性对偶公设，探测=耦合表述）**：

> 类空维 X 非静默（可被观测） ⟺ ∃ 稳定束缚结构 Y，使 X 与 Y 可发生非零耦合（探测=耦合）。
> 等价地：X 静默 ⟺ X 上无稳定束缚态可充当耦合载体（坍缩） 或 耦合振幅恒低于可见性阈值 c₂（弱耦合）。

**标注（诚实边界）**：
- MUFPF 现有机器证明覆盖：Cl(1,7) = 1 ⊕ 3 ⊕ 4 分解、可见维 = 4（1 时间 + 3 空间）、可见性阈值 c₂ = S₄ = e^{−d}、静默层 c₁ = S₃S₄ ≈ 0.003、分离裕度 e³ ≈ 20、d = N_IFS = 3（Paper XXXV §5 环③）。
- 但"**可观测 ⟺ 存在稳定束缚结构与之耦合**"这一跨域等价**未被机器证明**。它在场论侧（束缚本征值判据）与范畴侧（P_{V_Λ}D(f)=0 投影判据）之间架桥，是本证明唯一的非框架导出环节。
- 理由（模型化支持）：物理学中"维度的可观测性"由能否存在与探测对象发生耦合的稳定载体定义。静默有两种来源——**弱耦合**（有载体但振幅低于阈值 c₂，偶发不可见）与**无载体/坍缩**（d≥4 造不出稳定束缚态，结构性不可见）；坍缩是更强的不可见：不仅看不见，连可耦合的对象都不存在。此区分即用户"探测=耦合"直觉的形式化。

## 五、充要定理 T2：坍缩不稳定性 ⟺ 静默（在 B1 下）

**定理 T2**：设框架中可见时空为 1+3 维，额外 4 个类空维为 Cl(0,4) 扇区（静默）。在公设 B1 下：

> **静默 ⟺ 坍缩不稳定性**。即：四个额外类空维的静默，与 d ≥ 4 的坍缩不稳定互为充要；坍缩不稳定性是静默的**直接结构性因素**。

**证明**：

**(⟹) 坍缩不稳定 ⇒ 静默**（用户的直接因素）：
设某一额外类空维 X 并入可见空间后维数 d ≥ 4。由 T1，d ≥ 4 时无稳定束缚态（d=4 常规设定坍缩；d≥5 必然坍缩）。由 B1，无稳定束缚态 ⟹ X 不可观测 ⟹ X 静默。∎

**(⟸) 静默 ⇒ 坍缩不稳定**：
设 X 静默（不可观测）。由 B1，不可观测 ⟹ X 不承载稳定束缚态。反设 X 并入可见空间后 d ≤ 3（可稳定承载束缚态）：则 d ≤ 3 且整数，结合框架下界 d ≥ e ⟹ d = 3，即 X 就是三个可见空间维之一，与"额外"矛盾。故 X 并入后 d ≥ 4；由 T1，d ≥ 4 ⟹ 坍缩不稳定。∎

**合并**：静默维必坍缩不稳定（若被激活到可见阈值），坍缩不稳定维必静默。等价链条为

> **静默 ⟺ d_visible = 3 ⟺ S(3)（束缚稳定）⟺ 不坍缩（束缚稳定）**。

用户直觉成立，且从"并列巧合"被提升为**充要关系**。∎
