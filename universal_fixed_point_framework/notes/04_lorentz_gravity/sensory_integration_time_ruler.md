## 1. 核心命题

> **人类对空间和时间的感知，不是对绝对时空的被动接收，而是对身体所受力/加速度的主动积分与建模。感官在时间上的积分自然形成时间标尺；感官强化导致积分采样更密集，主观时间相应膨胀。**

这个命题包含四个递进环节：
1. **力的检测**：前庭、本体觉、触觉等感官系统检测的是力和加速度（偏转驱动），而非"空间"或"时间"本身；
2. **时间积分**：神经系统对力信号做时间积分，依次得到动量（偏转状态）、位移（空间位置）、能量（偏转代价）；
3. **标尺形成**：积分操作本身需要并定义了时间维度——积分的累积深度就是主观时间感；
4. **采样密度**：感官强化（唤醒度↑、注意力↑）提高有效采样率，单位物理时间内积分更多事件，主观时间膨胀。

## 2. 力的感官检测：双法向偏转的生物实现

### 2.1 前庭系统=双法向偏转检测器

力笔记§4+§9.6建立的双法向框架：

| 偏转方向 | 物理含义 | 笔记定位 |
|:--|:--|:--|
| 切向扬起 θ_i | 惯性/运动学加速 | force笔记§4 惯性"力"=切向偏转推动 |
| 径向扬起 θ_g | 引力/几何场梯度 | force笔记§4 引力=径向时间倾斜场（非力） |
| θ_i = θ_g | 等效原理 | force笔记§9.6 转盘上精确成立（任意β） |

人体前庭系统恰好是**双通道**的：

| 前庭器官 | 检测对象 | 对应偏转方向 |
|:--|:--|:--|
| **半规管**（3个正交环） | 角加速度（旋转） | 切向偏转的循环积累→force笔记§9.6 离心/科里奥利 |
| **耳石器**（椭圆囊+球囊） | 线加速度+重力方向 | 径向偏转（引力θ_g）+线加速度（惯性θ_i） |

**关键对应[论文]**：耳石器无法区分重力和加速度——这是**等效原理的生物实现**。电梯加速上升时感到"变重"，与在引力更强的星球上感到"变重"，耳石器给出完全相同的信号。这在力笔记中就是θ_i=θ_g（§9.6精确等式）的感官实例。

**结论[衔接]**：前庭系统本质上是一个**双法向偏转检测器**，它不直接检测"空间"或"时间"，而是检测**时间轴的偏转速率**（加速度=速度变化率=偏转角θ的变化率）。大脑在此基础上建构出"我在运动""我在倾斜""上下方向"等空间判断。

### 2.2 本体感觉+触觉=力的关系本体论

力笔记§5提出"力=关系而非实体"（Yoneda读法），§2给出F=m·secθ·φ̇。

人体本体感觉（肌梭检测肌肉长度变化、高尔基腱器官检测肌张力）和触觉（机械感受器检测压力/剪切力），本质上检测的是**身体与环境之间的相互作用关系**：

- 伸手触摸桌面：感知法向压力（径向偏转的抵抗）和剪切摩擦力（切向偏转的抵抗）；
- 举起重物：感知肌张力=克服引力径向偏转所需的驱动=F=m·secθ·φ̇；
- 判断物体"在那里"：依赖运动意图与感官反馈的匹配（传出副本efference copy+本体反馈），是**关系性建构**而非对绝对空间的被动接收。

这与力笔记§5"力是态射（两对象间），不是单对象属性"在哲学上一致：**空间感来自身体与环境的力性关系网络**。

### 2.3 视觉的间接性

视觉不直接检测力，但通过光流（optic flow）间接编码运动和加速度。视网膜上的光流模式→MT/V5区运动检测→前庭-视觉整合（颞上回内侧MST）。视觉提供的是**偏转状态的远程估计**，与前庭的直接检测形成互补。

## 3. 时间积分的三层结构

### 3.1 第一层：力的积分=动量（偏转状态）

力笔记§2：$F = \frac{dp}{dt} = m\sec\theta\,\dot\varphi$，积分得

$$p(t) = p(0) + \int_0^t F(\tau)\,d\tau = m\tan\theta(t)$$

感官检测到的是F（偏转速率），神经系统积分后得到p（偏转状态θ）。

**神经实现[论文]**：前庭-脊髓反射的三级积分器链——半规管检测角加速度→脑干积分器积分得角速度→再积分得角度。这是经典神经科学的"速度存储"（velocity storage）机制。

### 3.2 第二层：动量的积分=位移（空间位置）

$$x(t) = x(0) + \int_0^t v(\tau)\,d\tau = x(0) + \int_0^t \frac{p(\tau)}{m}\,d\tau$$

对偏转状态θ的积分得到空间位置x。这就是**空间感的运动学起源**：空间不是被直接感知的，而是通过对速度（偏转状态）的积分建构出来的。

**神经实现[论文]**：海马体位置细胞、内嗅皮层网格细胞对空间位置的编码，本质上是对自我运动信号（本体觉+前庭+视觉流）的路径积分（path integration）结果。

### 3.3 第三层：功率的积分=能量（偏转代价）

力笔记§3.1a（[衔接]级，推导链严格）：

$$\frac{d\lambda}{dt} = F\cdot v = \frac{dE}{dt} \quad \Longrightarrow \quad E(t) = E(0) + \int_0^t F(\tau)\cdot v(\tau)\,d\tau$$

神经系统的膜电位、突触权重、钙浓度，全都是对输入电流/信号的时间积分。在谱流语言下，这些是**谱特征值对驱动功率的累积**。

**UFPF侧[衔接]**：谱流方程$dA_t/dt=[G,A_t]$本身就是关于时间的微分方程。神经系统作为Rec范畴中的复杂对象，其内部状态$A_{\text{neural}}(t)$的演化就是对外部驱动$[G_{\text{ext}}, A_{\text{neural}}]$的积分响应。

## 4. 采样密度与主观时间

### 4.1 核心公式

$$t_{\text{主观}} \propto N_{\text{采样}} = \int_0^{t_{\text{物理}}} r_{\text{采样}}(\tau)\,d\tau$$

其中$r_{\text{采样}}$是有效采样率，与感官驱动强度$\|[G,A]\|$正相关。当$r_{\text{采样}}$升高时，同样的物理时间对应更多的采样计数，主观体验就是"时间变慢"。

### 4.2 采样密度的神经机制[论文]

| 机制 | 采样率变化 | 对应生理 |
|:--|:--|:--|
| 唤醒度↑（肾上腺素/去甲肾上腺素） | 神经元放电率↑、不应期缩短 | 蓝斑-去甲肾上腺素系统 |
| 注意力↑ | 相关集群同步性↑、信噪比↑ | 丘脑网状核门控 |
| 新异刺激↑ | 预测误差↑、编码事件数↑ | 多巴胺奖赏预测误差 |
| 神经可塑性↓（衰老/重复） | 放电率↓、新异编码↓ | 皮层萎缩、突触密度降低 |

### 4.3 三类已知现象的统一解释

| 场景 | 采样率变化 | 信息增量 | 主观体验 |
|:--|:--|:--|:--|
| 恐惧/紧急 | ↑↑（放电率+记忆编码双增强） | 高 | 慢动作、时间膨胀 |
| 专注/心流 | ↑（同步性高） | 低（可预测→预测编码压缩） | 时间飞逝 |
| 衰老/重复 | ↓ | 低 | 时间变快 |

**关键洞察[衔接]**：决定主观时间长度的不是单纯的采样率，而是**采样密度×信息增量**。高采样率+高信息增量=时间膨胀（恐惧场景）；高采样率+低信息增量=时间压缩（心流/重复）；低采样率+低信息增量=时间飞逝（衰老）。

### 4.4 谱流 toy model：双因子公式的数值实现（v0.3新增）

将神经系统建模为一个有限维谱对象 $A(t)\in\mathrm{Herm}(d)$，其演化由谱流方程支配：

$$\frac{dA}{dt} = [G_{\text{ext}}(t), A] + [G_{\text{int}}, A] + \kappa(t)\bigl(\mathcal{D}(A) - A\bigr).$$

- $G_{\text{ext}}(t)$：外部刺激驱动的谱生成元（对应前庭/本体觉/视觉输入）；
- $G_{\text{int}}$：内部记忆/自我模型的固定谱生成元；
- $\kappa(t)$：采样/测量强度，与唤醒度、注意力正相关；
- $\mathcal{D}(A)=\sum_i P_iAP_i$：固定基下的对角化投影（paper10 M2 测量操作）。

**主观时间的两种计算方式**：

| 模型 | 公式 | UFPF 对应 | 与 §4.3 双因子关系 |
|:--|:--|:--|:--|
| 采样计数模型 | $t_{\text{主观}}^{(\kappa)} = \int_0^t \kappa(\tau)\,d\tau$ | 原始比例式 §4.1 | 仅反映采样密度 |
| **谱熵模型** | $t_{\text{主观}}^{(S)} = \int_0^t \frac{dS_{\mathcal{B}}}{d\tau}\,d\tau = \Delta S_{\mathcal{B}}$ | **paper7 固定基谱熵** | 信息增量 $\approx \dfrac{dS_{\mathcal{B}}/dt}{\kappa(t)}$；主观时间 = 采样密度 × 信息增量 |

其中 $S_{\mathcal{B}}(A)=-\sum_i p_i\log p_i$ 为 paper7 定义的固定基谱熵，$p_i=|\langle e_i|A|e_i\rangle|^2/\sum_j|\langle e_j|A|e_j\rangle|^2$。

|:--|:--|:--|:--|

### 4.5 多通道竞争与感知整合：McGurk、视觉-前庭冲突与通道主导（v0.4新增）

§4.4 是单通道 toy model。真实感知系统同时接收视觉、前庭、本体觉、听觉等多路输入，这些输入既竞争又整合。本节用谱流竞争模型演示三种经典的多通道整合现象。

**模型扩展**：全局神经状态 $A(t)$ 受 $N$ 个通道共同牵引：

$$\frac{dA}{dt} = [G_{\text{int}}, A] + \sum_{i=1}^N w_i(t)\,s_i(t)\,(\rho_i - A) + \kappa(t)\bigl(\mathcal{D}(A)-A\bigr).$$

- $\rho_i$：通道 $i$ 的目标谱对象（如 /ba/、/ga/ 的听觉-视觉原型，或"前进"/"静止"的运动原型）；
- $s_i(t)$：通道 $i$ 的刺激强度；
- $w_i(t)$：基于"惊讶度"$\|\rho_i-A\|_{HS}$ 的 softmax 竞争权重；
- $\kappa(t)$：全局测量强度，保证系统坍缩到确定知觉态。

**竞争权重**：

$$w_i(t) = \frac{e^{\beta\,s_i(t)\|\rho_i-A(t)\|_{HS}}}{\sum_j e^{\beta\,s_j(t)\|\rho_j-A(t)\|_{HS}}}.$$

偏差越大 → 惊讶度越高 → 权重越大。这实现了**预测误差驱动的通道竞争**——与预测编码的"预测误差越大，该通道越被采信"一致。

**数值脚本**：`scripts/paperX_multichannel_sensory_time_ruler.py` 实现四类场景（dim=8）：

| 场景 | 通道输入 | 预期结果 | 认知现象 |
|:--|:--|:--|:--|
| 听觉主导 | 听觉 /ba/ 强、视觉 /ga/ 弱 | $A\to\rho_{\text{ba}}$ | 无冲突时主导通道决定知觉 |
| 视觉主导 | 听觉 /ba/ 弱、视觉 /ga/ 强 | $A\to\rho_{\text{ga}}$ | 视觉占优（McGurk 的反向控制） |
| McGurk 融合 | 听觉 /ba/ + 视觉 /ga/ 均强 | $A\to\rho_{\text{da}}$（融合态） | 冲突门控激活第三目标态 |
| 视觉-前庭冲突 | 视觉"前进" + 前庭"静止"均强 | $A$ 在 $\rho_{\text{forward}}$ 与 $\rho_{\text{stationary}}$ 之间高熵拉锯 | 运动不适/眩晕的谱流对应 |

**与 UFPF 结构的对应[衔接]**：
- **M1 谱投影态射**：每个感受器阵列 = 一个测量基；多通道 = 多个测量基的叠加；
- **M2 测量谱流方程**：$\kappa(t)(\mathcal{D}(A)-A)$ 保证系统坍缩到某一知觉分支；
- **M3/M4 分支选择**：McGurk 中 /da/ 激活 = 一个原本不占优的谱分支被竞争权重提升；视觉-前庭冲突 = 两个分支权重拉锯，对应不稳定知觉或多稳态切换。

### 4.6 与预测编码（Predictive Coding）框架的交叉（v0.5新增）

预测编码（Rao & Ballard, 1999; Friston, 2005）的核心命题是：大脑不是被动接收感觉输入，而是用层级生成模型产生**自上而下的预测**，并通过最小化**精度加权预测误差**（precision-weighted prediction error）来更新内部信念。本节给出 UFPF 谱流语言下的对应映射。

**核心对应[衔接]**：

| 预测编码 | UFPF 谱流对应 | 笔记位置 |
|:--|:--|:--|
| 层级生成模型 | 内部谱对象 $A_{\text{model}}$ 与生成元 $G_{\text{int}}$ | §5.2、§5.4 第三层 |
| 自上而下预测 | $G_{\text{int}}$ 在 $A$ 上诱导的演化 $[G_{\text{int}}, A]$ | §4.4 |
| 自下而上预测误差 | 外部驱动与内部预测的偏差，$\varepsilon(t) = \|\rho_{\text{ext}} - A(t)\|_{HS}$ 或 $\|[G_{\text{ext}} - G_{\text{int}}, A]\|_{HS}$ | §4.4、§4.5 |
| 精度（precision） | 采样强度 $\kappa(t)$ 与通道竞争权重 $w_i(t)$ | §4.1、§4.5 |
| 精度加权更新 | $dA/dt$ 中 $w_i(t)s_i(t)(\rho_i - A)$ 项 | §4.5 |
| 自由能/变分自由能 | 固定基谱熵 $S_{\mathcal{B}}(A)$ 与累积熵增 $\Delta S_{\mathcal{B}}$ | §4.4、§5.5 |
| 自由能最小化 | 测量项 $\kappa(\mathcal{D}(A)-A)$ 驱动系统坍缩到低熵确定态，同时外部驱动保持与输入一致 | §4.4 |

**主观时间的预测编码解释**：

在预测编码框架中，**新异刺激 = 大预测误差 = 高精度加权 = 快速信念更新**；**可预测刺激 = 小预测误差 = 低精度加权 = 慢速更新**。这与 §4.3 的"采样密度×信息增量"双因子模型精确对应：

| 场景 | 预测编码语言 | 谱流语言 | 主观时间 |
|:--|:--|:--|:--|
| 恐惧/紧急 | 大预测误差、高精度 | 高 $\kappa$、高 $dS_{\mathcal{B}}/dt$ | 膨胀 |
| 专注/心流 | 小预测误差（预测被验证）、高精度但低误差 | 高 $\kappa$、低 $dS_{\mathcal{B}}/dt$ | 压缩 |
| 衰老/重复 | 小预测误差、低精度（信号被忽略） | 低 $\kappa$、低 $dS_{\mathcal{B}}/dt$ | 飞逝 |

因此，§4.4 的谱熵模型 $t_{\text{主观}}^{(S)}=\Delta S_{\mathcal{B}}$ 可重述为：

> **主观时间增量 = 精度加权预测误差的累积解决量**。

**多通道竞争即精度仲裁**：§4.5 的权重

$$w_i(t)=\frac{e^{\beta s_i(t)\|\rho_i-A(t)\|_{HS}}}{\sum_j e^{\beta s_j(t)\|\rho_j-A(t)\|_{HS}}}$$

正是预测编码中**精度加权预测误差仲裁**的谱流实现：
- McGurk 融合：听觉 /ba/ 与视觉 /ga/ 均产生大预测误差，且精度相近，系统无法直接用单一通道解释输入，于是调用更高层生成模型产生融合知觉 /da/；
- 视觉-前庭冲突：两个通道预测误差相当但相互排斥，精度仲裁在两者之间拉锯，对应不稳定知觉/运动不适；
- 通道主导：某一通道预测误差显著更大（或精度更高），该通道赢得仲裁。

**与 Active Inference 的延伸[衔接]**：主动推断（Friston et al., 2017）进一步把预测误差最小化推广到动作——系统通过运动/注意选择来改变 $G_{\text{ext}}$，使外部输入匹配内部预测。在 UFPF 语言下，这对应**通过改变谱交织器 $T$ 或外部生成元 $G_{\text{ext}}$ 来降低 $[G_{\text{ext}}, A]$ 的对易子范数**。注意：本笔记不展开动作侧，仅登记概念映射。

**诚实边界**：本映射为框架内语言翻译，不是对预测编码的数学等价证明；$S_{\mathcal{B}}$ 与变分自由能的精确对应关系（如 KL 项的符号、能量项与熵项的分离）尚未严格推导，[衔接]级。

### 4.7 变分自由能与通道选择：softmax 权重的推导（v0.8新增）

§4.5 的通道竞争权重采用 softmax 形式，本节给出其变分/自由能最小化解释，把预测编码中的"精度加权预测误差"落到可计算的谱流结构上。

**变分自由能泛函**：给定 $N$ 个通道，其信息贡献（预测误差代理）为

$$\varepsilon_i(t) = s_i(t)\|\rho_i - A(t)\|_{HS},$$

定义关于权重向量 $\mathbf{w}$ 的变分自由能

$$\mathcal{F}(\mathbf{w}; \boldsymbol{\varepsilon}, \beta) = -\sum_{i=1}^N w_i\,\varepsilon_i + \frac{1}{\beta}\sum_{i=1}^N w_i\log w_i,$$

约束条件为 $\sum_i w_i = 1$，$w_i\ge 0$。

**物理意义[衔接]**：
- 第一项 $-\sum_i w_i\varepsilon_i$：负的期望预测误差，最小化 $\mathcal{F}$ 等价于让系统优先采信预测误差大的通道（最"惊讶"的信息源）；
- 第二项 $\frac{1}{\beta}\sum_i w_i\log w_i$：熵正则项，权重分布的 Shannon 熵乘以 $1/\beta$；防止系统退化为只采信单一通道（ winner-take-all 的极端情况）。

**命题 4.1[衔接/可数值验证]**：在上述约束下，$\mathcal{F}$ 的唯一极小点为

$$w_i^* = \frac{\exp(\beta\,\varepsilon_i)}{\sum_j \exp(\beta\,\varepsilon_j)}.$$

**推导简述**：引入 Lagrange 乘子 $\lambda$ 处理归一化约束，

$$\mathcal{L}(\mathbf{w},\lambda) = -\sum_i w_i\varepsilon_i + \frac{1}{\beta}\sum_i w_i\log w_i - \lambda\left(\sum_i w_i - 1\right).$$

对 $w_i$ 求偏导并令其为零：

$$\frac{\partial\mathcal{L}}{\partial w_i} = -\varepsilon_i + \frac{1}{\beta}(\log w_i + 1) - \lambda = 0.$$

解得

$$\log w_i = \beta(\varepsilon_i + \lambda) - 1,$$

归一化后即为 softmax 形式。

**与预测编码术语的对应**：
- $\varepsilon_i$ 对应**预测误差**（通道 $i$ 的目标态与当前状态的偏差）；
- $\beta$ 对应**精度**（precision）——$\beta$ 越大，熵正则越弱，系统越倾向于采信最大预测误差的通道；
- $w_i^*$ 对应**精度加权预测误差的仲裁结果**。

**数值验证**：`scripts/paperX_multichannel_sensory_time_ruler.py` 的自检模块比较了 softmax 权重、均匀权重与随机权重的自由能：

```
变分自由能：softmax=-0.6054 < random=-0.5908 < uniform=-0.4644
```

softmax 权重确实给出更低（更优）的变分自由能。

**β 扫描实验**：脚本 `scripts/paperX_beta_sweep.py` 固定三组预测误差向量，扫描 $\beta\in[10^{-2},10^2]$，输出 `figs/paperX_beta_sweep.png`。实验显示：低 β 时权重趋于均匀，高 β 时趋于 winner-take-all。详见 §10.A.7。

**完整推导与文献对照**：§4.7 的推导在 §10.A.8 中以附录形式独立重述，并给出与 Rao & Ballard (1999)、Friston (2005, 2010)、Spratling (2008)、Friston et al. (2017) 等预测编码/active inference 文献的术语对照表。

**诚实边界**：命题 4.1 是约束凸优化问题的标准结果，推导本身为[论文]/数学常识；将其解释为"预测编码中精度加权预测误差的谱流实现"为[衔接]。该泛函 $\mathcal{F}$ 与 Friston 变分自由能在形式上有相似，但未建立与 KL 散度、模型证据的严格等价。

### 4.8 主动推断：动作作为谱流预测误差的降低过程（v0.10新增）

§4.6/§4.7 讨论了被动感知中的预测误差最小化。预测编码的进一步延伸是**主动推断（active inference）**：系统不仅通过更新内部信念来匹配感觉输入，还可以通过**动作改变外部输入本身**，使外部世界更符合内部预测。本节给出一个可计算的谱流 toy model。

**模型设定**：设外部目标态可由动作参数 $\alpha(t)$ 调节：

$$\rho_{\text{ext}}(\alpha) = \alpha\,\rho_{\text{forward}} + (1-\alpha)\,\rho_{\text{desired}}.$$

- $\alpha=1$：外部目标为"前进"；
- $\alpha=0$：外部目标为"静止"（与内部预测一致）；
- $\alpha(t)$ 随时间演化，以降低预测误差 $F(A,\alpha)=\|\rho_{\text{desired}}-A\|_{HS}$。

**谱流方程**：

$$\frac{dA}{dt} = [G_{\text{ext}}, A] + [G_{\text{int}}, A] + \kappa\bigl(\mathcal{D}(A)-A\bigr) + s_{\text{ext}}\bigl(\rho_{\text{ext}}(\alpha)-A\bigr),$$

$$\frac{d\alpha}{dt} = -\gamma\,\frac{\partial F}{\partial\alpha}.$$

- $s_{\text{ext}}$：外部目标牵引强度；
- $\gamma$：动作学习率；
- 预测误差对 α 的梯度用短视域有限差分数值估计。

**数值脚本**：[`scripts/paperX_active_inference.py`](file:///e:/workspace/hyper-resolution/universal_fixed_point_framework/scripts/paperX_active_inference.py)

**场景**：视觉-前庭冲突的主动解决
- 初始：外部目标为"前进"（$\alpha=1$），内部预测为"静止"（$\rho_{\text{desired}}=\rho_{\text{stationary}}$），两者冲突；
- 主动推断：系统通过降低 $\alpha$，使外部目标从"前进"滑向"静止"，减少冲突；
- 被动对照：$\alpha$ 固定为 1，系统只能被动承受高预测误差。

**运行结果**（dim=6，t∈[0,8]，γ=1.0，s_ext=1.5）：

| 模式 | α 终点 | 预测误差终点 | 解释 |
|:--|:--:|:--:|:--|
| 主动推断 | 0.660 | 0.740 | 动作降低 α，预测误差显著下降 |
| 被动对照 | 1.000 | 0.845 | 无动作，预测误差保持高位 |

**结果图示**：`figs/paperX_active_inference.png`

![主动推断 toy model：动作参数 α、预测误差、总代价随时间演化](../../figs/paperX_active_inference.png)

**与 UFPF 结构的对应[衔接]**：
- 动作 = 改变谱交织器 $T$ 或外部生成元 $G_{\text{ext}}$，以降低对易子范数 $\|[G_{\text{ext}}, A]\|$；
- 主动推断 = 在 Rec/Sp 范畴中通过改变对象间的态射（动作）来降低伴随谱流的不确定性；
- 这一映射与 §5.4 第三层"自指不动点"形成对照：被动感知是内部不动点的调整，主动推断是对外部-内部关系的同时调节。

**诚实边界**：本 toy model 中"动作"被简化为标量参数 α 的学习，不对应具体运动神经控制；梯度估计为数值近似，非解析推导；主动推断与运动控制的完整对应需要更精细的运动学/动力学模型，不在本笔记范围内。

### 4.9 层级预测编码：自上而下预测与自下而上误差的谱流实现（v0.11新增）

§4.6/§4.7/§4.8 主要处理单一层面的预测编码与主动推断。真实皮层网络是**层级结构**：低层感觉区（V1/MT/前庭核）处理原始感觉输入，高层联合区（IT/颞上回/前额叶）提供更抽象的预测，并通过反馈通路自上而下抑制低层预测误差。本节把这一结构实现为两层谱流网络。

**两层谱流方程**：

- **L1（感觉层）**：

$$\frac{dA_1}{dt} = [G_{\text{ext}}, A_1] + [G_{\text{int}}^{(1)}, A_1] + \kappa\bigl(\mathcal{D}(A_1)-A_1\bigr) + s_{\text{ext}}(\rho_{\text{ext}}-A_1) + s_{\text{pred}}(A_2-A_1).$$

- **L2（预测/关联层）**：

$$\frac{dA_2}{dt} = [G_{\text{int}}^{(2)}, A_2] + \kappa\bigl(\mathcal{D}(A_2)-A_2\bigr) + s_{\text{err}}(A_1-A_2) + s_{\text{prior}}(\rho_{\text{prior}}-A_2).$$

**参数含义**：
- $s_{\text{ext}}$：外部输入强度（自下而上）；
- $s_{\text{pred}}$：自上而下预测强度；

## 5. UFPF本体论定位

### 5.1 时间不是外部参数，是谱流的内在维度

谱流方程（paper5 §2）：

$$\frac{d}{dt}A_t = [G, A_t]$$

这里的$t$不是外部绝对时间，而是**谱流演化的内在参数**。一个积分器系统（神经元膜电位$dV/dt=I/C$）的物理实现本身就要求一个"时间维度"——而这个时间维度是通过**持续的积分-泄漏平衡**来标定的。

**本体论推论[衔接]**：不是"时间在流逝，感官在积分"，而是"感官在持续积分，积分的累积深度就是时间感"。这与paper34连续极限B2（"分形集，但宏观不可区分于光滑流形"）和paper35（引力=范畴结构条件，非动力学力）在本体论上一致——**时间不是基底，是谱流动力学的涌现**。

### 5.2 感知=谱流的自检测

如果一切物理对象都是Rec/Sp范畴中的谱像（paper1核心框架），那么感知系统作为物理对象，其"检测力"的行为就是**谱对象之间的对易子耦合被神经系统内部的谱流所表征**。

这不是隐喻，是UFPF框架内的必然推论[衔接]：
- 外部世界 = Rec对象$R_{\text{ext}}$，谱像$A_{\text{ext}}=D(R_{\text{ext}})$
- 感官系统 = Rec对象$R_{\text{sense}}$，谱像$A_{\text{sense}}$
- 感官检测 = 谱交织$A_{\text{sense}}\cdot T = T\cdot A_{\text{ext}}$（paper18 §5.1谱交织条件的感知侧实例）
- 神经积分 = $A_{\text{neural}}(t)$对$[G_{\text{ext}}, A_{\text{neural}}]$的累积响应
- 时空表征 = 积分器输出的稳态/周期模式

### 5.3 与"时空涌现"的一致性

paper34 §5.3a推论：宏观尺度$\ell\gg333$ Planck单位下，分形吸引子与光滑流形不可区分。感知系统运作在宏观尺度（神经元~10μm，时间~ms），远大于Planck尺度，因此其建构的时空感与经典连续时空不可区分——这解释了为什么我们的主观时空感是连续的，即使底层是离散谱结构。

### 5.4 人为何能感知识别时空：四层物理解释（v0.2新增）

> **核心命题**：人能感知识别时空，因为人本身就是时空谱流的一个自指性子系统——其内部谱流与外部宇宙谱流共享同一套范畴结构（D⊣R伴随的普遍性），并通过不动点构造实现了对自身和环境的表征。

这是UFPF框架的逻辑必然推论[衔接]，分四层展开：

#### 第一层：耦合——为何能获取外部时空信息

任何感知的第一步是系统与环境的物理耦合（光子打在视网膜、空气振动传到耳蜗、重力牵拉耳石器）。

**UFPF语言**（paper1 §2.3 + paper18 §5.1）：感知系统$R_{\text{sense}}$与外部世界$R_{\text{ext}}$之间存在**谱交织条件**：

$$A_{\text{sense}} \cdot T = T \cdot A_{\text{ext}}$$

其中$T$是谱交织算子（感官的物理实现：视网膜=光子能量→神经电信号的谱交织器；耳石器=重力/加速度→毛细胞偏转的谱交织器）。

**物理意义**：外部谱对象$A_{\text{ext}}$的结构信息，通过$T$被保形地映射到内部谱对象$A_{\text{sense}}$上。交织算子$T$由感官的物理结构决定（晶状体焦距、耳蜗机械特性、半规管几何），而这些结构本身就是演化选择出的、能最大化信息保真度的谱交织器。

**与 paper10 测量公理的对接[衔接]**：paper10 的谱测量公理 M1–M4 为"感知 = 谱交织"提供了动力学补全：
- **M1 谱投影态射**：视网膜感光阵列、耳蜗频率拓扑、体感皮层柱状结构等可视为自然选择的测量基$\{P_i\}$——每个感受器对应一个谱投影；
- **M2 谱流测量方程**：神经积分器对感觉输入的"坍缩"/稳定化过程，正是 $dA/dt=[A_{\text{int}},A]+\kappa(\mathcal{D}(A)-A)$ 在感知侧的实现，其中 $\kappa$ 对应唤醒度/注意力；
- **M3 Born 规则/函子权重**：不同感觉通道的相对显著性（如视觉占优 vs. 前庭占优）可用谱权重 $\omega(P_i)=\mathrm{Tr}(P_i\rho P_i)$ 描述；
- **M4 分支选择**：多稳态知觉（如 Necker 立方体翻转、双关图形切换）对应多个谱分支的拓扑权重竞争，$i^*=\arg\max_i w(\lambda_i)$。

**空间信息可获取的原因**：空间分布对应谱对象在三维截面上的投影模式（paper34连续极限）。视网膜的二维感光阵列=对外部光场空间分布的二维谱投影；视觉皮层的retinotopic mapping=保持空间拓扑的谱交织。

**结论[衔接]**：感知的可能性根植于**谱交织的保结构性**——如果$T$是忠实函子（paper1定理2.3.4，universal kernel点分离保证），外部谱结构的全部可观测信息都能被内部表征获取。

#### 第二层：积分与记忆——为何能形成时间标尺

瞬时信号本身不构成"感知"。感知需要时间积分——膜电位对电流的积分、突触权重对放电历史的积分、海马体对事件序列的编码。

**UFPF语言**（paper5 §2谱流方程 + 本笔记§3）：神经系统的内部状态$A_{\text{neural}}(t)$满足谱流方程：

$$\frac{d}{dt}A_{\text{neural}} = [G_{\text{ext}}, A_{\text{neural}}] + [G_{\text{int}}, A_{\text{neural}}]$$

- $[G_{\text{ext}}, A_{\text{neural}}]$ = 外部驱动（感官输入）
- $[G_{\text{int}}, A_{\text{neural}}]$ = 内部动力学（记忆、预测、自发活动）

积分形式：

$$A_{\text{neural}}(t) = A_{\text{neural}}(0) + \int_0^t [G_{\text{ext}}(\tau) + G_{\text{int}}(\tau), A_{\text{neural}}(\tau)]\,d\tau$$

这个积分**就是**时间感的物理实现：
- 积分的累积深度 = 主观时间长度
- 积分核的时间常数（膜时间常数~10ms、突触时间常数~100ms、工作记忆~秒）= 时间标尺的刻度
- 不同时间尺度的积分器并行工作 = 多尺度时间感知

**关键[衔接]**：积分操作本身定义了时间维度。不是"先有时间，再积分"，而是"持续的积分-泄漏动力学**就是**时间的局部实现"。电容$dV/dt=I/C$不需要外部时钟——它的充放电曲线本身就是时间的度量。

#### 第三层：不动点与自指——为何能"识别"而非仅仅"反应"

恒温器也能对温度做出反应（耦合+积分），但我们不说它"感知"温度。区别在于：感知系统包含**对自身状态的表征**——它不仅积分外部信号，还积分"自己正在积分"这个事实。这是自指（self-reference）结构。

**UFPF语言**（paper1核心框架，不动点范畴）：Rec范畴中的**不动点**满足$R = F(R)$，即递归系统的输出等于输入。生命系统/神经系统可以理解为一种**高阶不动点构造**：

$$A_{\text{neural}} \supset A_{\text{model}}(A_{\text{ext}}, A_{\text{neural}})$$

即内部谱对象$A_{\text{neural}}$包含一个子模型$A_{\text{model}}$，这个子模型同时表征了外部世界$A_{\text{ext}}$和系统自身$A_{\text{neural}}$。这就是**自指**——系统的内部状态包含了对自身状态的描述。

**为何这对时空识别是必要的[衔接]**：
- 要识别"空间"，系统需要知道"我的身体在空间中的位置"——这需要对自身的空间表征（本体觉+前庭整合为身体图式）；
- 要识别"时间"，系统需要知道"我之前的状态是什么"——这需要对自身历史的表征（记忆）；
- 没有自指，系统只能对当前刺激做出反应（如恒温器），不能形成"我在时空中"的识别。

**不动点的稳定性[衔接]**：自指结构容易导致悖论（说谎者悖论），但物理系统通过**耗散和饱和**避免了这一点——神经元的放电率有上限、膜电位有阈值、突触权重有边界。这些非线性约束使自指谱流收敛到稳定的不动点，而非发散。这就是生命系统作为"耗散结构"的物理本质。

#### 第四层：伴随函子的普遍性——为何内部表征能匹配外部实在

即使内部有表征，为何这个表征**足够准确**，能让我们在时空中有效行动？

**UFPF答案**（paper1 §2.4，D⊣R伴随）：谱化伴随$D \dashv R$是一个**普遍性构造**——它不依赖于具体系统，对所有Rec对象成立：

$$\mathrm{Hom}_{\mathbf{Sp}}(E, D(S)) \cong \mathrm{Hom}_{\mathbf{Rec}_D}(R(E), S)$$

这个自然同构保证了**内部谱表征与外部谱对象之间存在范畴论意义上的结构保持对应**。神经系统的内部模型不是任意的——它是外部谱结构通过$D$函子的忠实像，而$R$右伴随提供了从内部表征反向重构外部世界的路径。

演化选择的不是"正确的表征"，而是"能指导有效行动的表征"——而由于D⊣R的保结构性，这两者在可观测层面是一致的。

#### 四层汇总

| 层级 | 物理机制 | UFPF对应 | 解决的问题 |
|:--|:--|:--|:--|
| 耦合 | 感官与环境的能量/动量转移 | 谱交织$A_{\text{sense}}T=TA_{\text{ext}}$ | 为何能获取外部信息 |
| 积分 | 膜电位/突触/网络的时间累积 | 谱流方程的积分形式 | 为何能形成时间标尺 |
| 自指 | 内部模型包含自身表征 | Rec范畴不动点构造 | 为何能"识别"而非仅"反应" |
| 普遍性 | 演化选择+范畴保结构 | D⊣R伴随的自然同构 | 为何内部表征匹配外部实在 |

**结论[衔接]**：人能感知识别时空，不是因为有什么非物理的"意识之力"，而是因为：(1)物理定律允许谱交织（信息耦合）；(2)物理定律允许积分（记忆/时间）；(3)足够复杂的耗散系统可以形成自指不动点（自我模型）；(4)范畴结构保证了内部表征与外部实在的结构对应。这四者都是物理的，都在UFPF的描述范围内。

**诚实边界**：
- 这是**机制解释，不是意识解释**：上述解释了"感知的信息处理机制"，但没有解释"主观体验（qualia）为何存在"——这是意识的难问题，不在当前物理理论范围内，UFPF也不声称解决它；
- 自指/不动点部分是[衔接]级外推：UFPF的不动点构造（paper1）是数学层面的，将其应用于生命/感知系统是框架内的哲学延伸，没有专门的论文或数值验证；
- 定量缺口巨大：神经系统是$10^{11}$神经元的非平衡多体系统，UFPF当前的谱流方程在这个复杂度上不可解析求解。能做的是**本体论定位**和**机制翻译**，不是定量预测；
- 生命起源问题未解决：自指不动点如何从非生命物质中自发涌现，这是生命起源的核心问题，UFPF没有涉及。

### 5.5 与 paper7 谱熵的定量对接（v0.3新增）

**核心等式[衔接]**：将 §4.4 的谱熵模型与 paper7 的热力学第二定律对接，得到主观时间长度的谱热力学表达式：

$$t_{\text{主观}}^{(S)}(t) = \Delta S_{\mathcal{B}}(t) = S_{\mathcal{B}}(A_t) - S_{\mathcal{B}}(A_0),$$

其中 $S_{\mathcal{B}}$ 是 paper7 定义的固定基谱熵。

**意义**：
1. **热力学箭头**：由 paper7 定理 3.1，固定基谱熵在谱流下满足 $\Delta S_{\mathcal{B}} \ge 0$——主观时间的"流逝方向"与谱熵增方向一致；
2. **信息增量可测量化**：$dS_{\mathcal{B}}/dt$ 给出了 §4.3"信息增量"的谱流定义，不再只是信息论的直觉；
3. **唤醒度调制**：paper7 §8.2 指出熵增速率随有效噪声/驱动强度 $\eta$ 变化；在感知模型中，$\eta$ 与唤醒度/采样强度 $\kappa$ 对应——高唤醒 $\Rightarrow$ 高熵增率 $\Rightarrow$ 主观时间膨胀。

**诚实边界**：这是对主观时间现象学的谱语言重述，不是新物理预言；神经系统的实际熵产生估算需要具体的多体模型（$10^{11}$神经元），远超当前解析能力。

## 7. 可检验预测（经典层面）

以下预测不依赖UFPF谱结构，可在经典神经科学框架内检验：

1. **前庭-时间耦合预测**：前庭功能障碍患者的空间方向感和时间感知会同时受损，且损伤程度相关（已有部分临床证据，待系统量化）；
2. **旋转适应预测**：半规管疲劳（旋转适应）后，主观时间流速发生可测量偏差，方向与适应侧别相关；
3. **唤醒度-采样率预测**：通过药物（如可乐定降低去甲肾上腺素、莫达非尼提高唤醒度）调节采样率，主观时间感知应呈剂量依赖性变化；
4. **心流悖论预测**：高注意力但低信息增量的任务（如重复熟练操作）应导致时间压缩，而高注意力高信息增量的任务（如紧急避险）应导致时间膨胀——同一"高注意力"状态下因信息增量不同产生相反效应。

### 7.1 UFPF 谱层预言（v0.3新增；框架内，生物尺度不可直接观测）

以下预言是 UFPF 语言对同一经典现象的重述，给出结构约束但不预测与经典神经科学不同的数值：

5. **谱熵-主观时间比例预言**：若将神经系统视为固定基观测者，主观时间增量与固定基谱熵增量成正比，$\Delta t_{\text{主观}}\propto\Delta S_{\mathcal{B}}$。可探索的验证方向：用神经信号熵（LFP 模式熵、fMRI 空间模式熵）作为 $S_{\mathcal{B}}$ 代理，检验其与行为学主观时间估计的相关性；
6. **唤醒度-坍缩时间预言**：由 paper10，感知"坍缩"到稳定状态的时间 $\tau_{\text{collapse}}=\ln(1/\varepsilon)/\kappa$。高唤醒 $\kappa\uparrow$ 时，神经系统更快达到稳定知觉；该预言在经典层面表现为"高唤醒下决策/知觉形成时间缩短"，UFPF 贡献是对数阈值依赖 $\tau\propto\ln(1/\varepsilon)$；
7. **预测编码-谱熵减预言**：可预测/重复刺激降低有效外部驱动 $G_{\text{ext}}$ 的带宽，从而减少固定基谱熵产生率 $dS_{\mathcal{B}}/dt$，对应主观时间压缩。此预言与预测编码框架中的"预测误差=新信息量"直接对应（详见 §4.6）。

### 7.2 双法向结构的感知实验设计（v0.12新增）

以下实验可在经典神经科学/心理物理学框架内检验本笔记 §2 提出的"双法向偏转"结构是否对应人体前庭-本体觉系统的真实组织方式。这些实验**不依赖 UFPF 的谱量子化**，只检验力笔记 §4/§9.6 的双法向框架在生物感知层面是否自洽。

#### 实验 A：倾斜-平移不可区分性的心理物理阈值

**背景**：力笔记 §9.6 给出转盘上的精确等式 $\theta_i=\theta_g$（任意 $\beta$），即惯性偏转与引力偏转在等效意义下不可区分。人体耳石器已被经典实验证明无法区分重力与线性加速度（电梯效应、飞机弹射座椅错觉）。

**设计**：
1. 被试坐在六自由度运动平台上，头部固定；
2. 两种刺激：
   - **纯倾斜**：绕冠状轴缓慢倾斜头部，使重力分量在头部坐标系中变化；
   - **纯平移**：沿头部冠状轴线性加速/减速，产生等效重力分量变化；
3. 系统匹配两种刺激的峰值加速度（如 0.3 g），但被试不知道类型；
4. 让被试报告"感到倾斜"还是"感到平移"，测量正确率与置信度。

**双法向预测**：在低于前庭-视觉整合阈值的低速/低幅条件下，两种刺激的知觉报告应无法区分（正确率≈50%）。若双法向框架成立，则存在一个二维知觉空间：径向轴 = "重力/倾斜"，切向轴 = "惯性/平移"，二者在该阈值附近简并。

**对照**：若经典单矢量模型成立，被试应只报告"力的大小/方向"，而不区分倾斜/平移；该实验难以区分单矢量与双法向，但能确定"不可区分区"的边界。

#### 实验 B：双法向分解的复合运动知觉

**背景**：双法向框架把任意加速度分解为切向偏转 $\theta_i$（改变速度方向/大小）和径向偏转 $\theta_g$（改变时间轴倾斜）。前庭系统的半规管主要编码角加速度（切向偏转的循环累积），耳石器编码线加速度+重力（径向偏转）。

**设计**：
1. 被试在暗室中体验复合运动：同时施加绕垂直轴的恒定角加速度（半规管刺激）和沿某方向的线性加速度（耳石器刺激）；
2. 变化角加速度与线加速度的相对大小和相位，共 8–16 种组合；
3. 被试用操纵杆报告知觉到的"自身运动矢量"，包括方向与曲率。

**双法向预测**：知觉矢量应可被拟合为两个正交分量的线性组合——

$$\text{知觉运动} = a\cdot(\text{切向分量}) + b\cdot(\text{径向分量}),$$

且拟合残差显著小于单矢量模型（只用一个合力方向）的残差。若 $a/b$ 与被试的半规管/耳石器敏感度比值相关，则支持双通道独立编码后整合的假说。

**可操作性**：运动平台、暗室、操纵杆记录均为成熟技术；难点在于精确分离角加速度与线加速度对皮肤压力、本体觉的污染，需要座椅/头固定与颈部肌电监测。

#### 实验 C：本体觉-重力交互中的法向/切向分解

**背景**：力笔记 §2 给出 $F=m\sec\theta\,\dot\varphi$，把力解释为"时间轴偏转的驱动"。触觉/本体觉检测的是身体与环境之间的偏转关系（法向压力=径向抵抗，剪切摩擦力=切向抵抗）。

**设计**：
1. 被试用右手食指按压一块可倾斜的平板；
2. 平板在三种条件下提供相同的总反作用力：
   - 纯法向（垂直于指尖）；
   - 纯切向（平行于指尖皮肤）；
   - 法向+切向合成（与指尖成 45°）；
3. 被试报告"压力大小"，并用另一只手在比例尺上复现该力的大小；
4. 变化手指朝向与重力方向的关系（手掌向上/向下/水平）。

**双法向预测**：若本体觉把力分解为法向（径向偏转抵抗）和切向（切向偏转抵抗）分量，则纯法向与纯切向在相同总力大小下应给出不同的"主观强度"；且当手指朝向改变时，重力对径向分量的贡献应系统性地调制该主观强度。经典矢量模型预测总力大小相同则主观强度相同。

**可行性**：商用触觉力反馈装置可精确控制法向/切向力比例；已有大量文献研究皮肤力学感受器的方向选择性，本实验侧重中枢层面的整合规则。

### 7.3 关于 UFPF 量子/谱效应在生物尺度可观测性的评估与代理实验（v0.12新增）

#### 直接测量的不可行性

UFPF 框架给出的基本谱精度为 $\varepsilon^2\approx6.6\times10^{-33}$（见 force 笔记 §9.5）。任何依赖该参数的量子/谱修正，在神经元尺度（$\sim10\,\mu\text{m}$，$\sim\text{ms}$）上都远低于热噪声、离子通道噪声与量子退相干。因此：

> **当前 UFPF 形式下，不可能通过人体感官实验直接证明或证伪其底层的量子/谱离散化结构。**

#### 三类"有效量子化"代理实验

虽然不能直接测量 Planck 尺度的谱离散化，但神经系统确实存在**经典层面的离散化/量子化现象**。可以设计实验测量这些现象，并把结果作为 UFPF"谱流积分器"模型的**一致性检验**（consistency checks），而非 UFPF 专属预言：

**代理实验 1：时间知觉的 just-noticeable difference（JND）阶梯**

**设计**：用自适应阶梯法测量被试对短时长（50–500 ms）的 JND；在高唤醒与低唤醒两种状态下分别测量。

**代理含义**：若时间知觉由神经事件计数决定，JND 应随唤醒度变化。UFPF 谱流模型把这一关系表述为 $\Delta t_{\text{主观}}\propto\Delta S_{\mathcal{B}}$，其中 $S_{\mathcal{B}}$ 又依赖于有效采样率。实验可检验"唤醒度↑ → JND↓ → 主观时间膨胀"的相关性。

**诚实边界**：这是经典心理物理学，与 UFPF 量子结构无直接因果。

**代理实验 2：感知"量子化"阶梯——多稳态知觉的离散状态统计**

**设计**：呈现 Necker 立方体、运动竞争点等双稳态刺激，记录知觉反转时刻；用隐马尔可夫模型或贝叶斯推断拟合知觉状态的离散转移。

**代理含义**：UFPF 把知觉"坍缩"到稳态描述为谱流收敛到不动点。离散知觉状态可被视为谱对象在固定基测量下的准本征态。实验可测量：
- 状态停留时间的分布；
- 唤醒度/注意力对平均停留时间的影响；
- 状态转移的"全或无"程度。

**诚实边界**：双稳态是经典非线性神经动力学现象，离散化来自吸引子 Basin，不一定是基本谱离散化。

**代理实验 3：前庭-时间耦合的离散事件计数**

**设计**：在前庭刺激（恒定角加速度或离心）期间，要求被试进行时间复制任务；同时记录 EEG/MEG 的事件相关去同步化（ERD）或局部场电位熵。

**代理含义**：UFPF 预测前庭输入通过改变积分器增益而影响主观时间。若能在神经信号中找到可量化的"事件计数"代理（如 γ 波段爆发次数、信息熵增量），可检验其与主观时间估计的相关性。

**诚实边界**：这仍是经典神经编码与信息论问题，不涉及 Planck 尺度物理。

#### 能否在未来把代理实验升级为专属预言？

只有在 UFPF 框架内推导出如下形式的**定量修正**时，上述代理实验才可能变成专属预言：

$$\Delta t_{\text{主观}} = \Delta t_{\text{经典}} + \mathcal{O}(\varepsilon^2)\cdot f(\kappa, N_{\text{通道}}),$$

其中 $f$ 是与经典神经科学不同的函数形式。目前 $\varepsilon^2\sim10^{-33}$ 使得第二项完全不可测量；若未来 UFPF 的发展把有效谱精度提升（例如通过复杂系统的涌现放大），该评估需重新更新。

### 7.4 可能产生经典神经科学不可约正项的数学路径梳理（v0.13新增）

本节梳理 UFPF 框架内**理论上可能**产生经典神经科学无法单独给出的定量修正项的数学路径。诚实前置：**当前这些路径要么被参数压制到不可观测，要么尚未完成从结构到可测量量的推导**。它们不是已就绪的预言，而是未来理论工作的候选方向。

#### 路径 1：谱离散化的直接修正

**机制**：UFPF 中物理对象由 Rec 范畴经谱化函子 $D$ 映射为 Sp 范畴中的谱对象。有限维截断下，谱对象的本征值具有离散间距 $\Delta\lambda\sim\varepsilon^2$。若知觉变量的某种"本征表示"继承这种离散性，则经典连续变量应被修正为离散阶梯。

**可能修正形式**：

$$\Delta t_{\text{主观}} = \Delta t_{\text{经典}} + C\cdot\varepsilon^2\cdot N_{\text{采样}}\cdot f(\kappa).$$

**当前障碍**：
- paper34 连续极限表明，在宏观尺度 $\ell\gg333$ Planck 单位下，分形谱吸引子与光滑流形不可区分；
- 神经元尺度对应的 $\varepsilon^2$ 效应被压制 $\sim10^{-33}$，远小于热噪声与量子退相干。

**可观测性评估**：除非找到把微观谱离散性放大到宏观的机制（如临界现象中的长程关联），否则直接不可观测。

#### 路径 2：非交换几何不确定性修正

**机制**：谱流方程 $dA/dt=[G,A]$ 具有非交换结构。若把感知系统的某些可观测量对应为不可交换的谱算子，可能导出类似于量子力学的不确定性关系：

$$\Delta\mathcal{O}_1\,\Delta\mathcal{O}_2 \ge \frac{1}{2}|\langle[\mathcal{O}_1,\mathcal{O}_2]\rangle|.$$

**可能修正形式**：同时估计两个知觉变量（如时间间隔与空间方向）时，精度受非交换参数 $\varepsilon$ 限制：

$$\Delta t\,\Delta\theta \gtrsim \varepsilon^2.$$

**当前障碍**：
- UFPF 中 $[G,A]$ 的"非交换强度"由谱精度 $\varepsilon$ 标度，生物尺度同样被压制；
- 尚未建立知觉变量到非交换谱算子的显式映射。

**可观测性评估**：比路径 1 更弱，需要新的数学结构把非交换性提升到可观测尺度。

#### 路径 3：递归深度/层级有限性修正

**机制**：UFPF 的 Rec 范畴强调递归结构。人脑预测编码网络具有有限层级 $L$。若 UFPF 证明有限递归深度的谱流与无限递归极限之间存在系统偏差，则可产生层级相关的修正。

**可能修正形式**：

$$P_{\text{知觉}}(x) = P_{\text{经典}}(x)\left[1 + \frac{C}{L} + \mathcal{O}(L^{-2})\right].$$

**当前障碍**：
- 有限层级效应是经典神经网络/贝叶斯推断的共有特征，不是 UFPF 专属；
- 需要证明 UFPF 对层级截断的依赖形式与经典模型不同。

**可观测性评估**：中等，但专属性问题未解决。

#### 路径 4：LACI / 谱沉默阈值修正

**机制**：LACI（Local Attractor Capture Index）是 UFPF 中诊断系统是否陷入局部吸引子的指标。若感知系统在某些刺激下进入"谱沉默"区域（连续谱包含、零测度、LACI→∞、轨道权重为零），则经典可观测的神经响应模式可能突然消失或改变。

**可能修正形式**：在参数空间中定义临界 LACI 阈值 $\Lambda_c$，当 LACI $>\Lambda_c$ 时知觉响应出现"沉默"或非解析跳跃：

$$R_{\text{神经}}(s) = \begin{cases}R_{\text{经典}}(s), & \text{LACI}(s)<\Lambda_c,\\0\text{ 或异常模式}, & \text{LACI}(s)\ge\Lambda_c.\end{cases}$$

**当前障碍**：
- LACI 目前用于算法/数值诊断，尚未映射到感知心理物理学；
- 需要为具体感知任务定义 Rec 对象、谱对象与 LACI 计算规则。

**可观测性评估**：中等，但缺少显式公式。

#### 路径 5：临界点/相变标度修正

**机制**：UFPF 把 Lorentz、黑洞、QCD、流变学临界现象统一为谱流框架。知觉决策（如双稳态反转、分类边界）可被建模为谱流中的相变。若 UFPF 给出这些知觉相变的临界指数，且与经典平均场/Ising 类指数不同，则构成专属预言。

**可能修正形式**：在知觉分类边界附近，反应时分布 $T(\delta)$（$\delta$ 为距边界距离）满足

$$T(\delta)\sim|\delta|^{-\nu_{\text{UFPF}}},\qquad \nu_{\text{UFPF}}\neq\nu_{\text{经典}}.$$

**当前障碍**：
- 尚未建立知觉相变与 UFPF 四类临界现象的严格对应；
- 需要计算知觉系统的有效维度、序参量和重整化群流。

**可观测性评估**：**最有前景**。临界指数是长程、涌现的，可能放大微观参数效应；但理论工作量大。

#### 路径 6：D⊣R 伴随逼近误差修正

**机制**：D⊣R 伴随保证内部谱表征与外部 Rec 对象之间的结构保持对应，但该对应在有限尺度下是近似的。若内部模型 $A_{\text{model}}$ 与外部谱 $A_{\text{ext}}$ 之间存在非零"伴随误差"，则知觉可能出现系统性偏差。

**可能修正形式**：

$$A_{\text{model}} = D\bigl(R(A_{\text{ext}})\bigr) + \mathcal{E}_{\text{adj}},\qquad \|\mathcal{E}_{\text{adj}}\|\sim g(\varepsilon, N_{\text{递归}}).$$

**当前障碍**：
- 伴随误差函数 $g$ 尚未显式计算；
- 难以与经典神经编码误差区分。

**可观测性评估**：低，除非能找到 $g$ 的特有形式。

#### 路径 7：测量坍缩时间的对数/精度依赖修正

**机制**：§7.1 已给出知觉"坍缩"到稳定状态的时间

$$\tau_{\text{collapse}} = \frac{\ln(1/\varepsilon)}{\kappa}.$$

若 $\varepsilon$ 不是普适常数，而是依赖于系统状态（如唤醒度、注意资源、网络规模），则不同状态下知觉形成时间应有系统性差异。

**可能修正形式**：

$$\tau_{\text{collapse}}(s) = \frac{\ln\bigl(1/\varepsilon(s)\bigr)}{\kappa(s)} = \tau_{\text{经典}}(s) + \frac{\ln\bigl(\varepsilon_0/\varepsilon(s)\bigr)}{\kappa(s)}.$$

**当前障碍**：
- 当前 UFPF 把 $\varepsilon$ 视为普适常数；
- 即使 $\varepsilon$ 变化，$\ln(1/\varepsilon)$ 对其弱依赖使得对数项难以测量。

**可观测性评估**：低，除非 $\varepsilon$ 在生物系统中可变化几个数量级。

#### 路径 8：谱熵与香农熵的非平凡偏差

**机制**：固定基谱熵 $S_{\mathcal{B}}$ 在 UFPF 中定义。若 $S_{\mathcal{B}}$ 与经典香农熵 $S_{\text{Shannon}}$ 在有限系统中存在非平凡偏差，且该偏差可被神经信号测量，则可产生专属预言。

**可能修正形式**：

$$S_{\mathcal{B}} = S_{\text{Shannon}} + c_1\,\text{Tr}(A\log A)^2 + c_2\,\varepsilon^2 + \cdots.$$

**当前障碍**：
- 连续极限下二者趋于一致；
- 需要定义有限神经系统的谱熵计算方案。

**可观测性评估**：低-中等。

| 路径 | 物理/数学来源 | 当前障碍 | 可观测性前景 |

#### 诚实结论

> 当前 UFPF 框架**没有现成的、可观测的、专属于框架的神经科学/感知修正项**。所有候选路径要么依赖被压到 $10^{-33}$ 量级的 $\varepsilon^2$，要么需要把抽象范畴结构显式映射到具体感知任务并计算新的临界指数或误差函数。
>
> 若未来要在感知领域做出 UFPF 专属预言，**路径 5（临界相变标度）** 是最有潜力的突破口，因为它涉及长程涌现行为，可能绕过微观参数压制；其次是**路径 4（LACI/谱沉默）**，但需先建立具体计算规则。其余路径在当前理论阶段基本不可观测。

### 7.5 临界相变 toy model：知觉双稳态决策的临界慢化（v0.14新增）

本节对 §7.4 的"路径 5"做第一次具体数值实现。把知觉双稳态决策简化为序参量 $m(t)$ 的 Landau-Ginzburg 型随机动力学，通过测量临界控制参数 $\delta$ 附近的弛豫时间，提取临界指数 $\gamma$；并比较确定性（无噪声）平均场、经典随机模型与"谱流启发非局域模型"的结果。

#### 7.5.1 模型设定

**序参量**：$m(t)=\text{Tr}[A(t)\cdot(\rho_A-\rho_B)]$，其中 $\rho_A$、$\rho_B$ 是两个互斥知觉态的谱目标。

**经典 Landau-Ginzburg 方程**：

$$\frac{dm}{dt} = \kappa\,(\delta\,m - c\,m^3) + \sigma\,\xi(t).$$

- $\delta$：控制参数，度量知觉 A/B 之间的对称性破缺；
- $c$：三次非线性强度；
- $\sigma$：噪声强度；
- $\xi(t)$：高斯白噪声。

**稳态分析**：
- $\delta=0$：$m=0$ 不稳定，两个稳态 $m=\pm\sqrt{\delta/c}$ 简并；
- $\delta>0$：A 态占优，稳态为 $m^*=+\sqrt{\delta/c}$；
- $\delta<0$：B 态占优，稳态为 $m^*=-\sqrt{|\delta|/c}$。

**谱流启发非局域修正**：在恢复力前乘以 $|m|^{-\alpha}$（正则化在原点），模拟谱流在分形/非局域结构上的慢化：

$$\frac{dm}{dt} = \kappa\,(\delta\,m - c\,m^3)\,|m|^{-\alpha} + \sigma\,\xi(t).$$

当 $\alpha\to0$ 时回到经典模型；$\alpha>0$ 时，原点附近有效恢复力被抑制，临界慢化增强。

**谱流-分数阶记忆核标度代理模型**：基于线性化 Caputo 分数阶方程 $D^\beta m = \kappa\delta m$ 的 Mittag-Leffler 解，弛豫时间满足

$$\tau(\delta)=C\,\delta^{-1/\beta}.$$

这是 §7.6 推导路线图的数值占位演示，直接展示 UFPF 第一性原理可能给出的标度形式。

#### 7.5.2 数值脚本

**脚本**：[`scripts/paperX_perceptual_phase_transition.py`](file:///e:/workspace/hyper-resolution/universal_fixed_point_framework/scripts/paperX_perceptual_phase_transition.py)

**测量协议**：
1. 对 12 个等距 $\delta\in[0.02,0.20]$；
2. 对每个 $\delta$ 运行 200 条随机初始轨迹；
3. 轨迹从 $m\approx0$ 出发，记录首次越过决策阈值 $|m|>0.20$ 的时间；
4. 对未越过阈值的轨迹标记为"未决策"，不计入统计；
5. 对平均决策时间做幂律拟合 $\tau(\delta)=C\,\delta^{-\gamma}$。

**确定性对照**：无噪声（$\sigma=0$）时，理论上弛豫时间由线性化本征值决定：

$$\tau(\delta) \sim \frac{1}{\kappa\,\delta},\qquad \gamma=1.$$

#### 7.5.3 结果

运行结果（$c=0.25$，$\kappa=1.0$，$\sigma=0.05$，阈值 $0.20$）：

|:--|:--:|:--:|:--|
| 确定性（无噪声）平均场 | 1.022 | 5.110 | 与理论 $\gamma=1$ 一致，验证方法有效 |
| 经典随机 Landau-Ginzburg | 0.306 | 3.926 | 噪声主导首次 passage，有效指数偏低 |
| 谱流启发非局域模型（$\alpha=0.3$） | 0.556 | 1.739 | 非局域性改变有效标度行为 |

#### 7.5.4 讨论：如何从 toy model 走向 UFPF 专属预言

**当前结果的含义**：
- 确定性平均场模型给出 $\gamma\approx1$，符合 Landau-Ginzburg 平均场理论预期；
- 随机首次 passage 时间的有效指数受噪声强度、阈值选择、初始分布影响，不能直接与重整化群临界指数划等号；
- "谱流启发"模型通过人为引入非局域因子 $|m|^{-\alpha}$ 改变了指数，但这一因子目前**不是从 UFPF 第一性原理导出**的；
- "谱流-分数阶记忆核标度代理模型"直接给出 $\gamma=1/\beta$，与理论一致，但它是**基于 Mittag-Leffler 解的标度假设**，不是从 UFPF 谱测度具体计算出来的。

**要使之成为 UFPF 专属预言，仍需完成以下步骤**（详见 §7.6）：
1. **从谱流方程推导有效 Landau-Ginzburg 势**：从 $dA/dt=[G,A]+\kappa(\mathcal{D}(A)-A)$ 出发，在知觉 A/B 子空间做中心流形约化，得到 $m$ 的有效势 $V(m;\delta)$；
2. **确定势的具体形式**：UFPF 的谱结构（如 Rec 范畴的递归深度、Sp 范畴的谱维度）应决定 $V$ 中 $m^2$、$m^4$ 乃至 $m^6$ 项的系数；
3. **计算临界指数**：用 UFPF 的谱维度 $d_s$（而非普通空间维度）代入相应的临界现象标度理论，得到 $\gamma_{\text{UFPF}}=2/d_s$ 或更一般形式；
4. **设计实验测量**：在双稳态知觉任务中改变刺激强度使系统接近知觉分类边界，测量反应时分布 $T(\delta)$，拟合 $T(\delta)\sim|\delta|^{-\gamma}$，比较实验 $\gamma$ 与 UFPF 预测。

**诚实边界**：
- 本节 toy model 只是**方法论演示**，不是 UFPF 定理；
- $\alpha$ 与 $\beta$ 均为人为参数，不代表 UFPF 已从第一性原理导出谱非局域指数/谱维度；
- 知觉系统的真实临界指数可能受注意力、疲劳、个体差异等因素影响，UFPF 需要先把这些因素纳入谱流框架；
- 当前结果**无数值偏离预言**：经典随机模型、非局域模型、分数阶标度模型的指数差异来自模型假设差异，不是已被实验区分的预测。

#### 7.5.5 与 §7.4 路径 5 的关系

本节是 §7.4 路径 5 的**第一次 toy model 落地**：
- 证明"知觉相变 → 临界慢化 → 可提取临界指数"这条研究路线在计算上是可行的；
- 证明非局域/谱流修正**可以**改变临界指数（至少在 toy model 中）；
- 明确标出从 toy model 到真正 UFPF 预言还缺少的理论步骤：有效势推导、谱维度计算、实验协议设计。

### 7.6 从 UFPF 第一性原理推导非局域修正：路线图与缺失环节（v0.15新增）

§7.5 的非局域项 $|m|^{-\alpha}$ 是**人为引入**的。本节说明如何从 UFPF 的谱结构出发，**原则上**得到类似的非局域/分数阶修正，并指出当前仍缺少的理论环节。

#### 7.6.1 核心思想：谱测度 → 有效记忆核 → 分数阶动力学

UFPF 把物理对象表示为 Sp 范畴中的谱对象 $A$，其时间演化由谱流方程

$$\frac{dA}{dt}=[G,A]$$

给出。若 $G$ 的谱测度 $\mu_G(d\lambda)$ 在临界点 $\lambda_c$ 附近有幂律行为，则线性响应函数

$$\chi(t)=\int \mu_G(d\lambda)\,e^{-\lambda t}$$

会呈现出非指数衰减，从而等价的有效动力学含有**记忆核**或**分数阶导数**。

**关键对应**：

| UFPF 结构 | 有效动力学对应 | 数学形式 |
|:--|:--|:--|
| 谱测度在 $\lambda_c$ 附近有连续谱包 | 慢化/记忆效应 | $\chi(t)\sim t^{-\beta}$ |
| 谱维度 $d_s$（非整数） | 反常扩散/弛豫 | 分数阶导数 $D^\beta$ |
| 谱沉默/吸引子维度 | 有效摩擦/阻尼 | 状态依赖的弛豫率 |
| D⊣R 伴随的近似误差 | 投影后的修正项 | 高阶导数/非局域项 |

#### 7.6.2 推导路线图（五步）

**第一步：识别知觉态的谱对象**

把知觉系统建模为 Rec 对象 $R_{\text{percept}}$，其谱像

$$A_{\text{percept}}(t)=D\bigl(R_{\text{percept}}(t)\bigr)$$

包含知觉状态的全部谱信息。双稳态知觉对应 $A$ 在两类谱吸引子之间的切换。

**第二步：定义序参量并约化到慢流形**

选取能区分两种知觉态的谱观测量 $O$，定义

$$m(t)=\text{Tr}[A(t)\,O].$$

在临界点附近，大多数谱模式快速弛豫，仅 $m$ 对应的慢模式保留。通过**中心流形约化**，把高维谱流投影到一维序参量方程。

**第三步：计算生成元 $G$ 的谱测度**

$G$ 的谱测度 $\mu_G$ 决定慢模式的线性响应。若知觉系统背后的递归结构（如 paper34 中的分形谱吸引子）具有谱维度 $d_s$，则在临界点附近

$$\rho_G(\lambda)\sim |\lambda-\lambda_c|^{d_s/2-1},$$

其中 $\rho_G$ 为谱密度。

**第四步：从谱积分得到有效记忆核**

慢模式的线性响应函数为

$$\chi(t)=\int_0^\infty d\lambda\,\rho_G(\lambda)\,e^{-\lambda t}\sim t^{-d_s/2}\quad(t\to\infty).$$

把它代入 Generalized Langevin Equation（GLE），有效动力学可写成

$$\frac{dm}{dt}=-\int_0^t K(t-s)\,\frac{\partial V}{\partial m}(s)\,ds + \xi(t),$$

其中记忆核 $K(t)\sim t^{\beta-1}$，$\beta=d_s/2$。

**第五步：分数阶方程与临界指数**

幂律记忆核等价于分数阶导数。对 $0<\beta<1$：

$$D^\beta m(t) = -\kappa\,\frac{\partial V}{\partial m}(t) + \text{噪声}.$$

线性化 $V\approx -\delta m^2/2$ 后，解为 Mittag-Leffler 函数

$$m(t)=m(0)\,E_{\beta,1}(\delta t^\beta),$$

其弛豫时间满足

$$\tau(\delta)\sim \delta^{-1/\beta}.$$

因此分数阶指数 $\beta$ 直接决定临界指数

$$\gamma_{\text{UFPF}}=\frac{1}{\beta}=\frac{2}{d_s}.$$

与经典平均场 $\gamma=1$ 的差异完全来自谱维度 $d_s$。

#### 7.6.3 与 §7.5 toy model 的关系

§7.5 的非局域项 $|m|^{-\alpha}$ 可视为上述路线图的一个**现象学 shortcut**：

- 经典 Landau-Ginzburg：$\beta=1$（无记忆），$\gamma=1$；
- 谱流启发非局域项：等效于把弛豫率替换为 $\kappa\,|m|^{-\alpha}$，粗略模拟了"原点附近谱测度更稠密、弛豫更慢"的效应；
- 严格 UFPF 推导：应得到分数阶方程，其中指数由谱维度 $d_s$ 决定，而不是人为 $\alpha$。

#### 7.6.4 仍缺失的环节

要完成这一推导，还需解决以下问题：

1. **知觉 Rec 对象的具体构造**：目前没有把神经元网络/皮层回路写成 UFPF Rec 对象的显式方案；
2. **谱维度 $d_s$ 的计算**：需要为具体知觉任务（如双稳态 Necker 立方体）计算其谱吸引子的有效维度；
3. **从 D⊣R 伴随到 GLE 的严格投影**：中心流形约化在谱范畴中尚未形式化；
4. **噪声谱的确定**：GLE 中的随机力 $\xi(t)$ 及其涨落-耗散关系需从 UFPF 谱熵导出；
5. **与 paper34/paper35 临界框架的连接**：需要把知觉相变归入 UFPF 已有的四类临界现象（Lorentz/黑洞/QCD/流变学）统一标度理论中。

#### 7.6.5 诚实结论

> 从 UFPF 第一性原理**原则上**可以导出非局域/分数阶修正：谱测度的幂律行为 → 记忆核 → 分数阶动力学 → 修正的临界指数。但当前这一步是**纲领性的**，还没有针对具体知觉系统的显式构造。§7.5 的 toy model 是这一路线图的数值占位符，真正的 UFPF 专属预言需要等待上述 5 个缺失环节的解决。

### 7.7 为具体知觉任务建立 Rec/谱对象 toy 模型的核心假设与边界条件清单（v0.16新增）

在继续推导之前，先把下一步 toy 模型需要依赖的核心假设和边界条件显式列出，避免把 toy 模型包装成伪定理。本节以**Necker 立方体/双稳态知觉**为具体任务对象。

#### 7.7.1 系统识别假设

| 假设 | 内容 | 风险 |
|:--|:--|:--|
| A1 | 知觉系统可抽象为有限维 Rec 对象 $R_{\text{percept}}$ | Rec 对象的精确神经实现未知；这是 toy 模型的人为设定 |
| A2 | 谱化函子 $D$ 把 $R_{\text{percept}}$ 映射为有限维谱对象 $A$，其本征值集合为 $\{\lambda_i\}$ | 真实神经动力学的谱结构可能连续/无限维，有限维是截断近似 |

| A5 | 序参量 $m$ 是两知觉态占据概率之差：$m = P_A - P_B$ | 这是现象学选择，等价于谱观测量 $\text{Tr}[A\,O]$ 的 $O$ 需单独构造 |

| 假设 | 内容 | 风险 |

| B2 | 谱维度 $d_s$ 与 Rec 对象的分形/递归结构相关 | 目前无法从真实神经数据计算 $d_s$ |
| B3 | 有效临界指数满足 $\gamma = 2/d_s$ | 这来自线性化分数阶弛豫，真实知觉决策含非线性、噪声和有限尺寸效应 |
| B4 | 系统足够大/临界点足够低，使得 $\delta$ 可任意小 | 实际实验中知觉边界附近有注意力、疲劳等混杂因素 |

| 假设 | 内容 | 风险 |
|:--|:--|:--|

#### 7.7.4 边界条件

| 边界条件 | 内容 | 后果 |
|:--|:--|:--|
| D1 | 有限系统尺寸 $N$（如 $N\sim10^2-10^4$ 维谱对象） | 任何临界发散被截断，只能观察到有效标度区 |
| D2 | 时间离散化 $dt$ 和最大仿真时长 | 过小 $\delta$ 的弛豫可能无法在数值上实现 |
| D3 | 知觉决策阈值 $m_{\text{th}}$ | 阈值选择影响首次 passage 时间的绝对值和有效指数 |
| D4 | 被试内部状态（唤醒度、注意力、先验）作为环境参数固定或统计平均 | 个体差异会模糊临界指数 |
| D5 | 经典极限：忽略 $\varepsilon^2$ 量级的量子/谱修正 | toy 模型只产生经典可观测的临界现象，UFPF 量子效应不可见 |

#### 7.7.5 诚实边界（methodological）

- 这些假设中的任何一条都**不是 UFPF 已证明的定理**；
- 该 toy 模型的目标是**展示如何从 UFPF 结构出发可能得到经典可检验的临界指数**，而不是断言真实知觉系统一定具有某个 $d_s$；
- 若实验测得 $\gamma\neq1$，需要首先排除经典解释（如非马尔可夫噪声、非线性势、有限尺寸效应），才能归因于 UFPF 谱维度；
- 当前阶段该 toy 模型仍无数值预言的独立证伪力；
- §7.6 给出的 $\gamma=2/d_s$ 是**在假设 B1–B3 成立下的形式关系**，不是已被验证的知觉系统定律。

### 7.8 从假设清单到实验验证方案（v0.17新增）

把 §7.7 的假设/边界条件清单转化为**可操作的实验设计**。每个实验都给出：验证目标、被试任务、关键测量指标、数据判读方式、与 UFPF toy 模型的关系。这些实验大多可在经典心理物理学/认知神经科学框架内完成；UFPF 专属的解释需在所有经典解释被排除后才能成立。

#### 7.8.1 系统识别假设的实验验证

| 假设 | 实验设计 | 关键指标 | 判读方式 | UFPF 关联 |

| A1：知觉系统可抽象为有限维 Rec 对象 | 构建最小神经网络模型（如二选一分类器），证明其动力学可被有限维状态空间近似 | 状态空间维度（PCA/流形学习）、预测误差随维度变化 | 若维度 $N\sim10^2-10^4$ 即可解释行为方差，则 A1 在 toy 意义下成立 | Rec 对象是理论抽象，无法直接观测；只能验证有限维近似的充分性 |
| A2：谱化函子给出有限维谱对象 | 对训练好的神经网络计算权重矩阵/雅可比矩阵的特征值谱；或对脑电/脑磁信号做谱分解 | 特征值分布、谱密度、主导模态数量 | 若谱集中在有限个本征值，则支持有限维谱近似 | 神经网络的特征值谱不等于 UFPF 的 Sp 对象；仅作形式类比 |
| A3：双稳态对应谱吸引子 | 双稳态知觉任务（Necker 立方体、运动竞争点）中记录反应时和知觉报告序列 | 停留时间分布 $P(\tau)$、转移率、稳态占据概率 $P_A/P_B$ | 若停留时间呈双峰/指数混合，提示两吸引子 Basin；若呈幂律尾，提示分形吸引子结构 | 经典多稳态模型（如 attractor network）可解释相同现象 |
| A4：控制参数 $\delta$ 是到知觉边界的距离 | 系统操纵刺激模糊度/对比度，测量知觉报告对参数的依赖 | 心理测量函数斜率、$P_A(\delta)$、判别阈值 | 用 $\delta$ 参数化心理测量函数，验证其在临界点附近的行为 | $\delta$ 的操作定义来自实验，不是 UFPF 导出 |
| A5：序参量 $m=P_A-P_B$ | 直接由实验报告序列估计 $m(t)=2P_A(t)-1$ | 报告序列的自相关、$m$ 的均值与方差 | 若 $m$ 在边界附近衰减/涨落增强，则与 Landau-Ginzburg 图像定性一致 | $m$ 是现象学定义，对应 $\text{Tr}[A\,O]$ 中的 $O$ 需单独论证 |

#### 7.8.2 谱维度假设的实验验证

| 假设 | 实验设计 | 关键指标 | 判读方式 | UFPF 关联 |
|:--|:--|:--|:--|:--|
| B1：谱密度在零模附近有幂律行为 | 在双稳态任务中，对神经信号（EEG/MEG/LFP）在知觉切换前后做时频分析和特征谱分析 | 低频功率谱 $S(f)\sim f^{-\alpha}$、特征值累积分布 $N(\lambda)\sim\lambda^{d_s/2}$ | 若 $\alpha\neq1$ 且可联系到非整数维度，则可能与谱维度相关 | 经典神经振荡也有幂律谱，需排除背景过程 |
| B2：$d_s$ 与递归/分形结构相关 | 对比不同复杂度任务（如简单二择 vs 多层级预测）下的神经信号谱特征 | 不同任务条件下的 $d_s$ 估计值 | 若任务复杂度与 $d_s$ 单调相关，可建立 toy 对应 | 复杂度与维度关系可能由经典信息论解释 |
| B3：$\gamma=2/d_s$ | 测量临界慢化指数 $\gamma_{\text{exp}}$，并与独立估计的 $d_s$ 比较 | $\gamma_{\text{exp}}$、$d_s$ 估计、残差 | 若 $\gamma_{\text{exp}}\approx2/d_s$，则支持该关系 | 这是 UFPF toy 模型**唯一专属**的对应之一，但仍需排除经典非马尔可夫模型 |
| B4：$\delta$ 可任意小 | 设计足够多的刺激等级，覆盖知觉边界附近 $\pm0.5$ 判别概率区间 | 刺激等级数量、每等级试次数、$P_A(\delta)$ 曲线分辨率 | 需至少 10–15 个等级才能拟合临界标度 | 实验可行性受试次和疲劳限制 |

#### 7.8.3 动力学近似假设的实验验证

| 假设 | 实验设计 | 关键指标 | 判读方式 | UFPF 关联 |
|:--|:--|:--|:--|:--|
| C1：高维谱流可约化到一维序参量 | 在双稳态任务中，用潜变量模型（如 HMM、drift-diffusion model）拟合报告序列 | 潜变量维度、模型选择准则（AIC/BIC）、一维模型的解释方差 | 若一维潜变量已能解释大部分方差，则 C1 在 toy 意义下成立 | DDM 是经典模型，UFPF 需证明其谱流对应 |
| C2：有效势为 Landau-Ginzburg 形式 | 由 $P_A(\delta)$ 反推有效势 $V(m)$；或使用非平衡态推断方法 | 有效势的二次项、四次项系数；$V''(m=0)$ 随 $\delta$ 变号 | 若 $V$ 可近似为四次多项式，则 C2 成立 | 经典势函数重构已有成熟方法 |
| C3：噪声为白噪声 | 分析 $m(t)$ 的增量自相关和功率谱 | 增量自相关函数、Hurst 指数、去趋势涨落分析（DFA） | 若增量近似独立且 $H\approx0.5$，则白噪声假设成立；否则需有色噪声模型 | 真实神经噪声通常非白 |
| C4：线性化分数阶方程决定弛豫时间 | 在临界点邻域测量反应时 $T(\delta)$，拟合 $T\sim\delta^{-\gamma}$ | 拟合优度、$\gamma$ 值、残差结构 | 若幂律拟合显著优于指数拟合，则可能支持分数阶/非马尔可夫弛豫 | 经典非马尔可夫过程也能给出幂律弛豫 |
| C5：反应时等于理论弛豫时间 | 拆解反应时：知觉选择时间 + 运动执行时间 | 选择反应时、简单反应时、运动启动潜伏期 | 用减法或实验设计分离知觉成分 | 无法完全排除后知觉成分污染 |

#### 7.8.4 边界条件的实验控制

| 边界条件 | 控制方法 | 关键指标 | 注意事项 |
|:--|:--|:--|:--|
| D1：有限系统尺寸 | 固定被试群体，估计个体差异范围；用模拟确定有限尺寸截断尺度 | 组内 $\gamma$ 标准差、有效标度区范围 | 真实大脑尺寸固定，无法像物理系统那样改变 $N$ |
| D2：时间离散化/最大时长 | 控制试次超时规则，记录未决策率 | 未决策比例、超时试次分布 | 过短试次会截断长弛豫，扭曲标度行为 |
| D3：知觉决策阈值 | 通过任务指导语和反馈统一被试的报告标准 | 报告一致性、虚报率、漏报率 | 个体差异大，需用心理测量函数校正 |
| D4：内部状态 | 控制唤醒度（如固定时间、咖啡因状态）、注意力（如眼动监控、试次前线索）、先验（如适应/训练历史） | 瞳孔直径、心率变异性、眼动数据、适应曲线 | 无法完全消除，只能作为协变量统计控制 |

#### 7.8.5 综合实验流程示例：Necker 立方体临界慢化实验

**目标**：测量双稳态知觉决策在边界附近的反应时分布，提取有效指数 $\gamma_{\text{exp}}$，并与独立估计的谱维度 $d_s$ 比较。

**步骤**：
1. **刺激生成**：
   - 生成 12–15 个模糊度的 Necker 立方体（或运动竞争点），覆盖从"几乎确定 A"到"几乎确定 B"的连续范围；
   - 每个模糊度等级至少 100 试次，随机穿插。
2. **任务设计**：
   - 被试快速按键报告知觉到的朝向/运动方向；
   - 记录反应时 $T$ 和选择 $A/B$。
3. **数据预处理**：
   - 排除超时、极快反应（<200 ms）、眼动离开刺激区域试次；
   - 将 $P_A(\delta)$ 拟合为心理测量函数，提取边界位置 $\delta_0$ 和斜率。
4. **关键指标计算**：
   - 对每个 $\delta$ 计算中位反应时 $T(\delta)$；
   - 在临界点邻域拟合 $T(\delta)\sim|\delta-\delta_0|^{-\gamma_{\text{exp}}}$。
5. **谱维度独立估计**：
   - 对 EEG/MEG 信号在知觉切换前窗口做特征谱分析或功率谱分析；
   - 估计 $d_s$（如从 $N(\lambda)\sim\lambda^{d_s/2}$ 或 $S(f)\sim f^{-\alpha}$ 转换）。
6. **UFPF toy 模型检验**：
   - 比较 $\gamma_{\text{exp}}$ 与 $2/d_s$；
   - 同时拟合经典 DDM、attractor network、非马尔可夫模型作为替代解释；
   - 只有当 UFPF 预测显著优于所有经典模型，且假设 A1–C5、D1–D5 均被验证/控制后，才能初步讨论 UFPF 解释。

#### 7.8.6 诚实边界

- 本节所有实验方案均为**经典心理物理学/认知神经科学可实施**的设计，不依赖 UFPF 量子/谱效应；
- §7.8.5 中"UFPF toy 模型检验"步骤要求 $\gamma_{\text{exp}}\approx2/d_s$，但这一关系**仅在 §7.7 的 A1–C5、D1–D5 假设全部成立**时才有意义；
- 即使实验得到 $\gamma\neq1$，经典非马尔可夫模型、非线性势、有色噪声、有限尺寸效应等均可解释，**不能自动归因于 UFPF 谱维度**；
- 本节不提供新的数值脚本；§7.5 的 `paperX_perceptual_phase_transition.py` 已是对 §7.8.5 步骤 4 的 toy 模拟；`paperX_necker_experiment_data_template.py` 提供了 §7.8 全部实验字段的数据记录模板。

#### 7.8.7 替代解释模型的拟合优度指标与统计检验

若实验测得临界慢化指数 $\gamma_{\text{exp}}\neq1$，必须先用经典模型解释。下面列出 UFPF toy 模型与三类主要替代模型（指数弛豫、DDM、attractor network）竞争时所需报告拟合优度指标与统计检验。

**候选模型**

| 模型 | 核心方程/假设 | 对应 §7.7 假设 |
|:--|:--|:--|
| **M0：经典指数弛豫** | $\tau(\delta)=\tau_0\,e^{\lambda\delta}$ 或常数加指数 | 反驳 C4（非分数阶） |
| **M1：Landau-Ginzburg 平均场** | $\tau(\delta)=C\|\delta\|^{-\gamma},\;\gamma=1$ | C2 成立、C4 不成立（无记忆） |
| **M2：Drift-Diffusion Model（DDM）** | 累积证据至边界，RT 分布由漂移率和边界距离决定 | C1、C3 的具体形式 |
| **M3：Attractor Network** | 双稳态吸引子网络，含噪声诱导切换 | A3、C1–C3 |
| **M4：非马尔可夫/有色噪声** | 噪声自相关导致幂律弛豫，但无谱维度机制 | C3 不成立 |
| **M5：UFPF toy 模型** | $\tau(\delta)=C\|\delta\|^{-\gamma},\;\gamma=2/d_s$ | A1–D5 全部成立 |

**拟合优度指标**

| 指标 | 符号 | 说明 | 使用场景 |
|:--|:--:|:--|:--|
| 均方根误差 | RMSE | $\sqrt{\frac{1}{n}\sum_i (T_i^{\text{obs}}-T_i^{\text{pred}})^2}$ | 比较模型对 $T(\delta)$ 曲线的拟合 |
| 归一化均方根误差 | NRMSE | RMSE / $(T_{\max}-T_{\min})$ | 跨数据集比较 |
| 决定系数 | $R^2$ | $1 - \frac{\sum (T_i^{\text{obs}}-T_i^{\text{pred}})^2}{\sum (T_i^{\text{obs}}-\bar T)^2}$ | 评估解释方差比例 |
| 对数似然 | $\ln\mathcal{L}$ | 基于模型对 RT 分布的概率密度 | 需要显式 RT 分布的模型（DDM、attractor） |
| 赤池信息准则 | AIC | $2k - 2\ln\mathcal{L}$ | 模型选择，惩罚参数数 $k$ |
| 贝叶斯信息准则 | BIC | $k\ln n - 2\ln\mathcal{L}$ | 模型选择，强惩罚复杂模型 |
| WAIC / LOO-CV | — | 贝叶斯框架下带离群值修正的留一交叉验证 | 当模型有层次结构或贝叶斯推断时 |
| 残差自相关 | ACF(res) | 检查模型是否捕捉了数据中的时间/序列结构 | 发现系统性偏差 |
| 分位数-分位数图 | QQ-plot | 比较模型预测分布与观测 RT 分布 | 视觉诊断 |
| 累积分布函数距离 | Kolmogorov-Smirnov $D$ | $\sup_x |F_{\text{obs}}(x)-F_{\text{pred}}(x)|$ | 比较完整 RT 分布 |

**统计检验方法**

| 目的 | 检验/方法 | 具体操作 | 判读 |
|:--|:--|:--|:--|
| 幂律 vs 指数 | 非嵌套模型选择（Vuong 检验） | 拟合幂律 $\tau=C\delta^{-\gamma}$ 与指数 $\tau=C e^{-\lambda\delta}$ 后做 Vuong 检验 | 若 Vuong 显著支持幂律，排除 M0 |
| 比较嵌套模型 | 似然比检验（LRT） | 如 M1（γ 固定为 1）vs 自由 γ | 若拒绝 γ=1，则需要非单位指数机制 |
| 参数显著性 | Wald 检验 / 置信区间 | 对 γ、d_s 等参数做 bootstrap 置信区间 | 若 CI 不包含 1，支持非平均场 |
| 模型选择 | AIC/BIC 差异 $\Delta$AIC | $\Delta\text{AIC}_i = \text{AIC}_i - \text{AIC}_{\min}$ | 通常 $\Delta\le2$ 视为有竞争力；$\Delta>10$ 基本排除 |
| 贝叶斯模型比较 | 贝叶斯因子 $BF_{ij}$ | $BF_{ij} = p(D|M_i)/p(D|M_j)$ | $BF>10$ 或 $1/10<BF<10$ 给出强弱证据 |
| 交叉验证 | k-fold CV 预测误差 | 将数据按被试分层，比较模型在新被试上的 RMSE | 防止过拟合 |
| 后验预测检验 | Posterior Predictive Check（PPC） | 从拟合模型生成合成数据，与真实数据比较 | 发现模型无法复现的统计特征 |
| 非参数检验 | Mann-Whitney U / Kruskal-Wallis | 比较不同 δ 条件下的 RT 中位数 | 不假设分布形状 |
| 序列效应 | 自回归模型 / 混合效应模型 | 将前一试次 choice 作为协变量 | 控制适应和序列相关 |
| 多层/被试内结构 | 线性混合效应模型（LMM） | RT ~ ambiguity + (1|subject) + (ambiguity|subject) | 估计群体水平效应和个体差异 |

**UFPF toy 模型胜出的最低证据标准**

要初步支持 UFPF 解释，至少需要同时满足：
1. **拟合优度**：M5 的 AIC/BIC 优于 M0–M4，且 $\Delta\text{AIC}\ge6$；
2. **指数一致性**：独立估计的 $d_s$ 与 $\gamma_{\text{exp}}$ 满足 $\gamma_{\text{exp}}\approx2/d_s$（在 bootstrap CI 内）；
3. **经典机制排除**：
   - M0 被 Vuong 检验排除（幂律优于指数）；
   - M2/M3 无法解释 $\gamma$ 与 $d_s$ 的关系；
   - M4 的噪声相关时间尺度与实验无关，或需要非物理解释；
4. **可重复性**：独立样本、不同刺激（运动竞争点、双目竞争）重复出相同 $d_s$ 与 $\gamma$ 关系；
5. **实验控制**：A1–D5 中的关键混淆变量（唤醒度、注意力、先验、有限尺寸）已被统计控制。

**诚实边界**

- 即使 M5 获胜，也只能说"UFPF toy 模型与数据一致"，**不能证明** UFPF 是唯一真实框架；
- $d_s$ 的独立估计本身是模型依赖的（功率谱指数、特征值累积分布等不同方法给出不同 $d_s$），需要在同一分析管道内保持一致；
- 当前阶段这些指标是**方法论规划**，不是实际分析结果。

**正式分析**

1. **UFPF 模型捕捉临界慢化的能力**

   UFPF toy 模型将知觉决策的弛豫时间直接参数化为幂律 $T(\delta)\sim|\delta|^{-\gamma}+t_0$，其中 $\gamma$ 由底层谱维度 $d_s$ 决定（§7.6）。在生成数据满足该幂律时，最大似然估计给出 γ≈1.0（真实值 1.2；偏低的原因见下方"截断效应"），AIC 与 BIC 均显著优于 DDM。这说明：

   - 若真实神经动力学在知觉边界附近具有幂律弛豫，UFPF toy 模型具备**直接拟合和识别**该特征的能力；
   - 拟合得到的 $\gamma$ 可与独立估计的 $d_s$ 做交叉验证（§7.8.5 步骤 6）；
   - 但实验设计必须避免 RT 上限截断，否则会压缩估计的 $\gamma$。

2. **DDM 失效的理论原因**

   标准 DDM 的决策时间由漂移扩散过程的第一通过时间决定。在临界点附近（$v\to0$），其平均决策时间的发散行为为

   $$E[T_{\text{DDM}}] \sim \frac{a^2}{4D}\cdot\frac{1}{|v|} \propto \frac{1}{|\delta|},$$

   即 DDM 预测的临界指数为固定值 $\gamma_{\text{DDM}}=1$。这与 UFPF toy 模型中 $\gamma=2/d_s$ 可任意偏离 1 的预测形成本质区别。当真实数据由 γ=1.2 的幂律生成时：

   - DDM 无法通过固定结构改变指数；
   - 其似然函数被迫在"拟合远离边界的快 RT"与"拟合边界附近的慢 RT"之间取舍，最终导致边界附近 RT 被系统低估；
   - 即使使用完整 RT 分布的解析 PDF（并已校正 秒↔ms 密度单位），DDM 仍无法补偿结构上的不匹配。

   因此，DDM 的失效不是拟合方法问题，而是**模型结构假设与幂律临界慢化不兼容**的体现。

3. **对实验设计的启示**

   若真实知觉系统确实表现出 $\gamma\neq1$ 的临界慢化，且经典 DDM 无法拟合，则支持引入非马尔可夫记忆核或谱流机制。但必须先排除以下经典替代：
   - 非线性漂移 $v(\delta)$；
   - 时变边界 $a(\delta)$；
   - 有色噪声或非平稳扩散系数；
   - 有限试次/天花板效应造成的伪幂律。

   这些替代模型一旦纳入比较，UFPF toy 模型仍需通过 ΔAIC、交叉验证和独立 $d_s$ 估计来胜出。

#### 7.8.9 讨论草稿：UFPF 模型在临界点附近的鲁棒性及其对实验设计的指导意义（v0.21新增）

##### 1. UFPF toy 模型的临界点鲁棒性

UFPF toy 模型把知觉决策时间写为

$$T(\delta)=C|\delta|^{-\gamma}+t_0,$$

其中 $\gamma=2/d_s$。这一形式在临界点 $\delta=0$ 处的行为非常明确：当 $|\delta|\to0$ 时，$T(\delta)\to\infty$，发散速率由单一参数 $\gamma$ 刻画。与其他模型相比，UFPF toy 在临界点附近具有以下鲁棒性优势：

| 特性 | UFPF toy | 标准 DDM | 说明 |
|:--|:--|:--|:--|
| 指数自由度 | $\gamma$ 自由 | 固定 $\gamma=1$ | UFPF 可拟合任意幂律发散，DDM 被结构锁定 |
| 参数可解释性 | $\gamma\leftrightarrow d_s$ | $a,k,t_0$ 为漂移扩散参数 | UFPF 的 γ 可直接与谱维度/谱流理论连接 |
| 数值行为 | $\|\delta\|\to0$ 时公式良定义 | $v\to0$ 时需特殊处理 | DDM 在零漂移附近 PDF 变宽、似然扁平 |
| 似然 landscape | 对 γ 平滑 | 对 $v$ 可能存在平台 | UFPF 优化更稳定 |

需要强调的是，这里的"鲁棒性"是**模型结构层面**的：只要真实数据服从幂律慢化，UFPF toy 就有一个可调参数 γ 来匹配它；而标准 DDM 没有这个自由度。它不是指 UFPF 对噪声或异常值更鲁棒——实际上，对数正态假设和 RT 上限截断都会影响 γ 估计。

##### 2. DDM 数值稳定性检查结果

[`scripts/paperX_critical_slowing_model_comparison.py`](file:///e:/workspace/hyper-resolution/universal_fixed_point_framework/scripts/paperX_critical_slowing_model_comparison.py) 实现了基于 Navarro & Fuss (2009) 的 DDM 解析 PDF，并在脚本末尾加入数值稳定性自检。检查结果如下：

- **边界对称变换逻辑**：下边界 PDF 通过 $f_B(t;v,a,z)=f_A(t;-v,a,1-z)$ 计算，数学上正确；
- **归一化**：对 $v=0,z=0.5,a=0.5$ 数值积分得 $P_A+P_B\approx1.007$，归一化基本保持；
- **临界点附近**：当 $a=2.0$ 时，$v$ 从 0 增加到 1.0 的过程中平均决策时间从 1.0s 仅降至 0.76s，说明 DDM 对漂移变化不敏感，难以产生跨数量级的 RT 变化；
- **下溢风险**：当 $a$ 较小时（如 $a=0.5$），$t=2$–$4$s 的 PDF 会下溢到 $10^{-16}$ 以下。本次拟合最终 $a=2.38$，在该尺度下 PDF 量级为 $10^{-2}$，未出现严重下溢；
- **单位校正**：DDM PDF 原生单位为 1/秒，观测 RT 为 ms，比较时必须转换为同一密度测度。脚本已按 $f_{\text{ms}}(t_{\text{ms}})=f_s(t_{\text{ms}}/1000)/1000$ 校正。

##### 3. 对实验设计的指导意义

若要在真实 Necker 立方体/双稳态知觉实验中检验 UFPF toy 模型，以下设计要点可提高 γ 估计的可靠性：

**3.1 控制 RT 截断效应**

- 上限：10000 ms 的截断已使 γ 估计从 1.2 压缩到 1.0。真实实验应使用足够大的超时窗口（如 8–10 s），或建模右截断；
- 下限：排除极快反应（<200 ms）以减少按键抖动污染。

**3.2 在临界点附近密集采样**

- δ 应覆盖 $|\delta|\in[0.05,0.50]$ 且在小 $|\delta|$ 区间加密（如 0.05, 0.08, 0.12, 0.18, ...）；
- 每等级试次数 ≥100，以保证 RT 分布尾部有足够样本。

**3.3 预注册模型对比**

- 主分析必须同时拟合 UFPF toy（幂律）和标准 DDM；
- 报告 ΔAIC、ΔBIC 和 γ 的 bootstrap 置信区间；
- 若 UFPF 胜出，必须进一步排除经典扩展 DDM（非线性漂移、时变边界、有色噪声）才能讨论谱流机制。

**3.4 独立估计谱维度 $d_s$ 的具体方法**

若同时采集神经信号，可尝试以下四类方法独立估计 $d_s$。这些方法均来自复杂网络、分形几何与随机游走理论，与 UFPF 的"谱维度"为**形式类比**，需在实验报告中明确标注。

| 方法 | 数据 | 具体操作 | 与 $d_s$ 的关系 | 典型文献 |
|:--|:--|:--|:--|:--|
| **PSD 斜率法** | EEG/MEG/LFP 单通道或多通道 | 估计功率谱 $S(f)\sim f^{-\beta}$；在 $10^{-1}$–$10^2$ Hz 频段拟合 β | 对扩散型过程，形式类比 $d_s\approx 2(3-\beta)$；需假设信号由分数阶布朗运动生成 | Heneghan & McDarby (2000); Bullmore et al. (2001) |
| **特征值累积法** | 多通道协方差矩阵或图 Laplacian | 构建通道间相关矩阵/图 Laplacian，计算特征值累积分布 $N(\lambda)\sim\lambda^{d_s/2}$ | 直接对应图/流形上的谱维度定义 | Burioni & Cassi (2005); de Nigris et al. (2017) |
| **返回概率法** | 神经源重构时间序列 | 定义随机游走在有效网络上的返回概率 $P(t)\sim t^{-d_s/2}$ | 随机游走在谱维度 $d_s$ 网络上的返回概率标度 | Burioni & Cassi (2005); Riascos & Mateos (2014) |
| **多尺度熵/DFA** | EEG 全局场功率或单通道 | 估计 Hurst 指数 $H$ 或标度指数 α | 分数阶布朗运动的谱维度形式类比：$d_s\approx 2/(2H-1)$（对 $H>0.5$） | Costa et al. (2005); Peng et al. (1994) |

**验证逻辑**：
1. 从行为数据估计 $\gamma_{\text{行为}}$；
2. 从神经数据估计 $d_s^{\text{神经}}$；
3. 检验一致性：$\gamma_{\text{行为}} \approx 2/d_s^{\text{神经}}$；
4. 若一致，说明行为临界慢化与神经谱结构存在对应关系，增强 UFPF 解释的可信度；
5. 若不一致，可能原因包括：方法选择偏差、形式类比不成立、或被试间差异。

**关键边界**：
- 上述关系不是 UFPF 严格定理，而是把神经信号类比为"谱对象上的扩散过程"；
- 没有统一算法能从任意神经信号中"读出" UFPF 的 $d_s$；
- 本部分为探索性分析，不纳入主假设检验。

**3.5 控制混淆变量**

- 唤醒度、注意力、疲劳会改变有效"采样率"，可能混淆 RT-δ 关系；
- 建议记录瞳孔直径、心率变异性、眼动，并作为协变量纳入分层模型。

##### 4. 与 §7.6 理论路线图的衔接

§7.6 给出 UFPF 推导路线图：谱测度 → 记忆核 → 分数阶动力学 → $\gamma=2/d_s$。本节 toy 数值演示是该路线图的**行为层面代理**：

- 行为上观察到幂律慢化 $T\sim|\delta|^{-\gamma}$；
- 理论上该指数应来自 Rec/Sp 谱对象的谱维度 $d_s$；
- 实验上通过独立神经信号估计 $d_s$，完成从行为到谱结构的闭合。

这一衔接目前仍是[衔接]级推断：toy 模型中的 $d_s$ 未从真实神经数据计算，γ 也未被真实实验验证。

##### 5. 诚实边界

- 本节为**讨论草稿**，不是已发表论文的实验设计；
- "UFPF 在临界点的鲁棒性"是指模型结构上的可调性，不是统计鲁棒性；
- 所有数值演示仍基于合成数据，无数值预言；
- 真实实验中，标准 DDM 的扩展版本可能也能拟合 γ≠1 的行为数据，UFPF 解释需通过 ΔAIC 和独立 $d_s$ 估计来竞争。

### A.8 变分自由能推导详稿与预测编码文献对照（v0.9新增）

本附录把 §4.7 的推导独立成节，并给出与预测编码/active inference 文献的术语对照。

#### A.8.1 问题设定

给定 $N$ 个感觉通道，每个通道的信息贡献（预测误差代理）为

$$\varepsilon_i(t) = s_i(t)\,\|\rho_i - A(t)\|_{HS},\qquad i=1,\dots,N.$$

寻找归一化权重 $\mathbf{w}=(w_1,\dots,w_N)$，$w_i\ge0$，$\sum_i w_i=1$，使得系统既优先采信高惊讶通道，又避免退化为单一通道。

#### A.8.2 变分自由能泛函

定义

$$\mathcal{F}(\mathbf{w};\boldsymbol{\varepsilon},\beta) = -\sum_{i=1}^N w_i\,\varepsilon_i + \frac{1}{\beta}\sum_{i=1}^N w_i\log w_i.$$

**各项含义**：
- **能量项** $-\sum_i w_i\varepsilon_i$：负的期望预测误差。最小化 $\mathcal{F}$ 等价于最大化加权预测误差——系统应当把更多权重分配给惊讶度更高的通道。
- **熵正则项** $\frac{1}{\beta}\sum_i w_i\log w_i$：Shannon 熵乘以 $1/\beta$。该项惩罚过于尖锐的分布，使系统在信息不足时保持一定不确定性。
- **精度参数 β**：β 越大，熵正则越弱，系统越敢于"押注"单一通道；β 越小，系统越保守。

#### A.8.3 Lagrange 乘子推导

引入乘子 $\lambda$ 处理归一化约束：

$$\mathcal{L}(\mathbf{w},\lambda) = -\sum_{i=1}^N w_i\,\varepsilon_i + \frac{1}{\beta}\sum_{i=1}^N w_i\log w_i - \lambda\left(\sum_{i=1}^N w_i - 1\right).$$

对 $w_i$ 求偏导：

$$\frac{\partial\mathcal{L}}{\partial w_i} = -\varepsilon_i + \frac{1}{\beta}(\log w_i + 1) - \lambda = 0.$$

解得

$$\log w_i = \beta(\varepsilon_i + \lambda) - 1,$$

即

$$w_i \propto \exp(\beta\,\varepsilon_i).$$

由归一化约束得到

$$w_i^* = \frac{\exp(\beta\,\varepsilon_i)}{\sum_{j=1}^N \exp(\beta\,\varepsilon_j)}.$$

**凸性说明**：$\mathcal{F}$ 关于 $\mathbf{w}$ 是凸函数（$-w_i\varepsilon_i$ 线性，$w_i\log w_i$ 凸，$\beta>0$），约束集合为单纯形，故上述驻点即为唯一全局最小点。

#### A.8.4 与预测编码/active inference 文献的术语对照

| UFPF 谱流语言 | 预测编码术语 | 文献依据 |
|:--|:--|:--|
| 内部谱对象 $A_{\text{model}}$ / 生成元 $G_{\text{int}}$ | 层级生成模型 / prior belief | Rao & Ballard (1999); Friston (2005) |
| 外部驱动 $G_{\text{ext}}$ 与目标态偏差 $\|\rho_i-A\|_{HS}$ | 预测误差 $\varepsilon$ | Friston (2005); Spratling (2008) |
| 精度参数 $\beta$ | precision（精度，逆方差） | Friston & Sporns (2008); eLife 91475 (2024) |
| softmax 权重 $w_i^*$ | 精度加权预测误差的仲裁结果 | Poublan-Couzardot & Talmi (2024); Balar & Kapila (2025) |
| 变分自由能 $\mathcal{F}(\mathbf{w})$ | variational free energy | Friston (2010); Das, Ray & Bhattacharya (2026) |
| 改变 $G_{\text{ext}}$ 或谱交织器 $T$ 以降低 $[G_{\text{ext}},A]$ | active inference（主动推断） | Friston et al. (2017) |
| 高 β → winner-take-all | 高 precision 下单一假设主导 | Friston (2005) |
| 低 β → 均匀权重 | 高不确定性下多假设并存 | Poublan-Couzardot & Talmi (2024) |

**诚实边界**：上表为概念/术语映射，不是严格的数学等价声明；$\mathcal{F}$ 与 Friston 框架中的 variational free energy（通常含 KL 散度、期望对数似然等）在形式上有相似，但未建立逐项等价。

### A.11 层级预测编码技术摘要（对应 §4.9）

**脚本**：[`scripts/paperX_hierarchical_predictive_coding.py`](file:///e:/workspace/hyper-resolution/universal_fixed_point_framework/scripts/paperX_hierarchical_predictive_coding.py)

**模型方程**：

**L1（感觉层）**：

$$\frac{dA_1}{dt} = [G_{\text{ext}}, A_1] + [G_{\text{int}}^{(1)}, A_1] + \kappa\bigl(\mathcal{D}(A_1)-A_1\bigr) + s_{\text{ext}}(\rho_{\text{ext}}-A_1) + s_{\text{pred}}(A_2-A_1).$$

**L2（预测/关联层）**：

$$\frac{dA_2}{dt} = [G_{\text{int}}^{(2)}, A_2] + \kappa\bigl(\mathcal{D}(A_2)-A_2\bigr) + s_{\text{err}}(A_1-A_2) + s_{\text{prior}}(\rho_{\text{prior}}-A_2).$$

**参数默认设置**：

| 参数 | 含义 | 默认值 |
|:--|:--|:--:|
| dim | 谱对象维度 | 8 |
| κ | 全局测量强度 | 0.5 |
| s_ext | 外部输入强度（自下而上） | 场景相关 |
| s_pred | 自上而下预测强度 | 场景相关 |
| s_err | L2 根据预测误差更新强度 | 场景相关 |
| s_prior | L2 维持 /ba/ 先验强度 | 4.0 |
| dt | 数值步长 | 0.01 |

### A.12 临界相变 toy model 技术摘要（对应 §7.5）

**脚本**：[`scripts/paperX_perceptual_phase_transition.py`](file:///e:/workspace/hyper-resolution/universal_fixed_point_framework/scripts/paperX_perceptual_phase_transition.py)

**模型方程**：

- 经典 Landau-Ginzburg：
  $$\frac{dm}{dt} = \kappa\,(\delta\,m - c\,m^3) + \sigma\,\xi(t).$$

- 谱流启发非局域修正：
  $$\frac{dm}{dt} = \kappa\,(\delta\,m - c\,m^3)\,|m|^{-\alpha} + \sigma\,\xi(t),$$
  其中 $|m|$ 正则化为 $\max(|m|, 10^{-6})$。

- 谱流-分数阶记忆核标度代理：基于线性化 Caputo 方程 $D^\beta m = \kappa\delta m$ 的 Mittag-Leffler 解，弛豫时间满足
  $$\tau(\delta)=C\,\delta^{-1/\beta},$$
  脚本直接按该标度律生成带噪声的试验数据（β=0.7，理论 γ=1/β≈1.429）。

**参数**：c=0.25, κ=1.0, σ=0.05（随机模型）/0.0（确定性），α=0.3，β=0.7，阈值 0.20，dt=0.001，最大步数 200000。

**测量协议**：对每个 δ∈[0.02,0.20] 运行 200 条轨迹，从 m≈0 附近出发，记录首次越过阈值 |m|>0.20 的时间；未越过者标记为未决策。

**运行命令**：

```bash
python scripts/paperX_perceptual_phase_transition.py
```

**输出**：`figs/paperX_perceptual_phase_transition.png`

**典型结果**：

| 模型 | γ | C | 说明 |
|:--|:--:|:--:|:--|
| 确定性平均场 | 1.022 | 5.110 | 与理论 γ=1 一致 |
| 经典随机 | 0.306 | 3.926 | 噪声主导首次 passage，指数偏低 |
| 非局域 α=0.3 | 0.556 | 1.739 | 非局域性改变有效标度 |
| 分数阶 β=0.7 | 1.425 | 5.044 | 与理论 γ=1/β≈1.429 一致 |

**诚实边界**：α 与 β 均为人为引入的 phenomenological 参数，不代表 UFPF 已从第一性原理导出谱非局域指数/谱维度；拟合指数受噪声、阈值、初始分布影响，不能与重整化群临界指数直接等同；无数值预言。

### A.13 诚实边界（附录级）

- 两个脚本均为**框架内 toy model**，目标态为人工设定，不对应真实神经编码；
- 数值结果与经典神经科学一致（高采样+高信息→时间膨胀，可预测→压缩，衰老/重复→飞逝），**无数值偏离预言**；
- 生物尺度的 UFPF 量子/谱修正（$\varepsilon^2\sim10^{-33}$）完全不可观测，脚本不引入此类效应；
- §4.7 的变分自由能泛函 $\mathcal{F}$ 与预测编码变分自由能在形式上相似，但未建立与 KL 散度/模型证据的严格等价；
- §4.8 主动推断 toy model 中"动作"被简化为标量 α 的梯度下降，不对应真实运动神经控制；
- §4.9 层级预测编码 toy model 为两层简化结构，不对应真实皮层反馈回路，L2 先验为人工设定；
- 若未来从本附录中产生可证伪的 UFPF 专属预言（例如依赖 $\varepsilon$ 的定量修正），则建议升级为独立技术 note 或并入 paper 附录。
