## 0. 一句话结论
**"相对熵 = Noether 荷"的证明由四条技术腿支撑：协变辛积 σ（App A）→ 对易子函数 Δ 与 Green 恒等式（App B）→ Δ 的 de Sitter 协变性（App C）→ 倾斜 Cauchy 面上模生成元的对易子化简 + 边界项消失（App D）。App D 的式 D12 是把"模流作用"翻译成"应力张量积分"的关键一步，式 D13 的边界项消失保证面积分良定义。**

## 1. Appendix A：协变正则量子化（第 11–13 页）

| 公式 | 内容 | 作用 |
|---|---|---|
| A1–A3 | 拉氏量 $\mathcal L=-\frac12(\nabla^\mu\phi\nabla_\mu\phi+m^2\phi^2)\sqrt{-g}$；协变动量 $\pi^\mu=-\nabla^\mu\phi$；Klein–Gordon 方程 | 场论的起点 |
| A4–A7 | 协变辛流 $J^\mu_{(1,2)}=i(\phi_1^*\pi^\mu_2-\phi_2\pi^\mu_{(1)})$ 守恒；辛积 $\sigma(\phi_1,\phi_2)=\int_\Sigma J^\mu n_\mu d^{n-1}\Sigma$；Gauss 定理 → Cauchy 面无关 | **σ 是整个证明的载体** |
| A8–A9 | t=0 面 $\sigma=i\int(\phi_1^*\dot\phi_2-\phi_2\dot\phi_1^*)d^{n-1}x$；反对称性 | 具体求值形式 |
| A10–A13 | 模式解 = 平面波 × Bessel 组合 $[J_\mu+ iY_\mu]$，$\mu\equiv\sqrt{(n-1)^2/4-m^2}/H$；$|c(p)|=\sqrt{\pi/4H}$；正交归一 | 谱分解 |
| A15–A18 | $\phi=\int(a\,f_p+a^\dagger f_p^*)$；CCR $[a(p),a^\dagger(q)]=(2\pi)^{n-1}\delta(p-q)$；等时 $[\phi,\dot\phi]=i\delta/\sqrt{-g}$；Bunch–Davies 真空 | 量子化 |
| **A17** | $\sigma(f_p,\phi)=a(p)$，$\sigma(f_p^*,\phi)=a^\dagger(p)$ | **湮灭算符 = 场与模式的辛积**——基态提取算子就是辛配对 |
| A19–A24 | Wightman 两点函数 $=\frac{H^{n-2}}{(4\pi)^{n/2}}I_\mu(x,x')$（超几何函数）；嵌入坐标 $i\epsilon$ 处方 | 因果结构从环境空间继承 |

要点：σ 是全场论的"空间"——场、对易子、湮灭算符都从它读出。这是 MUFPF"谱丛上的辛形式"的物理模板。

## 2. Appendix B：对易子与辛积（第 13–15 页）

| 公式 | 内容 | 作用 |
|---|---|---|
| B1–B5 | 推迟/超前传播子；对易子函数 $\Delta=G_{adv}-G_{ret}$；$[\phi(x),\phi(y)]=-i\Delta(x,y)$ | 因果结构编码 |
| B6–B9 | 涂抹场 $\phi(f)=\int f\,\phi\sqrt{-g}\,d^nx$（$f\in\mathcal S(\mathbb R^n)$）；内积 $(f,h)$；$[\phi(f),\phi(h)]=-i(\Delta f^*,h)$ | 分布化语言 |
| **B10–B14** | Green 恒等式（分部积分）→ $\boxed{(f,h)=-i\sigma(f,\Delta h)}$ | **把"场内积"翻译成"辛积"**——正文式 47 里 $\sigma(M\Delta f,\Delta f)$ 的来源 |
| B15–B18 | $\sigma(\phi,f)=(\phi,f)=-i\sigma(\phi,\Delta f)$；$[\phi(f),\phi(h)]=-\sigma(\Delta f^*,\Delta h)$；$[\sigma(\varphi,f),\sigma(\varphi,g)]=-\sigma(f^*,g)$ | 涂抹场 = 初值数据；对易子 ↔ 辛积词典 |
| **B19–B21** | Killing 矢量在内积下反对称 → $iD,iK_j,iP_j$ 对称 → **Noether 方法构造 Fock 空间对称算子 $\mathcal D,\mathcal K_j,\mathcal P_j$**，作用即对易子：$i[\mathcal D,\phi]=D\phi$ 等 | **守恒荷的量子实现**（自伴性引 [32] Borchers–Buchholz） |

要点：B21 是"几何 Killing 矢量 → 内积反对称 → i× 得对称算子 → 量子荷"的完整工序，**不依赖作用量的具体细节**。MUFPF 若要让"生成链自动长出守恒流"，这就是严格模板。

## 3. Appendix C：对易子的协变性（第 15 页）
- **C1（平移）**：$(P_j^x+P_j^y)\Delta(x,y)=0$ —— 平凡，平面波相位 $\partial_j e^{ipx}$ 抵消。
- **C2a–c + C3（boost）**：$(K_j^x+K_j^y)\Delta(x,y)=0$ —— 需要三条动量空间恒等式（$x^i f_p$、$p_i x^i f_p$、$x^2 f_p$ 改写为对 $\mathbf p$ 的导数）+ 分部积分。
- **意义**：Δ 是 de Sitter 不变的 ⇒ 正文 Sec. III 模 Hamilton 量 $K_\Omega=-2\pi M_{0j}$（式 34）与辛形式 $\sigma(M_{0j}\Delta f,\Delta f)$（式 47）自洽。**若 Δ 不协变，模流的"几何实现"就崩了**——这是整个"模理论 ↔ 几何"对接的相容性检查。

## 4. Appendix D：倾斜 Cauchy 面（第 15–16 页，Noether 荷证明的落点）
- **D1–D5**：$\Sigma=\{2Ht+\ln(1+H^2\boldsymbol x^2)=0\}$；未来指向法向量；诱导度规 $\gamma_{ij}=\frac{\delta_{ij}}{1+H^2x^2}-\frac{H^2x_ix_j}{(1+H^2x^2)^2}$，$\sqrt\gamma=(1+H^2x^2)^{-n/2}$。
- **D6–D10**：法向/切向分解；KG 方程在 Σ 上的形式（D9）；辛积在 Σ 上 $\sigma=i\int(\phi_1\partial_n\phi_2-\phi_2\partial_n\phi_1)\sqrt\gamma\,d^{n-1}x$（D10）。
- **D11–D13（核心计算）**：
  - D11：模生成元 $M_{0j}$ 沿 Σ 分解为 $\partial_n$ 部分 + 切向部分；
  - **D12**：对易子型括号在 Σ 上 =
    $$-\frac{x^j}{\sqrt{1+H^2x^2}}\Big[(\partial_n h)^2+\big((1+H^2x^2)\delta^{kl}-H^2x^kx^l\big)\partial_kh\,\partial_lh+m^2h^2+h(\nabla^2-m^2)h\Big]\ -\ \partial_k[\text{全导数项}]$$
  - **D13**：$\int\partial_k(\cdot)\sqrt\gamma\,d^{n-1}x=0$ —— 边界项严格消失（用 $\delta[2Ht+\ln(1+H^2x^2)]$ 积分 + 分部积分证明）。
- **意义**：D12 方括号内四项 = 正则标量应力张量 $T_{\mu\nu}(h)$ 的动力量（动能² + 空间梯度² + 质量项 + 运动方程项），配上系数 $x^j/\sqrt{1+H^2x^2}$ 与法向即得 $Q_j=n^\mu\xi^\nu_{(j)}T_{\mu\nu}$（式 71）。**这就是"模流的生成元对偶 = 应力张量"的落点**；D13 保证 $\int Q_j$ 良定义且正性可证（正文式 56 所说的"合适的 Cauchy 面"就是这里的 Σ）。

## 5. 完整证明链（Noether 荷证明的 8 步依赖链）
1. 模式展开（A10）→ 对易子函数 Δ（B3）→ $[\phi,\phi]=-i\Delta$（B4）；
2. Green 恒等式 → $(f,h)=-i\sigma(f,\Delta h)$（B14）→ 涂抹场 $\sigma(\phi,f)=-i\sigma(\phi,\Delta f)$（B15）；
3. Killing 矢量 → Noether 对称算子 $\mathcal D,\mathcal K,\mathcal P$（B19–B21）；
4. Δ 协变性（C1, C3）→ 模 Hamilton 量 $=-2\pi M_{0j}$（式 34，Bisognano–Wichmann + Borchers–Buchholz）；
5. Araki–Uhlmann → $S(f\|\Omega)=i\pi\,\sigma(M_{0j}\Delta f_+,\Delta f_+)$（式 47）；
6. 取倾斜 Σ（D1–D5）→ σ 在 Σ 上重写（D10）→ D11–D12 把 $M_{0j}$ 作用翻译成应力张量形；
7. 边界项消失（D13）→ $S=2\pi\int_{x^j\ge0}Q_j(\Delta f)\sqrt\gamma$（式 66，最终形式）；
8. $J^\mu=\xi^\nu T^\mu{}_\nu$ 守恒（式 69）→ $S=$ Noether 荷 $=\int\beta^\mu T_{\mu\nu}n^\nu$（式 73）→ 凸性二阶导 = NEC（式 79）。

衔接细节（第 10 页正文尾部，式 75–77）：$\beta(x)|_\Sigma=2\pi\Theta(x^j)\frac{x^j}{\sqrt{1+H^2x^2}}$，$S=\int\beta\,\epsilon(\Delta f)\sqrt\gamma$，$\epsilon\equiv u^\mu u^\nu T_{\mu\nu}$；平直极限 $H\to0$ 还原 $\beta\to 2\pi\Theta(x^j)x^j$ [49,50]。

**四点新结论**：
1. **$2\pi$ 的另一条出处链**：$S=i\pi\,\sigma(M\Delta f,\Delta f)$ 里 $i\pi$ 与模生成元的 $-2\pi$ 相乘得 $2\pi$——σ 的 $i$ 是辛积虚单位，$\pi$ 来自 $-2\pi M_{0j}$ 的 KMS 系数。MUFPF 内生 $2\pi$ 的靶点应锁定"模流周期 = 2π 的严格定理"（KMS/Bott 周期），而非凑数。
2. **荷的生成不依赖作用量**：B19–B21 只用"Killing 矢量 + 内积反对称 + 场变换"就构造出量子荷。这给 MUFPF 一个纯结构模板：**守恒荷 = 范畴自同构 × 内积反对称性**，无需先有拉氏量。
3. **B14 是"面积分 = 内积"的桥梁**：相对熵最终是 Δf 对易子函数的面积分，等价于一个内积——"量子信息量 = 谱丛内积"的严格对应。
4. **局限的附录级确认**：App A 的模式展开、App C 的协变性证明、App D12 的正则应力张量全部依赖自由标量场；相互作用时 Δ 的定义（B3）不再由两模函数给出、D12 的正则张量换作重整化张量——与作者正文自承"可能依赖重整化自由度 [51]"一致。这也是 MUFPF 的差异化空间（见对照表 §5）。
