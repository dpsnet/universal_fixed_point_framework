## 2. 精确形式：偏转语言下的 F = dp/dt

用 rapidity φ 与偏转角 θ 的恒等式（c = 1）：

- 时间耦合 $\cos\theta = d\tau/dt = 1/\gamma = \mathrm{sech}\,\varphi$；
- $\tan\theta = \sinh\varphi = \gamma v$，$\sec\theta = \cosh\varphi = \gamma$。

动量 $p = m\gamma v = m\sinh\varphi = m\tan\theta$。于是

$$F = \frac{dp}{dt} = m\cosh\varphi\,\dot\varphi = m\sec\theta\,\dot\varphi.$$

- **θ = 0（静止）**：F = m·φ̇ ⟹ 低速极限恢复 F = ma；
- **θ 固定时**：m 越大，同样的偏转速率 φ̇ 需要的力越大——**力 = 难度系数 × 当前偏转状态 × 偏转速率**；
- **做功 = 支付难度代价**：$\frac{dE}{d\varphi} = m\sinh\varphi$，且 $F\cdot v = m\sec\theta\,\dot\varphi\cdot\tanh\varphi = m\sinh\varphi\,\dot\varphi$——力做功恰是"时间轴偏转的难度代价"变化率。这就是 §1 直觉的动力学精确化：**力是难度代价的支付代理人**。

### 2.1 纵向/横向分解（[论文] + [衔接]）

三维中 F = dp/dt 按偏转几何分解：

- **纵向力**：改变 |v| ⟹ 改变偏转角大小 θ（rapidity φ̇）——支付难度代价的方向；
- **横向力**：改变运动方向 ⟹ 偏转面的水平旋转（动量方向的角速度 Ω̇，θ 大小不变）——不改变难度（θ 不变），只旋转偏转方向；匀速圆周运动的向心力即属此类。

**衔接（2026-08-15）**：横向力 = 偏转面内水平旋转——与"旋转 90°"（质量笔记 §7：引力 θ_g = 惯性 θ_i 水平旋转 90°）同一几何族：**改变运动方向与改变时间倾斜方向，是同一偏转结构在垂直面内不同角度的旋转**（[衔接]；几何一致 ≠ 推导证明，见 §12 诚实边界）。

## 4. 双法向偏转统一下的力 [论文]（v0.8 升级）

**锚点升级（v0.8 核查 paper35）**："引力不是力"是 paper35 摘要/引言的显式表述——**"引力不是 $\mathbf{Sp}$ 4-范畴中与其他三个'力'并列的第四个相互作用，而是范畴结构本身的自洽性条件"**；§3"$\Delta$ 不是场，因此不可屏蔽"；对比表"引力的角色：范畴 coherence 条件（非动力学）"——引力 = 几何/范畴结构条件为 [论文] 级。

paper44 §5.3 双法向偏转统一：惯性 = 切向扬起 θ_i、引力 = 径向扬起 θ_g，共享垂直时间轴——**两种"质量"是同一时间倾斜几何的双重读法**（质量笔记 §7）。力的对应：

- **惯性"力"**：切向偏转的推动——运动学驱动；
- **引力"力"**：径向偏转的推动——但 GR 标准结论（[论文]）引力不是力：自由落体沿自然时间倾斜场流动（测地线）零感受；"引力" = 时间方向场的空间梯度（几何，质量笔记 §5 引力侧谱流表达）——UFPF 侧为 paper35 的 $\Delta$ = 交换律偏差（范畴结构自洽性条件）；
- **真力** = 使时间方向**偏离其自然场配置**的谱流驱动 + 约束——静止于地表被支撑 = 时间方向被迫偏离局部自然场 = 有力；自由落体沿自然场 = 零力。

**统一候选**：惯性/引力 = 同一几何的两种读法（已闭合，paper44 §5.3）；真力 = 谱流生成元（[论文]，§3）。"力"作为独立实体消失——剩下几何（时间倾斜场）+ 谱流驱动（生成元）。

**力侧等效原理（v0.3）**：双法向偏转统一（paper44 §5.3）⟹ 力侧对应——**惯性力（切向驱动的响应）与引力（径向几何驱动）是同一时间倾斜结构的两种读法**：同一"推动偏转"行为，从自身看是惯性力（运动学），从源看是引力（径向场）。这是质量侧等效原理（m_i = m_g，paper18 §11）的动力学对应——质量侧等价的量，其驱动侧自动等价（[衔接]；几何一致 ≠ 推导证明）。

## 5. 力 = 关系而非实体 [衔接]

把 §1 范畴读法展开：

- **对象** = 递归系统 R（谱像 A = D(R)），质量 = 单对象属性（谱间隙，paper16 定理 6.3）；
- **力 = 态射** = 两对象间的作用，谱形式 = 对易子 [A₁,A₂]（paper18 定义 3.1）；
- **力的代数** = 态射空间（Lie 括号）——反对称性（§3.2）、守恒律（§3.3）、独立性判据（§9）全部是态射代数的结构性质；

## 6. 同心圆图像登记 [衔接]

### 9.6 旋转参考系的惯性力：离心/科里奥利的几何定位（v0.10，[衔接]）

**问题**：旋转参考系中的"伪力"（离心力、科里奥利力）在双法向偏转统一中如何定位？

**锚点**：标准物理（[论文]）——爱因斯坦转盘：旋转参考系边缘时间膨胀 ∝ 离心势，等效原理的旋转版本；离心力 = 径向"伪力"（切向运动的约束表现），科里奥利力 = 横向"伪力"（运动方向偏转）。

**框架内定位（[衔接]）**：

- **离心力 = 径向驱动**：旋转 = 切向驱动的循环积累——圆周运动中惯性（切向扬起 θ_i，v = ωr）与离心势（径向 θ_g，φ_c = ½ω²r²）同时存在，正交叠加 θ² = θ_i² + θ_g²——**质量笔记 §7.5 旋转检验差异函数 θ²(φ) = θ_i²cos²φ + θ_g²sin²φ 的物理实例（转盘上 φ 自动固定于 45°，见下方数值精确化）**；
- **科里奥利力 = 横向驱动**：运动方向偏转 = 偏转面水平旋转——与 §2.1 横向力同构（θ 大小不变、方向旋转）；转盘中 = 切向运动被径向位移偏转。

**核心洞察（[衔接]）**：**切向运动的循环积累产生径向"伪引力"**——旋转（纯切向驱动）在转盘上表现为径向离心力，与引力（径向驱动）同构。这与质量笔记 §7"惯性 θ_i 水平旋转 90° = 引力 θ_g"**动力学同构**：旋转 90° 不只是几何连接（时间轴倾斜方向），还是动力学连接（切向循环 ⟹ 径向伪引力）——**转盘 = 等效原理在"旋转 90°"处的工作实例**。

**数值精确化（v0.11，[论文] + [衔接]）**：转盘边缘 r、角速度 ω（v = ωr）：

- 惯性侧 $\sin\theta_i = v/c = \omega r/c$（切向扬起）；
- 引力侧 $\cos\theta_g = \sqrt{1 - 2\phi_c/c^2} = \sqrt{1 - \omega^2 r^2/c^2}$（离心势钟慢）⟹ $\sin\theta_g = \omega r/c$；
- **低速极限 $\theta_i = \theta_g$**——转盘**自动满足**谱交织/等效原理（分配固定于 φ = 45°）；总钟慢 $\dfrac{d\tau}{dt} = \sqrt{1-\omega^2 r^2/c^2} = 1/\gamma$：切向 SR 钟慢与径向离心势钟慢**自动一致**，无需任何调整。

**平台定位修正（v0.11）**：转盘 + 光钟 = **谱交织自动展示平台**，**非** φ 可调检验平台——θ_i 与 θ_g 的分配由同一 ω、r 决定，**无法独立扫描 φ**（旋转检验所需的自由度 φ 不是任何自然系统自动具备的，需实验设计）。转盘的意义：**"θ_i = θ_g 自动成立"是可测的事实**（φ = 45° 单点钟慢 ∝ ω²r²/c²；例：r = 10 m、ω = 10 rad/s ⟹ θ ≈ 3.3e-7 rad、Δτ/τ ≈ 5.5e-14，光钟 1e-18 精度可测）——但单点测量不能分离 θ_i/θ_g，不能给出 sin²φ 签名；该签名需要 φ 可调的设计（如地面运动光钟扫描速度方向，接质量笔记 §7.5 的 θ_i/θ_g 分配）。

**地位**：[衔接]——标准物理（转盘时间膨胀）为 [论文]，"切向循环 ⟹ 径向伪引力 ⟷ 旋转 90°"为本笔记框架内连接；与 §2.1 横向力、§4 力侧等效原理、质量笔记 §7.5 旋转检验互锁。
