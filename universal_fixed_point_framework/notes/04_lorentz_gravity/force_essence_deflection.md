## 2. 精确形式：偏转语言下的 F = dp/dt

用 rapidity φ 与偏转角 θ 的恒等式（c = 1）：

- 时间耦合 $\cos\theta = d\tau/dt = 1/\gamma = \mathrm{sech}\,\varphi$；
- $\tan\theta = \sinh\varphi = \gamma v$，$\sec\theta = \cosh\varphi = \gamma$。

动量 $p = m\gamma v = m\sinh\varphi = m\tan\theta$。于是

$$F = \frac{dp}{dt} = m\cosh\varphi\,\dot\varphi = m\sec\theta\,\dot\varphi.$$

- **θ = 0（静止）**：F = m·φ̇ ⟹ 低速极限恢复 F = ma；
- **θ 固定时**：m 越大，同样的偏转速率 φ̇ 需要的力越大——**力 = 难度系数 × 当前偏转状态 × 偏转速率**；
- **做功 = 能量动力学转移**：$\frac{dE}{d\varphi} = m\sinh\varphi$，且 $F\cdot v = m\sec\theta\,\dot\varphi\cdot\tanh\varphi = m\sinh\varphi\,\dot\varphi$——力做功恰是"时间轴偏转的能量变化"率（功率 P = F·v = dE/dt）。这就是 §1 直觉的动力学精确化：**力是能量转移的动力学机制**（做功 = 偏转能量变化）。

### 2.1 数学核心严谨化：三维分解、四动量与谱力衔接（v0.14，[论文] + [衔接]）

**① 能量-动量四矢量的偏转语言形式（[论文]）**

四动量 $P^\mu = (E, \mathbf{p}) = m(\cosh\varphi,\ \sinh\varphi\,\hat n) = m(\sec\theta,\ \tan\theta\,\hat n)$：

- 时间分量 E = m·secθ（难度 × 时间耦合倒数）；
- 空间分量 p = m·tanθ·n̂（难度 × 偏转的空间投影）；
- **质量壳恒等式** $E^2 - p^2 = m^2(\sec^2\theta - \tan^2\theta) = m^2$——偏转语言的 $\sec^2\theta - \tan^2\theta = 1$ 自动满足（同 paper44 图 5 语言）；四动量守恒 ⟺ paper18 定理 7.1/7.2 的能量/动量守恒（偏转读法）。

**② 三维力分解的完整公式（[论文] + [衔接]）**

三维 $\mathbf{F} = d\mathbf{p}/dt$ 按偏转几何分解为纵向 + 横向：

$$\mathbf{F} = m\sec\theta\,\dot\varphi\,\hat n \;+\; m\tan\theta\,\dot\Omega\,\hat\varphi_\perp$$

- **纵向**（沿 n̂，改变 θ/φ）：$F_\parallel = m\sec\theta\,\dot\varphi$——能量转移的方向（§2 一维结果的三维化）；
- **横向**（⊥ n̂，旋转偏转面）：$F_\perp = m\tan\theta\,\dot\Omega$——θ 不变、方向旋转（Ω̇ 为 n̂ 角速度）。

**一致性验证（[论文]）**：与标准相对论分解 $\mathbf{F} = \gamma^3 m\,a_\parallel + \gamma m\,a_\perp$ 一致——

- $a_\parallel = d\tanh\varphi/dt = \mathrm{sech}^2\varphi\,\dot\varphi$，$\gamma^3 = \cosh^3\varphi$ ⟹ $F_\parallel = m\cosh\varphi\,\dot\varphi = m\sec\theta\,\dot\varphi$ ✓
- $a_\perp = \tanh\varphi\,\dot\Omega$，$\gamma m = m\cosh\varphi$ ⟹ $F_\perp = m\sinh\varphi\,\dot\Omega = m\tan\theta\,\dot\Omega$ ✓

**③ 与 paper18 谱力的严格衔接（[衔接]）**

- **能量链闭环**：E = m·secθ ⟹ dE/dt = m·tanθ·secθ·φ̇ = F·v（§2 已证）——偏转语言下"力做功 = 能量动力学转移"与四动量时间分量自动一致；

### 3.1a secθ 因子的谱侧推导（v0.15，[衔接]）

**目标**：把 §3.1 的"secθ 因子"从断言推进为推导。

**前提（[衔接] 建模）**：时间耦合编码于 A_t 特征值——运动时能量特征值 $\lambda(t) = \lambda_0\sec\theta(t)$，其中 λ₀ = Δλ_min 级（静止谱间隙，paper16 定理 6.3）。前提为 paper44 图 5（时间耦合 = cosθ）+ paper16 定理 6.3（质量 = 谱间隙）的组合建模，推导链本身严格。

**推导链（严格）**：

1. 由 $\tan\theta = \sinh\varphi$：$\theta$ 与 rapidity 的关系 $\dot\theta = \cos\theta\,\dot\varphi$（$\frac{d\tan\theta}{dt} = \sec^2\theta\,\dot\theta = \cosh\varphi\,\dot\varphi$）；
2. **一阶谱演化**（paper18 定义 3.2 的谱速度）：$\dfrac{d\lambda}{dt} = \lambda_0\sec\theta\tan\theta\,\dot\theta = \lambda_0\tan\theta\,\dot\varphi$；
3. **经典极限**（λ₀ → m，paper18 命题 3.1）：$\dfrac{d\lambda}{dt} = m\tan\theta\,\dot\varphi = m\sec\theta\,\dot\varphi\cdot\sin\theta = F\cdot v$（v = sinθ，§2 恒等式清单）；
4. **闭环**：$E = m\sec\theta$ ⟹ $\dfrac{dE}{dt} = m\sec\theta\tan\theta\,\dot\theta = m\tan\theta\,\dot\varphi = \dfrac{d\lambda}{dt}$——**谱特征值演化率 = 力做功功率 = 能量变化率**（三者严格一致）。

**结论（[衔接]）**：谱力 $F_{\rm spec} = [G,A]$（paper18 定义 3.1）驱动的是编码时间耦合的能量特征值 λ(t) = λ₀·secθ(t)，其一阶演化 dλ/dt = F·v 给出 secθ 因子的谱侧来源——"力做功 = 能量动力学转移"的谱形式。二阶（d²λ/dt²）对应谱加速度，衔接 F_spec = m_spec·a_spec（定理 3.2）。**推导是严格的，前提（λ = λ₀·secθ）为 [衔接] 建模**。

### 9.6 旋转参考系的惯性力：离心/科里奥利的几何定位（v0.10，[衔接]）
