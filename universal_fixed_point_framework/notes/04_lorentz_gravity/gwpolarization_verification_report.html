四、缺口 G1：张量横波极化 +, ×

G1.1 问题回顾

T-03 形式化中引力波信号是 RecObj Y 中的周期态——状态 y 满足 Y.step^n y = y。这是标量/离散概念，不包含空间方向或张量结构。物理上引力波有两个独立的横向张量极化模式 + 和 ×（TT 规范下二阶对称无迹张量）。

G1.2 方案 A 实现：Pauli 矩阵极化分解

核心思路
  1. 2×2 谱算子 M 可经 Pauli 矩阵分解为三个分量 + 单极
  2. plusAmplitude = ⟨σ_x, M⟩_HS = tr(σ_x† · M) → + 极化振幅
  3. crossAmplitude = ⟨σ_y, M⟩_HS = tr(σ_y† · M) → × 极化振幅
  4. 周期源 → 谱算子迭代周期 → 极化振幅周期振荡
  5. 单极 = 不动点（不辐射）；四极 = 非平凡周期态（辐射）

G1.3 关键定义与定理

对称地对 X₂ / ch₂ 得 n₂。最终给出 ∃ n₁ n₂, 两通道极化投影周期性同时成立。

五、缺口 G3：四极辐射约束

G3.1 问题回顾

广义相对论中引力辐射无单极（质量守恒）、无偶极（动量守恒），最低阶为四极辐射。需在范畴层面证明此约束。

G3.2 关键洞察：G3 与 G1 统一

G3（四极约束）与 G1（极化模式）有共同数学根源：耦合矩阵的迹 = 单极（不辐射），无迹部分 = 四极（辐射）。Pauli 矩阵自然给出 + 和 × 两个自由度。

十、§19 SO(2) 极化基旋转不变性（缺口 7 部分闭合）

§19.1 问题回顾

§19.3 物理意义

虽然单个 h₊, h× 的值依赖传播方向选取（Pauli 基的选取），但极化功率 h₊² + h×² 是 SO(2) 不变量——物理可观测量不依赖方向选取。这将缺口 7 从"需内生推导传播方向"降级为"物理观测量不依赖方向选取"。
