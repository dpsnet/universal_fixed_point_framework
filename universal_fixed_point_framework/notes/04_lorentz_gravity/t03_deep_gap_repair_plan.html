一、缺口总览

T-03 引力波时序震荡定理已完成形式化（T03_gravitational_wave_timing_oscillation 零 sorry 闭合），但其物理预言力受限于三个深层缺口。这些缺口的共同根源是：当前 Rec/Sp 范畴仅有抽象的递归动力学和谱数据，尚缺从抽象振荡到物理时空张量波的投影机制。

缺口描述优先级性质
G1 张量横波极化 +, ×：标量相位震荡如何投影为横向张量极化 最高 公理性——若无法内生导出则需增补独立公理
G2 传播速度：函子耦合传递不强制等于 c 中 定量性——需定义耦合延迟与涌现度规的对应
G3 四极辐射约束：无单极、无偶极的范畴证明 中 结构性——需多极分解机制

二、缺口 G1：张量横波极化 +, ×

G1.1 问题诊断

当前 T-03 形式化中，引力波信号是 RecObj Y 中的周期态——某个状态 y ∈ Y.T 满足 Y.step^n y = y。这是一个标量/离散概念：状态在 n 步后回到自身，但不包含任何空间方向信息或张量结构。

物理上，引力波有两个独立的横向张量极化模式：

e₊ = (ê_x ⊗ ê_x − ê_y ⊗ ê_y) / √2   （plus 极化）
e× = (ê_x ⊗ ê_y + ê_y ⊗ ê_x) / √2   （cross 极化）

两者均为横向无迹（transverse traceless, TT）的二阶对称张量。问题的核心是：Rec 范畴中的标量振荡通过什么机制产生这些张量模式？

G1.2 现有基础设施分析

已有构件（可直接复用）
  • DFunctor : RecObj ⥤ SpObj（DecursionFunctor.lean）——将 RecObj 映射为其转移矩阵（Koopman 算子），周期态映射为单位圆上的特征值
  • hilbertSchmidtInnerProduct（SpCategory.lean）——Sp 范畴上的内积，可用于投影到子空间
  • spectralFlowTransform（SpCategory.lean）——谱流变换 U·A·V，无穷小版本 dA/dτ = [H, A] 已由 C7 定理建立
  • Pauli 矩阵 σ_x, σ_y, σ_z（SpCategory.lean）——2×2 无迹 Hermitian 基，是 TT 张量的最小实现
  • Clifford.lean——Clifford 代数生成元 e_01, e_10, e1_20, e2_20，提供方向性结构
  • spectral_lorentz_dynamics.md——已建立 Lorentz 群 = 谱流生成元理论：dA/dτ = [G_Lor, A_τ]

G1.3 三种候选方案

方案 A 耦合形状张量分解（推荐）

核心思路：从 BinaryCoupling 的双通道结构直接构造 2×2 耦合形状矩阵，分解为单极/偶极/四极分量。四极分量天然给出 + 和 × 两个独立自由度。

具体构造：

  1. 对 BinaryCoupling (X₁, X₂, Y)，经 D 函子得谱耦合 D(ch₁) : D(X₁) ⟶ D(Y) 和 D(ch₂) : D(X₂) ⟶ D(Y)，各有转移矩阵 P₁, P₂
  2. 构造 2×2 耦合形状矩阵：
    S = (1/√2) · [[⟨P₁,P₁⟩_HS, ⟨P₁,P₂⟩_HS], [⟨P₂,P₁⟩_HS, ⟨P₂,P₂⟩_HS]]
    其中 ⟨·,·⟩_HS 为 Hilbert-Schmidt 内积
  3. S 是 Hermitian 矩阵（因 HS 内积的共轭对称性），可分解为：
    • 迹 tr(S)/2 · I = 单极分量（总耦合强度，守恒，不辐射）
    • 无迹部分 S - tr(S)/2 · I = 四极分量（含 + 和 × 两个自由度）
  4. 无迹 Hermitian 2×2 矩阵 = Pauli 展开：S - (tr S/2)·I = a·σ_x + b·σ_y + c·σ_z，其中 a, b, c 为实系数
  5. 取横向截面（z 方向传播）：a → h₊, b → h×, c → 纵向分量（TT 规范下设为 0）

优点：完全使用已有 Sp 范畴基础设施；耦合形状矩阵自然从 BinaryCoupling 涌现；Pauli 分解已由 anticomm_traceless_2x2 和 sq_traceless_2x2 支撑。

风险：耦合形状矩阵的 Hermitian 性需验证；"横向截面"的选取需额外假设（什么定义传播方向？）。

可行性：高 可在现有框架内实现

方案 B 谱算子不可约分解（内生性更强但技术难度大）

核心思路：直接对观测者的谱算子 D(Y).A 做 SO(3) 不可约表示分解。利用 spectral_lorentz_dynamics.md 中已建立的 Lorentz 谱流方程 dA/dτ = [G_Lor, A_τ]，将 D(Y).A 分解为标量 (l=0)、矢量 (l=1)、张量 (l=2) 分量。

具体步骤：

  1. 定义 Lorentz 谱生成元嵌入 ι_Lor : so(1,3) → Sp 的 Lean4 形式（6 个反 Hermitian 生成元 J_i, K_i）
  2. 对 D(Y).A 做不可约分解：A = A_scalar + A_vector + A_tensor
  3. A_scalar = tr(A)/n · I（l=0，不动点，不辐射）
  4. A_vector = (A - A^T)/2（l=1，反对称，对应偶极）
  5. A_tensor = (A + A^T)/2 - A_scalar（l=2，对称无迹，对应四极）
  6. A_tensor 在横向截面投影给出 + 和 ×

优点：内生性最强——直接从 Lorentz 群表示论导出极化模式；与 spectral_lorentz 理论无缝衔接。

风险：Lean4 Mathlib 中缺乏 SO(3) 不可约表示的完整基础设施；4 维分解需要大量矩阵展开计算。

可行性：中 需约 2-3 倍方案 A 的工作量

方案 C 增补极化公理（保底方案）

核心思路：若方案 A 和 B 均遇阻，则承认张量极化无法从狭义 MUFPF 公理内生导出，增补独立公理：

Axiom GW-Pol：涌现截面中，谱振荡投影为 TT 规范下的 +, × 双极化模式

这将使假说从"狭义 MUFPF 内生推论"降级为"狭义 MUFPF + 一条额外公理"。

优点：最小工作量。

风险：破坏内生性原则；研究笔记 §3.3 明确将此列为"假说不再是狭义MUFPF内生推论"的风险。

可行性：最低工作量但最不理想

G1.4 推荐路径

优先执行方案 A（耦合形状张量分解），理由：

  1. 所有计算工具已存在于 SpCategory.lean（HS 内积、Pauli 矩阵、无迹分解）
  2. BinaryCoupling → 耦合矩阵 → Pauli 分解的路径自然且物理直观
  3. 若方案 A 成功，可作为方案 B 的基础（Pauli 展开等价于 l=1 不可约表示）
  4. 方案 C 仅作为兜底，不作为首选

三、缺口 G2：传播速度

G2.1 问题诊断

当前 T-03 的链式传导定理 chain_propagates_periodic 证明信号经 RecHom 链 X → Y → Z 保持周期性，但完全没有"速度"概念——Rec 范畴中只有迭代步数，没有空间距离。

物理上，GW170817 约束引力波速度 |v_gw - c| / c < 10^-15。框架需要解释为何函子耦合传递速度近似等于 c，以及更高/更低递归层级是否允许偏移。

G2.2 候选方案

方案（推荐） 耦合延迟 + 伴随余留 → 速度对应

核心思路：在 Rec 范畴定义"耦合延迟"为 RecHom 的信息传递步数；在 Sp 范畴通过伴随余留（C5 定理）将其与谱间隙关联；在涌现截面中映射为物理速度。

具体定义：

  1. 零阶耦合（严格伴随 δ=0）：RecHom φ 满足 φ.toFun (X.step x) = Y.step (φ.toFun x)，即 iterate_comm 给出 φ(step^n x) = step^n(φ(x))——信息传递零延迟。在涌现截面中，零延迟 = 极限速度 c。
  2. 弱耦合（δ≠0）：引入"伴随偏差" δ 后，谱交织条件变为 P * Y.A = X.A * P + δ（有余项）。此时 iterate_comm 不再精确成立，每步迭代产生残差累积——对应有限延迟。
  3. 速度公式：v = d_emergence / delay_rec，其中 d_emergence 是涌现截面中的空间距离，delay_rec 是 Rec 范畴中的耦合延迟步数。严格伴随 → delay=0 → v=c；弱伴随 → delay>0 → v
  4. C5 连接：伴随余留 E_residual = tr((A_X - A_Z)·δ·η^h)（SpCategory.lean 已定义）。δ=0 时 E_residual=0（v=c），δ≠0 时 E_residual≠0（v≠c），且 |v-c|/c ∝ |E_residual|。

形式化计划：

-- 耦合延迟：RecHom 的信息传递步数 -- 严格 RecHom（δ=0）: delay = 0（iterate_comm 精确成立） -- 弱耦合 RecHom（δ≠0）: delay > 0（iterate_comm 有残差） -- 谱交织偏差与伴随余留的关联（已有） -- adjunctionResidual (SpCategory.lean) = tr((A_X - A_Z)·δ·η^h) -- c5_zero_defect_zero_residual: δ=0 → E_residual=0（已有） -- 新增定理：严格伴随 → 零延迟 → 极限速度 theorem strict_adjunction_implies_light_speed ... := -- δ=0 → iterate_comm 精确 → delay=0 → v=c ... -- 新增定理：弱伴随 → 正延迟 → 亚光速 theorem weak_adjunction_implies_sublight ... := -- δ≠0 → iterate_comm 有残差 → delay>0 → v ...

优点：直接复用 C5 伴随余留机制；不需要额外公理；自然解释 GW170817 约束（当前层级的 δ 极小）。

风险：从 Rec 延迟到涌现速度的映射需要额外定义"涌现度规"；定量预测 |v-c|/c 的具体值需要物理常数对接。

可行性：高 核心结构已有，主要是定义和连接工作

四、缺口 G3：四极辐射约束

G3.1 问题诊断

广义相对论中引力辐射无单极（质量守恒）、无偶极（动量守恒），最低阶为四极辐射。当前 T-03 形式化没有任何多极分解机制——所有周期信号被平等对待，无法区分单极/偶极/四极。

G3.2 关键洞察：G3 与 G1 的统一

仔细分析后发现，G3（四极约束）与 G1（极化模式）有共同的数学根源：

  • G1 的方案 A（耦合形状矩阵分解）中，迹 = 单极，无迹部分 = 四极
  • 单极对应不动点（step x = x），不是周期态（n ≥ 1），因此不辐射
  • 偶极对应刚体平移（所有 RecHom 共有的全局平移），也不辐射
  • 只有四极（内部形变）才能产生周期振荡（step^n x = x, n ≥ 2）

因此 G3 的修复可以复用 G1 方案 A 的分解结果。

G3.3 形式化计划

多极约束定理

定理链：

  1. 单极 = 不动点：耦合形状矩阵的迹 tr(S)/2 对应耦合的总强度。若两个源都是不动点（step x = x），则 S 不随时间变化 → 迹为常数 → 单极不辐射。
  2. 偶极 = 质心运动：耦合矩阵的反对称部分（S - S†）/2（对于 Hermitian 矩阵为零）。物理上，偶极对应两源的相对平移，在动量守恒下为零。
  3. 四极 = 内部形变：无迹对称部分 S - (tr S/2)·I。只有当源有内部周期动力学（偏心子集群），此部分才随时间振荡 → 四极辐射。

优点：与 G1 方案 A 共享基础设施；单极/偶极/四极的区分自然从矩阵分解涌现；不需要额外公理。

风险：需要证明"Hermitian 矩阵的反对称部分为零"→ 偶极不辐射，这在 2×2 情形可由 anticomm_traceless_2x2 支撑，但一般维度需要推广。

可行性：高（与 G1 共享约 70% 工作量）
