## 3. 符号论证（MUFPF 层）

### 3.1 论证骨架

```
MUFPF 范畴公设（对象/生成箭头/谱丛 End(C)）
   ↓
真空态 = 区域子代数上的模态（KMS，逆温 β=+2π）
   ↓
区域 = 楔形区 W（模理论舞台）⇒ 要求 W 非空且具类空 Killing 视界结构
   ↓
W 的存在性（几何判据）：嵌入双曲面必须类空（X^A X_A = +H⁻²）
   ⇒ Λ = 3H² > 0 ⇒ H > 0（de Sitter，非 AdS）
```

关键命题：**Λ 的符号 = 区域（楔形区）几何存在性的推论**，而非观测输入。

### 3.2 抓手一：楔形区非空性（几何判据，可机检）

2310 的全部模理论计算依赖楔形区 W_j = {X^j > |X^0|}：
- dS 情形（X^A X_A = +H⁻²，类空嵌入）：W_j **非空**——取 X^0=0、X^j=1/H 即满足
  双曲面约束与不等式。模流由 boost K_j 生成，几何上良定义。
- AdS 情形（X^A X_A = −H⁻²，类时嵌入）：2310 式 13 型楔形区的**类空截面 + 类光
  边界结构不成立**（类时双曲面的"双楔形区"是边界-边界结构，其模算子由边界全纯性
  决定，与 2310 的体区楔形区计算不是同一对象）。

⇒ **第一判据（候选 Lean 化）**：∃X∈ℝ^{n,1}，X^A X_A = +H⁻² ∧ X^j > |X^0|（dS
楔形区非空）在类空嵌入下可证；类时嵌入（−H⁻²）无对应结构。这是一个纯坐标存在性
命题，可在 ℝ 层形式化（见 §4）。

### 3.3 抓手二：KMS 正逆温与区域定向（约定层，一致性条件）

模算子 Δ_Ω = e^{−2πM}（2310 式 34）的逆温 β=+2π 不是孤立约定：它与**楔形区选择**
（X^j>|X^0| 而非 X^j<−|X^0|）及**时间定向**共同构成一组一致条件。翻转楔形区把
Δ_Ω 换成 Δ_Ω⁻¹（交换"真空/激发"），但 Araki–Uhlmann 相对熵 S(ω|ω_Ω) ≥ 0 不变——
说明**符号的物理内容不在模算子本身，而在区域-流-温度三者的定向一致性**。

MUFPF 的表述：因果范畴的生成箭头方向（范畴定向）⇒ 谱丛自同态环的模流方向 ⇒
KMS 逆温取 +2π 而非 −2π ⇒ H>0 而非 H<0。这个方向一致性是范畴层结构（定向）的
推论——**符号论证独立于 Λ 观测即由此成立**。

### 3.4 抓手三：与 2510 的对照（论文可用段落）

  方程**，Λ 的符号未被推导约束"；
- 2310：Λ=3H²>0（背景层，固定输入）——"背景给正 Λ，机制未解释"；
