## 4. 统一分配机制（候选推导）

**候选机制**：静默 4 方向在观测窗口（w ≥ S₄，paper40 §5.10）筛选后按两个通道分配——

**通道 A（纵向 → 耦合/规范）**：静默方向的动量空间纵向投影 = 规范冗余（D3，已推导）。规范群自由度（A_EM 与 U(1) 同构，paper5 §5.2）对应静默方向的纵向通道。

**通道 B（横向 → 法向/偏振）**：静默方向的横向投影（im W 内 ⊥ q̂ 部分）表现为观测层的横向自由度——光子偏振（ε₁,ε₂ ⊥ k）占用此通道（零质量 ⟹ 无纵向分量，paper44 命题 3.1）。这是"静默 → 法向"的分配。

**分配结构**：观测层 4D 中，静默内容 = ker W（纵向 1 维，通道 A）；可见内容 = im W（横向 3 维 = 空间方向数，D4）。光子零质量分支的偏振 = im W 内 ⊥ k 的 2 维（通道 B 在观测层内的进一步筛选）。Cl(1,7) 的 4 静默方向与观测层 4D 的"纵向 1 + 横向 3"之间的对应为候选映射（无机器证明）。

### 4.4 谱类型判据：虚谱→规范/纵向、实谱→法向/横向（v0.5 推进）

**判据表述**：静默方向到纵向/横向的物理分配由**谱类型**决定——

**锚点（[论文]，力笔记 §9.4 分工结论）**："虚部破缺 = 规范 = 力；实谱边界破缺 = 几何 = 非力"——即谱类型已作为生成元形态判据在 paper5 定理 5.1/5.2 确立。本判据将其**延伸到静默方向的角色分配**（纵向 = 规范 = 虚谱；横向 = 法向 = 实谱）。
