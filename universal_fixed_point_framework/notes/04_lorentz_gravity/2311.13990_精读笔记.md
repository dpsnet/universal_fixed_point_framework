## 0. 一句话结果
**在 dS 钻石区内，真空与相干态的相对熵 = (1/4G_N) × 宇宙学视界面积扰动的零平均（式 24）——熵面积律不再是假设而是定理；相对熵凸性给出 QNEC；广义熵 δS_gen = 0（守恒）；静息观测者测得局部温度 β = (2π/H)(1−e^{−H(T−T_min)})，主项即 Gibbons–Hawking 温度，修正指数衰减。**

## 1. Setup：dS 钻石区与模 Hamilton 量（Sec. 2）
- 静态 patch 度规（式 2）：$ds^2=-(1-H^2R^2)dT^2+(1-H^2R^2)^{-1}dR^2+R^2d\Omega^2$；宇宙学视界在 $R=H^{-1}$。
- dS 钻石（式 3）：$\Diamond=\{(\eta,\boldsymbol x): r\in[0,\ell),\, \eta\in(\chi-\ell+r,\chi+\ell-r)\}$。
- 共形标量场（维数 $\Delta$）在共形真空中的模 Hamilton 量 = 量子应力张量的曲面积分（式 4），共形 Killing 矢量（式 5）：
$$\xi^\mu=\frac{\pi}{\ell}\big[(\ell^2-\tau^2)\delta_0^\mu+2(\tau-\eta)x^\mu-x^2\delta_0^\mu\big]$$
（来源 [54] = 2308.14797）
- 相干态相对熵（式 6/7）：$S=\frac12\langle[\phi(f_\omega),[\phi(f_\omega),\mathcal H_{\chi,\ell}]]\rangle=-\frac12\iint\frac{\delta^2\mathcal H}{\delta\phi\delta\phi}(\Delta f_\omega)(\Delta f_\omega)$。
- 经典 improved 应力张量（式 9）：$T_{\mu\nu}(f)=\frac23\partial_\mu f\partial_\nu f-\frac13 f\partial_\mu\partial_\nu f-\frac16\eta_{\mu\nu}\partial_\rho f\partial^\rho f$。
- **显式结果（式 11，正性显式）**：
$$\mathcal S=\frac{\pi}{2\ell}\int_{\eta=\chi}\Big[(\ell^2-x^2)\big(\partial_\eta(\Delta f_\omega)\partial_\eta(\Delta f_\omega)+\partial_i(\Delta f_\omega)\partial^i(\Delta f_\omega)\big)+2(\Delta f_\omega)^2\Big]d^3\boldsymbol x.$$

## 2. 凸性 → QNEC（Sec. 3）
- half-sided modular inclusion 的几何实现：**钻石向未来收缩、未来尖端固定**（式 12）——比 2310 的楔形族更物理的区域族。
- 关键恒等式（式 13）：$\partial_\ell^2 S=-(2/\ell)\partial_\ell S$ ⇒ $S=\mathcal S_1/\ell+\mathcal S_2$（式 14）；正性 ⇒ $\mathcal S_1,\mathcal S_2>0$ ⇒ $\partial_\ell^2 S\ge0$（式 15）。
- **推论：QNEC 对 dS 钻石成立**（依据 [33] Ciolli–Longo–Ranallo–Ruzzi 的半包含充分条件）。

## 3. 熵面积律与反作用（Sec. 4，核心）
- 零坐标 $u=\eta-r,\ v=\eta+r$；未来宇宙学视界 = $v=0$，$u\in[-2\ell,0]$（图 3）；模流共形 Killing 矢量（式 17）：
$$\xi^\mu\partial_\mu=-\frac{\pi}{\ell}\big[u(u+2\ell)\partial_u+v(v+2\ell)\partial_v\big].$$
- **Raychaudhuri 反作用（式 19）**：$\left.\frac{d\delta\Theta}{du}\right|_{u=0}=-32\pi G_N\,T_{uu}$ —— $G_N$ 以经典 GR 耦合系数身份进入（此处仍是输入）。
- 用 $u(u+2\ell)$ 权重积分（式 20）→ 分部积分（面积=对数导数 $\tilde\Theta=d\ln\sqrt\gamma/du$）→ **熵面积律（式 24）**：
$$\boxed{\mathcal S(\Omega\|e^{i\Phi(f)}\Omega)=\frac{1}{4G_N}\langle\langle\delta A_H\rangle\rangle}$$
其中零平均 $\langle\langle A\rangle\rangle=\frac{1}{2\ell}\int_{-2\ell}^0 A(u)du$（式 23）；**边界项 $\delta A_H(0)=\delta A_H(-2\ell)=0$**（无质量共形场沿零测地传播 ⇒ 面积扰动在未来无穷与钻石边缘消失）。
- **广义熵守恒（式 24 后）**：$\delta\mathcal S_{gen}=-\mathcal S+\frac{1}{4G_N}\langle\langle\delta A_H\rangle\rangle=0$ —— 广义熵猜想在 leading order 以**守恒律**成立；负号自然出现（回应 [41] 关于 dS 第一定律负号的讨论）。

## 4. 局部温度（Sec. 5）
- 温度来自**热时间假说**（Connes–Rovelli [66]）：$\beta=\partial t/\partial(-\tau)$（观测者固有时对模流参数）。
- 显式（式 28）：
$$\beta=\frac{2\pi}{H}\frac{2e^{HT}H\ell-1}{2e^{HT}H\ell-1+e^{2e\tau}}=\frac{2\pi}{H}\Big[1-e^{-H(T_\tau-T_{min})}\Big].$$
- 主项 $2\pi/H$ = 宇宙学视界温度（Gibbons–Hawking [59]）；**亚 leading 修正指数衰减**；$\ell\to\infty$（钻石→整个静态 patch）恢复 $\beta\to 2\pi/H$。

## 6. 局限
1. 无质量共形标量、相干态、leading order 反作用；
2. **G_N 仍是经典输入**——量子化度规扰动未含（展望：计入应使 δS_gen 减少，从而"验证"而非"守恒"）；
3. 规范不变性需 relational observables（[69–72]）；
4. 图 3 场景为偶数维（massless even dimensions 才只在 [u₀,u₁] 内扰动视界）。
