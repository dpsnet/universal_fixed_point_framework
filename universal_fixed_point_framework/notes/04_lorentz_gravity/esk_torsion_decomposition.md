## 背景与记号

骨架层（无 ∂̃ 项）的 Einstein 散度，4 个分量：

$$D_\nu \;=\; \sum_{\mu,a}\eta^{\mu a}\,\tilde\nabla_\mu G_{a\nu},
\qquad
\tilde\nabla_\mu G_{a\nu} = \sum_l\big(-\Gamma^l_{\mu a}G_{l\nu} - \Gamma^l_{\mu\nu}G_{al}\big),$$

其中 $G_{\mu\nu} = \mathrm{Ric}_{\mu\nu} - \tfrac12\eta_{\mu\nu}R$ 由常值相容联络按常度规
黎曼公式计算（η = diag(−1,1,1,1)，lowered $\Gamma_{abc}$ 对 $(a,c)$ 反对称，
全相容空间 48 维）。

**重要的过程性纠错**（2026-09-11）：本轮早期分析曾把
$\eta^{\mu a}\tilde\nabla_\mu G_{a\nu}$ 的对角部分 $\eta^{\mu\mu}\tilde\nabla_\mu G_{\mu 0}$
（不求和）误当作散度分量，得出"E₁=E₂=E₃≡0 指 conn 对角元"的含混表述。
正确对象是 4 个分量 $D_\nu$（对 μ,a 全缩并）。此前"E=0 ⟺ D 反对称"的结论
经正确管线复核后依然成立（见下），但中间表述以下文为准。

## 结论一：全相容空间（48 维）

- $D_\nu$ 的 4 个分量在一般相容联络上**全非零**（2000 随机样本，
  max|D_ν| ≈ 48–86，无一恒零）。
- $D_\nu$ 对联络**纯三次**（1、2 次项系数 < 1e-13，3 次项 O(50)）。
  这是骨架无 ∂ 项的直接后果：G 二次、联络再贡献一次。

## 结论二：恰单零指标族（12 维）的恒等式结构

族定义：$\Gamma^i_{0j}=C_{ij}$，$\Gamma^i_{j0}=D_{ij}$，$\Gamma^0_{ij}=D_{ji}$
（i,j = 1,2,3；C 反对称；D 任意 3×3）。把 D 分解为
$D = A + S$，A 反对称（ω 部分）、S 对称（挠率对称部分）。
**符号计算（sympy 精确）结果**：

| 分量 | 总项数 | S=0 时 | S 的次数分布（0/1/2/3 次项数） |
|---|---|---|---|
| D₀ | 37 | ≡ 0 | 0 / **6** / 0 / **16** |
| D₁ | 1（零） | ≡ 0 | 全零 |
| D₂ | 1（零） | ≡ 0 | 全零 |
| D₃ | 1（零） | ≡ 0 | 全零 |

即：

1. **空间分量恒等式**：$D_1 \equiv D_2 \equiv D_3 \equiv 0$ 在整族上成立
   （对 C, A, S 的多元多项式恒零）。这是结构性的：族内无
   $\Gamma^i_{jk}$ 型（三空间指标）分量，散度的空间分量失去全部支撑项。
2. **时间分量分解**：$D_0 = L(C,A)\cdot S + \mathrm{Cub}(S)$，其中
   - 线性部分：6 项，系数为 (C,A) 的二次型，如
     $-A_{12}^2 S_{11} - A_{12}^2 S_{22} + 2A_{12}^2 S_{33} - 6A_{12}A_{13}S_{23} + \cdots$
   - 三次部分：16 项，**只含 S**（与 C,A 无耦合），且在
     tr S²−(tr S)²、det S 等标准不变量的多项式组合下不分解（sympy factor 验证）。
   - 二次部分恒零——无 (C,A)×S² 型交叉项。
3. **ω 联络零点**：S=0（D 反对称，即挠率 $T^0_{ij}=-2\omega_{ij}$ 的
   ω-联络）时 $D_\nu \equiv 0$ 全部分量成立。数值复核：2000 随机 ω 样本
   max|D| = 2.7e-15。
4. **零点刻画**：族内数值上 $D = 0 \iff S = 0$（3000 随机样本无反例：
   S≠0 时 D 恒非零）。即 ω-联络是族内散度零点的**全部**。
5. ω 点沿 S 方向扰动展开：$D(t) = t\,L + t^3\,\mathrm{Cub}$（无常数、无 t² 项，
   与符号分解一致）。
