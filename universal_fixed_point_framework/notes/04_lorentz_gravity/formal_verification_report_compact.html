四、核心证明技术

关键数学工具
  1. 鸽巢原理（Pigeonhole Principle）：有限 RecObj 中 card+1 个迭代值必有两相等 → 最终周期性。用于 T-01（K ≤ card 上界）、T-02（脉冲星辐射持续性）、T-03（铃宕定理）、T-04（双通道最终周期性）。
  2. RecHom 迭代交换性：φ.toFun(X.step^n x) = Y.step^n(φ.toFun x)，对 n 归纳证明。这是谱交织条件在迭代层面的体现，是 T-02 至 T-04 所有传导定理的基础。
  3. 迭代加法引理：f^a(f^b z) = f^{a+b} z，用于周期态的迭代性质推导和周期对齐。
  4. 置换群对称性：用 Equiv.Perm (Fin K) 作用于子集群族，组合版本实现球对称构型定义。
  5. 集合上确界（csSup）：K_c 定义为 sSup {K : HasSymmetricFamily X K}，非空 + 有界 → 良定义。

六、形式化设计说明

设计原则
  1. 纯 Rec 范畴内可定义：所有定义不依赖强制平均猜想的深层机制，仅使用 RecObj/RecHom 的基本结构。
  2. 组合版本先行：K_c 和 T-01 用置换群对称（组合版球对称）实现，留几何对称衔接接口。置换群 S_K 作用于 Fin K 索引的子集群族，对称 = 任意置换下存在 RecObj 自同构保持集群族。
  3. 鸽巢原理为核心工具：有限态系统 → 最终周期性，贯穿 T-01 至 T-04 全链。
  4. 通道复用：T-04 的 DualChannel 直接复用 T-02 的 MagneticChannel 和 T-03 的 RecHom，体现因果链的层级衔接。
  5. 分支比为定性结构：BranchingType 仅描述三种极端情形（em主导/gw主导/均衡），具体数值需引入额外物理假设，不属于狭义 MUFPF 范畴公理推论。
  6. 零占位符：所有 theorem/lemma 均有完整证明，无 sorry、admit 或 axiom（代码层面）。

七与T-01的兼容性说明

与强制平均猜想的关系

研究笔记中 T-01 的 T 指谱交织算子（spectral intertwining operator），K_c 定义强制平均猜想的适用边界：

  • K ≤ K_c：全局对称 T 存在，强制平均猜想成立
  • K > K_c：全局对称 T 不存在，强制平均猜想失效

Lean 形式化中 T-01 定理 T01_no_symmetric_above_Kc 证明的是组合版本：K > K_c 时置换对称构型不存在。这是强制平均猜想在 Rec 范畴中的组合层面投影，不涉及谱范畴层面的深层机制。
