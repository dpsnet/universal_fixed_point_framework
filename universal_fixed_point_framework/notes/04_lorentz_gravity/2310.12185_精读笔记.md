## 0. 一句话结果
**在 de Sitter 楔形区（wedge）里，真空与相干激发之间的 Araki–Uhlmann 相对熵，恰好等于沿楔形 Killing 流的 Noether 荷（局部温度 × 能量密度积分）；其对区域参数的二阶导给出零能量条件（NEC）。**

## 1. 为什么这篇是前传
- Dorau–Much 2026 用的是 Rindler 视界（平直近似）；

- 关键结果：相对熵不是一个抽象的"量子信息量"，而是**直接等于一个守恒流的面积分**——这才是后面能拼出爱因斯坦方程的原因。

## 2. de Sitter 几何 setup（Sec. II）
- 嵌入 $\mathbb R^{n,1}$ 双曲面 $X^A X_A = H^{-2}$。
- 膨胀 Poincaré patch 度规（式 7）：$ds^2 = -dt^2 + e^{2Ht}d\boldsymbol x^2$。
- 因果距离（式 8）：$Z(x,x') = 1 - \frac{H^2}{2}[X_A(x)-X_A(x')][X^A(x)-X^A(x')]$。
- de Sitter Killing 矢量（式 12）：
  - $D = -H^{-1}\partial_t + \boldsymbol x\cdot\nabla$（dilation）
  - $\mathcal K_i = (\boldsymbol x^2 - H^{-2}e^{-2Ht})\partial_i - 2x_i D$（boost）
  - $\mathcal P_i = \partial_i$（translation）
  - $L_{ij} = x_i\partial_j - x_j\partial_i$（rotation）
- 楔形区（式 13）：$\mathcal W_j = \{X^A X_A=H^{-2},\, X^j>|X^0|\}$。

## 3. 模理论核心结果（Sec. III，式 34）
Bunch–Davies 真空的模 Hamilton量：
$$\boxed{\ln\Delta_\Omega = K_\Omega = -2\pi M_{0j} = \frac{\pi}{H}\big(H^2\mathcal K_j + \mathcal P_j\big)}$$
- 这是**可观测的几何生成元**的线性组合；
- 逆温 $\beta=2\pi$（即 de Sitter 温度 $T_dS=H/2\pi$，和 Gibbons–Hawking 一致）；
- 关键：模流 = 沿 $M_{0j}$ 的几何流，不是抽象算子。

## 4. 相对熵计算（Sec. IV）
### 4.1 化简（式 38）
$$S(f\|\Omega) = -\langle\Omega|U_+(h-f)\ln\Delta_\Omega U_+(f-h)|\Omega\rangle$$
只依赖测试函数差。

### 4.2 主结果（式 47）
$$S(f\|\Omega) = i\pi\,\sigma(M_{0j}\Delta f_+,\,\Delta f_+)$$
其中 $\sigma$ 是辛形式，$\Delta f_+$ 是被限制在右楔形的对易函数。

### 4.3 取合适 Cauchy 面后（式 66，最终形式）
$$\boxed{S(f\|\Omega) = 2\pi\int_{\boldsymbol x^j\ge 0} Q_j(\Delta f)\big|_\Sigma\,\sqrt{\gamma}\,d^{n-1}x}$$
其中 $Q_j$（式 63）是 $n^\mu \xi^\nu_{(j)} T_{\mu\nu}(\Delta f)$（式 71），即**沿 Killing 矢量的应力张量法向分量**。

## 5. 相对熵 = Noether 荷（Sec. V，核心）
### 5.1 守恒流（式 69）
$$\nabla_\mu J^\mu = 0,\qquad J^\mu = \xi^\nu_{(j)} T^\mu{}_\nu(\Delta f)$$
- $T_{\mu\nu}$（式 70）是正则标量应力张量；
- 因为 $\xi_{(j)}$ 是 Killing 矢量，且 $T_{\mu\nu}$ 守恒，$J^\mu$ 是守恒流；
- 因此它的面积分 $S(f\|\Omega)$ 就是**Noether 荷**。

### 5.2 局部温度形式（式 73, 74, 76）
$$S(f\|\Omega) = \int_\Sigma \beta^\mu\, T_{\mu\nu}(\Delta f)\,n^\nu\,\sqrt{\gamma}\,d^{n-1}x$$
$$\beta^\mu = 2\pi\Theta(\boldsymbol x^j)\,\xi^\mu_{(j)}$$
$$\beta(x)\big|_\Sigma = 2\pi\Theta(\boldsymbol x^j)\frac{\boldsymbol x^j}{\sqrt{1+H^2\boldsymbol x^2}}$$

**物理含义**：相对熵 = $\int$（局部温度）×（观察者共动能量密度）。温度在楔形内部 $2\pi/H$ 量级，在楔形边界 $\boldsymbol x^j=0$ 处为 0（阶跃函数 $\Theta$）。

### 5.3 一阶热力学（式 72）
$$\delta S(\rho\|\sigma_m) = -\delta S(\rho) + \beta\,\delta E(\rho) - \beta\mu\,\delta N(\rho)$$
- 把相对熵接到微正则热力学第一定律；
- $\beta$ 从对 $E$ 求偏导得到，$\mu$ 从对 $N$ 求偏导。

## 6. 二阶凸性 → NEC（式 79，对 MUFPF 极其重要）
对半包含楔形（half-sided modular inclusion）族，相对熵对区域参数 $\lambda$ 的二阶导：
$$\frac{\partial^2}{\partial\lambda^2}S_\lambda(f\|\Omega) = 2\pi\int v^\mu v^\nu T_{\mu\nu}(\Delta f)\big|_{\boldsymbol x^j=\lambda} d^{n-2}\boldsymbol x^\perp$$
- 左 ≥ 0（相对熵凸性）
- 右 = $2\pi\int v^\mu v^\nu T_{\mu\nu}$
- → **零能量条件 NEC：$v^\mu v^\nu T_{\mu\nu}\ge 0$**

**这是把"量子信息凸性"直接变成"经典能量条件"的严格定理。**
