# Direction 3: 谱隙比与 U_e-U_ν 旋转角度的精确公式

## 1. 谱隙比假设 (Spectral Gap Ratio Hypothesis)

**核心假设**: PMNS 6×6 对角化中 U_e 与 U_ν 之间的旋转角度 η_ij 由谱隙比给出。

**候选公式 (a) — 直接比值**:

$$
\eta_{ij} = \frac{\Delta\lambda_{ij}^{(\nu_R)}}{\Delta\lambda_{ij}^{(\text{lepton})}}
$$

**候选公式 (b) — 抵消公式 (cancellation formula)**:

$$
\eta_{ij} = \frac{\Delta\lambda_{ij}^{(\nu_R)}}{\Delta\lambda_{ij}^{(\text{lepton})} + \Delta\lambda_{ij}^{(\nu_R)}}
$$

其中谱隙定义为相邻本征值之间的归一化间距:

$$
\Delta\lambda_{ij} = \frac{|\lambda_j - \lambda_i|}{\text{avg}(\lambda_i, \lambda_j)} \quad (i < j)
$$

**物理动机**: CKM 混合角很小，因为 up/down 夸克谱均为层级结构，谱隙都很大，比值接近 1，导致旋转角小。轻子中 ν_R 的谱隙是 O(1)（而非 O(1/θ_C) 量级），因此轻子混合角可能是大的。

## 2. 从 c_i 值计算谱隙

### ν_R 扇区本征值 (来自框架 c_i)

由 Universal Fixed Point 框架给出 ν_R 扇区的归一化本征值:

$$
c_1 = 0.0033, \quad c_2 = 0.0666, \quad c_3 = 0.9998
$$

**ν_R 谱隙**:

| 通道 (ij) | |c_j - c_i| | 平均值 | Δλ^(ν_R) |
|:---:|:---:|:---:|:---:|
| (12) | 0.0633 | 0.03495 | **1.811** |
| (23) | 0.9332 | 0.53320 | **1.750** |
| (13) | 0.9965 | 0.50155 | **1.987** |

> 所有谱隙均为 O(1)，无小量。这解释了为什么轻子混合角（相对于 CKM）可以是大的——没有小谱隙比对来压制旋转角。

### 带电轻子扇区谱隙 (参考值)

若采用带电轻子质量归一化值:

$$
\ell_1 = m_e/m_\tau \approx 0.000288,\quad
\ell_2 = m_\mu/m_\tau \approx 0.0595,\quad
\ell_3 = 1.0
$$

**带电轻子谱隙**:

| 通道 (ij) | |ℓ_j - ℓ_i| | 平均值 | Δλ^(lepton) |
|:---:|:---:|:---:|:---:|
| (12) | 0.0592 | 0.0299 | **1.980** |
| (23) | 0.9405 | 0.5298 | **1.775** |
| (13) | 0.9997 | 0.5001 | **1.999** |

> 带电轻子谱隙也是 O(1)，与 ν_R 谱隙量级相当。

## 3. 计算 η 并与最优值对比

### PMNS 6×6 对角化得到的最优 η

| 参数 | 最优值 |
|:---:|:---:|
| η₁₂ | 0.58 |
| η₂₃ | 0.06 |
| η₁₃ | 0.22 |

### 公式 (a) — 直接比值 η = Δλ^(ν_R) / Δλ^(lepton)

| 通道 | Δλ^(ν_R) | Δλ^(lepton) | η_ij (计算) | η_ij (最优) | 偏差 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| (12) | 1.811 | 1.980 | 0.915 | 0.58 | +57.8% |
| (23) | 1.750 | 1.775 | 0.986 | 0.06 | +1543% |
| (13) | 1.987 | 1.999 | 0.994 | 0.22 | +352% |

> **结论**: 直接比值全部接近 1，无法产生不同混合角之间的巨大差异，完全偏离最优值。

### 公式 (b) — 抵消公式 η = Δλ^(ν_R) / (Δλ^(lepton) + Δλ^(ν_R))

| 通道 | 分子 | 分母 | η_ij (计算) | η_ij (最优) | 偏差 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| (12) | 1.811 | 3.791 | 0.478 | 0.58 | -17.6% |
| (23) | 1.750 | 3.525 | 0.497 | 0.06 | +728% |
| (13) | 1.987 | 3.986 | 0.498 | 0.22 | +126% |

> **结论**: 抵消公式让所有 η 趋近于 0.5 附近，仍然无法产生 η₂₃ = 0.06 和 η₁₃ = 0.22 这样的小值。

### 关键发现

**两种简单谱隙比公式均无法复现 PMNS 6×6 对角化得到的最优 η 值。** 这说明 η_ij 的起源可能比纯谱隙比更复杂，需要引入额外结构。

## 4. 对 U_e/U_ν 结构的讨论

### 4.1 目前遇到的困难

- 若 c_i 为 ν_R 本征值，则 ν_R 谱隙全部 O(1)，无法自然产生 η₂₃ ≈ 0.06 的小量
- 若带电轻子质量层级产生谱隙 O(1)，则 ν_R 与带电轻子的谱隙比也不够小
- 这意味着 η 的层级结构（η₁₂ > η₁₃ ≫ η₂₃）需要来自谱隙之外的机制

### 4.2 可能的修正方向

1. **谱隙定义修正**：将当前的分母从线性平均替换为其他归一化方案（如几何平均、最大值归一化等）
2. **非线性映射**：η 可能不是谱隙比的线性函数，而是形如 η = f(Δλ) 的非线性映射
3. **引入 U(1) 或 Z₂ 对称性**：某通道的谱隙可能被对称性压制，使得有效谱隙显著偏小
4. **层级依赖的耦合强度**：不同 generation 之间的 seesaw 有效耦合强度不同，需在分母中引入权重因子
5. **c_i 并非直接对应 ν_R 本征值**：c_i 可能是某个中间变换后的有效参数，ν_R 的真实谱需重新推导

### 4.3 与 CKM 的类比

CKM 混合角小的根源:

| 量 | CKM (夸克) | PMNS (轻子) |
|:---|:---:|:---:|
| up 谱隙比 | Δλ_(12)^(u) / Δλ_(12)^(d) → O(1) 但压制动能 | — |
| down 谱隙 | 层级强 | 层级弱 |
| 混合角量级 | O(θ_C) ~ 0.23 | O(1) |

在轻子情形下，两个扇区的谱隙比均为 O(1)，因此需要 **更高阶的 see-saw 机制** 或 **非平庸的 flavor 对称性** 来产生 η 之间的层级差异。

### 4.4 下一步建议

1. 检查 PMNS 6×6 数值扫描中 η 的最佳值是否唯一（可能有多组局部最优解）
2. 对 c_i 值的来源重新推导—如果 c_i 来自某个 RG 不动点，也许谱隙定义中应包含 RG 流权重
3. 测试修改后的谱隙定义: Δλ_{ij} = |λ_j - λ_i| / (λ_i + λ_j + λ_k)（加入第三本征值作总归一化）
4. 如果谱隙比假设完全失败，考虑 η 可能由 flavor 对称性自发破缺的 Goldstone 方向决定，而非动力学谱隙

## 附录: 数值计算核验

```
c₁ = 0.0033, c₂ = 0.0666, c₃ = 0.9998

ν_R fraction gaps:
  Δλ₁₂ = (0.0666-0.0033) / ((0.0033+0.0666)/2) = 0.0633/0.03495 = 1.811
  Δλ₂₃ = (0.9998-0.0666) / ((0.0666+0.9998)/2) = 0.9332/0.53320 = 1.750
  Δλ₁₃ = (0.9998-0.0033) / ((0.0033+0.9998)/2) = 0.9965/0.50155 = 1.987

Lepton fraction gaps (using m_e/m_τ, m_μ/m_τ):
  ℓ₁=0.000288, ℓ₂=0.0595, ℓ₃=1.0
  Δλ₁₂ = (0.0595-0.000288) / ((0.000288+0.0595)/2) = 0.0592/0.0299 = 1.980
  Δλ₂₃ = (1.0-0.0595) / ((0.0595+1.0)/2) = 0.9405/0.5298 = 1.775
  Δλ₁₃ = (1.0-0.000288) / ((0.000288+1.0)/2) = 0.9997/0.5001 = 1.999
```
