## 1. 物理背景：谱静默两阶段 → 双层谱系

胶球谱的物理来源是**谱静默的两个阶段**（paper32 机器证明 + 双标度论证）：

| 阶段 | 层 | 空间 | 有效维数 | 物理量 |
|:--|:--|:--|:--|:--|
| 谱静默前 | 代数层 | Cl(1,7) 8 维底空间（全谱空间） | D = 2+8 = 10 | 能级结构（J 量子化） |
| 谱静默后 | 观测层 | 观测窗口 4D 物理时空（唯一涌现） | D = 4 | 物理量取值（¾ 修正、ε） |

由此胶球谱分成两个 $m^2$-线性谱系（双层）：

- **谱系 R（偶 J Regge，D=10 层）**：闭弦 Regge 量子化
- **谱系 T（扭转模，D=4 层）**：¾ 因子激发修正

## 2. 数学设定：归一化谱参数 $n$

定义无量纲谱参数

$$n \equiv \frac{m^2}{\pi\sigma},$$

其中 $\sigma = 4\Lambda_{\mathrm{QCD}}^2 = 0.1764\ \mathrm{GeV}^2$（定理 5.5，$\Lambda_{\mathrm{QCD}} = 210.3$ MeV）。已知三态锚定：

$$0^{++}:\ n = 4 \ (m = 1.491\ \mathrm{GeV}),\qquad 0^{-+}:\ n = 10 \ (m = 2.354\ \mathrm{GeV}),\qquad 2^{++}:\ n = 12 \ (m = 2.579\ \mathrm{GeV}).$$

## 3. 谱系 R：偶 J Regge（D=10 代数层）

**命题 R1（偶 J 量子化）**。闭弦由左/右行波组成（level matching $N_L = N_R$），角动量量子化只允许**偶值**：

$$J \in \{0, 2, 4, 6, \dots\}.$$

*证明要点*。闭弦基态为 $N_L = N_R = 0$（$J=0$）；第一激发 $N_L = N_R = 1$ 的对称组合给出 $J = 2$（反对称组合被 $N_L = N_R$ 约束排除）。一般地，$J = N_L + N_R$ 模整数约束下，$N_L = N_R$ 的对称态给出偶 $J$。□

**命题 R2（Regge 谱公式）**。闭弦零点能截距 $\alpha_{0,c} = 1$（由 $\alpha_0 = 1/2$ 加倍，$\alpha_0 = N_{\mathrm{tr}}/16 = 8/16$，横向自由度 $N_{\mathrm{tr}} = 8$ = Cl(1,7) 底空间，框架内机器证明），Regge 谱：

$$m^2_J = 4\pi\sigma\,(J+1),\qquad J = 0, 2, 4, \dots$$

归一化谱参数：

$$n_R(J) = 4(J+1),\qquad J = 0,2,4,\dots \;\Longrightarrow\; n_R \in \{4,\ 12,\ 20,\ 28,\ 36,\ \dots\}.$$

## 4. 谱系 T：扭转模（D=4 观测层）

**命题 T1（¾ 因子）**。赝标量胶球（$0^{-+}$）的激发修正由 D=4 观测窗口零点能决定（谱静默唯一涌现的物理时空，paper32 机器证明）：

$$\tfrac{3}{4} = 1 - a_c(4) = 1 - \frac{4-2}{8},\qquad a_c(D) = \frac{D-2}{8}\ (\text{闭弦零点能}).$$

**命题 T2（扭转模谱公式）**。$0^{-+}$ 扭转模能级间距 $\Delta m^2 = \tfrac{3}{4}\cdot 8\pi\sigma = 6\pi\sigma$（非整数能级），谱公式：

$$m^2_k = 10\pi\sigma + 6\pi\sigma\cdot k = \pi\sigma\,(10 + 6k),\qquad k = 0, 1, 2, \dots$$

归一化谱参数：

$$n_T(k) = 10 + 6k,\qquad k = 0,1,2,\dots \;\Longrightarrow\; n_T \in \{10,\ 16,\ 22,\ 28,\ 34,\ \dots\}.$$

## 5. 交织的算术结构

两个谱系是 $n$ 轴上的**两个等差数列**：

$$\text{谱系 R:}\quad n_R = 4,\ 12,\ 20,\ 28,\ 36,\ 48,\ 60,\ \dots \quad (\text{公差 } 8, \text{首项 } 4)$$
$$\text{谱系 T:}\quad n_T = 10,\ 16,\ 22,\ 28,\ 34,\ 40,\ 46,\ \dots \quad (\text{公差 } 6, \text{首项 } 10)$$

**定理 I1（简并点定理）**。双层谱系在

$$n = 28 + 24m,\qquad m = 0, 1, 2, \dots$$

处**简并**（两谱系同质量态）。

*证明*。求 $n_R(J) = n_T(k)$ 的整数解：$4(J+1) = 10 + 6k$，即 $2J = 3 + 3k$。由命题 R1 要求 $J$ 为偶，$J = \tfrac{3+3k}{2}$ 为偶 ⟺ $k \equiv 3 \pmod{4}$（$k = 3, 7, 11, \dots$），对应 $J = 6, 12, 18, \dots$。代入：$n = 4(J+1) = 28 + 24m$（$m = \tfrac{J-6}{6}$）。□

**推论 I1（首简并对）**。第一个简并点在 $n = 28$：

$$6^{++}:\ m = \sqrt{28\pi\sigma} = 3.939\ \mathrm{GeV},\qquad 0^{-+'''}:\ m = \sqrt{28\pi\sigma} = 3.939\ \mathrm{GeV}.$$

即**谱系 R 的 $6^{++}$ 与谱系 T 的第三激发 $0^{-+'''}$ 质量简并**（3.939 GeV）——框架独有预言：观测上表现为 3.9 GeV 附近的双重态或强混合。

**推论 I2（邻近对与密度增强）**。除精确简并外，两谱系还有"近邻"对。定义间距 $d(n_R, n_T) = |n_R - n_T|$，最小非零间距：

| 谱系 R | $n_R$ | 谱系 T | $n_T$ | $\Delta n$ | $\Delta m$ (GeV) |
|:--|:--:|:--|:--:|:--:|:--:|
| $4^{++}$ | 20 | $0^{-+''}$ | 22 | 2 | 0.163 |
| $2^{++}$ | 12 | $0^{-+'}$ | 16 | 4 | 0.325 |
| $6^{++}$ | 28 | $0^{-+'''}$ | 28 | 0 | **0（简并）** |

**3.3–3.5 GeV 密度增强**：$n = 20$（$4^{++} = 3.329$ GeV）与 $n = 22$（$0^{-+''} = 3.492$ GeV）相距 $\Delta m = 0.163$ GeV——两态在窄区间内共存，该能区胶球态密度较周围（$\Delta n = 8$ 或 6 的均匀间距）**翻倍**。

## 6. 密度增强的定量表述

**命题 D1（局域态密度）**。单谱系（R 或 T）在 $n$ 轴的态密度为 $\rho_0 = 1/8$（R）或 $1/6$（T）；双层交织后，在非简并区间总密度 $\rho = \rho_R + \rho_T = 1/8 + 1/6 = 7/24 \approx 0.292$。在简并点附近（$|n - n_*| < 1$），两态重合 → 密度 $\approx 2\rho_0$。

**推论 D1**。$m^2$ 轴上的胶球态密度在简并点 $n = 28$（$m \approx 3.94$ GeV）与邻近对 $n = 20, 22$（$m \approx 3.3$–$3.5$ GeV）处局部增强——**可直接检验的谱特征**（格点：态密度/能级计数；实验：该能区粒子数密度）。

## 8. 诚实边界

1. **偶 J 量子化**（命题 R1）：闭弦 level matching 为标准弦论论证（理论输入），应用于 QCD 通量管为类推扩展（分级 🔶）。
2. **¾ 因子**（命题 T1）：D=4 观测窗口零点能（谱静默锚定，观测窗口本身机器证明；"扭转模 ↔ 观测窗口耦合"为机制建模）。
3. **扭转模等间距**（命题 T2）：$\Delta m^2 = 6\pi\sigma$ 由 $\tfrac{3}{4}$ 因子确定，等间距为机制建模假设。
4. **简并点定理**（I1）：纯算术结果（两等差数列交点的整数解），依赖谱系 R/T 的谱公式成立。
5. 格点对照：$4^{++}$ 带 [3.2, 4.0] GeV 为多格点组宽范围（Morningstar–Peardon 1999 等），尚无精确值。
