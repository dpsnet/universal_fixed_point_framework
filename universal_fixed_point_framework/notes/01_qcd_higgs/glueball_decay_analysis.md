# 胶球衰变过程分析：闭弦断裂 + 静默释放

**文档状态**：笔记层（2026-08-09）
**对应**：paper40 §5.11（胶球衰变过程分析）、§5.10（胶球谱谱定）
**配套脚本**：`scripts/paperX_glueball_decay.py`（6/6 注册 run_all_tests.py）
**实验来源**：BESIII X(2370)（arXiv:2607.20366 / 2608.03362）；格点（Morningstar & Peardon、Teper 等）

## 1. 物理图像

胶球衰变 = 闭合胶子通量管（闭弦）断裂为两个开弦（$\bar q q$ 对 = 介子）。
在谱静默框架中对应**静默维度的动力学释放**：胶球内部结构位于 D=10 代数层
（8D 横向 = Cl(1,7) 底空间），断裂时产生 $\bar q q$ 对并把能量释放到 D=4 观测层。

**核心原则**：质量谱由能级层（弦）决定，**衰变宽度由观测层（$\bar q q$ 混合与
相空间）决定**——谱静默两阶段的动力学体现。

## 2. 通道选择（量子数守恒，第一性）

| 胶球态 | $J^{PC}$ | 允许通道（最低角动量） | 阈值 |
|:--|:--:|:--|:--:|
| $0^{++}$（1.491 GeV） | $0^{++}$ | $\pi\pi$（S 波）、$KK$、$\eta\eta$、$\eta\eta'$ | 0.28 / 0.99 / 1.10 / 1.48 GeV |
| $2^{++}$（2.582 GeV） | $2^{++}$ | $\pi\pi$（D 波）、$KK$、$\eta\eta$、$\rho\rho$ | 0.28 / 0.99 / 1.10 / 1.55 GeV |
| $0^{-+}$（2.354 GeV，X(2370)） | $0^{-+}$ | $f_0(980)\eta'$、$\pi\eta$、$KK^*$（P 波） | 1.94 / 0.92 / 1.40 GeV |

$0^{-+}$ 无价夸克、味单态，主导耦合为拓扑荷密度 $G\tilde G$（与 $\eta'$ 家族同构）。

## 3. 宽度序（框架内论证 + 格点/实验对比表）

宽度序 $\Gamma(0^{++}) > \Gamma(2^{++}) \sim \Gamma(0^{-+})$，谱静默解释：
$0^{++}$ 与 $\pi\pi$ S 波同量子数零级耦合（释放无势垒）；$0^{-+}$ 需拓扑耦合
$G\tilde G$（受抑但非指数窄——观测层混合补偿）。

| 胶球态 | 谱定 m | 主导道（L 波） | 宽度锚定 Γ | 来源 |
|:--|:--:|:--|:--:|:--|
| $0^{++}$ | 1.491 GeV | $\pi\pi$（S 波） | ~500 MeV 量级 | 格点展宽 1.5–1.7 GeV 宽带（ππ 强混合）|
| $2^{++}$ | 2.582 GeV | $\pi\pi$（D 波）、$\rho\rho$ | ~100–300 MeV 量级 | 格点 |
| $0^{-+}$ | 2.354 GeV | $f_0(980)\eta'$、$\pi\eta$（P 波） | **170$^{+44}_{-29}$ MeV** | **BESIII 2026 X(2370) 组合** |
| $0^{-+'}$ | 2.978 GeV | $f_0(980)\eta'$ 等（同族，新预言） | 待测（预测与 X(2370) 同量级） | ★ 新预言 |

## 4. 弦断裂宽度标度律（机制建模）

相对权重 $\propto \exp(-\pi m^2/2\sigma)$（$\sigma = 4\Lambda^2$，定理 5.5）。代入扭转模
等间距 $\Delta m^2 = 6\pi\sigma$：

$$\frac{\Gamma(0^{-+'})}{\Gamma(0^{-+})} \sim e^{-3\pi^2} \approx 1.4\times10^{-13}\ (\text{纯弦指数})$$

观测层混合补偿至 O(1)——判据：若 X(2800) 确认，其宽度应与 X(2370) 同量级
（而非指数窄），支持"观测层主导宽度"的静默两阶段图像。

## 5. 最新实验数据（2026 BESIII）与框架对照

**X(2370)（arXiv:2607.20366 / 2608.03362）**：
- 观测道：$K_S^0K_S^0\eta'$、$K_S^0K_S^0\pi^0$、$\pi^0\pi^0\eta$（显著性 >14σ / >20σ）
- 组合质量 $2359^{+13}_{-14}$ MeV、宽度 $170^{+44}_{-29}$ MeV（2024 分波：2395±11 MeV / 188$^{+18}_{-17}$ MeV）
- **关键味单态证据**：$X(2370)\to K^*\bar K$ 未见信号——BR < 1.6%（90% CL）、
  部分宽度 < 2 MeV——广义 G 宇称禁止，味单态性质干净证据

**与框架对照**：
- $0^{-+}$ 主导耦合 $G\tilde G$（含 $\eta'$ 道）↔ $K^*\bar K$（普通 $\bar q q$ 特征道）受抑
  ——2026 实验直接支持 D1 论证（非独立第一性）；
- X(2370) 宽度 170 MeV 与 $2^{++}$ 同量级——支持"观测层混合补偿"（非指数窄）。

## 6. 框架独有新预言（衰变层面）

- **P7 扭转模同族衰变**：$0^{-+'}$（2.978）、$0^{-+''}$（3.492）与基态同族
  （含 $\eta'$ 道）；X(2800) 若确认应见 $f_0(980)\eta'$ 主导道；
- **P8 简并点混合**：$6^{++} \sim 0^{-+'''}$（3.939 GeV，§5.10 P5）处双层混合
  → 衰变模式叠加（高角动量介子对道 + $\eta'$/拓扑道）；
- **P9 味顺序 + OZI 免疫**：轻 $\bar q q$ 优先（$m_s$ 标度），无价夸克使胶球
  衰变不受 OZI 压抑——区别于普通介子的可观测特征。

## 7. 分级与诚实边界

| 环节 | 论证性质 | 分级 |
|:--|:--|:--|
| 通道选择 | $J^{PC}$ 守恒 + 味单态 | ✅ 第一性 |
| 宽度序 | 静默释放强度（观测层耦合） | 🔶 框架内论证 |
| 弦断裂指数 | Isgur-Paton 型弦模型 + 观测层补偿 | 🔶 机制建模 |
| P7/P8/P9 | 扭转模同族 / 简并点混合 / 味顺序 | 🔶 框架内预言 |

诚实边界：宽度序为定性/量级论证（绝对宽度需格点混合计算或实验提取）；
$\Gamma \propto (p^*)^{2L+1}/m^2$ 为简化权重（同族比较有意义，跨通道需完整矩阵元）；
$G\tilde G$ 拓扑耦合（0⁻⁺ 主导道）为**观测层主动耦合**（4D QCD 拓扑荷密度算符，
标准算符；其主导地位的具体耦合机制待定，方向 D 拓扑 θ 登记远期）；
X(2800) 身份与宽度待确认。

## 8. 与主流理论的差异性预测

**区分两类内容**：谱定质量与宽度序为**交叉验证**（与格点/弦模型一致，非差异）；
结构性预测（§5.10 P1-P5 与 §5.11 P7/P8）才是**与主流的差异性预测**。

### 8.1 谱结构（框架独有，主流未识别）

| 框架预测 | 主流（格点/弦模型） | 差异性质 |
|:--|:--|:--|
| 偶 J Regge 谱系（4⁺⁺=3.33、6⁺⁺=3.94 GeV，J 只取偶值） | 格点只给孤立态质量（4⁺⁺ 宽 [3.2,4.0] 带、6⁺⁺ 无值） | ★ 结构差异（无奇 J 胶球在轨迹上） |
| 扭转模等间距（0⁻⁺'=2.98、0⁻⁺''=3.49 GeV，Δm²=6πσ） | 弦模型/格点未给赝标量激发等间距结构 | ★ 结构差异 |
| 双层谱系交织 + 邻近对（3.3–3.5 GeV 密度增强） | 无对应结构 | ★ 结构差异 |
| 简并点 6⁺⁺~0⁻⁺''' = 3.939 GeV（n=28） | 无对应结构 | ★ 结构差异 |

### 8.2 衰变（§5.11 框架 vs 主流手征模型）

**核心差异性预测（P7）**：框架预言 $0^{-+}$ 胶球主导耦合为拓扑荷密度 $G\tilde G$，
主导衰变道含 $\eta'$（$f_0(980)\eta'$ 等），$K^*\bar K$（普通 $\bar q q$ 特征道）受
广义 G 宇称抑制。**主流手征拉氏量模型（Eshraim 2020，参数自由计算，arXiv:2005.11321）
预言 $0^{-+}$ 胶球 $\rho\pi$ 道最大、$K^*(892)K$ 道第二大且可观**——两者直接冲突。

| 0⁻⁺ 衰变道 | 框架（拓扑 G·G̃） | 主流手征模型 | BESIII 2026 实测 |
|:--|:--|:--|:--|
| $f_0(980)\eta'$ | **主导**（含 η' 族） | 未给大分支比 | X(2370) 观测道 ✓ |
| $K^*\bar K$ | **受抑**（G 宇称禁止） | **第二大、可观** | **< 1.6%（90% CL）✓ 支持框架** |
| $\rho\pi$ | 非主导（非拓扑耦合） | 最大 | 待测 |

BESIII 2026（arXiv:2607.20366）的 $X(2370)\to K^*\bar K$ 上限 < 1.6%（部分宽度
< 2 MeV）**更接近框架预测**，对主流手征模型的"K*K 第二大且可观"构成压力
（诚实边界：Eshraim 数值依赖模型参数（胶球质量 2.37/2.6 GeV 两版），此为
**定性/趋势对比**，非精确数值裁决；$\rho\pi$ 道状态待实验搜索）。

### 8.3 非差异内容（与主流共识一致）

宽度序 $\Gamma(0^{++}) > \Gamma(2^{++}) \sim \Gamma(0^{-+})$、OZI 免疫（无价夸克）、
弦断裂机制本身——均为格点/弦模型共识，非框架独有；框架为其提供了谱静默
两阶段的统一解释（机制层），但不构成实验可区分的差异。

**可区分性结论**：最强 falsifiable 差异 = P7（$0^{-+}$ 主导道 $\eta'$ 族 vs 主流
$\rho\pi$/$K^*K$）+ 谱结构 P1-P5。X(2800)（若确认）与简并点 3.939 GeV 是两条
独立检验路径。
