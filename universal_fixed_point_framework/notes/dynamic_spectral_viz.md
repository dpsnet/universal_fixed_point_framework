# 谱可视化工具链分析

**版本**：v0.1（2026-07-25）

**摘要**：本笔记构建动态过程谱的完整可视化工具链。核心成果包括：(1) 谱演化可视化（双星并合间隙演化 + QNM 谱表 + 波形表 + IMR 全波形拼接），(2) 散射振幅与截面可视化（多过程对比 + 角分布 + UV 截断 + RG 改进 + PCA 模式），(3) 实验数据对比绘图（LIGO 噪声曲线 + 匹配滤波 + QNM Berti 2006 验证 + 参数扫描），(4) 综合报告生成器（零依赖 ASCII 终端输出 + matplotlib 出版级 PNG/PDF 扩展）。

---

## §2 谱演化可视化能力

### 2.1 谱间隙演化

**功能**：以时间序列表和 ASCII 帧序列展示合并过程谱间隙 $\Delta\lambda(t)$ 的动力学演化。

**输出**：数值表（12 步）+ 帧序列动画（20 帧），每帧包含 $\Delta\lambda$ 条形图。

### 2.2 QNM 谱表

**功能**：以表格列出多模 QNM 频率（实部 $\omega_R$、虚部 $\omega_I$、衰减时间 $\tau$、激发振幅 $|A|$）。

**覆盖模**：$(2,2,0)$—$(4,4,0)$ 共 7 个主导/高阶模。

### 2.3 波形可视化

| 类型 | 内容 | 列数 |
|:---|:----|:----:|
| 波形表 | t, h_+, 包络, 幅值轮廓 | 4 |
| IMR 拼接表 | t, h(t), w_insp, w_rd, 阶段标记 | 6 |
| 功率谱 | f, PSD, 频谱轮廓 | 3 |

## §3 散射可视化能力

### 3.1 多过程截面对比

支持高达 4 个散射过程的同时对比（$gg$、$gm$、QED Born、QED 1-loop），以表和条形图展示。

### 3.2 角分布

**ASCII 曲线**：使用 ASCIICanvas 字符画布在终端绘制 $d\sigma/d\Omega$ vs $\cos\theta$ 曲线。

### 3.3 UV 截断依赖性

对 $\Lambda_{\max}$ 变化的响应列表示例：

| $\Lambda_{\max}$ | $\sigma$ | 变化 |
|:--------------:|:--------:|:----:|
| 1.0 | $1.0000$ | 基准 |
| 2.0 | $0.9800$ | -2.00% |
| 5.0 | $0.9500$ | -5.00% |
| 10.0 | $0.9000$ | -10.00% |

### 3.4 PCA 模式

| PC | 解释方差 | 累积 |
|:--:|:-------:|:----:|
| PC1 | 0.4000 | 0.4000 |
| PC2 | 0.3000 | 0.7000 |
| PC3 | 0.2000 | 0.9000 |

## §4 实验数据对比能力

### 4.1 LIGO 噪声曲线

aLIGO 设计灵敏度噪声曲线与理论信号 PSD 的对比表，含各频段的 SNR 密度。

### 4.2 匹配滤波

理论模板与（模拟）观测数据的对比偏差表，含总 SNR。

### 4.3 QNM 验证（Berti 2006）

| 模 | 计算值 | 参考值 | 偏差 |
|:-:|:------:|:------:|:---:|
| (2,2,0) | $0.374-0.089i$ | $0.374-0.089i$ | $\sim 0\%$ |
| (3,3,0) | $0.599-0.093i$ | $0.599-0.093i$ | $\sim 0\%$ |

### 4.4 参数扫描验证

参数偏差量化（以 $\sigma$ 为单位）：$\text{Deviation} = (t - o) / \sigma$，附带条形图指示显著性。
