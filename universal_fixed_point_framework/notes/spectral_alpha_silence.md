# α 指数的多重静默分析

## 问题

α 指数 $m_i \propto c_i^\alpha$ 目前是拟合值（$\alpha_\ell=1.358, \alpha_u=1.945, \alpha_d=1.229$），
需从谱框架第一性推导。已有 $\gamma_m$ RG 积分路径给出过大值，暗示需要多重静默压制。

## 思路

类比规范耦合 $\alpha_i(M_Z)$ 的多重静默路径：

```
S₁: Δλ_i/(4π) → 裸耦合
S₂: [G,[G,...]] → β 函数系数
S₃: n_f = 2N_gen → 代结构
S₄: ln(M_Pl/M_Z) → 分形边界
```

α 的静默分解应为：

```
S₁: α₀ → 普适谱指数（各扇区共享）
S₂: [G,[G,...]] → 规范耦合对谱流的修正
S₃: N_gen = 3 → 三代 IFS 递归深度
S₄: d_H = 2.7095 → 分形边界对谱流积分域的压制
```

## 数值探索

用多重静默压制 γ_m 积分，搜索各规范群有效分形维数 dH³,dH²,dH¹。

### 核心矛盾

γ_m 积分强制 `α_up > α_down > α_lepton`（下型有 QCD 贡献所以大于轻子），
但拟合值是 **`α_lepton > α_down`**（1.358 > 1.229），
这在 γ_m 框架中不可能成立——下型有 QCD，γ_m 必然更大。

### 结论

**α 不是 ∫γ_m d(ln μ)**。γ_m 描述的是质量随能标的跑动（同一扇区不同能标的比值），
而 α 描述的是同一能标下不同代之间的质量比（IFS 收缩因子的映射指数）。
两者是不同物理量——α 来自谱作用量中 Dirac 算符 D_F 的 IFS 自相似结构，
而非来自 QFT 的反常维度。γ_m 积分路径对此问题无效。

### 正确方向

α 应从谱三元组 (A, H, D) 的 KO-维数和非交换几何内禀结构推导：
- 各扇区的 α 差异来自有限 Dirac 算符 D_F 在手征投影下的不同耦合结构
- IFS 自相似性决定代间质量比，扇区差异来自 Higgs-Yukawa 结构在谱作用量中的投影
- 多重静默进入的方式不是压制 γ_m 积分，而是通过 S₃ 和 S₄ 确定 IFS 收缩因子 c_i 本身
- 这需要谱作用量框架内的 Yukawa 矩阵 IFS 分解的第一性推导
