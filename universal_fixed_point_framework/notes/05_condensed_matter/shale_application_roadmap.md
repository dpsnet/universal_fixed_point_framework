## 一、应用总框架

三因素机制把页岩油气评价从"单一判据"升级为"三分量分解"，各应用模块对应机制分量：

```
             ┌─ 原地生烃项 a·TOC ──→ 模块 A：资源潜力分级（TOC×效率）
S1 三因素 ──┤
             ├─ 成熟度窗形 f(M) ──→ 模块 D：可动油窗定位 + 模块 E：成熟度预测
             │
             └─ 运移背景项 c ────→ 模块 B：煤系/外部油源注入诊断（重点）
                                    └ 模块 C：低 TOC 端背景校正
```

| 模块 | 应用 | 对应分量/预言 | 验证状态 |
|:--|:--|:--|:--|
| A | 甜点资源量分级 | a·TOC（线性注入） | ✅ M5/M8 |
| B | **煤系页岩油勘探** | c 项正截距诊断 | ✅ [U6] 沙海组 + 准噶尔煤系源-储分离锚点 |
| C | 可动油评价校正 | c 背景修正 OSI 基准 | ✅ 中国湖相五体系 + 苏北阜宁可动性 |

## 二、模块 B：煤系页岩油勘探技术路线（重点）

**背景**：油-煤共存地层（如阜新盆地沙海组 K1sh4）中，湖相泥岩的 S1 背景受下伏/侧向煤系烃源岩（K1sh3）油源注入控制——传统"有效烃源岩 TOC 下限"判据在此类体系系统性失效（高 c 背景掩盖原地生烃信号）。

**核心诊断特征**（沙海组案例实证 + 九体系对照）：
- **煤系注入模板（沙海组）**：正截距 + 高 OSI + 油-煤共存地质背景三条件齐备——九体系唯一；
- **高背景变体（苏北阜宁 GY1 / 青山口 SL）**：负截距但 OSI 64.2/82.4 高背景——运移/滞留烃背景同样升高 OSI，**负截距不排除高 c 背景**（须 Z1 线性度+Z2 低端趋零判零阈值型）；
- **源-储分离**：煤系源岩 OSI 低（准噶尔 5.8）vs 储层页岩高（沙海 62.9）——**J2 加在储层端**。

| 特征 | 判据 | 沙海组（煤系注入模板） | 苏北阜宁 GY1（高背景变体） | 长7段（零阈值对照） |
|:--|:--|:--|:--|:--|
| S1-TOC 回归截距 | 正截距 vs 负截距 | **+0.95**（R²=0.28） | **−0.059**（R²=0.66） | −0.24（R²=0.994） |
| OSI 背景 | 高/低 | **62.9** | **64.2** | 53.6 |
| 线性度 R² | ≥0.90 | 0.28 | 0.66 | 0.994 |
| 判定 | 三条件 | c 型（煤系注入） | c 型背景（负截距+高 OSI） | 零阈值型 |
| 油源证据 | 原油地球化学对比 | K1sh3 煤系油源（文献） | 滞留/运移富集（高邮凹陷） | 原地生烃 |

**技术路线（五步）**：

```
① 数据获取 ──→ ② 三因素标定 ──→ ③ c 项诊断 ──→ ④ 油源确认 ──→ ⑤ 甜点优选
  OA 论文转录       S1=a·TOC+b       截距>0.05         生物标志物/       避开纯煤系
  油田岩心数据       f(M) 窗形        OSI 背景>60       碳同位素对比       段，聚焦湖相
  (browser_use      c 代理提取        (TOC<0.5 S1)       油源对比          泥岩段
   反爬方案)
```

**实施要点**：
1. **数据获取**：中国无国家级公开数据库——OA 论文表格转录（PMC HTML 解析 / browser_use 浏览器绕过 ACS 反爬）+ 油田合作数据（老教授建议的应用路径）
2. **c 项诊断**：S1-TOC 回归截距符号 + 低 TOC 端 S1 中位数（c 代理）+ OSI 背景——**正截距且 c>0.05 mg/g 判运移背景（沙海组模板）；负截距但 OSI>60 亦为高背景 c 型（苏北阜宁/青山口 SL），须结合 Z1 线性度（R²≥0.90）与 Z2 低端趋零（低/高比<0.35）判定是否零阈值型**——负截距≠c→0；
3. **油源确认**：c 项证据须与油源对比（原油-源岩生物标志物/碳同位素）互证——沙海组已验证
4. **甜点优选**：高 c 体系内优先选 f(M) 窗形峰值段（油窗 ~440℃）+ 高 TOC 段（原地生烃贡献大）；煤系夹层（高 Tmax 异常点）剔除
5. **预测-验证闭环**：对新区块先标定 c → 预测 OSI 背景 → 钻探验证 → 更新判据

**适用地质单元**：油-煤共存的断陷/小盆地（阜新型）、煤系-湖相叠置层系、有侧向油源注入口的泥岩段。

**判据跨体系验证（2026-08-08，`paperX_shale_criterion_validate.py`，9 体系）**：

| 体系 | n | 截距 b | OSI 中位 | R² | J1 正截距 | J2 OSI>60 | 判定 | 地质背景 |
|:--|:--|:--|:--|:--|:--|:--|:--|:--|
| 长7段 | 10 | −0.238 | 53.6 | 0.994 | 否（负） | 否 | 零阈值型 | 鄂尔多斯（原地） |
| 青山口 D86 | 16 | −0.059 | 104.8 | 0.799 | 近零 | **是** | c 型背景 | 松辽（滞留油） |
| 青山口 SL | 8 | −0.441 | 82.4 | 0.981 | 否（负） | **是** | c 型背景 | 松辽（滞留油） |
| **沙海组** | 22 | **+0.954** | **62.9** | 0.284 | **是** | **是** | **c 型（煤系注入）** | 阜新（油-煤共存） |
| 苏北阜宁 GY1 | 31 | −0.059 | 64.2 | 0.661 | 否（负） | **是** | c 型背景（负截距+高 OSI） | 苏北（滞留/运移） |
| TUSCALOOSA | 224 | +0.284 | 29.6 | 0.184 | 是 | 否 | c 型（低背景） | Gulf Coast 海相 |
| WILCOX | 624 | −0.050 | 25.8 | 0.442 | 否（负） | 否 | 曲率型 | Gulf Coast 海相 |
| SPARTA | 155 | −0.130 | 24.7 | 0.655 | 否（负） | 否 | 曲率型 | Gulf Coast 海相 |
| NEW ALBANY | 454 | +0.094 | 19.8 | 0.506 | 是（弱） | 否 | c 型（低背景） | 伊利诺伊 |

**判据验证结论（判据细化）**：
1. **J1 正截距是 c 型普遍特征，非煤系特有**——TUSCALOOSA/NEW ALBANY 亦正截距（海相运移/吸附背景），故正截距单独不构成煤系证据；
2. **煤系注入判定须 J1（强正截距>0.5）+ J2（OSI>60）+ 地质背景（油-煤共存）三条件互证**——沙海组为九体系唯一同时满足者；
3. **"正截距"与"OSI 高背景"可分离**：NEW ALBANY（弱正截距+OSI 19.8 低背景）vs 沙海组（强正截距+OSI 62.9）——煤系注入的强特征为**强正截距 + 中高 OSI**；
4. 负截距（长7段）唯一零阈值型——J1 是 c 型/零阈值型首要判别量；**苏北阜宁 GY1（2026-08-08 新增，负截距 −0.059 + OSI 64.2 高背景，R²=0.661）与青山口 SL 共同印证"负截距≠c→0"**——负截距须结合 Z1 线性度（R²≥0.90）与 Z2 低端趋零（低/高比<0.35）判零阈值型；
5. **源-储分离锚点（2026-08-08，准噶尔侏罗系煤系）**：煤系源岩（[E3] 类别，ACS Omega 2024 6 代表样品）OSI 中位 5.8（<20）远低于沙海组储层页岩 62.9——**判据 J2 加在储层端**：煤系生烃 → 油注入页岩储层才显 c 型正截距；勘探中须区分"源岩低 OSI（正常生烃态）"与"储层高 OSI（注入富集态）"。

## 三、模块 A/C/D：甜点评价与可动油校正

| 步骤 | 方法 | 输出 |
|:--|:--|:--|
| A1 资源分级 | TOC×a（原地生烃效率）分级 + 夹层自动识别（M5 线性偏差） | 烃源岩质量分区图 |
