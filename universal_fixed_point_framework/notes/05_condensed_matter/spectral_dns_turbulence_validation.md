# DNS 湍流高精度数值验证谱流体 k^{-5/3} 预言研究笔记

**日期**：2026-07-21（更新）
**关联**：Paper VI 谱流体动力学；Paper V §8.4；Paper I 未竞数值工程
**状态**：DNS 求解器已实现，数值验证运行中

## 1. 问题陈述

Paper VI 已从 N-S 谱流方程出发，理论推导出 Kolmogorov $k^{-5/3}$ 能谱（K41）：

$$E(k) = C_K \varepsilon^{2/3} k^{-5/3}$$

但尚未通过直接数值模拟（DNS）在 Navier-Stokes 方程上高精度验证该预言。

## 2. DNS 验证设计

### 2.1 模拟参数

| 参数 | 目标值 | 说明 |
|:----|:------|:----|
| 雷诺数 Re_λ | 100–1000 | 覆盖弱湍流到中等湍流 |
| 分辨率 N³ | 32³–128³（当前）；256³–2048³（完备） | 渐进式验证 |
| forcing | 大尺度随机（Fourier 空间，\|k\| < k_f） | 维持稳态各向同性湍流 |
| 积分时间 | 5–20 个大涡周转时间 | 统计收敛 |
| 时间步进 | RK4，CFL 自适应 | 数值稳定性 |

### 2.2 数据输出

- 三维速度场 $u_i(\mathbf{x}, t)$（Fourier 空间 + 实空间）
- 能谱 $E(k, t)$ 及其时间平均
- 能量耗散率 $\varepsilon(t)$
- 补偿谱 $k^{5/3}E(k)$（用于 C_K 标定）

### 2.3 与谱流体框架对比

| 验证点 | 经典结果 | 谱流体预言 |
|:------|:--------|:----------|
| 能谱标度 | $E(k) \sim k^{-5/3}$ | $E(k) = C_K \varepsilon^{2/3} k^{-5/3}$ |
| 惯性范围 | 存在 | 谱流在标度不变区的传播必然导致 |
| Kolmogorov 常数 | $C_K \approx 1.5$ | 从谱流几何导出 |
| 耗散范围 | 指数截断 | 谱间隙 $\gamma$ 控制截断（谱静默度 $S_{spec}$）|

## 3. 数值方法

### 3.1 DNS 求解器实现

`scripts/paperX_dns_turbulence.py` 实现了完整的 3D 伪谱 DNS 求解器：

| 组件 | 实现 | 说明 |
|:----|:----|:------|
| FFT | `numpy.fft.fftn`/`ifftn` | 3D FFT 变换 |
| 非线性项 | 伪谱法（实空间乘积 → Fourier 空间） | $(u\cdot\nabla)u$ |
| Dealiasing | 2/3 规则 | 截断高波数混叠 |
| 投影 | $P_{ij} = \delta_{ij} - k_i k_j/k^2$ | 满足 $\nabla\cdot u=0$ |
| 时间积分 | RK4 | 4 阶精度 |
| Forcing | 低波数随机 ($|k|<k_f$) | 维持稳态 |

## 4. 验证协议

### 4.1 三级验证协议

DNS 验证采用渐进式策略以提高效率：

**Level 1**（32³, Re_λ=100, T=5）— 功能测试 ✅ 通过
- 确认求解器基本功能正常
- 测试时间步进、能量衰减趋势

**Level 2**（48³, Re_λ=100, T=30）— 中精度验证 ❌ 未通过
- v3 结果：能量持续增长，未达稳态；斜率 -5.20（偏差 212%）
- 原因：forcing 过强（0.5），48³ 分辨率惯性区太窄

**Level 3**（64³, Re_λ=200, T=50）— 高精度验证 🔄 运行中
- 按能量平衡重新估算 forcing：force_amp=0.05
- 延长积分至 T=50，统计从 t=20 开始
- 能谱 $E(k)$ 惯性区斜率拟合
- Kolmogorov 常数 $C_K$ 标定
- 耗散区谱静默度 $S_{spec}$ 诊断

**Level 4**（96³–128³, Re_λ=300–500, T=100+）— 完备验证 📅 计划
- 间歇性修正 $k^{-5/3-\mu}$
- 高 Reynolds 数标度律检验
- 与文献 DNS 结果定量对标

### 4.2 关键诊断量

- **能谱斜率拟合**：加权最小二乘拟合 $E(k) \propto k^n$，验证 $n = -5/3 \pm 0.05$
- **补偿谱**：$k^{5/3}E(k)$ 在惯性区的平坦度（Kolmogorov 常数）
- **谱静默度**：$S_{spec} = E(k_\nu)/E_{\max}$，$S_{spec} \ll 1$ 对应强耗散静默
- **谱间隙**：$\gamma = 1 - E(k_\nu+1)/E(k_\nu)$
