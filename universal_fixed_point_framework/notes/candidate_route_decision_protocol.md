# 候选路线裁决协议（殊途同归 vs 异路）

> **协议来源**：用户 2026-10-25 立法（口头指令，MUFPF 推进方法论）。
> **状态**：生效中，适用于所有候选/开放路线选择点。

## 1. 协议条文

任何候选/开放路线在裁决取舍**之前**，必须先做**同归/异路分析**：

1. **殊途同归（同归）**：若候选实现是同一数学结构/同一机制的**等价描述路径**
   （同构、同源、同公式不同表述、不同表示维数/签名实现）——判定"殊途同归"，
   则**并举**：全部保留并分别机检/推进，**永不取舍**，登记"同归并举"。
2. **异路**：若候选实现**不是**同一结构（机制互斥、结构不同、预言冲突）——
   判定"异路"，则**分别探索**：对每条路径独立推进到**可证伪检验点**
   （数值探针/Lean 形式化/观测判别），**被证伪的路径剔除并保留证伪记录**，
   **未被证伪的路径存留继续**。
3. 同归与异路可并存于同一开放项的不同层级（见 §3 实例）。
4. 裁决只发生在异路路径必须取舍时；同归永不取舍。

## 4. 执行纪律

- 同归实例必须**双双机检**（不能只做一个宣称"同构所以够了"）。
- 异路证伪必须**留痕**（探针日志 + 证伪记录 + 登记"证伪剔除/存留"）。
- 裁决前先写一段同归/异路分析（可并入批注或本协议 §2/§3 表）；
  分析完成再执行取舍。
