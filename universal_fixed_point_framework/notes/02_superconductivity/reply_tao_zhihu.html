Tc ∝ √ρ0 标度律的代数推导——兼评 Tao 的复时间路径

作者：王斌（独立研究人）
日期：2026-09-11

评论对象：Y. Tao, "Universal square-root scaling between Tc and superfluid phase stiffness: From cuprates to FeSe films", Physica B 742, 419333 (2026)；知乎科普文章

1. 引言

Tao 在知乎文章中介绍了其 2026 年发表于 Physica B 的论文 [1]，从复数时间相对论（complex time relativity）出发，推导出 Božović 组 [2] 在 LSCO 薄膜中发现的根方标度律：

Tc = γ √ρ0     (1)

其中 γ = (4.2 ± 0.5) K1/2，并成功定量解释了铜基（γ(2) ≈ 3.7 K1/2）和铁基（γ ≈ 6.3 K1/2）超导的系数。Tao 的理论基于 Tomita-Takesaki 定理和热时间假说（thermal time hypothesis），预言绝对零度时时空是类空的。

本文指出：Tc ∝ √ρ0 的平方根关系可从更基础的代数结构内生导出，不需要复时间假设。整个推导仅依赖两个标准物理事实和一个 Nambu 空间代数恒等式，且已在 Lean4 定理证明器中形式化验证（零 sorry）。

2. Tao 的推导路径概述

Tao 的推导链条为：

  1. 公理基础：Tomita-Takesaki 定理 + 热时间假说 → 时间变量为复数 z = t + iτ
  2. 核心方程：库珀对虚时相对论方程（非线性 Klein-Gordon 形式），含 ℏ、c、kB 三个基本常数
  3. 重整化群：自由能密度变分 → 场方程 → RG 方程组 → 长波极限不动点 Tc(∞) = γ(D)√ρ0(∞)
  4. 定量验证：γ(2) = cF π √(16ℏ/(5kBca)) ≈ 3.7 K1/2（铜基），γ ≈ 6.3 K1/2（铁基）
  5. 独有预言：绝对零度时空是类空的

这一路径的优势在于能从材料常数（费米速度 νF、晶格常数 a、对称因子 γFd）定量计算 γ。

3. 代数推导：从 Nambu 对易子到 Tc ∝ √ρ0

3.1 起点：BCS 谱生成元

BCS 超导态的谱生成元（spectral generator）在 Nambu 空间中为：

ASC = ξk σz + Δ σx     (2)

其中 ξk = εk − μ 为相对于 Fermi 面的动能，Δ 为超导能隙，σz、σx 为 Pauli 矩阵。谱间隙为 δSC = Δ（详见 [3] §2.1，命题 2.1）。

3.2 U(1) 相位扭曲与对易子

超导序参量的 U(1) 相位 φ(x) 对应谱生成元的规范变换：

ASC(x) = U(φ(x)) · ASC(0) · U(φ(x))†     (3)

其中 U(φ) = eiφσz/2。对空间坐标 x 求梯度：

∂x ASC = (i/2)(∂x φ) · [σz, ASC]     (4)

关键一步——计算对易子：

[σz, ASC] = [σz, ξk σz + Δ σx] = Δ [σz, σx] = 2iΔ σy     (5)

因此：

∂x ASC = −Δ (∂x φ) σy     (6)

梯度范数：

‖∂x ASC‖ = Δ |∂x φ|     (7)

这里 Δ 以线性形式出现——它控制了谱生成元对相位扭曲的敏感程度。

3.3 谱梯度能与超流刚度

序参量空间扭曲的自由能密度为：

fgrad = (1/2βspec) ‖∂x ASC‖2 = (Δ2 / 2βspec) |∂x φ|2     (8)

其中 βspec 是谱框架的温度标度因子。与标准形式 fgrad = ρ0 |∂x φ|2 对比：

ρ0 = Δ2 / (2βspec)     (9)

3.4 βspec 的确定

从谱流方程（[3] §2.2）：

(d/dt) ASC(T) = [Apair + Athermal(T), ASC(T)] = 0     (10)

温度 T 作为热浴谱生成元 Athermal(T) 的耦合强度进入递归动力学。在不动点处，温度标度因子由 Fermi 能标确定：

βspec = EF / kB     (11)

物理含义：谱梯度能以 Fermi 能为自然能标进行标度。因此：

ρ0 = kB Δ2 / (2 EF)     (12)

3.5 标度律的导出

BCS 弱耦合并给出 Tc 与 Δ 的关系：

Δ = 1.764 kB Tc   ⟹   Tc = Δ / (1.764 kB)     (13)

即 Tc ∝ Δ（线性关系）。

而式 (12) 给出 ρ0 ∝ Δ2（平方关系）。

两者结合：

Tc = (1 / 1.764 kB) √(2 EF ρ0 / kB) = γ √ρ0     (14)

其中：

γ = √(2 EF / kB) / 1.764     (15)

4.2 平方根关系的本质

平方根关系 Tc ∝ √ρ0 的根源是两个独立的物理事实：

  1. Tc ∝ Δ：BCS 关系，由谱间隙动力学保证——临界温度正比于能隙
  2. ρ0 ∝ Δ2：谱刚度与谱间隙的平方关系，由 Nambu 空间对易子 [σz, ASC] = 2iΔσy 保证——能隙以线性形式进入对易子，但以平方形式进入梯度能

线性 × 平方 = 平方根。 这一推导不依赖于具体的配对机制（BCS、RVB、自旋涨落……），只依赖于：

  • 超导态有有限谱间隙 Δ（谱对称性破缺）
  • 相位扭曲的能量代价由 Nambu 对易子 [σz, ASC] 的范数控制

因此 Tc ∝ √ρ0 是代数结构的内生推论，而非材料依赖的经验律。

4.5 关于绝对零度

Tao 预言"绝对零度时空是类空的"——复时间虚部 τ 主导，度规退化为空间形式。

代数路径给出不同的图像：绝对零度对应谱流方程的热耦合项消失——Athermal(0) → 0，谱流退化为：

(d/dt) ASC = [Apair, ASC] = 0     (16)

递归动力学冻结（recursive freezing）：谱数据 {λi} 仍存在为静态结构，但不再有递归驱动的谱流演化。可度量的确实只有空间分布（静态谱结构），但这是因为递归动力学静默，而非度规本身变为空间型。

更精确地说：谱间隙 Δλmin 构成不可跨越的能垒。当 kBT / EF → 0 时，热扰动远小于谱间隙，递归无法被热激发跨越——这正是"机械运动趋于停滞"的数学表述。

5. 形式化验证

上述推导已在 Lean4 定理证明器中形式化（SuperfluidStiffness.lean，零 sorry，构建通过 2026-09-11）：

  1. SpectralStiffness：ρ0 = Δ2 / (2βspec)（定义）
  2. spectral_stiffness_gap_relation：ρ0 = (1/(2EF)) · Δ2（定理，代数恒等式）
  3. scaling_coefficient_gamma：γ = √(2EF) · aBCS（定义，aBCS = 1/1.764）
  4. Tc_sqrt_rho0_scaling：Tc = γ · √ρ0（定理，零 sorry 闭合）

关键证明步骤：恒等式 √(2EF) · √(Δ2/(2EF)) = Δ 通过 Real.sqrt_mul 合并两个平方根，再用 Real.sqrt_sq 闭合。

Lean4 形式化意味着上述推导的每一步都是机器验证的数学定理——不存在跳步或隐含假设。这是物理学推导中罕见的严格性保证。

6. 结论

Tc ∝ √ρ0 标度律可从 Nambu 空间对易子 [σz, ASC] = 2iΔσy 的代数结构内生导出，不需要复时间假设。平方根关系的本质是：

  • 线性：Tc ∝ Δ（BCS 关系，谱间隙动力学）
  • 平方：ρ0 ∝ Δ2（Nambu 对易子结构，能隙以线性进入对易子但以平方进入梯度能）
  • 线性 × 平方 = 平方根

Tao 的复时间路径与本文的代数路径从不同公理出发到达同一标度律，这种"殊途同归"增强了标度律的可信度。两条路径的互补性在于：

  • Tao 的优势：能从材料常数定量计算 γ 的数值（3.7 vs 4.2 实验）
  • 代数路径的优势：标度律是代数结构的内生推论，不依赖虚时间假设；额外预言多带超导隙比的 SU(2) Casimir 量化

关于绝对零度，Tao 预言"时空是类空的"（度规退化），代数路径给出"递归冻结"（动力学静默）——两者都指向"可度量的只有空间分布"，但机制不同：前者是度规结构变化，后者是递归动力学停止。
