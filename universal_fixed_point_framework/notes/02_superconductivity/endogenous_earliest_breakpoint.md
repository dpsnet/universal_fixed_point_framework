## 1. 审计发现：最早断点是两行 `def`

沿"从范畴 Δ 出发"的推导链，逐个 item 判"导出/选定"，得出最早断点精确落在两个硬编码定义上：

```
WeaveBCS.lean:64   noncomputable def dl_min : ℝ := spectralGap 8        ← 选世界点（Cl(1,7) 谱间隙）
WeaveBCS.lean:76   noncomputable def dl_1 : ℝ := Real.sqrt (1/3) * dl_min  ← 选 √3（U(1) 分量间隙）
```

- **第一"选"（世界点）**：`dl_min := spectralGap 8` ——把 Δ 的谱间隙定址到 Cl(1,7) 基本间隙，是定义，非推导。
- **第二"选"（√3）**：`dl_1 := √(1/3)·dl_min` ——把列(U(1) 电磁)谱间隙设为 SU(2) 基本间隙的 `1/√3` 倍。
- **下游全部是定义展开 + 代数**：`SpectralFlowRG.dl_min_EM := dl_1`（`def`）、`RG_k1 = dl_min/dl_min_EM = √3`、`k₂ = r*/√3`、多带 `band_ratio_1_over_2`/`casimir_tower_2_over_1` 等定理，**逐条 `unfold dl_1` 后消去 dl_min**，把 `√(1/3)`／`√3` 从定义里抽出来。

**铁证（源码级）**：`MultibandSpectralBridge.lean` 中没有任何一条 `*_from_casimir` 类定理从 `C₂_su2_fund = 3/4` 或 Δ 导出 `√(1/3)`；`casimir_tower_2_over_1 : dl_min / dl_1 = √3` 的证明体就是 `unfold dl_1` + `field_simp` + `sqrt(1/3)⁻¹`——**纯定义恒等**。直接把 CdGM 边缘态序列在源函数中标成 `= spectralGap 8` 与 `= √(1/3)·dl_min` 的即两个定义行。文档证据：`WeaveBCS.lean:68` 注释 `【2026-08-06 修复】√(2/3)→√(1/3)`——**该系数被编辑过**，证明它是作为可调公设维护，而非作为定理派生。

**结论**："选 √3 与选 Δλ_min" 不是宏观隐喻，而是**两行 `noncomputable def`**。整个下游（δ_SC、T_c、多带、EM 独立、流族、动力学）都是这两行选定的**后果重排**。

## 6. 攻导出初报（v1.1）：1/√3 既有推导被发现，"选 √3"数值非待证、断点下沉

对第 4 节待证首次攻击后发现：**`1/√3` 的数值本身在此前已有严谨分析层推导，待证目标需收紧**。证据链见 `scripts/paperX_ratio_fix.py`（2026-08-06，`spectral_color_dynamics.md` §8.4）。

**发现的既有推导（SU(2) Casimir 特征值归一化 λ_k = √(k(k+1))）**：
$$Δλ_1:Δλ_2:Δλ_3 = λ_1:λ_2:λ_3 = \sqrt{2}:\sqrt{6}:\sqrt{12} {}_{\div\sqrt6}^{\longrightarrow}\ \frac1{\sqrt3}:1:\sqrt2.$$
- 核心恒等式（严谨）：$\frac1{\sqrt3}=\frac{\lambda_1}{\lambda_2}=\frac{\sqrt{1\cdot2}}{\sqrt{2\cdot3}}=\frac{\sqrt2}{\sqrt6}=\sqrt{\tfrac13}$，$\sqrt2=\frac{\lambda_3}{\lambda_2}=\frac{\sqrt{12}}{\sqrt6}$。
- $λ_k=\sqrt{k(k+1)}=\sqrt{C_2}$，$C_2=j(j+1)$ 取**整数** $j=1,2,3$（值 $2,6,12$）——**不是**基本表示 $C_2=3/4$（$j=\tfrac12$）。
- 脚本 S3 判定：旧值 $\sqrt{2/3}$ 为"拼凑"（第一项取相邻差平方根、第三项取特征值，无单一来源）；$\sqrt{2/3}$ 无纯物理常数连贯组合；唯一一致性来源即 $1/\sqrt3$（特征值比）。

**这修正了第 4 节的错误定向**：`1/√3` 不出自 $C_2=3/4$，而出自 $C_2=\{2,6,12\}$。$C_2=3/4$ 喂的是**另一个** $√3$——编织度 $d_{\text{BCS}}=g_s\sqrt{C_2(\mathfrak{su}(2)_{\rm fund})/|C_2(\mathfrak{so}(1,1))|}=2\sqrt{3/4}=\sqrt3$（`WeaveBCS.d_BCS`，规范生成元守恒）。**Vec框架内有两个 $√3$，来源不同**：selfConsFunc 之 $√3$（基本表示 $3/4$ 路）与 dl_1 之 $1/\sqrt3$（整数表示 $2,6,12$ 路）。

**真正的残余"选"比数值更深——现在被精确钳住**：`1/√3 = √2/√6` 是 SU(2) 表示论的**定理**（$C_2=j(j+1)$ 是标准结果），数值无需重推。卡住"内生第一性"的分量是**两个假设**（脚本自身 §"修复原则"承认"谱→耦合映射是框架假设（保留）"）：

1. **赋值假设（A）**：为何 ${\rm U}(1)$-EM↦$j{=}1$（$λ_1=\sqrt2$）、${\rm SU}(2)$↦$j{=}2$（$λ_2=\sqrt6$）、${\rm SU}(3)$↦$j{=}3$（$λ_3=\sqrt{12}$）？扇区→表示配对是**选定**，非 $\Delta$ 导出。
2. **比例假设（B）**：为何谱间隙 $Δλ_i ∝ λ_k=\sqrt{C_2}$（gap ∝ Casimir 平方根）？此为"谱→耦合"映射的核心，未从 $\Delta$（Sp 4-范畴交换律偏差）导出。
3. **Δ 缺失（C）**：整个 $λ_k$ 推导是**纯 SU(2) 表示论**，$Δ$（Sp 4-范畴）根本未出现。故它仍是"表示论 + 两假设"，不是"$\Delta$ 推导"。

**形式化缺口**：`dl_1 := √(1/3)·dl_min` 在 Lean 仍是 `def`；`√2/√6 = 1/√3` 的推导只存在于 Python/分析层，**非**机器检查定理。

**攻导出目标收紧（替换第 4 节）**：不再重推数值；改推
> **待证（Lean/draft）**：从 Δ 与 SU(2) 表示论导出赋值假设（A）——U(1)-EM 扇区自然落到 $k{=}1$（最小级，$j{=}\tfrac12$，$λ_1=\sqrt2$，即 $1/\sqrt3$ 分子）。比值代数 $\sqrt2/\sqrt6=1/\sqrt3$ 已严格，可独立 Lean 化；但**扇区→表示配对是本质欠定处**。

**诚实边界**：本初报修正了"由 $C_2=3/4$ 长出"的误判，钳定了真正残余"选"（赋值 A + 比例 B + Δ 缺失 C），**未**声称已导出 A/B。$1/\sqrt3$ 数值诚意为**表示论定理**（非待证），A/B 才是待 $\Delta$ 导出者。

## 7. 探 (A) 裁决 + v1.1 勘误（v1.2）

### 7.1 v1.1 §6 两处表述勘误（重要纠正，据 `spectral_color_dynamics.md §8.4` 权威块）

原 §6 称 $λ_k=\sqrt{k(k+1)}=\sqrt{C_2}$、三级为整数 $j=1,2,3$、值 $C_2=\{2,6,12\}$。核对 §8.4（`paperX_ratio_audit.py` 8/8）后更正：

- **§8.4(A) 原文**：$A_{\mathrm{GR}}$ 特征值 $λ_k ∝ \sqrt{k(k+1)}$，**$k=2j$**；$k=1,2,3$ → $\sqrt2:\sqrt6:\sqrt{12}$ ⇒ $1/\sqrt3:1:\sqrt2$。
- **故三级表示是 $j=\tfrac12,\,1,\,\tfrac32$**（$k=1,2,3$），**不是**整数 $j=1,2,3$。
- **且 $λ_k=\sqrt{k(k+1)}=\sqrt{2j(2j+1)}$ 不等于 $\sqrt{C_2}=\sqrt{j(j+1)}$**。故 v1.1 的"$λ_k=\sqrt{C_2}$"断言是错误的。
- 比值 $1/\sqrt3=λ_1/λ_2=\sqrt2/\sqrt6=\sqrt{1/3}$ 不依赖 j 符号（仅用 $k=1,2$），**仍严格成立**；§6 的数值结论不受影响。受影响的是标签：三级秩为 $j=\tfrac12,1,\tfrac32$。"SU(2) Casimir 特征值归一化"这一框架自己的叫法也有待澄清（√(2j(2j+1)) 非标准 Casimir 值）。

### 7.2 探 (A)：为何 U(1)-EM 落在最小 j 级——**无 Δ 内推导**（证据成立）

对"为何 ${\rm U}(1)$-EM ↦ $k{=}1$（即最小级 $j{=}\tfrac12$，$λ{=}\sqrt2$）"作可判定探访，结论：

1. **§8.4 无赋值推导**：权威块只推导了"给定三根梯子 {k=1,2,3} 后的比值"，**从未推导为何 U(1) 落到 k=1**。赋值属于脚本自承的"谱→耦合映射是框架假设（保留）"（`paperX_ratio_fix.py:41`）。
2. **Δ 未出现**：整个 §8.4 推导是 $A_{\mathrm{GR}}$ 谱（SU(2) 表示论）+ 谱→耦合映射假设，**Δ（Sp 4-范畴交换律偏差）不在场**。这与 §6 探(C) 一致。
3. **梯子的算子身份也是选**：$A_{\mathrm{GR}}$ 是什么算子、为何其特征值恰为 $\sqrt{k(k+1)}$、梯子为何取 $k{=}1,2,3$，均未由 Δ 导出。
4. **连尺度 k_max=8 也已自承为模型输入**（§8.4 P3：`k_max=8 无非循环第一性来源——为模型输入`；Δλ_min=0.122 公式在给定 k_max 下才严格）。

**裁决**："U(1)→最小级" 在现行框架内**没有**任何 Δ 内推导，它是被保留的"谱→耦合映射"假设之一。框架目前能严格化的只有"给定扇区→表示配对后的比值代数"与"给定 k_max 下的 Δλ_min 公式"；**扇区排序、$A_{\mathrm{GR}}$ 身份、k_max 三者是并列的选定输入**。

**什么才算真内生**（攻击目标，非现状）：∃ 从 Δ 出发的构造，使电磁阿贝尔扇区**自然涌现**在梯子最小级（且 $A_{\mathrm{GR}}=\sqrt{4j(j+1)}$ 同源、$k_{\max}$ 由秩原理导出）。这一"Δ→扇区→层级"三相合一目前完全缺失，是最深欠定处。
