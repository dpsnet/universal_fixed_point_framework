2. **能证 B（内化分解）**：1.764 = π·e^{−γ_E}，其中
   - **π**：费米型谱权重因子（奇数频率 Matsubara 求和 Σ_{n≥0} (−1)ⁿ/(n+1/2) = π/2 的因子），来自有限温谱流的费米占据谱结构；
   - **e^{−γ_E}**：**谱 ζ 正则化常数** $e^{-γ_E}$——调和谱求和 Σ1/k 有限部常数 $γ_E$ 的倒数因子，正是 MUFPF 谱 ζ 资产中的 γ_E，是纯粹的谱解析对象。

3. **暂不可证（范畴 Δ 数值钉死）**：单凭 Cl(1,7)/SU(2) Casimir 范畴结构把 π 与 e^{γ_E} 的**数值**计算出来。π 与 e^{γ_E} 是全域常数；费米谱权重（BdG 线性能态密度）也是 BCS 物理输入。这一级**不伪称**。

**一句话结论**：把 1.764 从"BCS 全程输入"推进为"π×e^{−γ_E}：两个普适谱常数 $\pi$ 与 $e^{γ_E}$（后者以倒数 $e^{-γ_E}$ 入场）的内化分解，且普适性由 Lean4 定理保证"。谱常数的具体数值与谱权重仍登记为物理锚。

## 1. 谱流自洽与前置量

谱框架（Paper XIV §2.2；Paper V 谱流不动点）中，温度作为热浴谱生成元 A_thermal(T) 的耦合强度
进入谱流方程；不动点条件 dA_SC/dt = [A_pair + A_thermal(T), A_SC] = 0 在弱耦合下等价于 BdG 自洽隙方程

$$1 = \lambda \int_0^{\hbar\omega_D} \frac{\tanh\!\left(\sqrt{\xi^2+\Delta^2}\,/\,2k_BT\right)}{\sqrt{\xi^2+\Delta^2}}\,d\xi \qquad (1)$$

其中 λ = N(0)V 是态密度×配对强度（无量纲），ω_D 是 Debye 截断，Δ = Δ(T) 是序参量（谱间隙）。
- **T = 0**：Δ = Δ₀（谱刚性隙），tanh → 1，式 (1) 化为
  $$1/\lambda = \int_0^{\omega_D} \frac{d\xi}{\sqrt{\xi^2+\Delta_0^2}} = \operatorname{asinh}(\omega_D/\Delta_0) .$$
- **T = T_c**：Δ → 0（谱流隙闭合温度），式 (1) 化为
  $$1/\lambda = \int_0^{\omega_D} \frac{\tanh(\xi/2k_BT_c)}{\xi}\,d\xi .$$

## 2. 弱耦合渐近（两处对数散度的有限部）

**T = 0 支**：asinh 大自变量渐近
$$\operatorname{asinh}(\omega_D/\Delta_0) = \ln\bigl(2\omega_D/\Delta_0\bigr) + O\!\bigl((\Delta_0/\omega_D)^2\bigr) \xrightarrow{\ \ } \frac{1}{\lambda} \approx \ln\frac{2\omega_D}{\Delta_0}.$$
系数 **2** 是 asinh 的干净谱系数（来自 BdG 线性能态密度在 ξ~0 的平坦积分核），非自由。

**T = T_c 支**：Debye 型积分有限部（标准结果，弱耦合 ω_D ≫ k_BT_c）
$$\int_0^{\omega_D}\frac{\tanh(\xi/2k_BT_c)}{\xi}d\xi \;\approx\; \ln\frac{2e^{\gamma_E}\,\omega_D}{\pi\,k_BT_c}, \qquad \frac{2e^{\gamma_E}}{\pi} = 1.1340\ldots$$
即
$$1/\lambda \approx \ln\frac{2e^{\gamma_E}\,\omega_D}{\pi\,k_BT_c}.$$

## 3. 自洽分离（相对消去法）——普适核心

两式右端相等（同享 1/λ）：
$$\ln\frac{2\omega_D}{\Delta_0} = \ln\frac{2e^{\gamma_E}\,\omega_D}{\pi\,k_BT_c}
\;\Longrightarrow\; \frac{2\omega_D}{\Delta_0} = \frac{2e^{\gamma_E}\,\omega_D}{\pi\,k_BT_c}.$$

交叉消去 **ω_D**（截断无关）与 **λ**（耦合无关）：

$$\boxed{\frac{\Delta_0}{k_BT_c} = \pi\,e^{-\gamma_E} = 1.76389\ldots \approx 1.764},$$
$$\boxed{\frac{2\Delta_0}{k_BT_c} = 2\pi e^{-\gamma_E} = 3.52779\ldots \approx 3.528}.$$

即 `a_BCS = 1/1.764 = e^{γ_E}/π`。**耦合 λ 与截断 ω_D 在自洽分离中被相对消去**——这就是普适比值的普适性所在，
也是本讲的第一条 Lean4 定理（§5）。

**数值校验**：e^{−γ_E} = 0.561459，×π = 1.76389 ≈ 1.764 ✓；2e^{γ_E}/π = 2×1.78107/3.14159 = 1.1340 ≈ 1.13 ✓。

## 4. 两个因子的内生谱来源

**4.1 e^{γ_E}——谱 ζ 正则化常数**。两处对数散度中的有限部常数 γ_E 来自调和谱求和的正则化：
$$\sum_{k=1}^{\infty}\frac{1}{k}\ \xrightarrow{\ \text{谱ζ/Mellin正则化}\ }\ \ln\Lambda - \gamma_E + o(1).$$
γ_E 是**谱 ζ 函数（或热核展开）在平凡极上的常数项**——Mellin 变换 Σ_k k^{−s} 在 s=1 的留数展开
`` 1/(s−1) − γ_E + … `` 的正则化有限部。这是纯粹的谱解析对象，**已存在于 MUFPF 谱 ζ 资产中**，
与 Paper V/谱流方程的正则化结构共享同一机制。因此 1.764 中的 e^{−γ_E} 是框架"自带的"谱常数。

**4.2 π——费米型谱权重因子**。T_c 支的 tanh 积分核是费米占据谱权重的积分（奇数频率）：
$$\frac{2e^{\gamma_E}}{\pi}\ \text{中的}\ \pi\ \text{源自}\ \int\frac{\tanh(x)}{x}dx\ \text{的大 x 有限部},\quad\text{等价于}\ \sum_{n\ge 0}\frac{(-1)^n}{n+\tfrac12}=\frac{\pi}{2}.$$
π 来自有限温谱流的**费米（奇数频率）谱结构**——正是超导（配对）区别于玻色凝聚的谱签名。π 不是任意常数，
而是"费米谱权重折叠为 tanh 核"的结构因子。

**内化结论**：
$$1.764 = \pi\,e^{-\gamma_E} = \underbrace{\pi}_{\text{费米谱权重因子}}\times\underbrace{e^{-\gamma_E}}_{\text{谱ζ正则化有限部}}.$$
普适比值由两个**全域谱常数**的乘积唯一确定，与耦合、截断、材料参数无关。这就是 1.764 的"内生来源"——
不再是 BCS 特有的自由锚，而是两条普适谱机制的并置。

## 5. 普适性定理的 Lean 形式化

证明重点是 A 层（自洽分离的普适性）。把两处闭合写成指数形式，避开对数函数，
用实数域代数 + 正性 + 实指数相等交叉传递即可闭合：

闭 合 1（T=0 隙）：`exp(1/λ) = 2·ω_D/Δ₀`
闭 合 2（T_c 隙）：`exp(1/λ) = a0·ω_D/T_c`，其中 a0 := 2e^{γ_E}/π 为 Debye 有限部常数

**定理 `universal_ratio_cancellation`**：在 ω_D, Δ₀, T_c, a0 > 0 与两闭合方程下：

$$\frac{\Delta_0}{T_c} = \frac{2}{a_0} = \frac{\pi}{e^{\gamma_E}} = 1.764.$$

关键步骤：两闭合共享同一 exp(1/λ) ⟹ 两右端相等；交叉相乘后消去 ω_D（截断无关）；
结论只含 a0 与 2（与 λ、ω_D 无关）——普适性。证明是纯代数/正性论证，零 sorry。
