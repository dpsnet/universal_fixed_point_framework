**研究目标**：推导 RN-ENDO-002 中 `1.764 = πe^{−γ_E}` 两个普适谱常数的**数值**来源。

## 0. 一句话诚实结论：两者的数值来源深度完全不同

- **π 的数值是"可推导"的**：π 是根本连通常数，其数值由**多条相互独立的精确表示唯一确定**（周长/直径、高斯积分、Basel、arctan 交错级数、奇数频率 Matsubara 和）——无一需要调参，全部收敛到同一个 3.14159…。π 在 BCS 中的具体出现（费米型谱权重因子）**精确地**是奇数频率交错和 = 4·arctan(1)。所以"π 从哪来"有真正的推导：它就是这样被唯一钉死，且其在 BCS 中的"进场方式"可精确追到 Matsubara 求和。
- **e^{γ_E} 的数值是"定义性的"**：γ_E 由极限 $\gamma_E = \lim_{n}(\sum_{k\le n}1/k - \ln n)$ **定义**，其数值 0.57721… 由多种精确表示验证一致，但**没有**更深的封闭形式，**且 γ_E 是否无理是数学上未决的开放问题**。因此 e^{γ_E} 的数值**不是"从更深处推导出来"的**，而是"由定义计算得出"的普适正则化有限部常数。任何"范畴结构给出 0.57721566…"的说法都是**伪造**。e^{γ_E} 的谱来源是真实且谱论的——它精确等于谱 ζ 函数在平凡极 s=1 的常数项（下文 §3）——但其数值只能由定义给，不能由约化给。

这决定了后续一切言说的诚实框架。

## 1. π 的数值来源——根本连通常数，可由第一性唯一确定

π 是"周期常数"：单参量连通紧群的周期、单位圆的半周长、傅里叶基本频率。其数值不依赖任何物理模型，
由以下**相互独立**的精确表示唯一确定（全部在 `verify_pi_gamma.py` 中验证到 60 位）：

| 来源 | 等式 | 类别 |
|:----|:-----|:----|
| 周长/直径（基底） | $\pi = C/d$ | 定义 |
| 高斯积分 | $\pi = \Gamma(\tfrac12)^2 = \left(\int_{\mathbb R} e^{-x^2}dx\right)^2$ | 积分 |
| Basel（谱 ζ） | $\pi = \sqrt{6\,\zeta(2)} = \sqrt{6\sum_{k\ge1}k^{-2}}$ | 谱 |
| arctan 交错级数 | $\pi = 4\sum_{n\ge0}\frac{(-1)^n}{2n+1} = 4\arctan 1$ | 级数 |

数值核验（脚本 §A）：Leibniz 项（N=2e6）→ 3.14159215；Gauss → 3.1415926535897927；Basel（N=2e6）→ 3.14159218；
与 π=3.1415926535897932 全部一致（误差项来自有限截断，收敛到同一值）。

**π 在 BCS 中的"进场方式"（费米型谱权重因子）**：有限温谱流把配对序参量（奇宇称/频域反对称）折叠进
热浴时，T_c 支积分核的费米软模平均化为**奇数频率交错和**（脚本 §D）：

$$\sum_{n\ge0}\frac{(-1)^n}{n+\tfrac12} = 2\sum_{n\ge0}\frac{(-1)^n}{2n+1} = \frac{\pi}{2}, \qquad \pi = 4\arctan 1 .$$

数值核验：N=3e6 → 1.57079616 ≈ π/2（误差 1.67e-7，收敛）。**结论**：π 的数值来源是根本的、被唯一确定的，
其在 BCS/谱流中的出现由双向等式（求和 = 4arctan 1）精确钉死，不是自由参数。

## 2. e^{γ_E} 的数值来源——定义性普适正则化常数

γ_E 的定义（Euler–Mascheroni）：
$$\gamma_E = \lim_{n\to\infty}\left(\sum_{k=1}^{n}\frac1k - \ln n\right) = 0.57721\,56649\,01532\,86060\ldots$$

数值由下述**精确表示**相互一致地验证（脚本 §B，全部到 60 位，与 `mpmath.euler` 逐位吻合）：

| 表示 | 等式 | 属类 |
|:----|:-----|:----|
| 定义极限 | $\gamma_E = \lim_n(H_n - \ln n)$（慢，尾项 ~1/(2n)） | 定义 |
| 积分 | $\gamma_E = -\int_0^1\!\big(\tfrac1{\ln x}+\tfrac1{1-x}\big)\,dx$ | 积分 · 精确 |
| digamma | $\gamma_E = -\psi(1) = -\Gamma'(1)/\Gamma(1)$ | 特殊函数 · 精确 |
| 谱 ζ 平凡极有限部 | $\gamma_E = \lim_{s\to1}\bigl(\zeta(s) - \tfrac1{s-1}\bigr)$ | **谱 · 精确** |
| 快速级数 | $\gamma_E = 1 - \sum_{k\ge2}\frac{\zeta(k)-1}{k}$（指数收敛） | 级数 · 精确 |

数值核验：B2/B3/B4/B5 全部 = 0.57721566490153286061（与 euler 逐位一致，60 位）；B1 定义极限在 N=3e6 达
0.5772158316（尾项 ~1/(2N) 已确认）。

**γ_E 的数值不能从更深处"推导出来"**，原因（诚实且无可争辩）：
1. **无封闭形式**：γ_E 不是任何已知初等常数（π、e、代数数）的初等组合；不存在 π^p、e^q 之类的恒等式。
2. **无理未决**：γ_E **是否无理仍是数学界开放问题**（从未被证明也不被否定）。一个连有理无理都不知道的常数，
   自然不存在"从范畴结构算出其数值 0.57721566…"的推导。
3. 脚本 §C 的诚实检验：`log(e^{γ})/log(π) = 0.50424` 不是 p/q 有理小分数；无 π^p/q 匹配。即 e^{γ_E} 数值不与 π 互约。

**结论**：e^{γ_E} 的数值来源是**定义 + 计算**：它由极限定义唯一给定，并由多种精确表示逐位验证。
任何把它"约化"或"从范畴数值推导"的努力，在数学上是不可行的（且目前无理未决）。

## 3. e^{γ_E} 的"谱来源"是真实的，但仅指示机制、给出定位，不给出数值约化

尽管 e^{γ_E} 数值不可约，它在谱框架中的**身份是精确且谱论的**：

$$\gamma_E = \lim_{s\to1}\Bigl(\zeta(s) - \frac{1}{s-1}\Bigr) = \text{谱 }\zeta\text{ 在平凡极 }s=1\text{ 的常数项}.$$

这就是 RN-ENDO-002 §4.1 所言"调和谱求和 $\sum_k1/k$ 在平凡极上的正则化有限部"。谱流方程在弱耦合处的
对数散度 `∫ dξ/ξ → ln Λ − γ_E + o(1)`，其有限部常数精确是上述 ζ 常数项。**故 e^{γ_E} 的谱来源（它是那个
正则化常数）是真实、精确、可证的**；只是它的**数值由定义给定**，无法进一步约化。

一个深刻而与 π 并列的关系（作为谱正则化的"姐妹常数"，不作数值约化断言）：ζ-正则化无限积 $\prod_{k\ge1}k = \sqrt{2\pi}$
（源于 $\zeta'(0)=-\tfrac12\ln 2\pi$），与 γ_E 同属"ζ 正则化有限部"家族——e^{γ_E} 与 √(2π) 是在对数散度的
Stirling/正则化渐近中结伴出现的谱常数。这给出 e^{γ_E} 在谱框架中真实的**定位**，但不给出数值约化。

## 4. BCS 普适组合的精确值与表格舍入

用真值自洽核算（脚本 §C2，60 位）：BCS 弱耦合普适比值在理想极限下为

$$\frac{2\Delta_0}{k_BT_c} = 2\pi e^{-\gamma_E} = 3.527753977724091\ldots \approx 3.528,$$
$$\frac{\Delta_0}{k_BT_c} = \pi e^{-\gamma_E} = 1.763876988862046\ldots \approx 1.764,$$
$$\frac{2e^{\gamma_E}}{\pi} = 1.133865917311098\ldots \approx 1.13.$$

即教科书表列 **3.528 / 1.764 / 1.13** 是理想值经 3 位有效数字的**舍入**（1.764 相对真值 1.763877 的舍入误差
≈ 1.2e-4）。`a_BCS = 1/1.764` 因而是舍入后的值；`e^{γ_E}/π = 0.56693296` 与 `1/1.764 = 0.56689342` 相差 ≤ 4e-5，
纯属舍入。**谱框架主张的普适量是 $\pi e^{-\gamma_E}$ 本身**（精确、可计算到任意精度），不是舍入后的 1.764。

## 6. 对 G2 绝对能标的意义

- **π**：彻底"内生来源"可答辩——它是根本连通常数，数值被多条精确表示唯一钉死；它在 BCS 中的出现精确等于
  平方根相位 + 奇数频率求和，无可调旋钮。
- **e^{γ_E}**：它的**谱定位**（ζ 平凡极常数项=对数散度有限部）是真实、精确、框架内自带的；但它的**数值**
  是定义性的、不可约的、无理未决。MUFPF 谱 ζ 资产把 e^{γ_E} 作为**该正则化常数的名字**使用是合法的；
  把它当作"被范畴结构计算的量"则是不合法的（不伪称）。

净结果：`1.764 = πe^{−γ_E}` 中，π 一侧可完整推导其数值与处境，e^{γ_E} 一侧可推导并证明其**身份**
（谱正则化有限部）但**不得声称数值约化**。G2 绝对能标因此在"普适常数名称 + 普适性定理（RN-ENDO-002）+ π 数值来源
（本笔记 §1）+ e^{γ_E} 谱身份（本笔记 §3）"四个层面闭合，而"e^{γ_E} 数值由范畴 Δ 计算"明确登记为**不可行的
开放项（不伪称）**，与其无理未决的数学现实一致。
