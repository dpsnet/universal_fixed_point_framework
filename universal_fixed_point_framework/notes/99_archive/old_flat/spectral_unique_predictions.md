# 谱框架独有实验预言汇总

## 概述

本文档系统整理 UFPF 谱动力学框架给出的、区别于 Standard Model (SM) 及其他 BSM 理论的所有可检验预言。每个条目包含理论来源、精度/置信度、当前实验状态、区分性判据及可检验时间线。

---

## 1. 坍缩时间

| 属性 | 内容 |
|:-----|:-----|
| **理论来源** | Paper X §3；`paperX_collapse_time.py` / `paperX_collapse_experiment_sim.py` |
| **预言公式** | $\tau_{\text{collapse}} = \ln(1/\varepsilon) / \kappa$，其中 $\kappa$ 为测量交互强度（可调），$\varepsilon$ 为收敛阈值 |
| **数值估计** | 超导量子比特实验中 $\tau \sim \mu\text{s}$ 量级 |
| **置信度** | 中高 — 谱流方程直接导出，参数 $\kappa$ 由实验设定。但 $\varepsilon$ 与量子系统退相干率的耦合需进一步实验标定 |
| **区分性** | |
| | **标准 QM**: $\tau = 0$（瞬时坍缩），不可观测 |
| | **GRW 模型**: $\tau \sim 10^{-16}\,\text{s}$（普适常数），远短于任何测量时间 |
| | **谱动力学**: $\tau$ 随 $\kappa$ 可调，可进入 $\mu\text{s}$ 观测窗口 |
| **实验平台** | 超导 transmon 量子比特（IBM/Google 架构），通过弱测量调控 $\kappa$ |
| **时间线** | **近期（1-3 年）** — 现有超导量子比特平台可直接实施 |

## 2. L4 第四代轻子

| 属性 | 内容 |
|:-----|:-----|
| **理论来源** | Paper II §4；`paperX_categorical_generation.py`；`notes/spectral_remaining_SM_params.md` |
| **预言公式** | $m_{L4} = c_1^{-\alpha_L} \cdot \Lambda_{\text{weak}}$，由 $\rho = 0$（分离 IFS）导出 |
| **数值预测** | $m_{L4} \approx 1470\ \text{GeV}$ |
| **置信度** | 中 — 依赖于 IFS 收缩因子的精确标度关系。若 $\rho$ 存在微小非零值，质量可能偏移 $\pm 200\ \text{GeV}$ |
| **当前实验状态** | LHC 直接搜索下限 $\sim 1300\ \text{GeV}$（ATLAS/CMS，$\sqrt{s}=13\ \text{TeV}$，$\mathcal{L}=140\ \text{fb}^{-1}$） |
| **区分性** | SM 无第四代轻子；其他 BSM（如 $Z'$ 模型）的类 L4 信号有不同的衰变拓扑与产生截面 |
| **时间线** | **近期（1-3 年）** — HL-LHC 升级后在 $\sqrt{s}=14\ \text{TeV}$、$\mathcal{L}=3\ \text{ab}^{-1}$ 下可达 $1500\ \text{GeV}$ 灵敏度 |

### 3.1 A_GR 零模（超轻轴子）

| 属性 | 内容 |
|:-----|:-----|
| $m_{\text{DM}}$ | $\sim 8.2 \times 10^{-13}\ \text{eV}$ |
| **来源** | 谱规范理论中 $A_{GR}$ 场的零模式，由辫静默 $S_4$ 压制 |
| **置信度** | 低 — 零模质量依赖于红外截断的选择 |
| **当前状态** | 传统轴子实验（ADMX、CAST）未覆盖此质量窗口 |
| **区分性** | SM 无此类粒子；标准 QCD 轴子质量 $\sim \mu\text{eV}$ 量级 |
| **实验提案** | 将 $A_{GR}$ 零模耦合至超导微波腔，利用其类轴子-光子转换 |
| **时间线** | **长期（10+ 年）** — 需要新型低频轴子探测器 |

### 3.2 谱静默 WIMP

| 属性 | 内容 |
|:-----|:-----|
| $m_{\text{DM}}$ | $\sim 100\ \text{GeV}$ |
| **来源** | Spec 4-范畴对象静默 $S_3$ 层级与弱标度交叉 |
| **置信度** | 中 — 质量与 weak scale 自然相近，自然地满足 relic density 观测值 |
| **当前状态** | 与 LZ/XENONnT 直接检测的排除区间部分重叠 |
| **区分性** | 不同于 MSSM 中性微子（依赖 SUSY 参数空间）；谱 WIMP 有唯象的规范-沉默耦合模式 |
| **时间线** | **近期（1-5 年）** — LZ 最终数据集和 XLZD 项目可确认或排除 |

### 3.3 交换子缺陷

| 属性 | 内容 |
|:-----|:-----|
| $m_{\text{DM}}$ | $\sim 5 \times 10^{7}\ \text{eV}$ （$\sim 50\ \text{MeV}$） |
| **来源** | 非对易几何中交换子 $[D, \pi]$ 的拓扑缺陷 |
| **置信度** | 低-中 — 质量依赖于非对易标度 $\Lambda_{\text{NC}}$ |
| **当前状态** | 无直接限制；间接搜索（宇宙线、CMB 畸变）未排除此质量窗口 |

| **时间线** | **中期（5-10 年）** — MeV 伽马射线望远镜（e-ASTROGAM）可探测其衰变产物 |

## 4. PMNS 矩阵结构

| 属性 | 内容 |
|:-----|:-----|
| **理论来源** | 本文 (`this work`)；`paperX_pmns_diagonalization.py`；`notes/spectral_PMNS_theta13.md`；`notes/spectral_see_saw_rotation.md` |
| **预言公式** | $U_{\text{PMNS}} = U_e^\dagger U_\nu$，其中 $U_e$（带电轻子基）和 $U_\nu$（中微子质量基）来自谱 See-saw 对角化，旋转角 $\eta_{ij}$ 由收缩因子 $c_i$ 和谱指数 $\alpha_\nu$ 决定 |
| **数值预测** | |
| | $\sin^2\theta_{12} \approx 0.318$ |
| | $\sin^2\theta_{23} \approx 0.563$ |
| | $\sin^2\theta_{13} \approx 0.022$ |
| **置信度** | 中 — 最佳拟合来自 $\eta$ 角扫描。与当前全局拟合值偏差 $\sim 10\%$ 以内 |
| **当前实验状态** | 全局拟合（NuFit 5.2, 2024）：$\sin^2\theta_{12}=0.307\pm0.012$, $\sin^2\theta_{23}=0.573\pm0.025$, $\sin^2\theta_{13}=0.0222\pm0.0007$ |
| **区分性** | SM 不预言混合角；其他 See-saw 实现（如 $SO(10)$ GUT）给出不同相关结构 |
| **时间线** | **近期（1-3 年）** — JUNO（$\theta_{12}$ 到 0.5%）、DUNE（$\theta_{23}$ 八分圆）可检验 |

| 属性 | 内容 |
|:-----|:-----|
| **理论来源** | 本文 (`this work`)；`paperX_pmns_diagonalization.py`；`notes/spectral_neutrino_seeSaw.md` |
| **预言公式** | $m_\nu \sim c^{\alpha_\nu}$，由谱 See-saw 机制 $m_\nu \approx m_D M_R^{-1} m_D^T$ 导出 |
| **质量序** | **正序（Normal Hierarchy）** |
| **数值预测** | |
| | $m_{\nu_1} \sim 0.01\ \text{eV}$ |
| | $m_{\nu_2} \sim 0.04\ \text{eV}$ |
| | $m_{\nu_3} \sim 0.04\ \text{eV}$ |
| | $|m_{ee}| \sim 0.046\ \text{eV}$（无中微子双贝塔衰变有效质量） |
| | $\Delta m_{21}^2 \sim 7.4 \times 10^{-5}\ \text{eV}^2$ |
| | $\Delta m_{31}^2 \sim 2.5 \times 10^{-3}\ \text{eV}^2$ |
| **置信度** | 中 — 质量绝对值依赖于谱指数 $\alpha_\nu$ 和右手中微子标度。标度因子 $\sim 10$ 的不确定性影响 $|m_{ee}|$ 约一个量级 |

| **时间线** | **中期（3-7 年）** — nEXO、LEGEND-1000 可将 $0\nu\beta\beta$ 灵敏度推至 $|m_{ee}| \sim 0.01\ \text{eV}$，覆盖谱预言区间 |

## 6. 强 CP 问题

| 属性 | 内容 |
|:-----|:-----|
| **理论来源** | Paper IX；`paper39_theta_qcd.py`；`notes/spectral_strong_CP.md`；`notes/spectral_axion_silence.md` |
| **预言公式** | $\theta_{\text{QCD}} = 0$（来自谱算符的自伴性要求：$\theta = \arg\det(D) = 0$） |
| **轴子来源** | 辫静默 $S_4$ 的 braid silence 层自发破缺产生类轴子模 |
| **置信度** | 中高 — $\theta = 0$ 是谱自伴性的直接推论。但轴子质量/耦合依赖于 silence 破缺标度 |
| **当前实验状态** | nEDM 上限 $|\theta| < 10^{-10}$（与预言一致）；轴子直接搜索未发现 |
| **区分性** | SM 需要精细调节（$|\theta| < 10^{-10}$）；KSVZ/DFSZ 轴子模型给出不同的耦合常数 |
| **时间线** | **近期（1-5 年）** — n2EDM 实验将灵敏度提升至 $|\theta| < 10^{-11}$；**长期** — 轴子搜索（ALPS II、MADMAX） |

## 7. 引力子传播子 UV 修正

| 属性 | 内容 |
|:-----|:-----|
| **理论来源** | Paper XII §3；`paperX_graviton_propagator.py`；`notes/spectral_graviton.md` |
| **预言公式** | $G(k) \sim \frac{1}{k^2} \left[ 1 + \left(\frac{k}{M_{\text{Pl}}}\right)^\gamma + \cdots \right]$，修正来自谱作用量的高阶项 |
| **指数 $\gamma$** | 由谱维数 $d_H$ 决定：$\gamma = 2 - d_H/2 \approx 0.645$ |
| **置信度** | 中低 — 修正的存在具有理论必然性（谱作用量截断），但指数数值依赖 $d_H$ 的精确值 |
| **当前实验状态** | 不可测 — $M_{\text{Pl}} \sim 10^{19}\ \text{GeV}$ 远超任何加速器能量 |
| **区分性** | 渐近安全引力和弦论给出不同形式的 UV 修正 |
| **时间线** | **长期（30+ 年）** — 不现实。但可通过宇宙学探针间接约束（PGW、CMB B 模偏振） |
