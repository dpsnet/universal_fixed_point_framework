# Direction 2: α 指数第一原理公式

## 核心假设

谱预测各扇区质量比的幂律 $m_i \propto c_i^\alpha$ 中的指数 $\alpha$ 并非自由拟合参数，而是由费米子质量算符的重整化群反常维度的 $\ln\mu$ 积分决定：

$$\boxed{\alpha(R) = \int_{M_Z}^{M_{\text{Pl}}} \gamma_m(R, \mu) \, d(\ln\mu)}$$

其中 $R$ 标记费米子扇区（上型夸克、下型夸克、带电轻子），$\gamma_m$ 是质量算符 $\bar{\psi}\psi$ 的单圈反常维度。

---

## 1. 质量反常维度

### 1.1 单圈公式

质量算符 $\bar{\psi}_L \psi_R$ 的单圈反常维度对规范群的依赖为：

$$\gamma_m(R) = \frac{3C_2(R_3)\alpha_s}{\pi} + \frac{3}{4}\frac{C_2(R_2)\alpha_2}{\pi} + \frac{3}{4}\frac{Y^2\alpha_1}{\pi}$$

其中：
- $C_2(R_3)$ 是 SU(3) 二次 Casimir（基本表示 $= 4/3$）
- $C_2(R_2)$ 是 SU(2) 二次 Casimir（基本表示 $= 3/4$）
- $Y$ 是 U(1) 超荷（$Q = T_3 + Y$ 归一化）
- $\alpha_s, \alpha_2, \alpha_1$ 是跑动规范耦合

### 1.2 费米子表示与 Casimir

对本任务考虑的 Dirac 费米子，质量项耦合左手和右手手性分量，因此完整 $\gamma_m$ 为两个分量的和：

| 扇区 | 左手分量 | $C_2(3)$ | $C_2(2)$ | $Y$ | 右手分量 | $C_2(3)$ | $C_2(2)$ | $Y$ |
|:----|:--------|:--------:|:--------:|:--:|:--------|:--------:|:--------:|:--:|
| 上型夸克 | $Q_L = (3,2)_{1/3}$ | $4/3$ | $3/4$ | $1/3$ | $u_R = (3,1)_{4/3}$ | $4/3$ | $0$ | $4/3$ |
| 下型夸克 | $Q_L = (3,2)_{1/3}$ | $4/3$ | $3/4$ | $1/3$ | $d_R = (3,1)_{-2/3}$ | $4/3$ | $0$ | $-2/3$ |
| 带电轻子 | $L = (1,2)_{-1}$ | $0$ | $3/4$ | $-1$ | $e_R = (1,1)_{-2}$ | $0$ | $0$ | $-2$ |

### 1.3 各扇区 $\gamma_m$ 系数

将两个手性分量的贡献相加：

**上型夸克：**

$$
\begin{aligned}
\gamma_m^u &= [3\cdot\tfrac{4}{3}\cdot\alpha_s/\pi + \tfrac{3}{4}\cdot\tfrac{3}{4}\cdot\alpha_2/\pi + \tfrac{3}{4}\cdot(\tfrac{1}{3})^2\cdot\alpha_1/\pi] \\
&\quad + [3\cdot\tfrac{4}{3}\cdot\alpha_s/\pi + 0 + \tfrac{3}{4}\cdot(\tfrac{4}{3})^2\cdot\alpha_1/\pi] \\[4pt]
&= \frac{8}{\pi}\,\alpha_s + \frac{9}{16\pi}\,\alpha_2 + \frac{17}{12\pi}\,\alpha_1
\end{aligned}
$$

**下型夸克：**

$$
\begin{aligned}
\gamma_m^d &= [3\cdot\tfrac{4}{3}\cdot\alpha_s/\pi + \tfrac{3}{4}\cdot\tfrac{3}{4}\cdot\alpha_2/\pi + \tfrac{3}{4}\cdot(\tfrac{1}{3})^2\cdot\alpha_1/\pi] \\
&\quad + [3\cdot\tfrac{4}{3}\cdot\alpha_s/\pi + 0 + \tfrac{3}{4}\cdot(-\tfrac{2}{3})^2\cdot\alpha_1/\pi] \\[4pt]
&= \frac{8}{\pi}\,\alpha_s + \frac{9}{16\pi}\,\alpha_2 + \frac{5}{12\pi}\,\alpha_1
\end{aligned}
$$

**带电轻子：**

$$
\begin{aligned}
\gamma_m^\ell &= [0 + \tfrac{3}{4}\cdot\tfrac{3}{4}\cdot\alpha_2/\pi + \tfrac{3}{4}\cdot(-1)^2\cdot\alpha_1/\pi] \\
&\quad + [0 + 0 + \tfrac{3}{4}\cdot(-2)^2\cdot\alpha_1/\pi] \\[4pt]
&= 0\cdot\alpha_s + \frac{9}{16\pi}\,\alpha_2 + \frac{15}{4\pi}\,\alpha_1
\end{aligned}
$$

各扇区的 $(c_s, c_2, c_1)$ 系数汇总：

| 扇区 | $c_s = \partial\gamma_m/\partial\alpha_s$ | $c_2 = \partial\gamma_m/\partial\alpha_2$ | $c_1 = \partial\gamma_m/\partial\alpha_1$ |
|:----|:---------------------------------------:|:---------------------------------------:|:---------------------------------------:|
| 上型 (u) | $8/\pi$ | $9/(16\pi)$ | $17/(12\pi)$ |
| 下型 (d) | $8/\pi$ | $9/(16\pi)$ | $5/(12\pi)$ |
| 轻子 (ℓ) | $0$ | $9/(16\pi)$ | $15/(4\pi)$ |

## 2. 规范耦合跑动与积分

### 2.1 单圈跑动

规范耦合的单圈 $\beta$ 函数给出：

$$\alpha_i^{-1}(\mu) = \alpha_i^{-1}(M_Z) - \frac{b_i}{2\pi}\ln\frac{\mu}{M_Z}$$

其中 SM 系数：
- $b_1 = 41/10$（U(1)$_Y$，GUT 归一化）
- $b_2 = -19/6$（SU(2)$_L$）
- $b_3 = -7$（SU(3)$_C$）

### 2.2 解析积分

对 $\int \alpha_i(\mu)\,d(\ln\mu)$ 的解析结果为：

$$
I_i(L_{\max}) \equiv \int_0^{L_{\max}} \frac{dL}{A_i - B_i L}
= -\frac{1}{B_i}\ln\!\left(1 - \frac{B_i L_{\max}}{A_i}\right),\quad
L = \ln\frac{\mu}{M_Z}
$$

其中 $A_i = \alpha_i^{-1}(M_Z)$, $B_i = b_i/(2\pi)$, $L_{\max} = \ln(M_{\text{Pl}}/M_Z)$。

各扇区的总积分为：

$$
\alpha_R = c_s^{(R)} I_3 + c_2^{(R)} I_2 + c_1^{(R)} I_1
$$

## 4. 分析与讨论

### 4.1 预期特征

1. **上型 vs 下型夸克：** 由于 SU(3) 和 SU(2) 贡献相同，仅 U(1) 部分有差异（$17/12$ vs $5/12$），因此 $\alpha_u$ 和 $\alpha_d$ 应接近但 $\alpha_u$ 略大。
2. **轻子 vs 夸克：** 轻子没有 SU(3) 贡献，因此 $\alpha_\ell$ 应显著小于夸克 $\alpha$ 值。
3. **Sector ratios：** 与 U(1) 超荷的平方相关。

### 4.2 关键假设

- 使用 $M_Z$ 到 $M_{\text{Pl}}$ 的标准模型 RG 跑动（假设中间无新物理）
- $\gamma_m$ 的单圈公式足够精确
- 假设积分归一化 $\alpha(R) = \int \gamma_m\,d\ln\mu$ 无需额外系数

### 4.3 偏差分析

实测偏差模式：

| 扇区 | 预测/拟合 | 说明 |
|:----|:--------:|:----|
| 上型夸克 | ×2.44 | 夸克区整体偏高 |
| 下型夸克 | ×3.63 | 夸克区整体偏高 |
| 带电轻子 | ×0.91 | 接近匹配 |

关键发现：**夸克和轻子之间的比例严重偏离**——预测中轻子 α 远小于夸克（0.26 vs 0.70 归一化后），而拟合值中轻子 α 仅略小于上型夸克（0.70 vs 1.00）。这意味着当前 $\gamma_m$ 公式的 SU(3) 贡献权重可能被高估。

可能原因：
1. **SU(3) 系数调整：** 用户公式中 $\gamma_m$ 的 SU(3) 项系数 $3C_2/\pi$ 可能过大。标准文献中 $\gamma_m^{\text{QCD}} = -3C_F\alpha_s/(4\pi)$，而非 $3C_2\alpha_s/\pi$。
2. **超荷归一化（关键）：** 若使用标准 SM 超荷（$Q = T_3 + Y/2$，则 $Y_{\text{SM}} = Y/2$），所有 $\alpha_1$ 项的贡献会缩小 4 倍，可能改变比例结构。
3. **谱框架的 α 定义有额外因子：** $\alpha$ 可能正比于 $\int \gamma\,d\ln\mu / \ln(c_u/c_t)$，其中 $\ln(c_u/c_t)$ 是扇区依赖的——不同扇区的 $c$ 收缩因子不同，导致分母不同。
4. **多圈修正：** 两圈 $\gamma_m$ 对 SU(3) 部分的修正可达 $10\%$
5. **阈值效应：** $M_{\text{Pl}}$ 附近引力对耦合跑动的修正
