# 偏振判别闭合观测申请草案（Phase 104az-20，26.16j-68，2026-10-11）

> 对应 Paper 48 §7.6 第 5 项剩余工作的可执行版本。目标：用一次统一的偏振观测同时闭合 P1（线偏振平台/投影）与 P4（圆偏振手征/统一口径）判别。

## 1. 科学目标

**单一科学问题**：强磁场白矮星（>500 MG）的线偏振（Lp）与圆偏振（V）是否偏离标准物理（Kemp 自由电子 + Zeeman + 场几何）预言？——P1/P4 判别的终极闭合形式：**同星 Lp（横向投影 sin²i）+ V（纵向投影 cos i）+ 倾角 i 联合拟合**。

**★ 理论锚（26.16j-69/-70/-71/-72 更新）**：
- **P4（模型锚定）**：缺口=1 基态（极点）→ 残余 7 态混合净圆偏振 V/I≈14%——PG 1031+234 连续谱峰（12-17%）命中；**P6：高场连续谱峰 V 应 ~12–17%**（统一口径核心判据）
- **P1（修正恢复，26.16j-72）**：赤道缺口模型 → **连续谱峰 Lp ~12.5–14.3%（纯框架预言——与 P4 极点缺口对称）**——PG 1031+234 P~6% 同量级（1/2）；旧 P1 预言 0.73%（后验定标嫌疑）废弃；波长平均 0.6% = 稀释产物（解释项）；**P9：高场连续谱峰 Lp 应 ~6–14%**（与 P6 配对）
- **P7（几何指纹）**：同星 Q/U vs V 比值 = 缺口在 Poincaré 球上的位置（纯极点→P4、纯赤道→P1、混合→椭圆分量比）——PG 1031+234 同星 P~6%+V 12-17% 为几何指纹实例（候选级）

**★ 理论锚追加（26.16j-73~84，2026-10-11）**：
- **缺口窗口 = 高阶 Balmer 线带（26.16j-78）**：Hε 3970 → Hγ 4340 = 370.4 Å ≈ Balmer 带 1/8（364.6 Å，1.016× 命中）——**P9 波段约束：连续谱峰 Lp 在高阶线带波段（3970–4340 Å）测量应最强**（观测窗口需覆盖/加权该波段）
- **段 1 = B_th 梯度（26.16j-79）**：高阶线阈值低（n=7 48.01 / n=6 65.35 / n=5 94.1 MG）→ 磁场上升时缺口窗口从高阶线带累积——**线序缺失判别：Hε/Hδ/Hγ 缺失率应按 B_th 顺序依次触发**
- **线序双链闭合（26.16j-80）**：缺失率 Hβ<Hγ<Hδ 与距缺口窗口中心反单调、与 B_th 反单调、理论禁戒率单调——四链一致——**Hε 预测缺失 ≥84%**（B_th 最低 48 MG + 窗口内）——线序观测可直接检验
- **缺口窗口 = η_comp ≥ 0.8 线带（26.16j-81）**：η_comp 分量 Hα 0.015/Hβ 0.530/Hγ 0.806/Hδ 0.905/Hε 0.945——阈值 0.8 = 1 − N_active·σ（26.16j-82，三重静默扣除候选）——**窗口内线禁戒饱和（→1）对应观测 −98%**
- **双投影统一（26.16j-84）**：V=1/8（偏振计数）↔ 窗口内线禁戒→1（辐射计数）= 1 基态转移双投影——**同一事件在偏振观测（0.61%）与线序观测（−98%）双命中**
- **7/8 守恒判别（26.16j-83）**：46.9% 缺失 = 1/8 转移（连续区 +5.8% 命中）+ 7/8 通道关闭（41.0%）——**全波段光度守恒检验**（7/8 也辐射→总光度不变；关闭→冷却延迟/光度缺失）——观测申请可加全波段光度/冷却曲线项

**判别维度**（26.16j-62/-66/-67/-69/-70 收敛）：
- P1：常数平台 0.725%（含 sin²i 投影）——多星 Lp 平台 vs 场几何投影散布
- P4：Kemp 外推（12–22%）vs 观测（0.4–1.5%）量级异常 + 符号（必要非充分）+ V(λ) 谱形（平坦变号=场几何 vs 结构化=手征）

```
观测得同星 Lp + V + i（每目标）

P1 判别：
  ├─ 多星 Lp（投影修正后）围绕 0.725% 平台 → P1 常数平台成立（判别级）

  ├─ V(λ) 谱形：
  │    ├─ 全场平坦 + 相位回归变号 → 场几何（标准物理）
  │    └─ 结构化（波长特征）且与 B_th 阈值带相关 → 手征候选（P4）
  ├─ V 量级（统一连续谱峰口径）：
  │    ├─ 命中 Kemp 外推（12-22%）→ 无异常（标准物理）
  │    └─ 偏离 Kemp（<5%）+ 非零 → 量级异常（P4 判别维度）

       ├─ pole-on（Lp→0、|V|→max）→ 场几何
       └─ Lp 与 V 均非零且不互补 → 非简单偶极（P4 候选）
```
