## 1 研究起点与路线

本笔记源于 paper44 光子拓扑理论（方向性阶跃、双层正交、可拦截性、螺旋度=手性洛伦兹不变性）的延伸讨论。路线为五步递进：

1. **惯性系检测**（§2）：基于 paper44 理论启示，能否设计"证明自己在惯性系"的方法——结论：只能排除法；
2. **径向流判据**（§3）：径向发散/汇聚流场与惯性系的关系——三要素联合判据；
3. **光子无惯性参考系**（§4）：类光本质，非绝对空间；
4. **X 对象推演**（§5）：与引力、三维空间、光子三重正交对象的身份与特性；
5. **X 的可观测性**（§6–§7）：球状辐射指纹、可观测距离、Cl(1,7) 存在性。

## 2 惯性系检测：paper44 理论启示（排除法）

### 2.1 根本困难

- **所有惯性系等价**（洛伦兹不变性）：匀速直线运动不可检测——不存在"绝对惯性系"参照；
- **等效原理**（爱因斯坦）：局域加速与引力不可区分。

故"证明自己在惯性系"只能是负向检验：检测非惯性系特征信号，测不到即判定"与惯性系一致（到测量精度）"。

### 2.2 主方法：光子手性纯度检验（paper44 独有）

- **理论依据**：paper44 §2.5 螺旋度=手性洛伦兹不变性——无质量粒子螺旋度 $h=\mathbf{J}\cdot\hat{\mathbf{k}}=\pm1$ 是洛伦兹不变量（Weyl $\gamma^5$ 本征值），光子环绕定向 $s=\pm1$ 在惯性系中永不混合；
- **操作**：对已知手性圆偏振光（如 $\sigma^+$），沿传播路径多次测量螺旋度纯度；
- **判断**：惯性系中 $s=\pm1$ 严格保持（纯度=1）；非惯性系（加速/转动）中光子场经 Bogoliubov 变换（Unruh 效应）发生**手性混合**，纯度下降。

### 2.3 辅助判据

- **判据 A（全域光速一致性）**：定理 3.1 的 $c$ 是纤维粘合拓扑同胚不变量；**局域**单程光速不变在惯性/非惯性系均成立（无判别力），**全域**往返/各向光速一致仅在惯性平直坐标成立——旋转系有 Sagnac 效应 $\Delta t=4\Omega A/c^2$；
- **判据 B（零偏折测地线）**：推论 2.1 时间解耦 ⟹ 自由光子沿测地线；非惯性系中坐标偏折/假力可检出。

### 2.4 诚实边界

- 三判据均为排除法，不能正面证明"绝对惯性系"；
- 判据 B 无法区分"加速 vs 引力"（等效原理）；
- 手性纯度检验门槛：Unruh 温度 $T=a\hbar/2\pi ck$，$a\sim g$ 时约 $10^{-20}$ K——远期方案（与 paper44 P1–P6 的 15–20 年观测门槛同类）。

## 3 径向发散/汇聚流的非惯性判据（三要素联合）

### 3.1 原始主张与反例

**原始主张**：径向发散/汇聚（球心→球面 / 球面→球心）+ 非引力 ⟹ 非惯性。

**反例（爆炸自相似流）**：一次性抛出的无碰撞粒子族，每粒子匀速直线（$a=0$），速度场 $\mathbf{v}=\mathbf{r}/t$：净通量 $\oint_S\mathbf{v}\cdot d\mathbf{A}=4\pi r^3/t\neq0$、$\nabla\cdot\mathbf{v}=3/t\neq0$，但静止于原点的观测者是**惯性系**——径向发散只是冻结初始条件。**散度/通量非零不构成非惯性判据**。

### 3.2 修正判据（三要素）

| 层级 | 判据 | 非惯性 ⟺ |
|:--|:--|:--|
| ① 粒子动力学 | 自由粒子速度恒定（$a=0$，匀速直线） | 持续 $a\neq0$（径向加速度），无引力解释 |
| ② 观测者状态 | 观测者自身加速度 $a_{\text{obs}}=0$ | $a_{\text{obs}}\neq0$（Rindler/旋转） |
| ③ 场形状 | 净通量/散度 | **不单独成立**（爆炸流反例） |

### 3.3 类光筛选

若"观测到粒子速度无论如何运动都不变"：有限质量粒子不可能（速度合成必随观测者变），自动筛选出**类光粒子**（$v=c$，定理 3.1）。此特征是洛伦兹不变性之内的不变量（见 §4）。

## 4 光子无惯性参考系（类光本质，非绝对空间）

- **光子本身就不是惯性系**：狭义相对论禁止 $v=c$ 参考系——光子不拥有任何惯性参考系（推论 2.1 诚实边界），此属性**普适成立、与引力无关**；
- **两种"观测不变"分属不同层次**：
  - 光速 $c$ 观测不变 = **洛伦兹不变性**（相对性之内的不变量）；
  - 假力（旋转/加速）观测不变 = **绝对量**（突破相对性的绝对信号）；
  - 光速不变是相对性原理成立的证据，**不是绝对空间信号**（水桶实验范式解读废弃，见 §8）；
- **推论**：光子不能作为惯性系检测的载体——"以光子视角判定惯性"从一开始无效；判据必须由有限质量观测者构建。

## 5 X 对象推演：三重正交自由度的身份

### 5.1 定义与推演修正

**定义（X）**：与引力 Δ（Sp 水平 2-态射方向）、三维空间（基空间）、光子（法向 $n_1$）三重正交的对象。

- **修正 1（独立法向自由度）**：早期推演"X ⊥三维空间 + ⊥光子 ⟹ X = 时间方向"是**纤维一维假设**的误判。设底空间 $M^4=M^3\times\mathbb{R}$，纤维空间（法向拓扑自由度空间）维数 $r\ge2$：X 可为独立法向 $n_2$（$n_2\perp n_1$），任何法向 ⊥ 底空间整体 ⟹ 自动同时 ⊥ 时间、⊥ 三维空间；
- **修正 2（正交 ≠ 不可见）**：光子 ⊥ 三维空间但**可拦截可见**（共振，命题 2.2——与 KK 纯几何额外维度的本质区分）。**可观测性由耦合通道决定，不由方向正交性决定**。X 的"⊥光子"只关闭电磁通道，不关闭一切通道。

### 5.2 X 的球状辐射指纹（累积约束）

1. **球状辐射/逆球状辐射**（径向发散/汇聚，各向同性无方向指向）；
2. **速度处处相同**（波速均匀——"强度处处相同"约束已废弃，允许强度梯度）；
3. **无潮汐**（非引力——潮汐判别：引力场 $|\mathbf{F}|\propto1/r^2$ 有梯度，均匀惯性力场无梯度）；
4. **可被物质共振吸收**（启用 paper44 可拦截性机制）。

### 5.3 完整数学描述

**传播**（速度处处相同，3D 波动方程球面波解）：

$$\varphi(r,t)=\frac{f(r-v_0 t)}{r}+\frac{g(r+v_0 t)}{r},\qquad \frac{1}{v_0^2}\partial_t^2\varphi-\nabla^2\varphi=0.$$

**共振吸收**（命题 2.3 双门 + 定义 2.4 吸收截面）：

$$h\nu_{\text{X}}=\Delta E_{\text{atom}}\ \wedge\ \Delta m=J_z^{\text{X}},\qquad \sigma_{\text{abs}}^{\text{X}}(\nu)=\frac{h\nu}{c}B_{12}^{\text{X}}\,g(\nu).$$

**澄清**：X ⊥ 引力 = 方向结构正交（范畴层，同光子），**不排除** X 波携带能量、可被吸收——光子 ⊥ 引力但有能量（被引力红移）即为先例。

### 5.4 结论：X = 隐光子类可拦截玻色子

X 与光子结构同构（可拦截法向自由度）、方向正交（不同规范方向）——是"光子的正交兄弟"。可判别点：$B_{12}^{\text{X}}$ 选择定则/耦合强度 $\alpha_X$ 与光子不同 ⟹ 共振条件不同 ⟹ 可判别。物理对应：隐光子（dark/hidden photon，ε 混合）、Z'/Z/W 玻色子。

## 7 X 在 Cl(1,7) 中的存在性（框架内分析）

### 7.1 代数基础

- Cl(1,7) ≅ M₁₆(ℝ)，256 维代数空间；8 个生成元 Γ₀,…,Γ₇ 的代数结构（paper32 §6，谱静默作用于生成元的谱而非坐标轴）；
- Cl(1,7) 根系编码标准模型规范群 SU(3)_C × SU(2)_L × U(1)_Y（paper11 L73）；耦合谱间隙比由根系权重决定（dim=32 截断给出 α⁻¹≈128，<0.1%）；
- 对称破缺链：SU(4) → SU(3)×U(1) 经 S₃/S₄ 静默筛选 → 4D 投影（paper32 §5.1）；
- 力程谱解释：U(1)_EM 投影保留度 ~1（长程）、SU(2) ~S₄（短程）、SU(3) ~e⁻³（禁闭）（paper32 §5.2）。

### 7.2 存在性判定

**数学存在性：无代数障碍**——M₁₆(ℝ) 代数空间充裕（so(8) 28 维 ≫ SM 12 维），X 作为与 U(1)_EM 正交的独立生成元方向有位置。

**框架内约束（未闭合）**：

| 条件 | 状态 |
|:--|:--|
| Cl(1,7) 根系有**空闲**规范方向（未被 SM 占满） | **未验证**——SU(4) 链秩 3（T₃、T₈、Y）恰好填满 Cartan 子代数，X 的 U(1)' 需超出现有根系的新方向 |
| X 的耦合/质量由 Cl(1,7) 谱静默**无参数**固定 | **未建立**——标准模型中 (m_X, ε²) 是自由参数；与框架"零自由参数"立场冲突 |
| X 的力程由谱静默投影决定 | **可推演**——投影保留度 ~1（超荷型）⟹ 长程；~S₄（弱型）⟹ 短程有质量；二选一，无参数化自由度（可证伪特征） |

### 7.3 开放问题推进（2026-08-11）

**问题 1（可容纳性）——部分闭合**：

- **数学结构**：Cl(1,7) ≅ M₁₆(ℝ) 的最大紧致子代数 so(16)（120 维、秩 8）≫ SM（12 维、秩 4）——**4 个空闲 Cartan 方向**，X 的 U(1)' 纯代数可容纳；
- **学术先例**：SO(10) GUT 中 U(1)₍B-L₎ 即"SM 之外额外 U(1)"的标准候选；嵌入链 so(16) ⊃ so(10) ⊃ SU(3)×SU(2)×U(1) 给出 **X = U(1)₍B-L₎ 的天然身份**；
- **判定点**：paper32 破缺链 SU(4)→SU(3)×U(1) 仅秩 3，而完整 SM 秩 4（含 SU(2)_L）——**框架内 SU(2)_L 的来源未明确**；若 SM 嵌入允许 so(16) 层级，X 可容纳；若规范群锁死 SU(4) 秩 3 链则不可容纳。

**问题 2（无参数耦合决定）——推进但未闭合**：

- **机制路线（两条）**：
  - ① 谱间隙路线（paper11）：α_X = Δλ_min^(X')/(4πC_X)——耦合 = 谱间隙，谱间隙由根系权重归一化决定（已有 1/√3:1:√2 先例）；
  - ② 静默投影路线（paper32）：力程 ∝ 静默投影保留度（U(1)~1、SU(2)~S₄、SU(3)~e⁻³）。
- **B-L 候选**：若 X = U(1)₍B-L₎，其谱间隙 Δλ_min^(B-L) 可由 so(16) 根系权重计算（1/√3:1:√2 序列的扩展），耦合原则上无自由参数；
- **硬障碍（三条）**：
  1. paper32 §4.4 诚实标注："各 Clifford 方向的谱权重恰好是 c₁/c₂/c₃ 这一映射仍是框架的建模指派"——力程的"无参数"表述依赖此指派，非独立推导；
  2. paper11 谱 RGE 的 Z 因子（Z₁=2.13 等）含 ~17% 实验反演锚定（SM β 跑动 ~83% + 实验 α(M_Z) 锚定 ~17%）——严格"无参数"未被证实；
  3. GUT 归一化 C_X 未定（U(1)_Y 用 C_GUT=3/5）。
- **可证伪特征**：若 X = B-L 且投影保留度 ~1（超荷型干净）⟹ 无质量长程 ⟹ 与实验严格约束 ε_B-L ≲ 10⁻²⁴（库仑定律修正/恒星能量损失）对照——这是可检验的判决点。
