**悖论消解**：光子始终是单一开放拓扑对象，不存在"波粒二象性"切换，更无需超光速或 retrocausality。

### 2.4 电场与磁场正交性的拓扑起源

**核心机制**：环绕轴闭合的几何结构天然分解为两个正交分量：

| 分量 | 几何角色 | 场对应 | 物理意义 |
|------|----------|--------|----------|
| **径向振荡** | 形变沿法向平面的径向（离轴/向轴） | 电场 $\mathbf{E}$ | 电荷受力方向 |
| **切向环绕** | 形变沿法向平面的切向（绕轴旋转） | 磁场 $\mathbf{B}$ | 电流受力方向 |

**关键推论**：$\mathbf{E} \perp \mathbf{B} \perp \mathbf{k}$ 是环绕轴闭合几何结构的直接推论，而非额外的物理约束。

## 三、偏振态的拓扑诠释

### 3.1 圆偏振 = 螺旋形变循环

- **右旋圆偏振**（$s = +1$）：切向环绕方向与传播方向满足右手定则，径向振荡与切向环绕形成**螺旋结构**
- **左旋圆偏振**（$s = -1$）：切向环绕方向反转，螺旋结构镜像

在螺旋结构中，$\mathbf{E}$ 和 $\mathbf{B}$ 的相位差恰好为 $\pi/2$，形成旋转的场矢量。

### 3.2 线偏振 = 平面形变循环

- **线偏振**：切向环绕分量被"锁定"在固定方向，形变循环退化为**平面振荡**
- 此时 $\mathbf{E}$ 和 $\mathbf{B}$ 同相位（相位差为 0 或 $\pi$）
