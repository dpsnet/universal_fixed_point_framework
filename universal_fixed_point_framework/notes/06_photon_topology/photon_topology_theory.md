## §1 拓扑空间定义与公理

### 1.1 两类电磁拓扑空间

**定义 1.1**（紧致驻波拓扑）：原子束缚态电磁场对应紧致闭合拓扑空间 $(M_{\text{atom}}, \partial M_{\text{atom}}, g_{\text{atom}})$，其中：
- $M_{\text{atom}}$：原子势场约束的有界 3-流形
- $\partial M_{\text{atom}} \neq \emptyset$：拓扑边界（原子核库仑势与电子关联形成的有效边界势垒），电磁形变不可逾越
- $g_{\text{atom}}$：诱导度量，使电磁场形成驻波（闭合拓扑形变循环）

对应 UFPF **Rec 递归范畴**对象：驻波拓扑是 Rec 范畴中的紧致对象，向外传播通道处于 S3 谱静默。

#### 类比：内外翻转的法拉第笼

紧致驻波拓扑的边界效应与法拉第笼**拓扑等价、方向相反、物理机制不同**：

| 特征 | 标准法拉第笼（外向屏蔽） | 紧致驻波拓扑（内向屏蔽，内外翻转法拉第笼） |
|:-----|:----------------------|:----------------------------------------|
| **场的初始位置** | 外部电磁场入射 | 内部电磁能量已存储（闭合驻波） |
| **边界物理机制** | 导体表面**自由电子感应电流**（宏观经典效应）：外场驱动自由电荷重新排布，感应场抵消入射场 | **原子核库仑势阱**（微观量子效应）：束缚电子波函数的有效边界势垒，无自由电荷感应 |
| **边界作用** | 外场不入（外向屏蔽）：阻止外部电磁场进入笼内 | 内场不出（内向屏蔽）：阻止内部电磁形变向外传播 |
| **内部状态** | 内部场显著衰减（理想导体时 $E=0$，实际取决于结构/频率/趋肤深度） | 驻波（闭合拓扑形变循环），场被边界束缚在有限区域 |
| **场泄漏条件** | 笼体破损（裂缝尺寸 ~ λ）、工作频率高于截止频率 → 连续泄漏 | 能级跃迁（拓扑分岔）→ 离散整体逃逸（以 $h\nu$ 为单位整体释放，无"部分泄漏"过渡态） |
| **拓扑本质** | 边界的**连续几何破损**（破损程度连续可调，泄漏量连续变化） | 边界的**离散拓扑相变**（边界拓扑类整体改变，全有或全无） |
| **对应 UFPF 机制** | — | S3 谱静默屏障（内向型） |

**关键区分（诚实边界）**：法拉第笼的"外向屏蔽"与紧致驻波拓扑的"内向屏蔽"仅在**拓扑边界的约束效果层面**构成类比，二者的物理机制完全不同——前者是宏观导体的自由电子感应（经典电动力学），后者是微观原子的库仑势束缚（量子力学）。不可将类比延伸至物理机制。

### 1.1.1 拓扑分岔的能量泄漏机制（基于法拉第笼类比深化）

**命题 1.1**（拓扑分岔能量泄漏机制）：能级跃迁时，边界 $\partial M_{\text{atom}}$ 的拓扑完整性被打破，发生**离散拓扑相变**（而非连续破损），导致 S3 谱静默屏障被解除，存储在闭合驻波中的电磁能量以光子为单位**整体逃逸**。

具体过程分解为四步：

**Step 1：边界拓扑类切换**
- 初态：边界 $\partial M_{\text{atom}}$ 属于"封闭拓扑类"——即 $\partial M$ 与内部 $M$ 的相对同调群 $H_k(M, \partial M)$ 满足驻波条件，向外传播的谱模态在同调层被阻（S3 静默）。
- 扰动触发：入射光子（受激辐射）或真空涨落（自发辐射）扰动边界拓扑结构，使边界从"封闭拓扑类"离散跳变到"开放拓扑类"。
- 关键：这是**离散相变**，不存在"半开半闭"的中间拓扑等价类——边界要么封闭（静默屏障存在），要么开放（静默屏障解除），对应量子跃迁的无中间态性质。

**Step 2：S3 静默破缺 → D 谱化函子激活**
- 封闭拓扑类下：$D$ 谱化函子作用于 Rec 紧致对象，像集中在 S3 静默层，传播谱模态系数为 0。
- 开放拓扑类下：S3 静默屏障被解除，$D$ 谱化函子的传播模态像被"解锁"，Rec 对象的谱组分被映射为 Sp 传播对象。

**Step 3：能量重分配的拓扑约束**
- 总能量守恒（公理 A3）：跃迁前后系统总能量不变。
- 拓扑层面：闭合一整套驻波形变循环**被"切割"**为两套子循环——跃迁后电子新能级的低能驻波形变循环（仍属 Rec 紧致对象）+ 光子的完整行波形变循环（Sp 传播对象）。
- 关键约束：行波形变循环必须是**完整单元**（对应 $E = h\nu$ 的量子化），不存在"半套循环"的拓扑稳定等价类。这解释了为什么辐射能量以 $h\nu$ 为整体单位，而非连续泄漏。

**Step 4：新生光子拓扑的诞生即光速**
- 方向属性：该分岔方向为**法向自由度**——Rec→Sp 纵向跳变 ⊥ 引力 Δ（水平偏差）、⊥ 物理三维空间（基空间方向），新生行波拓扑即正交于引力与三维空间的法向拓扑（公理 A1 方向属性，详见 §1.2.1、§1.2.2）。
- 行波拓扑 $(M_{\text{photon}}, \emptyset)$ 的传播速度由全域时空-电磁纤维粘合拓扑唯一确定（定理 2.1，光速不变拓扑定理）。
- 光子拓扑一旦从分岔点脱离源拓扑，就不再受原驻波边界约束，其传播标度完全由全域 $c$ 锁定——不存在"从 0 加速到 c"的连续过程，因为低速行波拓扑无稳定等价类（命题 2.2，零静质量 $v < c$ 不自洽）。

**经典笼破损 vs 拓扑分岔泄漏的本质差异总结**：

| 维度 | 法拉第笼破损（经典连续泄漏） | 原子拓扑分岔（量子整体逃逸） |
|:-----|:--------------------------|:--------------------------|
| 泄漏单位 | 连续：能量随时间连续耗散（$dE/dt$ 连续函数） | 离散：能量以 $h\nu$ 为单位整体释放（全有或全无） |
| 边界变化 | 连续几何破损：裂缝尺寸从 0 → λ（连续可调） | 离散拓扑相变：边界拓扑类整体跳变（无中间态） |
| 泄漏速率 | 取决于破损程度：裂缝越大泄漏越快 | 取决于跃迁概率：受激辐射 $\propto$ 入射光强，自发辐射 $\propto A_{ij}$ 爱因斯坦系数 |
| 频谱特征 | 连续谱：泄漏能量分布在宽频范围 | 线谱：单光子 $E = h\nu$，对应能级差精确值 |
| 方向特征 | 无拓扑方向：经典电磁场在三维空间内传播，无法向自由度 | 法向：分岔方向为法向自由度，⊥ 引力 Δ、⊥ 三维空间（公理 A1，详见 §1.2.1、§1.2.2） |
| 可逆性 | 可逆：修补裂缝即可恢复屏蔽 | 不可逆（单向）：分岔后须通过吸收过程（$R$ 右伴随映射）才能重构驻波拓扑 |

**定义 1.2**（开放行波拓扑）：光子对应无界开放拓扑空间 $(M_{\text{photon}}, \emptyset, g_{\text{photon}})$，其中：
- $M_{\text{photon}}$：沿类光测地线延展的无界 3-流形
- $\partial M_{\text{photon}} = \emptyset$：无拓扑边界，形变可自由传播
- $g_{\text{photon}}$：使电磁场形成行波（开放拓扑形变循环）

对应 UFPF **Sp 谱范畴**对象：行波拓扑是 Sp 范畴中的传播对象。

### 1.1.2 光子的自旋与横向偏振结构（拓扑重述）

**拓扑表述 1.2.1**（自旋 = 形变循环的手性自由度）：光子开放行波拓扑的形变循环携带内部旋转自由度——圆偏振对应螺旋形变循环（沿传播方向旋转），线偏振对应平面形变循环（沿固定方向振荡）；两种手性（自旋 $s = \pm 1$）对应形变循环的两个定向（orientation）拓扑类。无螺旋度 0 模（无纵向分量）是零静质量分支的拓扑结果（命题 2.2：$v < c$ 不自洽 → 无低速过渡拓扑 → 无纵向传播模式）。

**拓扑表述 1.2.2**（E⊥B⊥k 横向传播条件）：平面波解中电场 $\mathbf{E}$、磁场 $\mathbf{B}$ 与传播方向 $\mathbf{k}$ 两两正交（右手系），对应电磁形变循环在基空间中的横向传播结构——形变循环仅在垂直传播方向的平面内振荡，无沿传播方向的纵向分量。这与命题 2.2（零静质量强制 $v = c$）自洽：**横向性 = 零静质量拓扑分支的传播结构约束**。

**拓扑表述 1.2.3**（纵向模式为场截面/集体层涌现性质）：单个光子行波拓扑的形变循环严格横向（拓扑表述 1.2.2，零静质量约束），不携带纵向自由度；电磁场的纵向分量属于**场截面（多光子/场态）层级的涌现性质**，仅在两类情形出现：（i）真空中非平面波叠加——不同 $\mathbf{k}$ 方向的平面波角谱叠加使横向性约束 $\mathbf{E}\cdot\mathbf{k}=0$ 无法逐分量保持，紧聚焦光束在束腰处出现纵向场分量（已知聚焦光学结果）；（ii）介质中光子获得有效质量（等离子体频率 $\omega_p$），纵向集体模被激活——等离子体振荡（Langmuir 波），对应 Proca 质量项引入第三偏振的机制。

**诚实边界**：真空自由电磁场严格无纵向物理自由度（规范场论，Gupta-Bleuler 量子化中纵向模为非物理鬼态）；本节为已知物理（聚焦光束纵向分量、等离子体集体模）的拓扑重述，不构成新预言；"纵向性属于截面层"是框架语言的组织表述，非可独立检验的新效应。

**与预言 6.1 的衔接**：圆偏振/线偏振对应不同手性形变循环，4-范畴偏差 Δ 对二者不等拉伸 → 引力 Δ-偏振红移差（§6.1）。

**诚实边界**：光子自旋 $s = 1$（两种螺旋度，无螺旋度 0 模）与 E⊥B⊥k 均为经典/量子电动力学已确立事实，本节为已知物理的拓扑重述（温和兼容），不构成新预言；其价值在于为预言 6.1（偏振红移差）提供自旋/偏振的拓扑结构基础，并保持与"零静质量 → 无纵向自由度"的自洽。

### 1.2 拓扑分岔公理

**公理 A1**（拓扑分岔）：能级跃迁对应离散拓扑分岔——存在分岔映射
$$\Phi: (M_{\text{atom}}, \partial M_{\text{atom}}) \to (M_{\text{photon}}, \emptyset)$$
将紧致闭合拓扑解离为无界开放拓扑。该映射对应 UFPF 的 $D$ 谱化函子（Rec → Sp）。**方向属性**：分岔方向为**法向自由度**——Rec→Sp 纵向跳变 ⊥ 引力范畴偏差 Δ（Sp 水平 2-态射方向）⊥ 物理三维空间（基空间方向），即光子拓扑是正交于引力方向与三维空间的法向拓扑（双层正交，详见 §1.2.1、§1.2.2）。

**公理 A2**（离散性）：分岔映射 $\Phi$ 是离散的——不存在介于 $(M_{\text{atom}}, \partial M)$ 和 $(M_{\text{photon}}, \emptyset)$ 之间的连续中间拓扑。这对应量子能级的分立性。

**公理 A3**（能量守恒）：分岔前后总能量不变——跃迁前全部电磁能量存储在闭合驻波拓扑中，分岔后能量重分配为电子低能驻波 + 光子行波，总和不变。

**公理 A4**（方向性阶跃）：设 $t_*$ 为分岔时刻，$\Theta$ 为 Heaviside 阶跃函数，定义拓扑类指标 $\chi_\Phi(t) = \Theta(t - t_*)$ 与静默指标 $\sigma_{\text{S3}}(t) = 1 - \chi_\Phi(t)$，其中 $\chi_\Phi = 0$（$t < t_*$）对应封闭拓扑类（S3 静默，驻波），$\chi_\Phi = 1$（$t \ge t_*$）对应开放拓扑类（S3 解除，行波）。此公式同时编码**过程性**与**方向性**：
- **过程性**（与公理 A2 一致）：$\lim_{t \uparrow t_*} \mathcal{M}(t) = (M_{\text{atom}}, \partial M)$，$\lim_{t \downarrow t_*} \mathcal{M}(t) = (M_{\text{photon}}, \emptyset)$——转变在 $t_*$ 处瞬间完成，无连续中间拓扑；
- **方向性**：$\sigma_{\text{S3}}$ 只能自发地 $1 \to 0$（静默解除、行波释放）；反向 $0 \to 1$（静默恢复）不能自发发生，必须由外部 $R$ 右伴随折叠（物质吸收，定义 1.3）驱动——分岔在自发动力学下**不可逆**。

**诚实边界**：$t_*$ 与 $\chi_\Phi$ 是抽象叙事参数化——具体分岔时刻由量子跃迁概率（爱因斯坦系数）决定，本公理仅编码"离散阶跃 + 单向不可逆"的抽象结构，不预言 $t_*$ 数值；记号 $\mathcal{M}(t)$ 表示 $t$ 时刻系统所属的拓扑等价类，非时间连续拓扑路径。

### 1.2.1 光子方向与引力方向的正交性：法向拓扑 vs 水平偏差

**直觉来源**：从离散方向看，光子拓扑分岔与引力范畴偏差 Δ 的演化方向"相反"，光子方向很像是正交于三维空间的法向拓扑。

**形式化修正**：
- **"相反"→"正交"**：光子方向与引力方向不在同一方向上的反向，而是分属两个**几何正交**的拓扑方向（详见下文命题 1.2）。
- **"正交于三维空间"→ 确认（双层正交）**：光子方向的正交性同时体现在两个层面——
  1. **范畴层**（§1.2.1）：光子拓扑分岔（Rec→Sp 纵向跳变）⊥ 引力 Δ（Sp 4-范畴水平 2-态射偏差）；
  2. **纤维丛层**（§1.2.2）：光子拓扑分岔（纤维方向拓扑类跳变）⊥ 物理三维空间（基空间方向）。
  两个层面正交指向一致，共同构成"光子 = 正交于三维空间的法向拓扑"的完整图像。

**命题 1.2**（光子-引力方向正交性）：在 UFPF 的 Rec/Sp 伴随 + 4-范畴结构中，光子拓扑分岔方向与引力范畴偏差 Δ 方向构成几何正交关系：

```
                    Rec 范畴（紧致对象层）
                         ↕ D 函子（纵向，法向）← 光子拓扑分岔方向
                    Sp 范畴（传播对象层）
                         ├── 1-态射方向 ──→
                         ├── 2-态射方向 ↗  ← 引力 Δ 出现方向（水平）
                         ├── 3-态射方向 ↘
                         └── 4-态射方向 ←↗
```

| 方向 | 几何位置 | 物理现象 | UFPF 数学结构 |
|:-----|:--------|:--------|:------------|
| **水平方向**（引力 Δ） | Sp 4-范畴**内部** 2-态射复合方向 | 引力作为范畴复合偏差 | $\Delta = \text{fail}(\gamma_2 \circ \gamma_1 = \gamma_1' \circ \gamma_2')$，水平面内的结构残余 |
| **法向方向**（光子） | Rec → Sp **跨范畴层级**跳变 | 光子拓扑分岔 | $D: \text{Rec} \to \text{Sp}$，纵向跨层映射 |

**关键几何图像**：
- 引力 Δ = Sp 范畴**水平面内**的 2-态射复合不交换残余（基空间方向的几何畸变）
- 光子 = Rec → Sp 的**纵向跳变**（纤维方向的拓扑类切换）
- 二者在 4-范畴几何中分属正交方向，不可相互约化

**用纤维丛语言的精确表述**：

在 UFPF 的 Grothendieck 谱纤维丛 $\pi: E \to B$ 中：
- 基空间 $B$（代表时空流形）：引力 Δ 是 $B$ 内部的几何畸变（水平方向）
- 纤维 $F_b = \pi^{-1}(b)$（代表电磁场拓扑）：光子拓扑分岔是 $F_b$ 内拓扑类的跳变（法向/纤维方向）
- 粘合函子 $\mathcal{G}: B \times F \to E$ 锁定 $c$（光速不变拓扑定理 §2）

**物理推论**：
1. **光速 $c$ 与引力常数 $G$ 的独立性**：$c$ 属于纤维方向（光子拓扑），$G$ 属于基空间方向（引力 Δ），二者分属正交几何方向，不可相互约化。
2. **$h$-$c$-$\Delta$ 三常数约束的几何分工**（§6.3 预言 6.3）：
   - $h$：纤维方向的形变能量量子（法向）
   - $c$：纤维-基空间粘合的传播标度（法向-水平耦合）
   - $\Delta$：基空间方向的范畴偏差（水平）
   - 三常数约束来自粘合函子 $\mathcal{G}$ 的自洽性，但 $h$ 主要锚定法向，$\Delta$ 主要锚定水平，$c$ 是二者的耦合点。
3. **引力红移 vs 多普勒红移的方向区分**（§5.2）：
   - 引力红移：基空间方向（水平）的 Δ 拉伸 → 影响承载光子的基底几何
   - 多普勒红移：光源-观测者在基空间内的相对运动（水平面内）→ 压缩/拉伸拓扑褶皱序列
   - 二者都是水平方向效应，但作用于不同层级（基底几何 vs 褶皱序列）
4. **光子视角中的时间解耦（递归静止）**：正交性（纤维方向 ⊥ 基空间方向）意味着光子时间标度（纤维内形变循环周期 $T = 1/\nu$）与递归层时间演化（基空间方向）分属正交几何方向，**无相互投影**。结合粘合函子对 $c$ 的锁定（定理 2.1）与相对论固有时极限（$\gamma = 1/\sqrt{1-v^2/c^2} \to \infty$，$d\tau = dt/\gamma \to 0$），在形式极限意义下：光子与递归层仅在**分岔瞬间**（$\Phi$，$h\nu = \Delta E$）与**吸收瞬间**（$R$ 折叠）发生时间耦合，传播途中**零时间耦合**——对应"光子传播途中无相互作用、观测仅发生在吸收/散射时刻"的物理事实。

**推论 4 的诚实边界**：
- 光子不存在惯性参考系（相对论禁止 $v = c$ 参考系），"光子视角"是 $\gamma \to \infty$ 的形式极限，非物理参考系——"递归静止"是极限意义直觉，不构成严格物理命题；
- 正交性本身不直接推出时间静止，充分链条为"方向解耦（正交性）+ 光速锁定（粘合函子 $\mathcal{G}$）+ 固有时极限（相对论）"三重条件；
- "静止"指**时间演化解耦**，非空间静止——光子仍沿基空间以 $c$ 传播，与递归层的空间重合由相遇条件（§1.2.2）决定。

**正交性的第二层面**（纤维丛层）：光子方向不仅与引力 Δ 正交（范畴层），也与物理三维空间正交（纤维方向 vs 基空间方向）——且这个法向自由度**可被物质拦截**。详见 §1.2.2。

### 1.2.2 光子拓扑与物理三维空间的正交性：可交互的法向自由度

**直觉来源**：本节的推论**源于 §1.2.1 与引力 Δ 的对比**——光子方向与引力方向分属正交拓扑方向（Rec→Sp 纵向跳变 ⊥ Sp 水平 2-态射偏差），引力方向是水平（基空间内部）的，对比之下光子方向即"法向"。将该法向落实为纤维丛几何，则光子拓扑与物理三维空间（基空间）正交，且这个法向自由度**可以被拦截**（被物质捕获吸收）——这是与 KK 纯几何法向自由度的本质区分（命题 1.3）。

**形式化确认**：在纤维丛结构 $\pi: E \to B$ 中，基空间 $B$ = 物理三维空间（+时间），纤维 $F_b$ = 电磁场拓扑，光子拓扑分岔是纤维方向的拓扑类跳变——在纤维丛几何中**确实正交于基空间**。此前的"法向仅相对于 Sp 4-范畴水平态射空间"表述**过度保守**，纤维丛层面可修正为：光子拓扑是物理三维空间（基空间）的法向自由度。

**命题 1.3**（可交互的法向自由度）：光子拓扑是垂直于物理三维空间的法向（纤维方向）自由度，但与 KK 额外维度等纯几何法向自由度不同，它是**可以被物质拦截的**。

**可拦截性 = 与 KK 额外维度的本质区分**：

| 法向自由度 | 可拦截性 | 物理机制 | 能量载体 |
|:-----------|:--------|:--------|:--------|
| KK 额外维度（紧致化） | ❌ 不可拦截 | 纯几何额外空间，物质拓扑无法"抓住" | 无独立能量载体（无传播子、无谱流） |
| **光子拓扑（纤维自由度）** | ✅ **可拦截** | 法向形变循环携带能量与传播标度，可被物质拓扑捕获折叠 | $E = h\nu$（法向形变循环能量量子）+ $c$（传播标度） |

**可拦截性的机制 = $R$ 右伴随映射（吸收/折叠）**：

**定义 1.3**（$R$ 右伴随折叠函子）：设 $D \dashv R$ 为伴随对，其中 $D: \text{Rec} \to \text{Sp}$ 是谱化函子（拓扑分岔），$R: \text{Sp} \to \text{Rec}$ 是其右伴随（吸收/折叠函子），满足自然同构：
$$\text{Hom}_{\text{Sp}}(D(A), B) \cong \text{Hom}_{\text{Rec}}(A, R(B)), \quad \forall A \in \text{Rec},\; B \in \text{Sp}$$

$R$ 在拓扑对象上的作用：$R(M_{\text{photon}}, \emptyset) = (M'_{\text{atom}}, \partial M'_{\text{atom}})$，其中 $M'_{\text{atom}}$ 为激发态原子拓扑（含 $R$ 折叠后的形变循环）。

**命题 1.4**（拦截的必要条件：频率匹配/Bohr 条件）：光子被物质拦截（$R$ 折叠可发生）的必要条件是光子形变循环频率 $\nu$ 与物质拓扑的能级差匹配：
$$h\nu_{\text{photon}} = E_j - E_i = \Delta E_{\text{atom}}$$

其中 $E_i, E_j$ 为原子初末能级。拓扑表述：光子的法向形变循环能量量子 $h\nu$ 必须恰好等于物质拓扑激发所吸收的能量量子——这是 $R$ 折叠的**共振条件**，也是为什么"拦截"是离散、选择性（线谱）而非连续、普适的。

**定义 1.4**（拦截概率/吸收截面）：满足命题 1.4 时，光子被拦截的概率由吸收截面描述：
$$\sigma_{\text{abs}}(\nu) = \frac{h\nu}{c}\, B_{12}\, g(\nu)$$

其中 $B_{12}$ 为爱因斯坦吸收系数，$g(\nu)$ 为线型函数。拓扑表述：拦截概率 = $R$ 折叠的跃迁概率振幅；$B_{12}$ 刻画 $R$ 折叠的强度，$g(\nu)$ 刻画共振偏离的容忍度。

**可拦截性的完整机制（三阶段，含数学约束）**：

1. **传播期**：光子作为开放行波拓扑沿基空间（三维空间）传播，携带法向形变循环能量 $E = h\nu = h/T$（$T = 1/\nu$ 为形变循环时间周期）——法向自由度 → 基空间可观测量的耦合通道。

2. **相遇期（几何重合）**：光子拓扑与物质拓扑在基空间相遇（时空重合 $\cap_{\text{spacetime}} \neq \emptyset$）——法向自由度与水平几何重合的必要几何条件。

3. **拦截期（$R$ 折叠，需满足命题 1.4）**：若频率匹配 $h\nu = \Delta E_{\text{atom}}$，$R$ 右伴随映射将开放行波拓扑**折叠回收**为激发态紧致驻波拓扑：
$$R(M_{\text{photon}}, \emptyset) \to (M'_{\text{atom}}, \partial M')$$
法向形变循环能量 $h\nu$ 通过 $R$ 映射转移为物质拓扑激发（电子跃迁到高能级 $E_j = E_i + h\nu$），拦截概率由定义 1.4 决定；若频率不匹配，$R$ 折叠概率趋近于零（仅存在非共振散射，对应 $g(\nu)$ 尾翼）。

**三类法向自由度的对照**：

| 类型 | 正交于三维空间？ | 可拦截？ | 物理角色 |
|:-----|:--------------|:--------|:--------|
| KK 额外维度 | ✅ | ❌ 纯几何 | 隐藏空间，无直接观测效应 |
| 光子拓扑（纤维自由度） | ✅ | ✅ 可交互 | 电磁辐射：法向自由度携带能量，可被物质拦截 |
| 引力 Δ（水平偏差） | ❌ 水平 | — | 基空间内部几何畸变，非法向 |

**物理推论**：
1. **光子同时是"法向"与"可观测"**：法向自由度不必然不可观测——光子的可拦截性证明法向拓扑携带可交互的物理量（能量量子 $h\nu$）。
2. **与引力红移的对照**：光子拓扑是法向自由度，但引力红移通过**水平**（基空间 Δ 畸变）作用影响它——法向自由度可以被水平几何修改（§5.2 引力红移），这解释了为什么引力能影响光子传播。

**诚实边界**：
- "光子拓扑垂直于物理三维空间"在此处指**纤维方向 vs 基空间方向的几何正交**（谱纤维丛意义：$\pi: E \to B$ 中纤维 $F_b$ 与基空间 $B$ 正交），**并非 KK 式的几何额外空间维度**——三维空间之外不存在紧致化的空间维度，光子拓扑仍沿三维空间传播（$c$）。正交性发生在**拓扑自由度方向（纤维方向）与三维空间（基空间）**之间，而非三维空间内部的某个方向关系。
- **新增公式均为已知物理的拓扑重述**：命题 1.4（Bohr 条件 $h\nu = \Delta E$）与定义 1.4（吸收截面 $\sigma_{\text{abs}}$，爱因斯坦 $B_{12}$ 系数）是标准量子光学结果，本节 UFPF 贡献在于将其表述为"$R$ 右伴随折叠的必要条件/概率"，**不构成新物理预言**。
- **命题 1.3 是框架性表述，非独立验证结论**："光子吸收 = $R$ 右伴随折叠"是 UFPF 独有的翻译——标准量子光学以相互作用哈密顿量 + 费米黄金规则描述光子吸收，其中不存在 $R$ 伴随概念。本节将该机制翻译为伴随函子语言，属于**框架等价性叙事**：该翻译与标准描述的完全等价性**尚未独立验证**（既无实验判据，也无机器证明）。定义 1.3 的自然同构 $\text{Hom}_{\text{Sp}}(D(A), B) \cong \text{Hom}_{\text{Rec}}(A, R(B))$ 依赖 $D \dashv R$ 伴随对的严格存在性——该伴随对在 Paper I 中已建立，但 $R$ 在具体拓扑对象（光子 → 激发态原子）上的作用规则尚未在 Lean 中形式化。
- 本节的"正交性"是定性几何直觉的**几何表述**，而非严格证明。§1.2.1 确立的"双层正交"两个层面均未在 Lean 中严格证明：范畴层（4-范畴态射方向与伴随函子方向的几何正交）与纤维丛层（纤维方向与基空间方向的"正交"依赖垂直-水平分解 $TE \cong TF \oplus H$ 及其联络/度量结构，该结构的严格意义未形式化）。

## §2 光速不变拓扑定理

### 2.1 定理陈述

**定理 2.1**（光速不变拓扑定理）：真空光速
$$c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}$$
是时空-电磁纤维粘合拓扑的同胚不变量。光源/观测者的局域拓扑平移不改变 $c$。

### 2.2 证明思路

1. **纤维丛粘合几何**：在 UFPF 的 Grothendieck 谱纤维丛中，时空基底纤维与电磁谱纤维通过粘合函子 $\mathcal{G}$ 耦合。$c$ 由 $\mathcal{G}$ 的几何结构唯一确定。

2. **同胚不变量**：光源/观测者的运动仅是局域拓扑平移（流形上的微分同胚），不改变纤维丛的粘合拓扑结构。因此 $c$ 是拓扑同胚不变量。

3. **与引力 Δ 的层级对齐**：
   - 引力偏差 Δ：Sp 4-范畴 2-态射复合不完全交换的结构残余（Paper 35）
   - 真空光速 $c$：时空-电磁纤维粘合拓扑的唯一相容本征传播标度
   - 二者同属全域底层结构属性，不是局域物质/粒子的动力学行为

### 2.3 零静质量约束

**命题 2.2**（零静质量拓扑分支的 $v < c$ 不自洽）：对零静质量（$m = 0$）开放拓扑分支，相对论能量-动量关系 $E^2 = p^2 c^2 + m^2 c^4$ 简化为 $E = pc$，其群速度 $v = \partial E/\partial p = c$ 被强制锁定——$v < c$ 在 $m = 0$ 时无解，低速电磁拓扑无法稳定承载跃迁释放的能量。

**结论**：零静质量拓扑分支天然仅存在 $v = c$ 一类稳定等价类，无低速过渡拓扑。

### 2.4 介质中"光速变慢"的拓扑补充

**命题 2.3**：玻璃/水体等介质中宏观测得 $v < c$，并非光子拓扑自身减速。本质是光子开放拓扑被介质原子紧致拓扑捕获 → 再重新分岔生成新光子拓扑的宏观统计效应。两次捕获之间的真空区间内，单光子拓扑严格遵循 $c$ 约束。

## §3 $c = \lambda\nu$ 拓扑自洽定理

### 3.1 定理陈述

**定理 3.1**（$c = \lambda\nu$ 拓扑自洽定理）：开放电磁拓扑的周期性形变，其空间周期 $\lambda$ 与时间周期 $\nu$ 的乘积等于全域拓扑固有传播常数 $c$：
$$\lambda \cdot \nu = c$$

### 3.2 拓扑释义

- $\lambda$：单次完整拓扑形变循环沿传播方向的空间延展长度（空间维度拓扑周期）
- $\nu$：单位时间内完成的形变循环数量（时间维度拓扑周期）
- $c$：全域基底拓扑强制的形变平移传播标度（时空耦合拓扑的固定几何参数）

**自洽约束**：一旦全域基底拓扑不变，$\lambda$ 增大时 $\nu$ 必然同步降低（反比例），是拓扑自洽的必然结果。

### 3.3 温和兼容标注

**注意**：$c = \lambda\nu$ 本身是经典运动学公式，本节的拓扑释义是**温和兼容**（经典结论的拓扑重述），不构成 UFPF 独有预言。其价值在于为后续红移拓扑推导提供统一框架。

## §4 $E = h\nu$ 拓扑释义

### 4.1 定理陈述

**命题 4.1**（$E = h\nu$ 拓扑释义）：单次完整拓扑形变循环携带固定能量量子 $h$，总能量正比于形变循环密度：
$$E = h \cdot \nu$$

### 4.2 拓扑释义

- $h$：单次完整电磁拓扑形变循环的固有能量量子
- $\nu$：单位时间内的形变循环次数（拓扑形变循环密度）
- $E$：总能量正比于形变循环密度

### 4.3 温和兼容标注

**注意**：$E = h\nu$ 是 Planck 量子假说的经典表述，本节的拓扑释义是**温和兼容**。UFPF 独有贡献在于：若 $h$-$c$-$\Delta$ 三常数拓扑约束（§7.3）成立，则 $h$ 不再是独立基本常数，而是由全域拓扑几何绑定的不变量。

## §5 红移/紫移的统一拓扑解释

### 5.1 底层前提

**前提**：真空基底拓扑传播标度 $c$ 永不改变。红移/紫移不是光子自身拓扑形变循环的内在改变，而是外部条件拉伸或压缩了整套周期性拓扑褶皱序列。

### 5.2 三类红移的拓扑机制

**类型 1：多普勒红移/紫移**（光源-观测者相对平移）

- 紫移（相向靠近）：连续发射的拓扑褶皱序列被空间压缩 → $\lambda$ 缩小、$\nu$ 升高
- 红移（相互远离）：拓扑褶皱序列被空间拉伸 → $\lambda$ 变长、$\nu$ 降低

拓扑公式：$\lambda_{\text{obs}} = \lambda_{\text{emit}} \sqrt{(1-\beta)/(1+\beta)}$（相对论多普勒效应的拓扑推导）

**5.2.1 多普勒公式的拓扑推导链**（62D 定量化）：设光源以周期 $T_{\text{emit}}$ 发射形变循环（拓扑褶皱），相邻褶皱空间间距 $\lambda_{\text{emit}} = c\,T_{\text{emit}}$；观测者相对光源以 $u = \beta c$ 远离。观测周期分解为两个因子的乘积：
1. **几何路径差（拓扑褶皱序列的到达间隔）**：后一褶皱需多走距离 $u\,T_{\text{emit}}$，故 $\Delta t_{\text{obs,geom}} = T_{\text{emit}}(1+\beta)$；
2. **光源时钟时间膨胀（Rec 层时间标度在运动系的表现）**：$T_{\text{emit}} \to \gamma T_{\text{emit}}$，$\gamma = 1/\sqrt{1-\beta^2}$。
综合：$T_{\text{obs}} = \gamma\,T_{\text{emit}}(1+\beta) = T_{\text{emit}}\sqrt{(1+\beta)/(1-\beta)}$，即 $\lambda_{\text{obs}} = \lambda_{\text{emit}}\sqrt{(1+\beta)/(1-\beta)}$（$z>0$ 红移时 $\beta>0$ 远离）——拓扑重述与标准相对论多普勒一致。

**类型 2：引力红移**（4-范畴偏差 Δ 效应）

光子从高引力势（Δ 强区域）向低引力势（Δ 弱区域）传播时，时空基底拓扑被 Δ 持续缓慢拉伸：
$$z_{\text{grav}} = \frac{\Delta\Phi}{c^2} + \delta z_{\Delta}$$

其中 $\Delta\Phi$ 为引力势差（标准 GR 记号，与范畴偏差 $\Delta$ 下标区分），$\delta z_{\Delta}$ 是 **UFPF 独有修正项**（4-范畴偏差对电磁纤维粘合的附加拉伸），经典 GR 中无此项。

**类型 3：宇宙学红移**（谱纤维丛整体膨胀）

Grothendieck 谱纤维丛随宇宙演化持续均匀拓扑膨胀：
$$z_{\text{cosmo}} = \frac{a(t_{\text{obs}})}{a(t_{\text{emit}})} - 1$$

### 5.3 统一拓扑公式

$$z = \frac{\lambda_{\text{obs}} - \lambda_{\text{emit}}}{\lambda_{\text{emit}}}$$

$z$ 是拓扑形变拉伸/压缩比例系数：
- $z > 0$：拓扑褶皱被拉伸 → 红移
- $z < 0$：拓扑褶皱被压缩 → 紫移

$c = \lambda\nu$ 恒等式保证 $\lambda$-$\nu$ 同步偏移。

### 5.3.1 $\delta z_{\Delta}$ 修正项的量级估计（62D 定量化）

$\delta z_{\Delta}$ 是 UFPF 独有修正项，其量级由 4-范畴偏差 $\Delta$ 的代数强度决定。论证链：

1. **$\Delta$ 与引力强度的关联**：$\Delta$ 是基空间（水平）方向的范畴偏差（附录 A.4），其范数 $\lVert\Delta\rVert$ 与引力常数 $G$ 同属基空间方向强度（Paper 35：$G_N = c\,(\Delta\lambda_{\min})^2$ 路径）——故 $\delta z_{\Delta}$ 与引力红移基础项 $z_{\text{grav}} = \Delta\Phi/c^2$ 同源、但为高阶修正；
2. **量级结构假设**：$\delta z_{\Delta} = \varepsilon_{\Delta}\cdot z_{\text{grav}}$，其中 $\varepsilon_{\Delta}$ 为 Δ 修正的代数系数（框架锁定量级 $\sim 10^{-2}$–$10^{-4}$，具体值未定——开放问题 5）；
3. **量级结论**：太阳系引力红移 $z_{\text{grav}}\sim 10^{-6}$–$10^{-9}$（太阳表面 ~$2\times10^{-6}$，地球表面 ~$7\times10^{-10}$），故 $\delta z_{\Delta}\sim 10^{-6}\times\varepsilon_{\Delta}\sim 10^{-8}$–$10^{-13}$（太阳系），与预言 6.1（偏振红移差 $\delta z\sim10^{-6}$–$10^{-8}$）同量级带。

**诚实边界**：$\varepsilon_{\Delta}$ 的精确值未定（开放问题 5），上述为量级结构论证而非精确预言；$\delta z_{\Delta}$ 的具体代数形式需 4-范畴完整形式化（§7.3 依赖）。

## §6 颠覆性交叉衍生效应（UFPF 独有预言）

### 6.1 引力 Δ-偏振红移差

**预言 6.1**：线偏振与圆偏振光子经过同一引力场，红移量存在固定微小差值 $\delta z$。

**定量形式**（62E）：$\delta z_{\text{pol}} = \kappa_\Delta \cdot z_{\text{grav}} = \kappa_\Delta \frac{\Delta\Phi}{c^2}$，其中 $\kappa_\Delta$ 为 Δ 的偏振不对称系数（螺旋 vs 平面形变循环的拉伸倍率差），框架锁定量级 $10^{-2}$–$10^{-4}$（与 §5.3.1 的 $\varepsilon_\Delta$ 同源）。

**推导思路**：光子圆偏振/线偏振对应不同螺旋拓扑形变（§1.1.2 拓扑表述 1.2.1）；4-范畴偏差 Δ 对两种偏振褶皱产生不等拉伸倍率，其差即 $\kappa_\Delta$。

**量级估计**：太阳系 $z_{\text{grav}}\sim10^{-6}$ → $\delta z_{\text{pol}}\sim10^{-8}$–$10^{-10}$；强引力场（白矮星 $z_{\text{grav}}\sim10^{-4}$）→ $10^{-6}$–$10^{-8}$——与预言带一致。

**诚实边界**：$\kappa_\Delta$ 精确值未定（开放问题）；$\delta z_{\text{pol}} \le \delta z_\Delta$（偏振差分量不超过引力红移总 Δ 修正，§5.3.1）。

**可证伪条件**：需下一代空间高分辨偏振光谱望远镜（规划周期 15 年以上）。

### 6.2 S3 静默-辐射波长标度关系

**预言 6.2**：同一能级跃迁，原子核电荷数越高（S3 静默越强），辐射光子基准频率系统性抬升。

**定量形式**（62E，候选标度）：$\frac{\nu(Z)}{\nu_0} = 1 + \eta_{\text{S3}}\left(\frac{Z}{Z_{\text{ref}}}\right)$，其中 $\eta_{\text{S3}}$ 为 S3 静默耦合系数（量级 $10^{-5}$–$10^{-3}$，依赖静默强度 × 边界刚度因子），$Z_{\text{ref}}$ 为参考核电荷数。

**推导思路**：S3 静默强度 → 拓扑紧致边界刚度 → 闭合驻波形变压缩程度 → 分岔后光子基础周期 $\lambda$ 更小（高频短波）。

**诚实边界**：标度形式（线性）为候选假设，框架无独立定标；$\eta_{\text{S3}}$ 精确值待定。

**可证伪条件**：需超高分辨真空紫外光谱仪，多元素同能级对比实验。

### 6.3 $h$-$c$-$\Delta$ 三常数拓扑约束

**预言 6.3**：普朗克常数 $h$、真空光速 $c$、引力范畴偏差 $\Delta$ 由同一套全域拓扑几何绑定，存在固定代数关联。

**候选代数形式**（62E）：以框架既有量构造——$G_N = c\,(\Delta\lambda_{\min})^2$（Paper 35 路径，$\Delta\lambda_{\min} = (\sqrt6-\sqrt2)/\sqrt{k_{\max}(k_{\max}+1)}$，$k_{\max}=8$）；候选关联 $hc/\Delta\lambda_{\min}^2 \sim$ 框架能量标度（量级合理性检验见数值脚本 E3）。

**推导思路**：全域纤维粘合拓扑 → 三类基础拓扑不变量（形变能量量子 $h$、传播标度 $c$、范畴偏差 $\Delta$）→ 代数约束式。

**当前状态**：具体代数形式为开放问题（路线图 §七.4）；62E 仅登记候选并检验量级合理性，完整 4-范畴 + 电磁纤维形式化证明未闭环。

### 6.4 分形宇宙红移周期性震荡

**预言 6.4**：高红移星系光谱存在分形尺度 $d_H = \ln 15 + \delta$ 对应的微小周期性红移震荡。

**定量形式**（62E，候选）：震荡幅度与谱静默权重关联 $\delta z_{\text{osc}} \sim z \cdot S_4^p$（$S_4 = e^{-d_H} = 1/15 \approx 0.0667$；$p=1$ 时相对幅度 6.7%）；候选对数周期形式 $\delta z_{\text{osc}}(z) = A \sin(2\pi \log_{15}(z/z_0) + \phi)$。

**推导思路**：分形基底微小局部拓扑起伏 → 光子跨宇宙传播交替拉伸/压缩 → 周期性震荡。

**诚实边界**：震荡幅度/周期的具体形式为候选；$A$、$z_0$、$\phi$ 待定。

**可证伪条件**：需高红移星系深度巡天数据 + 高精度分形拟合算法。

### 6.5 $D \dashv R$ 无粒子假设康普顿散射

**预言 6.5**：康普顿散射波长偏移可表达为两套拓扑形变循环的耦合差，无需依赖质点光子动量假设。

**定量形式**（62E）：$\Delta\lambda = \lambda_e(1-\cos\theta)$，$\lambda_e = h/(m_e c) = 2.426\times10^{-12}$ m（康普顿波长）——两套形变循环（光子行波循环 + 电子静质量驻波循环）的耦合差。

**推导思路**：光子 Sp 行波拓扑 → $R$ 右伴随映射 → 原子 Rec 紧致驻波 → 拓扑扭曲 → $\lambda$/$\nu$ 同步偏移。

**诚实边界**：$\Delta\lambda = \lambda_e(1-\cos\theta)$ 为标准康普顿公式（已知物理，温和兼容）；UFPF 声称的"无粒子假设推导路径"为框架翻译，其与标准推导（动量守恒 + 能量守恒）的等价性尚未独立验证。

**可证伪条件**：康普顿散射高精度实验，检验波长偏移公式的拓扑形式与标准推导的差异。

### 6.6 多层静默无辐射跃迁判据

**预言 6.6**：多层嵌套 Rec 拓扑叠加 S3 静默屏障可抑制光子拓扑分岔，给出辐射/无辐射定量判据。

**定量形式**（62E）：辐射抑制比 $R_{\text{supp}}(N) = \sigma_{\text{silent}}^N$，单层静默强度 $\sigma_{\text{silent}} = e^{-d_H} = 1/15 \approx 0.067$（与 $S_4$ 谱静默权重同源）；无辐射判据 $R_{\text{supp}}(N) < \theta_{\text{crit}}$，临界层数 $N_{\text{crit}} = \lceil \ln\theta_{\text{crit}}/\ln\sigma_{\text{silent}} \rceil$（$\theta=10^{-3}$ 时 $N_{\text{crit}}=3$）。

**推导思路**：静默叠加判据 → 拓扑分岔抑制条件 → 辐射/无辐射跃迁定量区分。

**诚实边界**：单层静默强度取 $e^{-d_H}$ 为框架内候选（依赖谱静默层级形式化）；叠加假设（乘积）为候选形式。

**可证伪条件**：特定原子体系中辐射抑制效应的定量检验。
