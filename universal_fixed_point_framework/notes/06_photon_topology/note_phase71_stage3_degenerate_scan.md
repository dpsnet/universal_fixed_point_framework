## 3. 核心结论（推论 2.1 的修正）

1. **跳变不在取向通道，在手性通道**。S3 证明 A_BG 对 z（左旋量相位/⟨ij⟩）零敏感——
   BG 递归(20) 的 Θ 只含 [ ] 括号（全由 z̄ 决定），⟨ij⟩ 不进入剥离振幅。
   全部跳变（S2 的 92 次、S4 的 392 次）由 **ω 符号格点**（手性通道）驱动。

2. **半共线 ⟨ij⟩=0 不是剥离振幅非零的来源，而是全振幅可定义的适用域**。
   S1+S5：在 (2,2) 签名 + R1（ω₁<0, ω_{a>1}>0）+ 动量守恒下，剥离振幅对任意 z
   （共线或非共线）均非零（≈30%，±1/0 整数）且满足全部一致性。
   半共线条件的物理角色 = 使含 MHV 因子 ∏⟨aa+1⟩ 的全振幅被支撑/定义良好，
   而非"判零-解除"机制。这与 2602.12176 论文口径需进一步核对
   （论文的功率计数判零论证针对全振幅；剥离振幅层面非零是更普适的性质）。

3. **推论 2.1 搜索原则修正**：离散跳变信号定位在 **手性通道符号格点**
   （ω 符号的组合变化），而非取向通道边界。对 MUFPF：这对应翻译笔记的双通道映射中
   "手性通道 w_i = 拓扑相变载体"——Paper 44/46 的取向通道对应适用域/禁戒条件（Paper 48 语言），
   手性通道对应离散符号结构。

4. **软极限的阶梯-极限结构**：A_n(eps) 沿软极限路径多次跳变（±1/0 格点间），
   但极限值稳定满足软定理(28)。"阶梯函数 + 极限连续"是离散符号结构的典型表现，
   与通式(39) 的逐点整数取值一致。

## 4. 诚实边界

  n=3,4,6 的跳变结构未单独测绘（S3 的"z 不敏感"在 n=3–6 由 B1/B2 间接成立，

- 阶段3b 未产生"标准振幅学未注意的新非零构型"级别的预言——剥离振幅非零（30%）
  在 generic z 下是 BG 递归的直接输出，需确认其在物理全振幅层面的意义后才可谈预言。

## 4b. 论文口径核对（2026-09-30 完成，悬案解除）

核对论文原文（2602.12176v2 第1–3页）后，S1 的"非半共线剥离振幅非零"**不与论文冲突**：

1. **判零论证针对全振幅**：第3页左栏——"for generic kinematics, if we choose |r⟩ = |1⟩,
   then we find that all the polarization vectors are orthogonal... Hence,
   single-minus amplitudes vanish for generic kinematics."——判零的是**全振幅 A_n**
   （极化矢量正交 → 动量收缩数 n−2 不足），不是剥离振幅。

2. **半共线是 δ 支撑条件**：公式(15)(16)——全振幅
   A_n = i^{2−n}(⟨r1⟩^{n+1})/(⟨r2⟩⋯⟨rn⟩) · A_{1⋯n} · ∏_{a=2}^n δ(⟨1a⟩) · δ²(Σλ_i)，
   且论文明言 "the n-point amplitude **may only be supported when all ⟨ij⟩ = 0"。
   半共线 ⟨ij⟩=0 使全振幅**被支撑**（δ 因子非零），剥离振幅 A_{1⋯n} 本身对任意运动学
   由 BG 递归(21) 定义。→ 3b 结论 2 的表述获论文原文直接证实。

3. **剥离振幅只依赖右旋量（论文已声明）**：第3页右栏（公式(16) 后）——
   "A_{1⋯n} is a function only of {λ̃_i}"。S3 的"z 不敏感"（零跳变）是论文此声明的
   **数值确认**（n=5），非新发现。

4. **R1 区之外的通式论文未给出**：第2页——"a longer general formula for the
   single-minus amplitude **outside of R₁ will appear elsewhere"。
   → S1/S5（非半共线 + R1 + 动量守恒下剥离振幅 ~30% 非零、全整数、满足循环/KK/软定理）
   是对论文明确留白的"R₁ 之外区域"的**数值测绘**——构成 MUFPF 侧的实质增量素材
   （3c 候选升级，但价值评估为技术笔记级，非投稿级）。

5. **SDYM 联系是论文自己提出的**：第1页——"Single-minus amplitudes also arise in
   self-dual Yang-Mills theory (SDYM)... Potentially, the single-minus tree amplitudes
   in SDYM found here resolve this tension."——3a 的阿贝尔极限路径获论文侧方向支撑
   （非 MUFPF 侧验证，但路径选择与论文一致）。

## 4c. 跳变点解析判定与 (31) 适用域（待办4，2026-09-30 完成）

脚本 `scripts/paperX_jump_symbol_map.py`（N1–N3，结果 `paperX_jump_symbol_map_results.json`）：

| 扫描 | 内容 | 结果 |
|:---|:---|:---|
| N1 | n=5 generic z：A5(31) vs BG 递归 | agree=19512/20000（97.6%），**disagree=488（2.4%）**——非退化差异 |
| N2 | n=5 模式决定论（60000 采样） | 52 符号模式：36 决定性、**16 非决定性**（同模式给 0 或 ±1）；恒非零 8、恒零 28 |
| N3 | n=6 generic z：A6(32) vs BG 递归 | **agree=5000/5000 全一致** |

结论：
1. **(32) 的记号在 generic z 下全一致**（n=6，逗号块和版适用域广）；**(31) 在 generic z 下有 2.4% 系统性偏差**——
   (31) 的"无逗号首索引"记号严格适用于半共线 R1 区（B2：n=5 仅 2/800 退化差异），
   非半共线下不完整。→ 引用 (31) 作为 n=5 剥离振幅公式须注明适用域；
   S1/S5 的非零率测绘基于 **BG 递归**（ground truth），不受此影响。
   **记号混淆候选已数值否定**（2026-09-30 诊断 `paperX_diag_s1234_notation.py`）：
   s1234 首索引→块和只修复 167/488=34%，106 样本首索引==块和仍不一致——
   (31) 的 generic z 偏差为多因子结构差异，非单一记号问题；
   generic z 下以 BG 递归为准，(31) 视为半共线 R1 区公式。
2. **n=5 跳变判据不封闭**：8 个 sg 因子不能完全决定 A_BG（16/52 非决定性模式）——
   与 n=4 不同（n=4 的 (sg₁₂−sg₂₃)(sg₃₄−sg₄₁)=0 决定性恒等式，已 Lean 证明）。
   n=5 需要更高阶 sg 关系或动量守恒内 z̃ 细节——**Lean n=5 恒等式候选未闭合**，诚实记录。
3. 非零率：n=5 ≈30.9%、n=6 ≈15.5%（generic z + R1 + momentum）——随 n 下降，
   与通式(39) 半共线区 2^{2−n}∏(…) 的结构相容（更多因子 → 更多零机会）。
   n=6 测绘（`paperX_n6_jumps.py`）：S2_n6 61 次跳变（R1 区 27/非 R1 区 34）、
   S4_n6 91/410 采样跳变（22%，n=5 为 48%）、S1_n6 k=0 非零率 14%——标度单调下降确认。
