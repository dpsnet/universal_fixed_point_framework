## 2. 关键调试发现（记号体系澄清）

阶段1 中最大障碍是 **sg 级联记号的两套规则**，曾导致 (31)(32) 大范围误判：

1. **无逗号** `sg_{abc...} = sg([λ_a, λ_b+λ_c+...])`——逗号在**第一个索引后**（"首索引规则"）。论文正文定义 `sg_{i,jk}=sg([λ_i,λ_j+λ_k])` 即此规则。用于 (31)：`sg_{234}=sg([λ_2,λ_3+λ_4])`，`sg_{123}=sg([λ_1,λ_2+λ_3])`，`sg_{1234}=sg([λ_1,λ_2+λ_3+λ_4])`。
2. **显式逗号** `sg_{A,B} = sg([Σλ_A, Σλ_B])`——逗号两边均为**块和**。用于 (32)：`sg_{1,23}`、`sg_{12,3}`、`sg_{123,4}`、`sg_{12,34}`、`sg_{2,345}`、`sg_{23,45}` 等（放大 OCR 确认，3000/3000 与 BG 递归一致）。

教训：**整页 OCR 对长公式下标不可靠**（曾给出 3 个互相矛盾的 (32) 版本）；最终以"裁剪放大图像 + 数值与 BG 递归拟合"双通道定案。初次实现将 (31) 的 `sg_{1234}` 误作块和版 `sg_{12,34}`、将项1 `sg_{51}` 误作 `sg_{31}`（第二版 OCR 误读），修正后通过率 19.8% → 99.4%。

## 3. 两个方法的澄清（重要）

### 3.1 循环性/反射的配置要求

剥离振幅 `A_{1..n}` 的定义（论文(15)(16)）含动量守恒支撑 `δ²(Σλ_i)`——**只对壳上运动学定义**。因此在**无动量守恒的一般半共线配置**下测循环性(24)/反射(25) 失败是**测试方法错误**（T3 与早期 B3 均如此），而非公式错误。改用动量守恒配置（`λ̃_n = -Σ_{i<n}λ̃_i`）后 B3 全pass。U1/KK 因是更强恒等式，一般配置下也通过。

### 3.2 (31) 的退化配置残余差异（0.6%）

n=5 的残余失败（20000 样本中 118 例）**全部**为剥离振幅=0 的退化配置：BG 递归中预振幅的 Θ 因子消失（`Θ(-[K]/[λ]) = 0`）导致 `A_BG=0`，而 (31) 是纯 sg 多项式给出 ±1。即 **(31) 是"generic position"公式**——在预振幅 Θ 非零的通用配置下与 (21)/(39) 完全一致，退化配置下不适用。论文正文"Details of this calculation will appear elsewhere"（(24) 下方）暗示显式公式的推导细节未完全公开，此差异大概率源于此，而非笔误。**未完全解决**：退化配置下 (31) 的正确形式（是否需显式 Θ 因子）留待后续。

## 4. 与 MUFPF 的连接点（阶段 2 入口）

1. **记号二义性本身是物理信息**：sg 在"首索引"与"块和"两种读法下的差别，对应形变循环中"单轴 vs 多轴复合"的谱权重次序——(31) 用单轴首索引、(32) 用块和，暗示 n=5→n=6 时形变模式耦合方式变化（与 Paper 44 单轴→Paper 46 三轴的阶数增长同构）。
2. **退化配置 = 拓扑奇异点**：预振幅 Θ 消失的配置（剥离振幅=0）即 (21) 的零点集——对应形变循环的退化/简并构型，是功率计数失效的候选位点（阶段 2b 环绕数分析对象）。
3. **镜像关系可正式化**：B1/B3 确认 (39) 与一致性与论文声称一致，为阶段 2c（与 Paper 48 拓扑禁戒的镜像形式化）提供可靠数值基座。
