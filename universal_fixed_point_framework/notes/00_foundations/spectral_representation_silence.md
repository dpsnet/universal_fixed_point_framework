## 1. 背景：态射层不可闭合的发现链

伴随对 $D\dashv R$（$D:\mathbf{Rec}\to\mathbf{Sp}$ 谱化函子，$R$ 余伴随）的闭合历程：

1. **Lean 侧** `Adjunction.lean` 恒等原型编译失败（`nS=nT`、`step=id`、`S.A=单位阵` 三个隐含条件，`lake env lean` 实证）

3. **基数反例**（决定性）：D 的 full 性在有限维原型中为假

## 2. 基数反例（决定性证据）

设 $X=Y$ 为 **2 状态平凡递归系统**（$\mathrm{step}=\mathrm{id}$）。则：

$$A_X = A_Y = \mathrm{transferMatrix}(\mathrm{id}) = I_2 \quad(\text{单位矩阵})$$

- **谱态射空间**：$\mathrm{Hom}_{\mathbf{Sp}}(D(X), D(Y)) = \{P \in \mathbb{C}^{2\times 2} : P\cdot I = I\cdot P\} = \mathbb{C}^{4}$——交织条件恒成立，**不可数无限**
- **递归态射空间**：$\mathrm{Hom}_{\mathbf{Rec}}(X, Y) = \{\mathrm{Fin}\,2 \to \mathrm{Fin}\,2\} = 4$ 个函数——**有限**

伴随自然同构要求 $\mathrm{Hom}_{\mathbf{Sp}}(D(X),D(Y)) \cong \mathrm{Hom}_{\mathbf{Rec}}(X,Y)$——**不可数集与有限集之间不存在双射**，矛盾。

**直接反例**：$P = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$ 是合法谱态射（满足交织），但每行非"恰一个 1"，不是任何 $\mathrm{transferMatrix}(f)$。因此 **D 不 full**，`RIm_map` 不可定义。

## 3. 表示静默的定义

### 3.1 静默度的同构推广

框架既有定义（MUFPF 修复方案定义 R7）：态射 $f$ 的可见性函数

$$v(f_t) = \frac{\|P_{V_\Lambda}D(f_t)\|}{\|D(f_t)\|} \in [0,1],$$

其中 $V_\Lambda = E_{A_2}([0,\Lambda])\mathcal H_{R_2}$ 为可观测谱子空间。

**表示静默（D-静默）**：谱态射 $\varphi \in \mathrm{Hom}_{\mathbf{Sp}}(E,F)$ 的 D-静默度

$$\boxed{S_D(\varphi) = 1 - \frac{\|P_{\mathrm{Im}(D)}(\varphi)\|}{\|\varphi\|}}$$

其中 $P_{\mathrm{Im}(D)}$ 是到转移矩阵像 $\mathrm{Im}(D)\subset\mathrm{Hom}_{\mathbf{Sp}}$ 的正交投影。结构上与定义 R7 **完全同构**——仅投影空间从"可观测谱子空间 $V_\Lambda$"换成"D 的像 $\mathrm{Im}(D)$"。

**定义（表示静默）**：$\varphi$ 是 **表示静默的**，当且仅当 $P_{\mathrm{Im}(D)}(\varphi)=0$（$\varphi$ 正交于所有转移矩阵），即 $\varphi$ 在递归表示下完全不可达。

### 3.2 与框架静默的对照

| | 框架静默（定义 R7） | 表示静默（D-静默） |
|:--|:--|:--|
| 判据 | $P_{V_\Lambda}D(f)=0$ | $P_{\mathrm{Im}(D)}(\varphi)=0$ |
| 静默度 | $1-\|P_{V_\Lambda}D(f)\|/\|D(f)\|$ | $1-\|P_{\mathrm{Im}(D)}(\varphi)\|/\|\varphi\|$ |
| 静默对象 | 态射 $f$ 的**像**落于不可观测谱 | 谱态射 $\varphi$ **本身**不可被 Rec 表示 |
| 类型 | 动力学层（沿演化参数 $t$） | 表示/编码层（静态结构） |
| 投影空间 | 谱子空间 $V_\Lambda$ | D 的像 $\mathrm{Im}(D)$ |

## 4. 量级分析

平凡系统反例中：$\mathrm{Im}(D)$ = 4 个转移矩阵（有限集），$\mathrm{Hom}_{\mathbf{Sp}} = \mathbb{C}^4$（连续统）。

- $\mathrm{Im}(D)$ 在 $\mathrm{Hom}_{\mathbf{Sp}}$ 中**测度为零**
- **"几乎所有"谱态射是表示静默的**（$S_D \approx 1$）

这是极端静默：连续统级的态射信息在递归表示下不可达。物理读法：只有"确定性跳转"型动力学（0-1、每行恰一 1）能被递归表示捕获；携带连续谱参数的态射（如 $P=\begin{pmatrix}1&0\\1&1\end{pmatrix}$ 的任意复参数）在递归表示下完全静默——类比量子相干在经典测量下的静默，但发生在**表示层**而非观测层。

## 5. 分层定位：S0 表示层

现有四层静默体系（S1 严格 / S2 渐近 / S3 ε-有效 / 辫子）均为**动力学/观测层**。表示静默构成新的一层：

- **S0（表示静默）**：$P_{\mathrm{Im}(D)}(\varphi)=0$——谱态射不可被递归表示

## 10. S0 静默的筛（sieve）结构（P2，2026-07-31）

### 10.1 问题：S0 静默类是否构成 sieve？

对照定理 R6（严格静默筛），动力学静默态射类构成 sieve。自然问题：表示静默类
$$\mathcal{S}_D = \{\varphi \in \mathrm{Hom}_{\mathbf{Sp}} : P_{\mathrm{Im}(D)}(\varphi) = 0\}$$
是否也构成 sieve（对复合封闭）？答案：**否**——左、右复合均破坏静默。

### 10.2 数值验证（`scripts/paperX_s0_sieve.py`，7/7 PASS）

平凡 2 态系统（$A_X = A_Y = I_2$，$\mathrm{Hom}_{\mathbf{Sp}} = \mathbb{C}^{2\times2}$）：

- **S0 静默空间**：$\mathrm{span}\big\{\begin{pmatrix}1&1\\-1&-1\end{pmatrix}\big\}$（一维，测度零；正交于全部 4 个转移矩阵）
- **左复合（后复合）不封闭**：$\varphi = \begin{pmatrix}1&1\\-1&-1\end{pmatrix} \in \mathcal{S}_D$，取 $\psi = \begin{pmatrix}1&0\\0&0\end{pmatrix}$（合法谱态射，与 $I$ 可交换），则 $\psi\varphi = \begin{pmatrix}1&1\\0&0\end{pmatrix} \notin \mathcal{S}_D$（$S_D: 1.000 \to 0.293$）
- **右复合（前复合）不封闭**：$\varphi \in \mathcal{S}_D$，$\chi = \begin{pmatrix}1&0\\0&0\end{pmatrix}$，则 $\varphi\chi = \begin{pmatrix}1&0\\-1&0\end{pmatrix} \notin \mathcal{S}_D$（$S_D: 1.000 \to 0.293$）
- **S_D 非保静默扫描**：100/100 随机 $\psi$ 使 $S_D(\psi\varphi) < S_D(\varphi)$——复合几乎必然破坏静默

### 10.2b 扩展验证（P2 深入，2026-07-31）

- **S_D 下降率分布**（2000 随机 $\psi$）：$S_D(\psi\circ\varphi)$ 均值 0.342、中位数 0.294、$\sigma=0.240$，73% 被压到 0.5 以下——复合破坏静默**不是小扰动而是系统性的**：静默度中位数跌至约 0.29。
- **高维 n=3**：$\mathrm{rank}(\mathrm{Im}\,D) = 7$，S0 静默空间维数 = $9-7 = 2$（非平凡，测度零依旧）。复合仍破坏静默（$1.00 \to 0.42$）。**S0 静默空间维数随 n 增长**（n=2 → 1，n=3 → 2），但它始终是"低维子空间 vs 全态射空间"的退化结构。
- **标量演化保持**：$e^{-t}I$（平凡系统动力学演化）复合**保持** S0 静默（t∈[0,10]）。对照结论：**破坏静默的是结构性复合（改变态射形状），标量缩放不破坏**——静默度对纯缩放不变，对形状扰动敏感。

### 10.3 理论含义

1. **S0 与 S1-S4 的结构性差异**：动力学静默构成 sieve（定理 R6），表示静默**不构成** sieve。静默体系内部出现"筛/非筛"的二元结构。
2. **静默度在复合下不单调**：$S_D$ 不是复合上的单调量，$S_D(\psi\circ\varphi)$ 可由 1 跌至 $<1$。复合是"打开 S0 静默"的通道——表示静默态射经合法谱态射复合后可变得可表示。
3. **物理解读**：S0 静默对应"编码前不可表示"，但其破坏（复合到可表示）恰恰说明——**表示性是相对结构而非绝对性质**：态射的表示可达性依赖它所在的复合上下文。这与 §6 的"态射限制为转移矩阵"的规范语义相容（限制 = 固定在无复合上下文中的表示层）。
4. **修正开放问题 #3 的预期**：原问"S0 静默态射是否在复合下封闭？是否形成 sieve？"——答案：均否。sieve 判定为负，进一步研究应转向"S_D 在复合下下降的精确速率/结构"。

中位数 $1-\sqrt{1/2}\approx0.2929$（数值 0.2918 ✓，解释 §10.2 的 ~0.294）、均值 $1/3\approx0.3333$、标准差 $\sqrt{1/18}\approx0.2357$。推导：$M=[[u,u],[v,v]]$（$u=\psi_{00}-\psi_{01}$ 复高斯），投影到行和相等空间得 $S_D=1-|u+v|/\sqrt{2(|u|^2+|v|^2)}=1-\sqrt{X/(X+Y)}$（$X,Y$ 独立指数）$=1-\sqrt U$。注意 $\psi$ 为**复**高斯（$\sqrt U$ 分布）；若为实高斯则得 $1-|\cos\theta|$（均值 $1-2/\pi$，与数值不符——已排除）。

**遗留 2（非平凡动力学演化）——已解决**：S0 静默态射 $\phi$ 经非平凡动力学 $e^{-tA}$（$A=\mathrm{diag}(1,2)$ 非标量）左复合：
$$S_D(t) = 1 - \frac{|e^{-t}-e^{-2t}|}{\sqrt{2(e^{-2t}+e^{-4t})}},$$
从 $S_D(0)=1$（静默）单调下降至极限 $1-1/\sqrt2\approx0.293$——**非平凡动力学破坏 S0 静默**（对比平凡系统 $A$ 标量时保持静默）。结构发现：swap 系统（$A=[[0,1],[1,0]]$）$\mathrm{Hom}_{\mathbf{Sp}}=\mathrm{span}\{I,A\}\subseteq\mathrm{Im}(D)$（$I=\mathrm{transferMatrix}(\mathrm{id})$、$A=\mathrm{transferMatrix}(\mathrm{swap})$ 均在像中），故 **S0 静默 = {0}**——静默的非平凡性依赖 $\mathrm{Hom}_{\mathbf{Sp}}$ 未被 $\mathrm{Im}(D)$ 覆盖的程度。

**遗留 3（高维闭式）——已解决**：$\mathrm{Im}(D)$ 张成 $=$ **行和相等矩阵空间**（转移矩阵每行行和 $=1$；构造性基 $\{E_{ij}-E_{i0}\}\cup\{J\}$ 均在张成中且维数 $n^2-n+1$ 匹配），故
$$\dim\mathcal{S}_D = n^2 - \mathrm{rank}(\mathrm{Im}\,D) = n^2 - (n^2-n+1) = n-1.$$
数值验证 n=2..7 全部通过（n=2→1，n=3→2，…，n=7→6）。

## 11. 物理对应研判：表示静默是"特征还是缺陷"（P3，2026-07-31）

### 11.1 候选类比

| 类比 | 投影结构 | 与 S0 静默的对应 | 关键差异 |
|:--|:--|:--|:--|
| **经典化/相干性丢失**（decoherence） | 环境测量把密度矩阵投影到经典基 | $P_{\mathrm{Im}(D)}$ 同为"正交投影到受限像"，静默度 $S_D$ 类比相干性丢失比例 | **不可逆**：decoherence 后信息无法恢复；S0 静默可经复合"打开"（§10.2b，$1.0\to0.29$），是**上下文依赖而非绝对丢失** |
| **有损压缩/量化** | 连续信号投影到有限码本 | $\mathrm{Im}(D)$ = 有限个转移矩阵（码本），连续统态射空间被投影 | 更贴切：递归表示 = 有限码本编码，S0 静默 = 码本外信息 |
| **采样/分辨极限**（Nyquist） | 有限采样重建带宽受限信号 | Rec 的有限态空间对连续谱参数采样不足 | 类比有效，但采样定理有定量重建误差界，S_D 尚无解析界 |

### 11.2 研判：特征而非缺陷

**判定：表示静默是"特征"（表示论的基本约束），不是框架缺陷。** 论据：

1. **定义性**：$\mathrm{Im}(D)$ = 转移矩阵（每行恰一个 1）是 **Rec 范畴定义的本质**（$\mathrm{Fin}\,m\to\mathrm{Fin}\,n$ 函数像）。Rec 只能表示确定性跳转动力学，这是范畴的**定义属性**，如同"经典系统无叠加"是定义属性——不是错误。
2. **项目经验一致性**：交换律偏差是特征（揭示结构而非错误）。同理，表示静默揭示的是"**递归表示的本质分辨极限**"——连续谱参数（如 $P=\begin{pmatrix}1&0\\1&1\end{pmatrix}$ 的复参数）在有限码本下不可达，这是**信息论事实**而非实现缺陷。
3. **结构可逆性**（§10 新证据）：S0 静默态射经合法复合可变得可表示——静默不是不可逆信息丢失（区别于 decoherence），而是"表示基准的相对性"。这强化"特征"判定：它是**表示的固有基准选择问题**，不是编码错误。

**缺陷成分**（已由 P0 修正）：框架早期声明的"$D\dashv R$ 全域严格成立"超出表示能力范围，属声明过度——P0 已将 paper I / paper XIX / RAP 方案的断言限定到"对象层 + 受限态射层"。

### 11.3 物理读法（首选类比：有损压缩）

表示静默的最贴切物理类比是**有损压缩**而非 decoherence：
- $D$ 编码 = 把（连续参数的）谱态射压缩进有限码本（转移矩阵）
- $S_D(\varphi) = 1 - \|P_{\mathrm{Im}(D)}(\varphi)\|/\|\varphi\|$ = 编码损失率
- "几乎所有"谱态射 $S_D \approx 1$（测度零静默） = 码本对连续信号**几乎处处不可达**
- 复合破坏静默 = 改变信号的"表示基准"后，部分信息落入码本

物理含义：**递归表示（Rec）是有损编码器**，其码本是确定性跳转动力学的集合；连续谱自由度的可表示性不是绝对性质，而是依赖复合上下文的相对性质。这与框架"以 Rec 为动力学底座"的定位一致——Rec 捕获的是动力学结构的**粗粒化/符号化**层面。

### 11.4 结论与遗留

- **结论**：表示静默是特征（表示论基本约束），首推"有损压缩"类比；伴随声明过度属缺陷，已由 P0 修正。
- **遗留**：S_D 是否有解析重建误差界（类比采样定理）；复合破坏静默的物理过程解读（什么样的动力学过程会"打开"S0 静默）。
