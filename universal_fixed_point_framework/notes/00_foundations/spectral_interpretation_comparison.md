# 量子基础六大诠释的范畴论对比

## 概述

本文以 $\mathbf{Rec}/\mathbf{Sp}$ 范畴框架为基准，对量子力学六大诠释进行系统对比。对比维度包括：波函数本体论、坍缩机制、Born 规则起源、纠缠非定域性解释、测量问题消解方式，以及**范畴论可表达性**。

## 2. 逐项分析

### 2.1 Copenhagen 诠释

**核心主张**：量子理论是预测实验结果的工具，不提供微观实在的描述。

| 子项 | 内容 | 谱动力学评价 |
|------|------|------------|
| 波函数 | 计算工具，非实在 | $\mathbf{Sp}$ 对象是实在的谱结构 |
| 坍缩 | 外部公设，无动力学机制 | M2 谱流提供坍缩的动力学起源 |
| Born 规则 | 独立公设 | M3 从轨道函子结构导出 |
| 测量问题 | 承认但未解决 | M1-M4 消解 |
| 范畴论表达 | 无——Copenhagen 拒绝形式化形而上学 | 与谱动力学不兼容 |

**范畴论困境**：Copenhagen 的工具主义立场拒绝为"实在"赋予范畴结构，因此无法在 $\mathbf{Rec}/\mathbf{Sp}$ 或任何范畴框架中表达。这是唯一**原则上不可范畴化**的诠释。

---

### 2.2 Bohmian 力学（de Broglie-Bohm）

**核心主张**：粒子有确定轨迹，由导波 $\psi$ 引导。

| 子项 | 内容 | 谱动力学评价 |
|------|------|------------|
| 波函数 | 实在导波 $\psi: \mathbb{R}^{3N} \to \mathbb{C}$ | $\mathbf{Sp}$ 对象替代 |
| 坍缩 | 无——投影是表观效应 | 谱流提供更简洁的机制 |
| Born 规则 | 量子平衡分布 $P = \|\psi\|^2$ | M3 函子权重更根本 |
| 纠缠 | 非定域导波（瞬吋） | 结构属性更快（无传播需要） |
| 额外假设 | 导波方程 + 量子平衡 | M1-M4 更少假设 |
| 范畴论表达 | **部分可能**——导波方程可视为 $\mathbf{Rec}$ 中的递归系统，但非定域性打破 $\mathbf{Sp}$ 态射的条件 |

**范畴论表达**：
- 导波方程 $\partial_t \psi = -\frac{i}{\hbar}H\psi$ 可映射为 $\mathbf{Rec}$ 对象 $R_{\text{pilot}} = (\mathbb{C}^\infty, e^{-iHt}, \mathbb{R}_{\ge 0})$
- 但粒子的确定轨迹 $\{x(t)\}$ 需要额外结构（非定域引导条件），**在 $\mathbf{Sp}$ 中无对应**
- 谱动力学评价值："C-"（范畴论深度极低——非定域性破坏态射条件）

---

### 2.3 Many-Worlds 诠释（Everett）

**核心主张**：全域波函数始终幺正演化，分支对应不同测量结果。

| 子项 | 内容 | 谱动力学评价 |
|------|------|------------|
| 波函数 | 全域实在 | 类似——但 $\mathbf{Sp}$ 对象有结构 |
| 坍缩 | 无——只有分支 | 谱流到不动点是更精确的描述 |
| Born 规则 | 自证（Squared amplitude = measure） | M3 函子权重严格推导 |
| 概率问题 | 为何体验概率？ | M4 分支拓扑权重回答 |
| 本体论负担 | 无限多世界 | 单一 $\mathbf{Sp}$ 对象 |
| 范畴论表达 | **部分可能** |
| - 对象 | 全域波函数 $\Psi \in \mathcal{H}_{\text{univ}}$ → $\mathbf{Sp}$ 对象 $(\mathcal{H}_{\text{univ}}, H, \sigma(H))$ | ✅ |
| - 分支 | 需要额外结构定义"分支" → $\mathbf{Rec}$ 中的递归系统族 $\{R_i\}$ | 🟡 |
| - 概率权重 | 无自然范畴论对应 | ❌ |

**范畴论瓶颈**：MWI 无法范畴化概率权重。Born 规则中的 $|c_i|^2$ 在 MWI 中是"自证的"，但这一主张在范畴框架下无对应——这正是 M3 填补的空白。

---

### 2.4 关系性量子力学（RQM, Rovelli）

**核心主张**：量子态是系统间关系的编码，非绝对属性。

| 子项 | 内容 | 谱动力学评价 |
|------|------|------------|
| 波函数 | 关系性（相对事实） | 与 $\mathbf{Sp}$ 态射的谱交织条件 $\text{TA}_1 \subseteq \text{A}_2\text{T}$ 一致 |
| 坍缩 | 无——事实是相对的 | M2 谱流 + M4 分支替代 |
| Born 规则 | 关系概率 | M3 函子权重 |
| 纠缠 | 相对事实 | 结构属性 |
| Wigner 朋友 | 自然消解（事实相对性） | M1-M4 同样消解 |
| 范畴论表达 | **高兼容性** |

**范畴论对应**：
- RQM 的"关系" $\leftrightarrow$ $\mathbf{Sp}$ 中的态射 $T: E_1 \to E_2$
- RQM 的"相对事实" $\leftrightarrow$ 态射施加后的谱数据 $T(A_1) \subseteq A_2$
- 但 RQM 缺少**谱流动力学**和**不动点结构**（M2, M4）

**谱动力学超越**：RQM 说"事实是相对的"，谱动力学进一步说"相对事实收敛到相容的不动点"（M2.1）。RQM 是描述性的，谱动力学是**构造性的**。

---

### 2.5 QBism（Fuchs, Mermin, Schack）

**核心主张**：量子概率是决策者的信念度，Born 规则是理性决策的规范。

| 子项 | 内容 | 谱动力学评价 |
|------|------|------------|
| 波函数 | 信念（主观） | 与 $\mathbf{Sp}$ 对象不兼容 |
| 坍缩 | 信念更新 | M2 提供客观机制 |
| Born 规则 | 理性规范 | M3 是结构定理，非规范 |
| 纠缠 | 关联信念 | 结构属性 |
| 量子-经典边界 | 无 | M2 $\kappa$ 提供定量判据 |
| 范畴论表达 | **低兼容性**——QBism 的主观主义原则上拒绝客观范畴结构。信念更新不能范畴化。 |

**根本分歧**：QBism 认为量子态是**主观的**，谱动力学认为 $\mathbf{Sp}$ 对象是**客观的谱结构**。这是"认识论 vs 本体论"的根本对立。

---

### 2.6 谱动力学（本工作）

**核心主张**：量子现象是 $\mathbf{Rec}/\mathbf{Sp}$ 范畴框架中谱结构的自然涌现。

| 子项 | 内容 | 优势 |
|------|------|------|
| 波函数 | $\mathbf{Sp}$ 对象 $(\mathcal{H}, A, \sigma(A))$ | 谱结构严格定义 |
| 坍缩 | M2 谱流到不动点 | 动力学，非公设 |
| Born 规则 | M3 函子谱权重 | 推导，非公设 |
| 随机性 | M4 分支拓扑权重 | 动力学的，非概率公设 |
| 纠缠 | 谱对象不可分解性 | 结构属性，非动力学 |
| 延迟选择 | 态射选择 | 无回溯 |
| 测量问题 | M1-M4 统一消解 | 无额外假设 |

**范畴论独特性**：谱动力学是唯一**原生范畴论框架**的量子诠释——不是将现有诠释映射到范畴论，而是从范畴论出发构造诠释。

## 3. 范畴论兼容性矩阵

假设范畴 $\mathbf{C}$ 是量子诠释的形式化框架：

| 诠释 | $\mathbf{C}$ 存在性 | $\mathbf{C}$ 中坍缩 | $\mathbf{C}$ 中 Born 规则 | $\mathbf{C}$ 中纠缠 |
|------|:---:|:---:|:---:|:---:|
| Copenhagen | $\nexists$ | — | — | — |
| Bohmian | $\exists$ (部分) | $\perp$ | $\perp$ | $\perp$ |
| Many-Worlds | $\exists$ (部分) | $\times$ | $\perp$ | $\sim$ |
| RQM | $\exists$ | $\sim$ | $\sim$ | $\sim$ |
| QBism | $\nexists$ | — | — | — |
| **谱动力学** | **$\exists$** | **M2** | **M3** | **结构属性** |

符号：$\exists$ = 存在, $\nexists$ = 不存在, $\perp$ = 不兼容, $\times$ = 无对应, $\sim$ = 部分对应
