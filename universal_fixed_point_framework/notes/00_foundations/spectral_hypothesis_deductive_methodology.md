# 谱假设-演绎论证方法论（2026-08-04）

> **状态**：方法论笔记（第一手研究资料）。提炼产物：Paper XXXVII（方法论章节）、RAP 勘误 §一·补充。
>
> **问题**：在范畴层（$\mathbf{Sp}$ 4-范畴、D⊣R 伴随、谱对应）之上，假设 Cl(1,7)/SU(2) 谱框架（A_GR 谱）的物理存在，然后论证其存在的合理性——这是否构成理论模型可行的论证方法？其论证强度如何定位？

## 1. 结论

**是**。这是科学中标准的**假设-演绎（hypothetico-deductive）论证**，在理论物理中通行（弦理论、公理化 QFT 等均如此）。但它不是先验证明，而是**公理化辩护**。关键在于诚实标注论证强度，并区分"物理断言"与"数学定理"。

## 2. 论证强度三层级

| 层级 | 形式 | 强度 | 项目实例 |
|:---:|:-----|:-----|:---------|
| **① 弱形式：预测检验** | 假设 → 推导可观测预言 → 与实验吻合 → 反推假设合理（似然/贝叶斯辩护） | 解释力累积（非证明） | paperX_gravity_c_constant.py 数值验证、29 参数验证、Fisher p≈0 |
| **② 中形式：框架自洽** | 假设 → 框架内部结构咬合（谱流保持、静默定理、维度确定、O2 统一） | 结构涌现 | 静默机制、Bott 塔、统一 3 定理、d_H≈ln15 结构导出 |
| **③ 强形式：先验导出** | 范畴层纯结构 → 无需物理假设 → 导出谱结构 | 最强（未完成） | Bott 塔 log₂k_max=3（部分达成）；Cl(1,7)/SU(2) 谱完整先验导出**未完成** |

**当前 A_GR 谱假设的论证强度定位**：① + ②（公理化辩护），**非** ③（先验证明）。③ 是未完成、可继续追求的方向。

## 3. 为什么"可行"而非"循环论证"

合理性的关键在于**假设独立于它要解释的现象**：
- A_GR 谱是数学结构假设（Cl(1,7) 代数的谱约定），不包含"三代质量 = 实验值"这类结论 → 用它推出质量谱才是非平凡预测
- 若假设本身已把要解释的量编码进去，才是循环——本项目已明确规避（勘误纪律：A_GR 谱为物理模型断言，非从质量实验反推）
