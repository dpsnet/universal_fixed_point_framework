# 逆问题审计：物理层约束 → 范畴层自由度（F 核厚度）

**日期**：2026-11-27
**触发**：用户指出「静默信息逆向多解 ≠ 引力逆向多解」，要求把「从物理层逆向推出范畴层底层抽象」做成可核验的审计，而非类比挪用。
**结论前置**：物理层能推出「**必须有什么结构**」，不能推出「**结构取什么数**」。数值自由度欠定度 8/8，结构自由度覆盖度 6/6（但仅到存在性）。

## 0. 与静默逆向的严格区分

定理 7.23/7.24（EFT 的 IR→UV 重构）的多解来自**能标截断**：IR 观测不到 UV 自由度，投影核非平凡；唯一化条件是「完备静默信息」（s ≥ 1/2, r ≤ 1/10, γ ≥ 10, w ≤ 1/2）。

引力逆向**没有截断机制**——引力数据在边界内全部可见，这正是「处处相容」的另一面。两者多解成因不同，定理不可搬用。

更根本的一条已由库内结论固定：**静默是观测层概念（在 D 下是否可见），N_active 是生成层计数（是否生成物理自由度），两者不同域，不能互推**（`RESEARCH_STATE.md` L13663）。因此本审计不引用静默逆向的任何结论作为引力逆向的依据。

本审计的对象只有一件事：**逐条清点物理层给出的独立约束，与范畴层的独立自由度对比，算出核的厚度。**

## 3. 约束类型学

必须区分两类，否则欠定度会算错：

- **存在型**：只排除「缺少某结构」的候选，不固定取值。删掉某公设后若约束仍成立，该公设落在核内。
- **定值型**：钉具体数。只有它能减少数值自由度。

物理层给出的 6 条约束**全部是存在型**。这意味着它们能删候选、不能定值。

## 4. 欠定度计算

**数值意义**：8 个数值自由度 − 0 条定值型约束 = **欠定度 8**。全部欠定：物理层完全不能告诉 `N_active` 是 3 还是 4、`B` 是 15 还是 12。

**结构意义**：6 个结构自由度 − 6 条存在型约束 = **0**（恰好覆盖）。但覆盖只到「存在/形态」，不到「唯一取值」——C2 只说「必须可加」，不说「加法怎么复合」；C4 只说「必须有迹」，不说「迹在哪个域上」。

**注意**：6:6 这个整齐度可能是本次口径选择的产物（我把 F15/F16 单列才凑成 6）。它不构成证明，只登记为一个可复核的观察。

## 6. 关键结论（含一处循环的剔除）

> **【已被 §11 推翻，保留作修正轨迹】** 本节结论建立在「C2 的形式化触及范畴结构」这一假设上。R-b 机检（§10）证明 `DeviationBound` 的 import 闭包不含任何范畴模块，故「线性 ⟹ 预加范畴」只是语义推论，不是机检事实。结论以 §11 为准。

清点后，引力的约束力落在三处，但其中一处**不能算数**：

| 目标 | 强制来源 | 是否循环 | 结论 |
|:--|:--|:--|:--|
| F1 组合律 = 加法 | C2 `source_defect_linearity`（机证，不依赖谱交织） | 否 | **真·必要条件，注入点项被钉死** |
| F2 `timeLayerDim = 1` | C5 双法向（paper44 §5.3，不依赖谱交织） | 否 | **真·必要条件**（但仅在 `√g_00` 层严格） |
| F3 `T` 存在 / F4 谱交织 | C4 `m_i = m_g` | **是（且方向为充分条件）** | **零约束**：C4 形如 `T ⟹ m_i = m_g`，逆命题未证 |

**C4 的循环**：C4 本身的条件就是谱交织（`MassEquivalenceBridge` 的 6 个定理全部以 `intertwine` 为假设）。用 C4 去证明谱交织必要，等于用前提证明前提。因此上一轮「约束力全部指向 T 与谱交织」的说法**在这里被推翻**：不是指向那里，而是那个方向原本就测不到。

更准确地说：C4 的逻辑形式是 `intertwine ⟹ trace 相等`（**充分条件**）；其逆 `trace 相等 ⟹ ∃ intertwine` 未被证明。所以 C4 对「T 是否存在」的约束力**恰好为零**——它只说明「若有 T 则等质量」，不说明「等质量则必须有 T」。这也意味着 §8 的 R-c 不能做成「必要性骨架」，只能做成「充分性骨架」，否则会把充分条件误当必要条件。

**真正确定的结论只有一条，但很硬：**

> **「组合律 = 加法」不是指派，是被机证线性（`source_defect_linearity`，零 sorry）强制出来的必要条件。第 59 批定义的注入点两项里，这一项应当注销。**

`timeLayerDim = 1` 同理被 C5 强制，但 C5 的强度低一档：只有 [论文] 层级，且诚实边界写着「仅 `√g_00` 层严格」。所以它算「强提示」而非「钉死」。

**修正后的注入点口径**：由「两项 `{timeLayerDim = 1, 组合律 = 加法}`」变为——

- **`组合律 = 加法`：注销（由 C2 强制，不再是自由度）**
- **`timeLayerDim = 1`：保留，但降级为「被 C5 强提示」**
- 净效果：**注入点由两项降为一项，且这一项的强制来源弱一档**

**关于证伪通道**：C4 既然循环，就不能用它造通道。真正可用的通道来自 C2 的反面——但 C2 已机证，无法推翻。所以当前**没有**由引力数据给出的、针对 T 与谱交织的证伪通道。这条必须如实登记为「未获得」。

## 7. 对上一轮表述的修正

上一轮称「`n² = 2^n` 一元生成 3/4/5/15，是从物理层逆向推出的最底层」。本节审计否证了这句话的一半：

- `n² = 2^n` 的成立是**内部来源**（纯数论，框架自己给的），不是**逆向来源**。
- 引力约束完全不触及 F5–F8（全在核内）。逆向只能给结构，数值只能由框架内部给。

正确表述：**逆向给「必须有什么结构」，内部给「结构取什么数」。** 两者不可互相冒充。

4. 本审计不涉及静默逆向；两者不同域，不能互推。

## 11. 逆向的死结（本轮最终结论）

补充审计：全库 **39 个模块** import 了这些常数所在模块，其中包含 `BlackHoleBounce`、`HawkingSpectrum`、`KerrFiber`、`SpectralBundle/QuantumGravity`、`SuperfluidStiffness`、`CuprateDistribution`。所以「物理侧整体不用这些常数」不成立。

于是二分成立：

| 定理类型 | 是否含常数 | 逆向约束力 |
|:--|:--|:--|
| 能不依赖常数独立机检（C2/C3/C4） | 不含 | **零**：删它不变 |
| 依赖常数机检（黑洞 / Kerr / 量子引力等） | 含，且以之为假设 | **被污染**：用前提证前提 |

**二分穷尽。** 所以「从物理层逆向推出范畴层抽象」在**当前依赖图结构下结构性不可能**——不是信息不足，不是能标截断，而是：任何一条物理定理，要么与范畴层不相交（无约束），要么以范畴层为前提（循环）。

**这同时推翻 §6**：`source_defect_linearity` 的形式化是纯矩阵线性（`DeviationBound` 闭包不含任何范畴模块），「线性 ⟹ 预加范畴」是语义层推论，不是机检事实。

**若要让逆向可行，唯一切实的第一步**：造一个**共享符号**的模块——把范畴层的某个常数真正写进物理侧定理的**陈述**（而非注释）。在此之前，一切「逆向」都只是语义层叙事。

## 12. 本轮累计结论（三次修正后）

1. 静默逆向 ≠ 引力逆向（用户指正，成立）。
2. C4 是充分条件 ⟹ 对 `T` 存在零约束（§6）。
3. C2/C3/C4 的证明项与范畴层常数零相交 ⟹ 连「加法被强制」也推翻（§10 / §11）。
4. 净结论：**逆向不可行，原因是依赖图的二分结构，不是信息量不足**。（§13 补充：该二分**未被解除**，但已被局部穿透——见下。）
5. 本轮**没有产出新定理**。唯一的确定结构事实是：物理侧与范畴侧对这三个锚而言是**互不相交的子图**；跨界的那 39 个模块全是「使用常数」，没有一个「被常数约束」。
6. 正确的下一步由第 5 条直接给出：先造共享符号模块，再谈伴随。

**结论：是非题的答案是「能」。** 常数可以进陈述，全部等式零 sorry。派生的三条事实：

1. `B = catOrder² − 1 = 2^catOrder − 1 = 15` 第一次被同一条定理串起。此前 `3 × 5` 与 `n² − 1` 是两套并行叙事，现在机检确认两者数值同一。
2. `K₄/m = B²/32` 是本库**第一条陈述里同时出现范畴层常数与物理侧量的定理**。迭代关系因此变了：此前是「物理定理不含常数」，现在至少有一条含。
3. 但**方向未变**：`catOrder → windowSteps → K₄/m`。R-b 的二分**没有被解除，只是被局部穿透**，且穿透点正好落在二分允许的那半边（让常数进陈述）。

**诚实边界**：

- 「窗口长度为什么是 4（从而等于 `catOrder`）」仍是公设。模块只证明「一旦取定 `catOrder`，所有相关等式成立」，没有证明「物理必须用范畴阶」。
- `B = catOrder² − 1` 是**数值合流**，不是导出：`B` 的定义仍走 `ActiveLayers.card * N_total`，其中 3 与 5 是两个独立读法。第 63 批的四口径（15 / 12 / 9 / 6）不受影响，本模块只钉住 `N_active × N_total` 这一支。
- **逆向唯一性仍是空白**。下一步真正该攻的不是「再写几条等式」，而是「给定 `K₄/m` 的读数，能否反定 `catOrder`」。按现有结构答案应为**否**：读数 `225/32` 只对应 `n = 4` 这一支，`n = 2` 给的是 `(4−1)²/8 = 9/8`，不同 `n` 给出不同读数，但读数本身不携带「来自哪一层」的信息。要把「不可反推」从判断变成机检结论，需要一条**多解显式化**定理：构造两个不同的范畴参数赋值，使物理读数完全相同。这是 §14 的入口。

## 14. R-c″：逆向读数审计（机检裁决，预测被证伪）

§13 结尾留了一个**预测**：「构造两个不同的范畴参数赋值，使物理读数完全相同」。本节做机检裁决，结果**预测的前半被证伪**——在连续读数这一支上，读数唯一反定参数，不存在第二个赋值。

**产物**：`src/MUFPFormalization/ReverseReadoutAudit.lean`（14 theorem / 3 def / 0 sorry / 0 warning）。

### ① 连续读数唯一反定参数：成立

读数定义 `stepCoeff n = (2^n − 1)² / 2^(n+1)`，且 `deflectionStep4Coeff = stepCoeff catOrder`（`readout_eq`）。

机检链：

| 命题 | 内容 |
|:--|:--|
| `stepCoeff_succ_sub` | `f(n+1) − f(n) = (2·(2^n)² − 1) / (4·2^n)` |
| `stepCoeff_succ_gt` | 分子在 `2^n ≥ 1` 时恒正 ⟹ `f(n) < f(n+1)` |
| `stepCoeff_strictMono` | `StrictMono stepCoeff` |
| `stepCoeff_injective` | `Function.Injective stepCoeff` |
| `readout_recovers_order` | `stepCoeff n = K₄/m → n = catOrder` |
| `readout_recovers_four` | `stepCoeff n = 225/32 → n = 4` |

⇒ **「多解」预测在这一支上不成立**：读数 `225/32` 唯一反定 4 步窗口，没有第二个 n 给出同一读数。预测记录保留，不删。

### ② 离散读数 15 在层对路线下四解：成立

`routeLayerPair (1,15) = routeLayerPair (3,5) = routeLayerPair (5,3) = routeLayerPair (15,1) = 15`（`routeLayerPair_fiber_four`）；
`routeLayerPair_not_injective : ¬ Function.Injective routeLayerPair`；
`layer_route_underdetermined : ∃ p ≠ (3,5), routeLayerPair p = routeLayerPair (3,5)`。

⇒ 15 这个**数字**不携带「3 主动 + 5 总层」的语义：`(1,15)` 给出同一读数，语义完全不同。

### ③ 离散读数 15 在阶路线下唯一：成立

`routeOrder n = n² − 1`（ℝ 值口径）；`routeOrder_inj : n, m ≥ 1 ⟹ routeOrder n = routeOrder m ⟹ n = m`；`routeOrder_recovers_four : routeOrder n = 15 → n = 4`。

### 汇总裁决

`reverse_readout_verdict : Injective stepCoeff ∧ ¬ Injective routeLayerPair ∧ (阶路线在 n ≥ 1 上单射)`

`reversibility_is_route_dependent : (routeLayerPair (3,5) : ℝ) = routeOrder 4 ∧ ¬ Injective routeLayerPair ∧ (阶路线单射)`

**结论：同一个读数 15，走因子路线四解，走阶路线单解。逆向的可逆性由路线决定，不由读数决定。** 这是「逆向 = 约化，不是重构」的机检版本：读数能把参数压到唯一，压不出「参数从哪条路线产生」。

### 对第 63 批的直接后果

② 给「6 个交叉项」一个解释：15 在层对路线下有四个原像，任何从「15」直接读出层结构的尝试都注定多解。层语义（主动层 3、总层 5）只能来自 `isActive` 的定义，不能来自数值。这与第 63 批「层标号有限性是类型设计而非结构定理」同向。

### 诚实边界

1. **预测被证伪，记录保留**：§13 预期「读数相同 ⟹ 参数不同」可构造，机检在连续支上给出否定。
2. ① 只证「读数 ⟹ 窗口长度唯一」，**不证**「读数 ⟹ 范畴结构唯一」。窗口长度取 `catOrder` 仍是定义选择。
3. ③ 用 ℝ 值口径 `routeOrder : ℕ → ℝ`，因 ℕ 截断减法在 n = 0 处使 `0² − 1 = 1² − 1 = 0`；对 n ≥ 1 两者数值一致。这是口径选择，写明以免被读作偷换。
4. ② 的多解是算术事实，不是物理新发现。
5. 本模块不含任何「物理必须如此」的断言。

### 下一个可做

把 ② 与第 63 批的 `isActive` 计数接起来：证明四原像中**只有 `(3,5)` 满足层表判据**（第一分量 = `ActiveLayers.card` = 3，第二分量 = `N_total` = 5），即语义筛选在机检层把四解压到一解。这是「结构信息不在读数里、在判据里」的正面构造——比继续找多解更有价值。

## 15. R-c‴：语义判据把读数四解压到一解（正向构造）

§14 的结论是**负面**表述：「结构信息不在读数里」。本节把它翻成正向构造：把层语义写成判据，看它能否在四个原像里筛出唯一一个。

**产物**：`src/MUFPFormalization/SemanticFilterAudit.lean`（10 theorem / 1 def / 0 sorry / 0 warning）。

**判据**：`layerTable p := p.1 = ActiveLayers.card ∧ p.2 = N_total`，两个分量都取自库内定义，不自造常数。

| 命题 | 内容 |
|:--|:--|
| `active_layers_eq_filter` | `ActiveLayers = univ.filter isActive`——把「3」从字面量变成谓词筛选结果 |
| `active_by_predicate` | `(univ.filter isActive).card = 3`，与 `active_layers_count` 交叉验证 |
| `four_preimages_one_survivor` | `(3,5)` 通过；`(1,15)`、`(5,3)`、`(15,1)` 全部不通过 |
| `layer_table_pins` | `layerTable p ⟹ p = (3,5)` |
| `readout_plus_semantics_pins` | 读数单独不定解 ∧ 读数 + 判据 ⟹ 唯一 |
| `filter_compresses_four_to_one` | `¬ Injective routeLayerPair ∧ 加判据后唯一` |

**结论：读数 15 + 层表判据 ⟹ 唯一 `(3,5)`。** 「15」本身仍然不定解（`(1,15)` 给出同一读数），加判据后被压成一解。

### 四轮审计的定位（一张表）

| 轮次 | 模块 | 判了什么 | 结果 |
|:--|:--|:--|:--|
| R-b（§10–§11） | `scripts/rb_dep_audit.py` | 物理侧定理是否含范畴层常数 | 二分穷尽 ⟹ 逆向结构性不可能（负） |

### 对原始问题的最终答案

用户最初的问题是：范畴论到物理层断裂，能否从物理层逆向推出底层抽象本质、甚至完善范畴论。五轮机检后能给出的最精确答案：

> **逆向能到「参数」，不能到「判据」。**
> 给一条物理读数，若读数与范畴参数之间的映射已知，参数可从读数唯一反定（§14①、§15）。
> 但读数本身不携带「走的是哪条路线」的信息（§14②③）——判据必须由框架给出（§15 用 `layerTable`）。
> 所以「逆向完善范畴论」在可机检的范围内**只能做到参数层**；范畴结构（层表、`isActive` 的取舍）不能被物理读数生成。

这条与 §11 的结论一致，但比 §11 更强：§11 说「结构性不可能」，是因为当时没有任何一条物理定理含常数；§13 打通了一条，§14–§15 又在打通的这条上判定可逆性上限。**结论没变，但路径被完整走了一遍，且每一步都有机检锚。**

### 诚实边界

1. 本模块证「给定判据 ⟹ 唯一」，**不证**「判据为什么是这一条」。判据两分量仍是 `ActiveLayers` 与 `N_total` 的定义读法。
2. `active_layers_eq_filter` 只说明字面集合与谓词筛选重合，不给 `isActive` 的定义以独立根据。
3. 与第 63 批口径一致：「层标号有限性是类型设计而非结构定理」。
4. 四轮里 **R-b 与 R-c″ 的负面结论都没有被后来的轮次推翻**——只被限定到更窄的范围。这是有意保留的：负面结论被缩小范围，不等于被撤销。

## 16. R-a：物理命题强制范畴结构的显式引理

§13–§15 三批全是「读数 → 参数」。R-a 换问法：不问读数能反定什么，而问**物理命题本身强制范畴侧必须有哪一条结构**。每条都写成显式蕴含，物理侧前提摆在假设里，读者一眼能看见哪一半是物理、哪一半是范畴。

**产物**：`src/MUFPFormalization/PhysicsImpliesCategory.lean`（7 theorem / 0 sorry / 0 warning）。

### 三条

| 编号 | 蕴含 | 物理侧前提（假设） | 范畴侧结论 |
|:--|:--|:--|:--|
| A1 | `2^E = 2^nActive ⟹ E = nActive`（`deviationBound_exponent_pinned`） | 偏差界是**以 2 为基**的指数形式 | 指数 = 主动层数 |
| A1′ | `2^E = 8 ⟹ E = 3`（`deviationBound_three`） | 读到偏差界数值 8 | 同上，数值形式 |
| A2 | `B = 2^n − 1 ⟹ n = catOrder`（`branchCount_forces_order`） | 分支数取「2 的幂减一」形式 | 幂指数 = 范畴阶 |
| A3 | 任意 `f : ℕ → ℕ`，四原像取值相同（`readout_value_blind`、`four_preimages_same_readout`） | 读数只经乘积这一条通道 | **无**判别信息（负向） |
| A3′ | 不存在只凭读数分开 `(3,5)` 与 `(1,15)` 的函数（`no_readout_separates`） | 同上 | 同上 |

A2 的证明链是纯算术：`2^n − 1 = B = 15` ⟹ `2^n = 16 = 2^4` ⟹ 指数单射 ⟹ `n = 4`；用到的只有 `Nat.pow_right_injective` 与 `omega`，没有新公设。A1 同理。

### 裁定

1. **正向穿透确实存在，但只有两类入口：指数与幂。** A1 的入口是「基为 2 的指数」，A2 的入口是「2 的幂减一」。两者都不需要连续性、不需要截断机制——与 §14① 的连续读数通道（`stepCoeff`）是三条互不相同的穿透路径。
2. **这不解除 R-b 的二分。** A1 的前提「基为 2」在物理侧不是定理，是既有材料（静默/活跃二值分解、16 维表示）。所以 A1 的准确读法是「**若**偏差界是 2 的指数形式，**则**指数 = 3」——仍是一条带前提的蕴含，前提本身不带范畴内容。
3. **A2 与 §13 的 `B = n² − 1` 是同一数值的两种写法。** `silent_layers_eq_B`（`2^windowSteps − 1 = B`）与 `B_eq_catOrder_sq_sub_one`（`B = catOrder² − 1`）在 15 处合流；A2 只是把这条合流改写成「从幂形式反推指数」的方向。
4. **A3 把 §11 与 §15 接起来。** 结构不在读数的**任何**函数里（A3），而读数 + 判据唯一（§15）⟹ 判据不可从读数获得。这两条合起来才是完整的：逆向到参数可以，逆向到判据不可以。
5. **C3（`PhotonTopology`）没有可形式化的正向蕴含。** 该模块 8 个 import 全为 Mathlib，闭包内零范畴层常数（R-b 已机检）。此处如实登记为空缺，没有用 `: True` 充数。

### 与 §11 的关系（不变的部分）

§11 的二分是：能独立机检的定理 ⟹ 不含常数 ⟹ 逆向约束力零；依赖常数机检的定理 ⟹ 以常数为假设 ⟹ 被污染。R-a 没有推翻它，而是补上了第三种情形：**定理的形式本身（指数、幂）承载了常数**，既不需要以常数为假设，也不需要常数出现在陈述里——`2^E = 8` 里根本没有 `3`，但 `E` 只能取 3。

这是本轮唯一一个新东西。它说明 §11 的二分**不穷尽**：还有「形式即常数」这一类。但这一类要求物理侧的量天然是幂形式，所以它虽打开了一条缝，缝的宽度由物理侧的形式决定，不能由框架指定。

> **【§17 勘误】** 上面「本轮唯一一个新东西」一句**已被 §17 推翻**：同型定理（`catOrder_pinned_by_branch`、`pair_product_mer_iff`）在库里早已存在，A1/A2 是既有机制的实例，不是新机制。缝的实测宽度见 §17。

## 17. 「形式即常数」类的全库规模审计（自己的新意被证伪）

§16 把「定理的形式（指数、幂）承载常数」当作新发现，并断言「这是本轮唯一一个新东西」。本批用脚本扫全库，验证这个断言。结果**把断言证伪**：同型定理早就存在，A1/A2 只是既有机制的两个新实例。

**产物**：`scripts/form_constant_audit.py`（纯标准库，pyenv 3.11.8 执行）。

### 口径（两轮收紧，过程如实记录）

**第一轮（过宽）**：抽 `theorem`/`lemma` 陈述段（从 `theorem` 行到下一条含 `:=` 的行），判定「陈述里出现 `2 ^ <局部变量>` 或幂减一形式，且不含范畴常数名」。

- 总计 **5471** 条陈述，命中 **451** 条（8.2%）。
- 但 `CONST_NAMES` 漏了 `fixedPoint`、`powers`、`k_max`、`kMax`、`Nc`、`silenceUnit`、`nGen`、`powerBase`、`involution` 等框架常数 ⟹ 「陈述不含常数」判定失真。

**第二轮（补入框架常数后重跑）**：

| 指标 | 第一轮 | 第二轮 |
|:--|--:|--:|
| 陈述总数 | 5471 | 5471 |
| 形式候选 | 451 | **392**（7.2%） |
| 物理侧候选（模块直接 import 常数定义模块） | 23 | **12** |
| 数学侧候选 | 428 | 380 |

物理侧 12 条逐一判读后，真正构成「以形式钉住常数」的只有 4 条：

| 定理 | 陈述 | 判定 |
|:--|:--|:--|
| `BranchCountOrigin.catOrder_pinned_by_branch` | `(c−1)(c+1) = 2^c − 1 ⟹ c = 4` | **真钉住**，前提无常数 |
| `BranchCountOrigin.pair_product_mer_iff` | `(c−1)(c+1) = 2^c − 1 ↔ c = 4`（`c ≥ 3`） | 同上，iff 形式 |
| `ThreeInjectionCensus.exponential_weld` | `2^d = 2^c ⟹ d = c` | 机制型（指数单射），不钉具体值 |
| `ThreeInjectionCensus.card_eq_spaceDim_of_pow` | `2^d = 2^(card ActiveMorphismLayer) ⟹ d = card` | 前提含结构量（3），半污染 |

其余 8 条是纯算术恒等式或数值实例（`AlphaChain` 5 条、`BottTower.spinorDim_eq_pow`、`BranchCountOrigin.pair_product_eq_sq_sub_one`、`mer_pair_at_four`），没有自由变量被读数钉住，不属于这一类。

### 判决

1. **§16 的「新东西」不成立。** `catOrder_pinned_by_branch` 早已从「`(c−1)(c+1) = 2^c − 1`」这条纯形式推出 `c = 4`，与 §16 的 A2 同型。A2 只是把同一形式改写成 `B = 2^n − 1` 的写法，且前提里带 `B`，反而比原定理**更污染**。
2. **A2 的前提含 `B` ⟹ 它是「用前提证前提」。** §16 把 A2 列为正向穿透，口径过宽。按 §11 的标准，A2 应归入「污染」而非「穿透」。
3. **干净结论只有 4 条。** `pair_product_mer_iff`、`catOrder_pinned_by_branch`、`exponential_weld`，再加 §16 的**数值形式** A1′（`2^E = 8 ⟹ E = 3`，前提只有数字 8）。§16 的符号形式 A1（`2^E = 2^nActive ⟹ E = nActive`）陈述里含 `nActive`，按本口径同样归入污染——它的作用只是把 A1′ 的机制写成一般式，不构成独立的穿透。
4. **缝的实际宽度 = 4 条定理，且它们几乎同源。** `pair_product_mer_iff` 与 `catOrder_pinned_by_branch` 是同一算术事实的 iff 版与蕴含版；`exponential_weld` 是它们使用的引理的通用版。真正独立的「形式承载常数」入口只有**一个**：`(c−1)(c+1) = 2^c − 1` 这条一元生成方程。
5. **§11 的二分仍然成立，只是多一条脚注。** 能机检的定理要么不含常数（⟹ 逆向约束力零），要么含常数（⟹ 污染）；「形式承载」不是第三条路，而是**第二条路的变体**：形式里的数字（`2^c − 1` 的 `2`、`−1`）本身来自框架（幂基与静默位），不是在物理侧独立给定的。§16 说它「不需要以常数为假设」只对 A1 成立；对 `catOrder_pinned_by_branch` 类，形式本身就是框架约定的产物。

### 诚实边界

1. 审计是**句法级**的：正则匹配陈述文本，不是语义分析。命中数是下界，漏检（`where` 结构、多 `:=`、缩写定名）未计入。
2. 「物理侧」的定义沿用 R-b：模块**直接** import 常数定义模块。间接依赖未计入，故 12 这个数偏小。
3. 12 条的归类（4 条钉住 / 8 条恒等式）是人工判读，判读依据写在表中，可复核。
4. 本批**没有**新增 Lean 模块，全部是脚本 + 笔记；不产生新定理，只改口径。

## 18. 唯一干净入口的效力判定：钉数值 ≠ 钉结构（机检）

§17 把「形式承载常数」的独立入口收窄到**一个**：`(c−1)(c+1) = 2^c − 1 ⟹ c = 4`
（`BranchCountOrigin.catOrder_pinned_by_branch`）。本节判它的效力：它钉住的到底是
「数值 4」，还是「范畴阶 `catOrder` 这个结构」。

### 18.1 判据设计

三条判据，全部可机检，全部落在 `EntryEfficacyAudit.lean`

| ③ | 任一 `ℕ → ℕ` 函数在三个来源上取同值 | 只拿数值的判别力是否为零 |

## 19. R-c：充分性骨架的效力判定（交织 ⟹ 谱相等）——条件式成立，但前提更强

前十八节全是否定结论（§11 依赖图二分、§18 唯一入口只钉数值）。本节做**正向**尝试：
不问「能不能逆向」，而问「若物理侧真的给出交织条件 `A_GR · T = T · A_SM`，
它能不能把范畴侧的谱不变量钉住」。

模块 `IntertwineSufficiencyAudit.lean`（`MUFPF.IntertwineSufficiencyAudit`，
4 theorem / 1 def / 0 sorry / 0 warning）。

### 19.1 形式化设定

    Intertwines A B T  :≡  A * T = T * B          （n 维实方阵）

`A` = 引力侧 `A_GR`，`B` = 标准模型侧 `A_SM`，`T` = 谱交织。

### 19.2 机检结果

| 定理 | 内容 | 判定 |
|:--|:--|:--|
| `intertwine_trace_eq` | `T*S = 1 ∧ S*T = 1 ∧ Intertwines A B T ⟹ A.trace = B.trace` | 成立 |
| `intertwine_charpoly_eq` | 同前提 ⟹ `A.charpoly = B.charpoly`（**全谱转移**） | 成立 |
| `no_inverse_no_trace` | `n=1`、`A=1`、`B=0`、`T=0`：`Intertwines` 成立而 `trace 1 ≠ trace 0` | 反例成立 |
| `sufficiency_skeleton_verdict` | ① ∧ ③ | 骨架是条件式 |

证明链（两处同构）：`A = T·B·S`（由 `A·(T·S) = A`、结合律、交织移项），再
`charpoly(T·B·S) = charpoly(S·(T·B)) = charpoly((S·T)·B) = charpoly(1·B) = charpoly B`
（`Matrix.charpoly_mul_comm`、`mul_assoc`、`one_mul`）；迹链同法用 `Matrix.trace_mul_comm`。

### 19.3 判决

**骨架成立，但它的前提比「T 存在」更强。**

- 判① 成立：只要 `T` 有双侧逆，**整个特征多项式**（不止迹）从 `A` 搬到 `B`。
- 判③ 成立：`T = 0` 时交织照样成立（`1*0 = 0*0`），而迹不等。故「交织」自身不含逆。
- ⇒ 骨架的假设是「`T` 可逆」；框架内登记的只是「`T` 存在」（CONJECTURE，清单 C1）。
  可逆严格强于存在。R-c 把待证项**换成一个更强的待证项**，因此不构成
  「从物理侧推出范畴侧」的通路。

### 19.4 与主线的收敛

即使判① 完整成立（全谱转移），转移到的也只是**特征多项式 / 迹**这类数值型谱不变量。
§18 已机检：同一数值可有三个互不相同的结构来源。故「谱相等」不传递「这是哪个范畴结构」。

于是三节在同一处收敛：
- §11：不含常数 ⟹ 逆向约束力零；含常数 ⟹ 污染；
- §18：唯一干净入口只钉数值，不钉结构；
- §19：正向骨架能搬的也只是谱（数值型不变量），且前提更强。

**谱是数值层，结构不在谱里。** 这条现在是三处机检共同支撑的结论，而不是立场。

### 19.5 过程记录（三处实现订正）

1. `Intertwines` 初版写成 `def Intertwines {n : Type} (...) : Prop := A * T = T * B`，
   漏了 `[Fintype n] [DecidableEq n]`，矩阵乘法实例无法合成（`HMul` 合成失败）。
2. `rw [h]`（`h : Intertwines A B T`）不被接受——`rw` 要的是等式而非自定义谓词；
   先 `have hEq : A * T = T * B := h`（定义展开）再 `rw [hEq]`。
3. 反例的 `simp [Intertwines]` 未闭合；改为 `show 1 * 0 = 0 * 0` + `simp`，
   迹不等式改 `norm_num [Matrix.trace_one, Matrix.trace_zero]`。
4. `sufficiency_skeleton_verdict` 的 lambda 绑定 `m` 未使用触发 linter 警告，改 `_ _ _` 后 0 warning。

### 19.6 诚实边界

1. 只在 `Matrix n n ℝ` 上做，不在一般交换环/一般范畴上做：`charpoly_mul_comm`、
   `trace_mul_comm` 在 ℝ 上直接可用；非交换情形未覆盖。
2. 「双侧逆」用显式 `S`（`T*S = 1 ∧ S*T = 1`），不用 `IsUnit det`；两者在此设定下等价
   （`Matrix.mul_nonsing_inv` 已核存在），但本模块只证显式版。
3. 反例只给 `n = 1`——判③ 只需一个反例即可否掉无条件命题。
4. 「可逆严格强于存在」是元层判断（Lean 中未形式化「存在 vs 可逆」的强度比较），
   本模块只机检「可逆 ⟹ 转移」与「不可逆 ⟹ 可能失效」两侧。
5. 本节不新增常数、不新增公设。


## 20. R-d：`G_N` ↔ `Δλ_min` 桥的效力判定（系数 = 谱隙平方的倒数 ⟹ 0 比特）

§1 清单里 C1 是唯一还带「[论文]」标记的引力侧约束：

    G_N = 18(2+√3)·(Δλ_min)²/M_Pl²          （paper35 定理 2.1；paper49 §6.1）

模块 `GNBridgeAudit.lean`（`MUFPF.GNBridgeAudit`，7 theorem / 3 def / 0 sorry / 0 warning）。

### 20.1 先承认：两个因子来自两条不同的链

| 因子 | 值 | 来处 |
|:--|:--|:--|
| `c_Planck` | `18(2+√3)` | Cl(1,7) 旋量纤维系数（paper35 / paper49 §6.1） |
| `Δλ_min` | `(√3−1)/6` | SU(2) Casimir 谱 `λ₂−λ₁`（paper20 定理 6.1） |

两者**不是**从同一公式拆出来的，所以「乘积 = 1」不是同义反复——它是两条独立链的数值在 1 处
精确对上。这是**真结果**，本节的判决不针对它的真值。

### 20.2 机检三件

| 编号 | 定理 | 内容 |
|:--|:--|:--|
| ① | `coefficient_eq_inv_gap_sq` | `18(2+√3) = 1/(Δλ_min)²`（精确相等）—— 两因子互锁 |
| ② | `gn_normalization_lambda_blind` | `∀ λ ≠ 0`，`(1/λ²)·λ² = 1` —— 系数取成倒数时乘积恒为 1，与谱隙值无关 |
| ③ | `gn_one_does_not_pin_gap` | `∀ C > 0`，`∃ λ > 0`，`C·λ² = 1` —— `G_N = 1` 只钉乘积，钉不住因子 |

辅证：`dlmin_pos`（`Δλ_min > 0`）、`dlmin_sq_eq`（`Δλ_min² = (2−√3)/18`）、
`bridge_product_one`（`c_Planck·Δλ_min² = 1`，即 `gnInternal = 1`）。

### 20.3 判决

**C1 这条桥是 0 比特。**

1. 由 ①：系数与谱隙平方**互为倒数**（精确恒等式，非拟合）。故谱隙一旦由 Casimir 链定住，
   系数就被代数强制为 `1/Δλ_min²`；系数一旦由 Cl(1,7) 定住，谱隙就被强制为 `√(1/c_Planck)`。
   「两条链在 1 处对上」这句陈述**没有自由度可供它失败**。
2. 由 ②：把系数写成「谱隙平方的倒数」后，乘积恒为 1，对**任意**非零谱隙成立。
   所以这条公式不是「谱隙取 `(√3−1)/6`」的物理证据——换任何 λ，同样写法照样给 1。
3. 由 ③：内部自然单位制下 `G_N·M_Pl² = 1` 是**归一化**（不是测量）。归一化只钉乘积、钉不住因子。
   外部 CODATA 反解 `Δλ_min = √(G_N M_Pl²/(18(2+√3)))` 只是把同一个数重算一遍，
   不构成独立检验（无自由参数可被否证）。

### 20.4 对主问题的意义

主问题是「能否从物理层逆向推出范畴层」。C1 曾被视为引力侧对谱层的**约束**。
本判定的结论：C1 只能给出「两个已由其它链确定的数互锁」这一条一致性事实，
**不含可供逆向的结构信息**。

与前三批同向：§11（含常数 ⟹ 污染）、§18（钉数值不钉结构）、§19（谱相等不传递结构）、
§20（互锁不等于约束）——四次机检，四种不同的失败方式，指向同一句：
**数值对上，不等于结构被推出。**

### 20.5 过程记录

1. `dlmin`、`cPlanck`、`gnInternal` 三个 def 首轮报 `noncomputable` 缺失（`Real.sqrt` 与
   `Real.div` 非可计算），补 `noncomputable` 后 0 error。
2. 证 `Δλ_min > 0` 一度想用 `nlinarith` 从 `(√3)² = 3` 硬推；改用 `Real.lt_sqrt`
   （`a < √b ↔ a² < b`，需 `0 ≤ a`）直接给 `1 < √3`，再 `linarith`。
   `Real.lt_sqrt'` 在 v4.34.0-rc2 中**不存在**（已 `#check` 核实）。
3. 正性证明用 `dlmin_sq_eq` 归到 `(2−√3)/18`，由 `Real.sqrt_lt'`（`√x < y ↔ x < y²`，需 `0 < y`）
   给 `√3 < 2`，再 `div_pos` + `linarith`。

### 20.6 诚实边界

1. 本节不否认 `18(2+√3)·((√3−1)/6)² = 1` 是两条独立链的精确会合，也不否认它作为自洽性结果的价值。
   判决只针对它的**约束力 / 逆向力**。
2. ① 的「互锁」是代数事实；把它进一步说成「两条链其实是一条」需要额外论证，本模块不做。
3. ③ 只证「归一化钉不住因子」，不证「外部 CODATA 支持或不支持该框架」——那是 σ_score 口径的事，
   本模块不涉及任何外部数据。
4. 本节不新增常数、不新增公设。

## §22 R-f：`T` 存在的地位审计 —— 「存在」与「效力」互斥

四处真断裂已判三处（谱交织 §19、`G_N` 桥 §20、α⁻¹ §21），本节判最后一处：
谱交织条件里的 `T` 是否存在（框架登记为 CONJECTURE）。
机检模块 `IntertwinerExistenceAudit.lean`（13 theorem / 1 def / 0 sorry / 0 warning / 220 行）。

### 22.1 判据从哪来

- §19（R-c）已机检：「交织 + T 可逆 ⟹ 全谱转移」。其载体 `MassEquivalenceBridge.trace_eq_of_intertwine`
  的前提是 `T * U = 1 ∧ U * T = 1`——**双侧逆**。故框架登记「T 存在」时，真正需要的不是单个存在量词，
  而是「T 可逆且非平凡」。
- 框架自己给了 T 的身份：`notes/04_lorentz_gravity/φθ谱交织指认_等变平均旋转不变.md` L183——
  T = 弥漫层间结构的谱测度强制平均。`ForceAverageIsotropy.lean` 已机检该算符的全部代数性质
  （幂等 `groupAverage_idempotent`、自伴随 `groupAverage_orthogonal_projection`、保迹
  `groupAverage_trace_eq`、保交织 `groupAverage_preserves_intertwine`、反射精确湮灭
  `groupAverage_reflection_annihilates`）。
- 于是「T 存在」不是空猜想，它有具体候选。本节判这个候选能不能承担桥的职责。

### 22.2 判①：谱不交 ⟹ 唯一交织子是 0（机检）

`sylvester_diag_forced_zero`：2×2 对角算符，`diag(a₁,a₂)·X = X·diag(b₁,b₂)` 的第 (i,j) 条目
给出 `(a_i − b_j)·x_ij = 0`；四条非等条件成立 ⟹ `X = 0`。

框架实例 `no_T_between_gapped_spectra`：`A_GR = diag(0,2)`、`A_SM = diag(1, 1 + Δλ_min)`，
谱距取框架谱隙；`dlmin_in_unit_interval` 机检 `0 < Δλ_min < 1` ⟹ 唯一解 `X = 0`。

判决：**「需要转移」的场合（两侧谱不同）恰恰不存在非零 T。** 在这一场合 C1 不是待证的猜想，
而是可被否证的命题。

### 22.3 判②：T 存在 ⟹ 转移退化，或迹桥失效（机检）

| 子情形 | 机检命题 | 结果 |
|:--|:--|:--|
| 同谱（a₁ = b₁） | `diag_intertwine_witness` | `E₁₁` 是非零交织子 |
| 见证质量 | `E11_ne_zero` / `E11_singular` | 非零，且 `det = 0`（奇异，§19 不适用） |
| 部分重合 | `partial_overlap_no_trace_transfer` | `trace A_GR ≠ trace A_SM` ⟹ 迹桥前提不可满足 |
| 退化全同 | `trivial_case_T_exists` | `A_GR = A_SM = 1` 时 `T = F ≠ 0` 交织 |

同谱时非零 T 存在，但「同谱」意味着 `A_GR = T·A_SM·T⁻¹` 只是把同一张谱换个写法——§19 已判无信息。
部分重合时 T 存在（一个本征值对上），但迹不等 ⟹ `trace_eq_of_intertwine` 的结论不成立。
两行合起来：**T 存在的场合，桥要么无信息、要么直接断。**

### 22.4 判③：框架自己的 T 不可逆（机检）

1. `groupAverage_F_zero`：`F = diag(1,−1)` 无迹 ⟹ `groupAverage F = ((1−1)/2)·1 = 0`（引 `groupAverage_isotropy`）。
2. `framework_T_kernel_nontrivial`：`F ≠ 0 ∧ groupAverage F = 0` ⟹ 强制平均的核非平凡。
3. `framework_T_no_left_inverse`：若存在 `inv` 满足 `∀ T, inv (groupAverage T) = T`，
   则 `inv 0 = F` 与 `inv 0 = 0` 同时成立 ⟹ `F = 0`，与 `F ≠ 0` 矛盾。

与既有资产合流：幂等 + 自伴随 ⟹ 强制平均是**正交投影**；正交投影核非平凡 ⟹ 不可逆。

判决：**§19 的转移引理在框架自己给出的 T 上恒不适用。** 登记的是「T 存在」，给出来的是一个不可逆的投影。

### 22.5 判决表与四处断裂的统一形态

| 场合 | 非零 T | 转移（迹/谱） | 框架能用吗 |
|:--|:--|:--|:--|
| 谱不交 | 无（唯一解 0） | — | 要转移但没有 T |
| 谱相同 | 有（可取可逆） | 有但无信息（同谱换写法，§19） | 有 T 但没有新信息 |
| 部分重合 | 有（奇异） | 迹不等 ⟹ 迹桥断 | 有 T 但桥断 |
| 框架的 T（强制平均） | 有（投影） | 无逆 ⟹ §19 不适用 | 有 T 但无转移资格 |

**一句话：「T 存在」与「桥有信息」互斥。**

四处真断裂至此全部判完，且同型：

| 节 | 断裂 | 登记形态 | 实际需要 | 判词 |
|:--|:--|:--|:--|:--|

| §21 | α⁻¹ | 「α⁻¹ 达标」 | 可预言 | 装配恒真（读数反推参数） |
| §22 | `T` 存在 | 「T 存在」 | 可逆且非平凡 | 存在不等于可逆 |

共同结构：**把一个功能性要求（可逆、独立、可预言）登记成了一个存在性/数值性命题；
机检能证明后者，前者则落空。** 这是 §11「二分穷尽」的另一面——不是「常数进不了定理」，
而是「功能性要求进不了存在性命题」。

## §23 R-g：修补方案的判决 —— 「改成 T 可逆」是循环；平均型 T 秩亏一半

§22 判完四处断裂并给出共同形态（功能性要求被登记成存在性/数值性命题）。最自然的反驳是：
「那就把登记写对」——把谱交织条件从「`∃ T`，交织」改成「`∃ T` 可逆，交织」。本节判这个修补有无效力。
机检模块 `IntertwinerRepairAudit.lean`（10 theorem / 2 def / 0 sorry / 0 warning / 198 行）。

### 23.1 判据从哪来

修补方向看似唯一：§19 的转移引理前提是**双侧逆**（`T * U = 1 ∧ U * T = 1`），§22 判「T 存在」不足以承担桥，
故「补上可逆」是唯一自然的加强。要判它，只需三条：

1. 修补后的前提是否**已蕴含**结论？若蕴含，桥不能证新东西 ⟹ 循环。
2. 在需要桥的框架实例上，修补后的登记**是否有解**？若无解，补的是空条件。
3. 框架自己的 `T`（强制平均）为什么不可逆——是「差一点」还是结构性？若结构性，换构造也救不了。

### 23.2 判①：可逆 + 交织 ⟹ 迹相等（实矩阵版，自机检）

`trace_eq_of_invertible_intertwine_real`：`T * U = 1`、`U * T = 1`、`T * B = A * T` ⟹ `trace B = trace A`。

证明链：`B = 1*B = (U*T)*B = U*(T*B) = U*(A*T) = U*A*T`；再用迹的循环性
`trace (U*A*T) = trace (T*(U*A)) = trace (T*U*A) = trace (1*A) = trace A`。

（ℂ 版已有 `MassEquivalenceBridge.trace_eq_of_intertwine`；本节在 ℝ 上自行重证，避开共轭转置记号，
不新增假设、不依赖复结构。）

### 23.3 判②：修补 = 把结论搬进前提，桥退化为同义反复

`repair_is_circular` 是两支合取：

| 支 | 命题 | 判词 |
|:--|:--|:--|
| 递推 | 任意 2×2 实矩阵，可逆 + 交织 ⟹ `trace A_SM = trace A_GR` | 前提的代数后果就是桥的结论 |
| 逆否 | `trace A_SM ≠ trace A_GR` ⟹ 不存在可逆交织子 | 迹不等处修补直接无解 |

所以「补上可逆」之后，迹桥的结论**从前提里就能读出**：修补不是加强桥，而是把桥写成恒等式。
信息量 0 比特——这与 §20 的「互锁不等于约束」是同一个病的两种表现。

### 23.4 判③：框架谱隙实例上，修补后的登记是假命题

`framework_repair_unsolvable`：不存在 `T U` 使 `T*U = 1 ∧ U*T = 1 ∧ T*diag(1, 1+Δλ_min) = diag(0,2)*T`。

拆解：两侧迹分别为 `tr diag(0,2) = 2` 与 `tr diag(1, 1+Δλ_min) = 2 + Δλ_min`，差 `Δλ_min > 0`
（`GNBridgeAudit.dlmin_pos`）⟹ 与判① 的迹相等矛盾。

即：**在需要桥的场合（两侧谱不同），修补后的登记不是「待证」，而是「假」。**

### 23.5 判④：平均型 T 的完整形态（对任意 2×2，不只是对称）

`groupAverage_general_form T`（`A := !![0,1;−1,0]`）：

```
groupAverage T = ((T₀₀ + T₁₁)/2) • 1 + ((T₀₁ − T₁₀)/2) • A
```

对**任意**实 2×2 矩阵成立，是纯代数恒等式（不依赖群表示论）。读出三点：

1. 像空间 ⊆ `span{1, A}`，维数 2——4 维矩阵空间里只剩 2 维。
2. 对称无迹分量（`F = diag(1,−1)`、`S = !![0,1;1,0]` 张成的那一块）被**整块**投影掉。
3. 对称输入时 `T₀₁ = T₁₀` ⟹ 反对称项归零 ⟹ `(tr T/2)·1`——这正是既有的 `groupAverage_isotropy`，
   本节形态顺带给出了它的完整解释。

### 23.6 判⑤：秩亏一半，不是「差一点可逆」

| 机检命题 | 内容 |
|:--|:--|
| `groupAverage_F_zero'` | 转引 §22：`groupAverage F = 0`（核元素一） |
| `groupAverage_offDiag_zero` | 由 ④ 直接读出：`tr S = 0`、`S₀₁ − S₁₀ = 0` ⟹ `groupAverage S = 0`（核元素二） |
| `offDiag_ne_zero` / `F_ne_offDiag` | `S ≠ 0`；`F ≠ S`（(0,0) 条目分别取 1 与 0 ⟹ 线性无关） |
| `no_left_inverse_two_kernels` | 若存在左逆 `inv`（`∀ T, inv (groupAverage T) = T`），则 `inv 0 = F` 且 `inv 0 = S` ⟹ `F = S`，矛盾 |

核至少 2 维、像 2 维 ⟹ **秩 2/4**。与 §22 判③ 的单点结论（`F` 被湮灭）相比，这里给出机制：
核不是「一个方向」，而是对称无迹的**一整块**；换哪个 `T` 都不改变像空间维数 2。

### 23.7 判决表：修补方向穷尽

| 修补方向 | 机检载体 | 判决 |
|:--|:--|:--|
| 改登记为「`∃ T` 可逆 ∧ 交织」 | `repair_is_circular` | 循环：结论 ⟸ 前提，0 比特 |
| 在框架谱隙实例上试该登记 | `framework_repair_unsolvable` | 无解（迹差 `Δλ_min > 0`，命题为假） |
| 换构造：用强制平均当 `T` | `groupAverage_general_form` + `no_left_inverse_two_kernels` | 秩 2/4，结构性不可逆 |
| 保持原登记「`∃ T` 交织」 | §22 判①（`sylvester_diag_forced_zero`） | 谱不交时唯一解 `T = 0` |

四条合起来：**这一处桥没有可修补的形态**——改登记变循环、实例上无解、换构造秩亏、原登记为空。
判词不是「登记写得不够强」，而是**所需对象在需要它的场合不存在**。

与其余三处的关系：这张表的四行其实就是同一处的四层剥离——条件式成立（§19）、
存在与效力互斥（§22）、修补循环且实例无解（§23）、构造型候选秩亏（§23 判④⑤）。
连同 §20（常数互锁 0 比特）、§21（读数反推参数、装配恒真），**四处真断裂全部判为「不可修补」，
且每条判据都是机检的**。

由此 R 系列的可判定工作到此收束：剩下的不是「再找一条桥」，而是两个需要理论裁决的出口（须用户拍板）：

- 出口 A：把功能性要求**本身**当公设——直接公设「`∃ T` 可逆，`A_GR = T·A_SM·T⁻¹`」，
  并接受其代数后果（`A_GR` 与 `A_SM` 相似 ⟹ 同谱 ⟹ 桥不带新信息），即承认它只是重述。
- 出口 B：承认该桥在当前登记下不可闭合，把它从「定理位」降为「开放登记」，与 §22 的 C1 一并挂账。

两者都不产生新预测，区别只在账面上如何记——本笔记不替用户选。

## §24 R-h：救桥的其余路线穷尽 —— 桥的载体必然在「数值」与「结构」之间二选一

§23 只封死了一条修补方向（把登记改成「`∃ T` 可逆」）。既然「找更多可能」是硬要求，
本节把**其余可想的救桥路线逐条判死**：商掉核（R-h1）、换不变量（R-h2）、换载体（R-h3）。
机检模块 `QuotientBridgeAudit.lean`（11 theorem / 1 def / 0 sorry / 0 warning / 204 行）。

### 24.1 为什么要判这三条

- **R-h1 商掉核**：这是框架自己主张的方向（「完善范畴论 = 商掉 `F` 的核」）。既然 `T` 不可逆，
  就不要求逆，只要求它在**商空间**上诱导相等——若成立，桥就能带非零信息。
- **R-h2 换不变量**：§23 判① 说「可逆交织 ⟹ 迹相等」，太强；很自然会想「换 `det` 或特征多项式就绕开」。
- **R-h3 换载体**：不比算子，比**不变量子空间**（子空间格）。谱不交时若无公共子空间，这一路直接死；
  若有，则它可能传递「结构」而非「数值」。

### 24.2 R-h1 商桥：商恰 2 维，且框架实例上仍不等

| 机检命题 | 内容 | 读出什么 |
|:--|:--|:--|
| `one_rotGen_indep` | `1` 不是 `A = !![0,1;−1,0]` 的标量倍（(0,0) 条目 1 vs 0） | 商像的基底无关 ⟹ 两个系数唯一 |
| `groupAverage_eq_zero_iff` | `groupAverage T = 0 ⟺ tr T = 0 ∧ T₀₁ = T₁₀` | **核恰是对称无迹**（`F`、`S` 张成），维数 2 |
| `groupAverage_coords_of_eq` | 商上同像 ⟹ `tr` 和与旋度 `T₀₁−T₁₀` 逐一相等 | **可达信息 ≤ 2 个实标量** |
| `eq_of_coords_eq` | 两个坐标逐一同 ⟹ 商像相同 | 合起来：商上恰 2 个自由度 |
| `framework_quotient_still_fails` | `groupAverage (diag(0,2)) ≠ groupAverage (diag(1, 1+Δλ_min))` | 两侧旋度均 0、迹 2 vs 2+Δλ ⟹ 第 1 坐标就不等 |

判决：**商桥不是「无信息」，而是「至多 2 比特」，且框架实例连这 2 比特里的第 1 个都对不上。**
这是本轮唯一有正面产出的结论——「桥的可达信息维数」第一次变成可数命题（2），
而不是笼统的「无信息」。但它在需要桥的那个实例上仍然失败。

### 24.3 R-h2 换不变量：`det` 与 `trace` 被同一前提同时吞掉

`det_eq_of_invertible_intertwine_real`：`T` 双侧可逆、`T·B = A·T` ⟹ `det B = det A`。
证明走 `B = U·A·T` 与 `det(U·T) = 1`（`Matrix.det_mul` 的乘性）。

`invariant_swap_circular` 把它与 §23 的迹版并列：**同一个前提同时给出 `det` 相等和 `trace` 相等**。
2×2 下迹 + 行列式决定特征多项式 ⟹ 换任何不变量都是同一处循环的另一种写法，
不是新桥。判决：**0 比特**。

### 24.4 R-h3 换载体：公共不变量子空间存在，但标值不同

| 机检命题 | 内容 |
|:--|:--|
| `yAxis_ne_zero` | `w = ![0;1] ≠ 0` |
| `common_invariant_yAxis` | `diag(0,2)·w = 2·w` 且 `diag(1, 1+Δλ_min)·w = (1+Δλ_min)·w` |
| `eigenvalue_on_common_subspace_differs` | `2 ≠ 1 + Δλ_min`（用 `Δλ_min < 1`） |

也就是说：**子空间层面的「对应」确实存在**——`y` 轴同时是两侧的不变子空间；
但它上面的标值一个是 `2`、一个是 `1+Δλ_min`。换载体传得动「哪个方向不变」，
传不动「这个方向上本征值是多少」。

判决：**钉结构，不钉数值 —— 0 个数值比特。**

## §25 R-i：引入更强的载体 —— 阻塞解除了，判别力没换来

### 25.1 判据先立：什么才算「更强」

§24 的结论是「现有载体集合里数值与结构从不同时被同一载体传递」，并把出口①写成
「允许新载体（比 2×2 矩阵 + 迹/行列式更强，如带分级结构的载体）」。若要这一条有内容，
必须先说清「更强」指什么。本批取的判据是：

> 载体 `C` 强于 2×2 矩阵，当且仅当 `C` 能在**相似等价类之外**还持有内容，
> 即存在 `A ≃ A′`（可逆交织）而 `C` 能区分它们。

按此判据，「更大矩阵」不算更强（4×4 若仍只靠相似类，判据自动退化），
只有**在同一对象里并存多个层**才算：两侧不再是「被要求相似」，
而是「被要求共存」。

最小可行形态就是 `Fin 2 ⊕ Fin 2` 上的 4 维分层载体：

```
        ┌ A_物理    B_耦合 ┐
  C  =  │                  │       A,D：两侧层数据；B：层间耦合；C：反向耦合
        └ C_反向    D_范畴 ┘
```

这同时是框架「弥漫层间结构」最省事的代数化——只多一个耦合块，不多一个维度。

### 25.2 判①：迹相加律 —— §23 的阻塞是被「换掉要求」解除的

§23 的死结是：可逆交织 ⟹ `trace A = trace A′`，而框架实例 `trace A_GR = 2`、
`trace A_SM = 2 + Δλ_min`，故无解。

在分层载体上这条不再出现，机制是机检过的恒等式：

> **`trace (blk A B C D) = trace A + trace D`**

对角块相加，交叉块不贡献（它们不在对角线上）。于是「相等」变成了「相加」：

| 载体 | 桥对两侧的要求 | 框架实例（迹 2 与 2+Δλ_min） |
|---|---|---|
| 2×2 矩阵（§23） | 存在可逆 `T` 使两侧**相似** | 逆否：迹不等 ⟹ 无解 |
| 分层载体（§25） | 存在载体使两侧**共存** | 恒可满足：迹为 `4 + Δλ_min` |

**这一步是本批唯一实质性的收获，也必须看清它收获的是什么**：不是桥被修好了，
而是桥的**要求被换成了更弱的一个**（相似 → 共存）。弱化要求当然容易满足——
这也正是判别力流失的入口。

### 25.3 判②：框架谱隙实例确实装得进去

机检的具体载体：

> `blk (diag 0 2) E₁₂ 0 (diag 1 (1+Δλ_min))`，迹 `= 4 + Δλ_min`

其中 `E₁₂ = !![0,1;0,0]` 是耦合块的一张显式选片。层数据可逐条读出
（`blk (inl i)(inl j) = A i j`、`blk (inr i)(inr j) = D i j`），
反向耦合取 `0` 时左下块恒零（上块三角）。所以两侧的谱隙核数据（`0,2` 与 `1,1+Δλ_min`）
**没有被载体吞掉**，只是被搬进了一个更大的对象里。

### 25.4 判③：耦合块是自由参数 —— 这就是全部代价

三条机检：

1. 同一组层数据 `(A_GR, A_SM)`，耦合块取 `0` 与取 `E₁₂`，载体**不同**
   （`(inl 0, inr 1)` 条目分别为 `0` 与 `1`）；
2. 耦合块可在**任意** 2×2 矩阵上取值，都给出一个载体（`coupling_arbitrary`）；
3. 载体**区分**不同的耦合块，即不是「对所有 `B` 给出同一对象」
   （`carrier_distinguishes_coupling`）。

三条合起来的话是：**耦合块是真实自由度，但不是被推导出来的自由度。**
它对两侧数据没有任何约束，两侧数据对它也没有任何约束。所以：

> 更强载体把「欠定」换成了「任意」。
> §24 说「现有载体钉不住两样东西」；§25 说「更强载体装得下两样东西，
> 但装它们的那个自由度不是推导出来的」。

差别是实质的：前者是**无解**，后者是**解太多**。解太多与无解在判决力上是同一件事——
桥不再告诉我们任何关于 `B` 的事情。

### 25.5 三种「更强」候选，本批只取了一种

| 候选 | 加强方式 | 本批状态 |
|---|---|---|
| 分层（`2+2` 分块，实矩阵） | 两侧由「相似」改为「共存」，多一个耦合块 | **已机检**（本批） |
| 谱测度当载体（`(算子, μ)` 对） | 把谱分布本身变成一等对象 | 未做（需测度论层，且 §20 已证 `Δλ_min` 只是谱隙的倒数改写，换载体不改 0 比特） |
| 带分级标签（`(算子, 层标号)`） | 载体持有坐标系/层选择 | 未做；但 §25.4 的自由参数结论对它是同型的（标签若不受算子约束，即自由参数） |

第二、三行不是「留着以后做」，而是**按 §25.4 的机制已被判为同型**：
凡加强方式是「多挂一个不受两侧数据约束的分量」，结论都是「装得下、钉不住」。
真正的例外只有一种：那个新分量**本身由框架内生钉住**。

### 25.6 出口回写

§24.6 三个出口：

- ① **允许新载体** —— 本批已试，判决见上：可行，但换来的是自由度而非判决力。
- ② **接受二分**（数值走 §18、结构走 §24，承认无单一桥）—— 现在是唯一**没有代价**的出口。
- ③ **放弃该桥** —— 与 §23 两出口合并，仍开放。

也就是说：本批不是把①关掉，而是把①的成本算清了。①成立，但它成立的方式是
「承认 `B` 是新增自由参数」——那等于把「桥」重述成「一个带自由参数的嵌入」，
而嵌入总是存在的。这在物理上是空话，除非 `B` 有独立判据。

### 25.7 下一个开口：钉住 `B` 需要什么

要让分层载体有判决力，只有一条路：**`B` 必须是内生的**，即由框架的既有结构决定，
而不是任取。这需要回答一个问题：

> `B` 的 4 个实参数中，哪几个有框架内的身份？若一个也没有，则 `B` 只能登记为自由参数。

而 `B` 的自然身份候选，恰好是**层标号/层间权重**这一类对象——也就是 §63 判为
「口径四选一（15/12/9/6）、选择无结构依据」的那一处。所以本批的实际去向是：

> 「引入更强载体」把问题从「载体不足」搬到了「层标号无内生判据」。
> 不是解决了，是**换了个位置**。

这条搬移是可检验的：若后续能给出 `B` 的内生判据（不需要外部数据），
分层载体就能从「任意」变成「被钉住」，桥才真正复活；若给不出，
则①与②等价，应直接采②。

## §26 R-j：`B` 的四口径之争 —— 不是写法之争，是四个不同对象的指认之争

### 26.1 为什么先攻这里

§25 把桥的复活条件压在「`B` 必须有内生判据」，而 `B` 的身份候选落在 §63 判为
「口径四选一、选择无结构依据」的那一处。所以攻 §63 是唯一能动的钥匙。本轮要回答的
是一个可判定问题：

> 15、12、9、6 是同一个对象的四种写法（那就有「统一口径」的活可干），
> 还是四个不同对象（那就没有写法可统一，「选哪个」是物理指认）？

答案在机检里已经定了：**是后者**。

### 26.2 每个值都有自己无歧义的组合对象

| 值 | 组合对象 | 机检定理 | 形态（`c = 4`） |
|---|---|---|---|
| 15 | `Fin 4` 的**非空子集**数 | `fifteen_is_nonempty_subsets` | `2^4 − 1 = c² − 1` |
| 12 | `Fin 4` 的**有序不同对**数（`offDiag`） | `twelve_is_ordered_distinct_pairs` | `c² − c` |
| 9 | `Fin 3` 上的**有序对**（含自对） | `nine_is_active_ordered_pairs` | `(c−1)² = nActive²` |
| 6 | `Fin 4` 上的**无序对**数 | `six_is_unordered_pairs` | `C(4,2)` |

四件事分别是：层的「非空组合」、层的「有序推进」、活跃层之间的「有序对」、层的「无序对」。
它们不是同一个数的四种记法，而是四个可分别定义的计数对象。

### 26.3 15 的读法已被封口，6 反而有两条链

两处不对称，都必须写明：

**15 是唯一被恒等式封口的**。`BranchCountOrigin.pair_product_mer_iff` 已经证明

> `(c−1)(c+1) = 2^c − 1 ⟺ c = 4`（`c ≥ 3`）

所以「层对乘积 `3 × 5`」与「非空子集 `M₄ = 2^4 − 1`」**不是两条竞争路线**，
在 `c = 4` 处它们是同一个数的同一个恒等式两侧（`branch_eq_mer` 即此）。15 没有歧义。

**6 反而有两条互不蕴含的链**（`six_has_two_chains`）：

- `C(4,2) = 6`（层的无序对数）；
- `2·nActive = 2·3 = 6`（活跃层的二倍）。

两条都只用框架整数，却指向不同的组合对象。于是同一个 `6` 可以有两套自洽的生成叙述——
这是四值中唯一一个「同值不同链」的值。

**这构成一个反直觉的结论**：§63 把 6 当作「15 的一个竞争口径」，
但从生成链唯一性看，6 是四值里最不唯一的那一个；15 才是最干净的。

### 26.4 §63 判词的机制化修正

§63 的原判是「口径四选一（15/12/9/6），选择无结构依据」。
本批把这句话落到机制上，并拆成两句：

1. **四个值两两不等**（`four_counts_pairwise_distinct`：15≠12≠9≠6 六个不等式全部机检），
   故它们**不可能**是同一对象的四种写法——「统一口径」这件事根本不存在；
2. 真实的问题是**「分支数该数什么」**：数非空组合、数有序推进、数活跃有序对、数无序对，
   是四个不同的物理问题。框架内没有判据在这四个问题之间做选择。

所以 §63 的结论不是「选择无依据所以存疑」，而是更硬的一条：
**四个候选各自都是干净的，缺的是「分支数」这个概念的物理定义。**
这把问题从「口径规范」移到了「概念指认」——而这不是 Lean 能判的。

### 26.5 同名不同物：`B` 的两种身份必须拆开

§25 的 `B` 是耦合块（`2×2` 矩阵），自由度 `Fintype.card (Fin 2 × Fin 2) = 4`；
§63 的 `B` 是计数（15/12/9/6）。机检：

> `coupling_dim_not_a_count`：`4 ≠ 15 ∧ 4 ≠ 12 ∧ 4 ≠ 9 ∧ 4 ≠ 6`

两处 `B` 无一相符 ⟹ 它们是不同对象，**禁止互推**。这一步是防守性的，但必要：
若沿用同一记号，很容易把「耦合块自由度 4」读成「分支数 15」，从而把 §25 的
自由度当成被 §63 钉住的量。

### 26.6 一个未判候选（不登记为定理）

数值上 `4 = catOrder`。耦合块的自由度 4 与范畴阶 4 撞上，看上去像「层间耦合的维数
就是范畴阶」。**本批不把它登记为定理**，理由：这只是四个四的偶合
（`2×2` 条目数、`catOrder`、`spaceLayerDim + timeLayerDim`、层标号），
没有任何一条能说明「耦合维数应当等于范畴阶」。若要做，必须给出独立判据，
否则就是把巧合升格为定理。此条留作未判候选。

### 26.7 对 §25 的回写

§25 说：更强载体装得下两样东西，但耦合块自由，要复活须给 `B` 内生判据。
本批的回答是：**这个判据不可能来自 §63**，因为 §63 那一处本身是四个不同对象的指认问题。
于是链条更清楚了：

- 桥的阻塞（§23）→ 载体不足（§24）→ 更强载体只带自由度（§25）
  → 自由度要的判据落在 §63 → §63 是四个不同对象的物理指认 → **指认不是机检问题**。

四节连起来的话是：**逆推桥的失败，逐层剥到最后，剥出的是一个概念定义缺口**
（「分支数」到底数什么），而不是一条可以补的数学引理。这与 §11 的「结构性不可能」
不同：§11 说的是依赖图；这里说的是**语义**。

## §27 R-k：口径的条件式闭合 —— 「与 `σ⁻¹` 同形」把四选一降到唯一

### 27.1 `§26` 之后唯一能动的地方

§26 把四口径拆成四个不同组合对象，并判定「选哪个」是概念指认问题。但那一步留下一个
没试过的可能：**四个候选里也许只有一个与框架已定的常数形式相容**。

框架的 `σ⁻¹ = 15` 在 `SigmaFormOrigin` 里写作 `f² − 1`（不动点 ± 1 之积，`f = 4`，
`sigmaInvSq`）。若要求 `B` 与 `σ⁻¹` **共用同一函数形式**，则四选一是否被筛掉三个？
答案是：是。

### 27.2 四个候选在 `c = 4` 处各是什么形式

| 候选 | 关于 `c` 的形式 | 与 `c² − 1` 同形 |
|---|---|---|
| 15 | `c² − 1` | **是** |
| 12 | `c² − c` | 否 |
| 9 | `(c−1)²` | 否 |
| 6 | `2·(c−1)` | 否 |

机检（`other_calibers_have_own_forms` + `only_fifteen_matches_sigma_form`）：
`nActive·catOrder = c² − c`、`nActive² = (c−1)²`、`2·nActive = 2(c−1)`，
而 `nActive·nTotal = c² − 1` 且 `12, 9, 6` 各自 `≠ c² − 1`。

这一步比 §26 更细：§26 说「四个值不同」，本批说「四个值的形式也不同」——
排除 12/9/6 不是排除「同一个数的小数位差」，而是排除**不同多项式族**。

### 27.3 条件式闭合

`caliber_pinned_by_form` 机检：

> `B = sigmaInvSq catOrder`（`15 = c² − 1`），且 `12 / 9 / 6` 都不等于 `sigmaInvSq catOrder`，
> 并附 `sigmaInvSq 4 = 15`。

于是判决可写成一条条件句：

> **接受「`B` 与 `σ⁻¹` 同形（都是不动点 ± 1 之积）」⟹ `B = 15` 唯一；不接受 ⟹ 仍是四选一。**

这是本主线第一次给出 `B` 的**正面依据**——不是「无依据」，而是「依据是一条形式约束」。
它的地位必须说清：**形式约束本身是理论裁决项，不是定理**。

### 27.4 与 §53 是同一条裁决

`§53 / SigmaFormOrigin` 对 `σ⁻¹` 自己的裁决原文是：

> 「`σ⁻¹ = f² − 1` 这条函数形式，要么由『必须是不动点 ± 1 之积』这条对称性决定，
> 要么仍是建模选择。」

本批把这个「要么」从常数原样搬到了 `B` 上，并证明搬过去之后**变成一个可判的相容性筛**：
形式约束一按，四选一立刻降为唯一。所以 §63 的开放项（「口径四选一，无结构依据」）
现在有两种结束方式：

- **结束方式甲**：承认「同形」这条形式约束 ⟹ `B = 15` 被钉住，§63 关闭（留下一项
  形式公设，与 §53 合并计一项）；
- **结束方式乙**：不承认形式约束 ⟹ §63 保持开放，`B` 仍是四选一，
  §25 的耦合块判据仍缺。

**本批不替用户选甲或乙。** 但已经把选择代价摆平：甲 = 多一条形式公设、少一个开放项；
乙 = 不新增公设、留一个开放项。

### 27.5 对 §25 的回写：耦合块还是没判据

要说清楚边界，避免读者误以为桥复活了：

- 本批钉住的是 **`B_计数`（= 15）**，且是**条件式**钉住；
- §25 的 **`B_耦合`（2×2 矩阵块，自由度 4）** 仍无判据——`4 ∉ {15,12,9,6}`（§26.5），
  两者同名不同物，`B_计数` 被钉住**不传递**到 `B_耦合`。
- 所以桥的状态不变：载体装得下两侧，耦合块自由。本批只是把「分支数」这一处的
  判断条件化了，没有给耦合块提供依据。

若要把这条条件式依据接到耦合块上，需要的是一条**独立**的指认（例如「层间耦合的
自由度就是分支数」），而这条指认目前没有——`4 = catOrder` 那个数值巧合已在 §26.6
明确不入定理。

### 27.6 未判项（须用户裁决）

1. 形式约束「`B` 与 `σ⁻¹` 同形」是否接受（= 上面的甲/乙）。
2. 若接受，这条形式公设与 §53 的 `σ⁻¹` 形式裁决是否合并为**一条**公设——
   合并则框架公设数 +1（不是 +2），这是 §53 留下的账。

## §28 R-l：耦合块的 4 个自由参数逐一对上框架内已有对象

§25 的判决是：分层载体把「欠定」换成「任意」，耦合块 `B`（`2×2` 实矩阵）的 4 个实参数
不由两侧数据约束。§27 又只条件式钉住了 `B_计数`。剩下来的是一个具体问题：

> `B` 的 4 个实参数，能不能**逐个**对上框架里已经存在的对象？
> 若 4 个都对上，则「自由参数」是误判；若只部分对上，缺口就落在剩下的那几个上。

本批把这个问句机检化：`src/MUFPFormalization/CouplingDecompAudit.lean`
（158 行 / 7 theorem / 0 def / 0 sorry / 0 warning / 8119 B），命名空间
`MUFPF.CouplingDecompAudit`，import `IntertwinerRepairAudit`（复用 `rotGen`、`offDiag`、
`groupAverage_general_form`、`trace_eq_of_invertible_intertwine_real`）。

### 28.1 判①：4 参数确实逐一对上了已有基元

用库内已有的四个基元作分解：

```
  M = α·1 + β·F + γ·S + δ·A
```

| 参数 | 读出 | 基元 | 框架内已有对象 |
|---|---|---|---|
| `α` | `(M₀₀+M₁₁)/2` | `1` | 单位元 / 迹的一半 |
| `β` | `(M₀₀−M₁₁)/2` | `F = diag(1,−1)`（`Isotropy.F`） | 分谱差（与 `Δλ_min` 同类型） |
| `γ` | `(M₀₁+M₁₀)/2` | `S = !![0,1;1,0]`（`offDiag`） | 对称非对角（层间对称混合） |
| `δ` | `(M₀₁−M₁₀)/2` | `A = !![0,1;−1,0]`（`rotGen`） | 反对称生成元（`SO(2)`） |

`decomp_reconstruct` 对任意 `2×2` 实矩阵给出上式的重建恒等式（`ext` + `fin_cases` ×4 + `ring`）。
四个读出公式直接由基元结构给出，因此「每个参数都有一个库内身份」成立。

**这一步就把「4 个自由参数」的说法纠正了一半**：它们不是四个无名的数，
而是「标量 / 分谱差 / 对称混合 / 反对称旋转」四个已命名机制各取一个系数。

### 28.2 判②：框架自带的平均把对称无迹的 2 维整块抹掉

`avg_kills_symmetric_traceless : groupAverage (β • F + γ • offDiag) = 0`。
`F`、`S` 张成的是「对称无迹」2 维，而 `groupAverage` 正是朝 `1` 与 `rotGen` 的方向做投影——
所以 `β·F + γ·S` 整块入核。等价地 `avg_keeps_alpha_delta`（即抄录 `groupAverage_general_form`）：

```
  groupAverage M = ((M₀₀+M₁₁)/2) • 1 + ((M₀₁−M₁₀)/2) • rotGen
```

⇒ 4 参数经一次平均降到 2：只剩 `α`（单位方向）与 `δ`（生成元方向）。

### 28.3 判③：剩下的两个参数性质相反

- **`α` 是相似不变量**。`alpha_survives_similarity`：给定可逆交织对（`T·U = U·T = 1`，
  `T·M' = M·T`），有 `(M'₀₀+M'₁₁)/2 = (M₀₀+M₁₁)/2`。证明走 §23 既有的
  `trace_eq_of_invertible_intertwine_real` + `trace_fin_two_eq` + `linarith`。
  推论：`α` 在相似类上取常值，**不可能携带基的信息**，它是「数值型」参数。
- **`δ` 逃出相似类**。`delta_escapes_similarity` 给具体见证：
  `M' = S = !![0,1;1,0]`（`δ = 0`）、`T = !![1,1;0,1]`、`U = !![1,−1;0,1]`、
  `M = T·S·U = !![1,0;1,−1]`（`δ = −1/2`）。三处乘积 `T·U = 1`、`U·T = 1`、`T·S = M·T`
  逐条机检，结论 `−1/2 ≠ 0` 由 `norm_num` 判死。
  推论：`δ` 是「结构型」参数——**方向**由 `A`（`rotGen`）钉住，**大小**由基的选择决定。
  数值侧另有旁证：同一 `S` 在 `T = !![1,0;2,1]` 下 `δ = 2`、在 `T = diag(1,3)` 下 `δ = −4/3`
  （`$env:TEMP\delta_probe.py`，numpy；仅作旁证，不进 Lean）。

### 28.4 判④：逐一对上的净结果

`coupling_decomp_verdict` 把 ①②③ 合成一条四重合取。判决是：

> 4 参数 → 2 个（平均）→ 方向有身份（`A`）+ 大小无判据（`δ`），另有一个基无关的自由标量（`α`）。
> **耦合块能同时持有「数值型」与「结构型」两样东西，但两者的「大小」都没有判据。**

这是 §24 结论在耦合块内部的**原样复现**，不是破解。但它同时**修正了 §24 的判词**：

- §24.5 原来写的是「现有载体集合里数值与结构从不同时被同一载体传递 ⟹ 载体不足」；
- 本批显示，耦合块 `B` 恰恰**能**同时持有两类量（`α` 数值型 + `δ` 结构型），

1. `α` 在**任意可逆变换**（`GL(2,ℝ)`）下不变——转引 §28 的 `alpha_survives_similarity`；

## §39 R-w：一般分块行列式（Schur 补）——§24「`det` ⟹ 0 比特」是**有条件**的判词

**本批定性**：补上 §38 留下的开口 `DET_4x4_BLOCK_LAW` 的完整版（`C ≠ 0` 的一般情形），并因此**反向修正** §24 的一条判词。

### 39.1 一般律（机检）

`Mathlib` 已有 `Matrix.det_fromBlocks₂₂`（`LinearAlgebra/Matrix/SchurComplement.lean` L384，需 `[Invertible D]`）：

> `det (fromBlocks A B C D) = det D · det (A − B·⅟D·C)`

`SchurCarrierAudit.lean` 落两条：

- `blk_eq_fromBlocks_gen`：`blk A B C D = Matrix.fromBlocks A B C D`（**任意**四块，不限 `C = 0`）。
  §38 的 `blk_eq_fromBlocks` 只是 `C = 0` 特例。
- `det_blk_schur`：`det (blk A B C D) = det D · det (A − B·⅟D·C)`（`D` 可逆）。

这是 §38 三角律 `det (blk A B 0 D) = det A · det D` 的上位律。

### 39.2 关键读数：耦合 `B` 只从 `A − B·⅟D·C` 一项进入

一般律的右端里 `B` 只有一个入口，且**与 `C` 相乘**。于是

- `C = 0` ⟹ 该项退化为 `A` ⟹ `B` 完全消失（`one_way_det_blind`：一般层数据下
  `det (blk A B 0 D) = det (blk A B' 0 D)`，对任意 `B, B'` 相同）。
- `C ≠ 0` ⟹ `B` 进入读数（`det_not_blind_when_reverse_nonzero`：同一组层数据 `A = D = 1`、`C = 1` 下，
  `B = 1` 给 `det = 0`（`det_sees_coupling_zero`），`B = 0` 给 `det = 1`（`det_sees_coupling_unchanged`））。

### 39.3 判决一：§38 的「载体 `det` 恒零」有两个**独立**零点

框架实例 `blk A_GR B 0 A_SM`（`A_GR = diag(0,2)`、`A_SM = diag(1, 1+Δλ_min)`）中：

1. `A_GR` 奇异 ⟹ `det A_GR = 0`，层数据被清零；
2. `C = 0` ⟹ `B` 根本不进公式，耦合被清零。

两者各自都能给出 `0`。`framework_det_zero_via_schur` 用 Schur 律复算了这个 `0`（与 §38 的三角律同值、同因）。
所以 §38 那句「可乘量被奇异因子清零」只说对了一半：**另一半是 §25 把反向块设成 `0` 这个构造选择**。

### 39.4 判决二（修正 §24）：`det` 不是普遍「0 比特」，而是「1 个混合标量」

§24 判「换不变量 `det` ⟹ 0 比特，逃不掉」。本批机检显示这条判词**以单向下耦合为载体前提**。
若载体换成双向耦合（`C ≠ 0`），`det` 会随 `B` 变，读到的不是 `0`，而是

\[
\det D \cdot \det(A - B\,\mathrm{⅟}D\,C)
\]

一个**把层数据与耦合乘在一起**的标量。所以 `det` 的问题不是「读不到」，而是「读到的是乘积」——
它既不纯（分层与耦合不可分离），也不分（一个实数），因此在桥的作用上仍是 0 比特，但**理由换了**：
不是免疫，而是混叠。

### 39.5 诚实边界

1. 一般律只在 `D` 可逆时成立（`det_fromBlocks₂₂` 的固有前提）；`A` 侧对称版 `det_fromBlocks₁₁` 需 `[Invertible A]`，
   框架里 `A_GR` 奇异，故本批不用。
2. 见证用的是最简载体（`A = D = 1`），**不是**框架实例。
3. 框架实例的双向版本数值（`det = det A_SM · det(A_GR − B·⅟A_SM·C)` 具体等于多少）**未算**，
   登记开口 `TWO_WAY_FRAMEWORK_DET`——须先显式构造 `⅟A_SM` 并算出 `A_GR − B·⅟A_SM·C` 的 2×2 行列式。
4. 不声称「1 个混合标量能承担桥」；能否从中拆出 `2` 与 `2+Δλ_min` 未测。
5. 本批不新增公设、不新增常数；`⅟A_SM` 的可逆实例只依赖 `Δλ_min > 0`（`framework_sm_det_ne_zero`）。

### 39.6 与 §25 的接口

§25 之所以能「造出」分层载体，正是因为允许 `C` 与 `B` 各自独立赋值；当时取 `C = 0` 是为简化，
而 §36–§38 的 `det` 判据全建立在这个简化上。本批把它翻过来：**简化项恰好是 `det` 唯一的信息通道**，
堵死它 `det` 就是常数。这是「载体不足」（§24 判决）在行列式语言下的重述：
不是 `det` 无能，是载体只给了一条单向边。

## §40 R-x：双向载体上的框架 `det` 实值——§39 开口 `TWO_WAY_FRAMEWORK_DET` 收口

**本批定性**：§39 把 `det` 的一般律写到符号层就停（`det D · det(A − B·⅟D·C)`），框架实例的**数值**没出。本批把 `⅟A_SM` 显式算出来，取两组耦合见证，把框架双向载体的 `det` 钉死。

### 40.1 `⅟A_SM` 显式（机检）

`invOf_diag2_sm`：`⅟(diag(1, 1+Δλ_min)) = diag(1, (1+Δλ_min)⁻¹)`。

走法不依赖 Mathlib 的对角逆引理，而是 `invOf_eq_right_inv` + 自建的逐条目乘法律 `diag2_mul_diag2`（`diag(a,b)·diag(c,d) = diag(ac, bd)`），辅以 `diag2_sub_diag2`、`diag2_one_one`。这是 §36–§39 那条教训（先检索 Mathlib）的反向应用：此处 Mathlib 的对角逆引理要 `[Invertible v]` 的点态实例与 `diagonal` 表示，绕道自建反而更短。

### 40.2 两组耦合见证的 `det` 实值（机检）

框架实例固定 `A_GR = diag(0,2)`、`A_SM = diag(1, 1+Δλ_min)`：

| 耦合 `(B, C)` | `det (blk A_GR B C A_SM)` | 闭式 |
|---|---|---|
| `B = C = 1`（恒等） | `−1.24402` | `1 − 2·(1+Δλ_min) = −1 − 2Δλ_min` |
| `B = C = diag(1,0)`（第一槽投影） | `−2.24402` | `−2·(1+Δλ_min)` |
| `C = 0`（§38 单向载体，对照） | `0` | `0` |

机检定理：`framework_two_way_identity`、`framework_two_way_projection`、`framework_two_way_det_ne_zero`、`framework_two_way_det_depends_on_coupling`、`two_way_carrier_verdict`。数值已用 `numpy` 独立复核（`Δλ_min = (√3−1)/6 ≈ 0.122008`，三行两项逐一吻合，`trace = 4.122008 = 4 + Δλ_min` 亦吻合）。

### 40.3 判决一：§38 的「载体 `det` 恒零」只在单向载体上成立

同一层数据、同一 `A_SM`，只把反向块 `C` 从 `0` 换成恒等，`det` 就从 `0` 跳到 `−1.244`；换成第一槽投影，跳到 `−2.244`。**非零，且随耦合选择变**（两值相差 1）。

所以 §38「`det` 这条路两级全死」应精确为：**在 §25 那个 `C = 0` 的载体上全死**。换载体 `det` 是活的——这与 §39 的抽象结论（`C ≠ 0` ⟹ `B` 进入读数）在框架实例上完全一致，本批只是把它落到具体数字。

### 40.4 判决二：`det` 活着，但读到的是乘积而非可分数据

两组值都能写成「`A_GR` 的非零对角元 `2`」与「`det A_SM = 1+Δλ_min`」的乘积：

- 投影耦合：`−2·(1+Δλ_min)` —— 系数 `−2` 就是 `A_GR` 的 `2`；
- 恒等耦合：`1 − 2·(1+Δλ_min)` —— 其中 `2·(1+Δλ_min)` 同源，余下常数 `1` 来自 `det A_SM` 的 `1` 与 `⅟A_SM` 的对角 `(1+Δλ_min)⁻¹` 相乘。

也就是说，`det` **只能**以「`2` × `(1+Δλ_min)`」这种乘法的形式同时碰到两个层数据；它给不出 `2` 与 `2+Δλ_min` 的**加法可分**读数——后者只有 `trace` 有（§38：`trace = 4 + Δλ_min`）。桥要的正是可分性（要能读出「两侧迹不同」这件事本身）。

故本批判决：

> `det` 路线的阻塞理由由 §38 的「恒零/免疫」改写为「**可读但混叠**」：它能随耦合变、能非零，但给出的永远是乘积；不能把 `2` 与 `2+Δλ_min` 分开，因此不承担桥。

这与 §24 的「换不变量 `det` ⟹ 0 比特」在**结论**上一致（仍是 0 比特的作用），在**理由**上不同（不是读不到，是读到的不可分）。§39 已预告这一改写，本批给出数值证据。

### 40.5 诚实边界

1. 只测两组耦合见证；一般 `(B, C)` 的闭式仍然只有 §39 的符号律（含 `⅟D`），本批不出普遍数值表。
2. 这两组耦合是**见证**而非框架内生耦合。`B, C` 的内生判据仍属 §26–§27 的未决悬案（`B_计数` 四口径、`B_耦合` 无判据），故 `−1.24402` / `−2.24402` 不得读作「框架预言」。
3. `⅟A_SM` 的显式值只对这一实例成立（`A_SM = diag(1, 1+Δλ_min)`），不推广到一般可逆对角块以外的情形。
4. 未检查 `det` 与 §31 四值耦合（`1, −1, A, −A`）的交叉：本批的 `B` 不取 §31 的量化四值，故「量化后的双向载体 `det`」仍为开口 `TWO_WAY_QUANTIZED_DET`。
5. 无新公设、无新常数；`Δλ_min > 0` 是唯一用到的外部事实（`dlmin_pos`）。
