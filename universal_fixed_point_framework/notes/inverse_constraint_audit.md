# 逆问题审计：物理层约束 → 范畴层自由度（F 核厚度）

**日期**：2026-11-27
**触发**：用户指出「静默信息逆向多解 ≠ 引力逆向多解」，要求把「从物理层逆向推出范畴层底层抽象」做成可核验的审计，而非类比挪用。
**结论前置**：物理层能推出「**必须有什么结构**」，不能推出「**结构取什么数**」。数值自由度欠定度 8/8，结构自由度覆盖度 6/6（但仅到存在性）。

## 0. 与静默逆向的严格区分

定理 7.23/7.24（EFT 的 IR→UV 重构）的多解来自**能标截断**：IR 观测不到 UV 自由度，投影核非平凡；唯一化条件是「完备静默信息」（s ≥ 1/2, r ≤ 1/10, γ ≥ 10, w ≤ 1/2）。

引力逆向**没有截断机制**——引力数据在边界内全部可见，这正是「处处相容」的另一面。两者多解成因不同，定理不可搬用。

更根本的一条已由库内结论固定：**静默是观测层概念（在 D 下是否可见），N_active 是生成层计数（是否生成物理自由度），两者不同域，不能互推**（`RESEARCH_STATE.md` L13663）。因此本审计不引用静默逆向的任何结论作为引力逆向的依据。

本审计的对象只有一件事：**逐条清点物理层给出的独立约束，与范畴层的独立自由度对比，算出核的厚度。**

## 3. 约束类型学

必须区分两类，否则欠定度会算错：

- **存在型**：只排除「缺少某结构」的候选，不固定取值。删掉某公设后若约束仍成立，该公设落在核内。
- **定值型**：钉具体数。只有它能减少数值自由度。

物理层给出的 6 条约束**全部是存在型**。这意味着它们能删候选、不能定值。

## 4. 欠定度计算

**数值意义**：8 个数值自由度 − 0 条定值型约束 = **欠定度 8**。全部欠定：物理层完全不能告诉 `N_active` 是 3 还是 4、`B` 是 15 还是 12。

**结构意义**：6 个结构自由度 − 6 条存在型约束 = **0**（恰好覆盖）。但覆盖只到「存在/形态」，不到「唯一取值」——C2 只说「必须可加」，不说「加法怎么复合」；C4 只说「必须有迹」，不说「迹在哪个域上」。

**注意**：6:6 这个整齐度可能是本次口径选择的产物（我把 F15/F16 单列才凑成 6）。它不构成证明，只登记为一个可复核的观察。

## 6. 关键结论（含一处循环的剔除）

> **【已被 §11 推翻，保留作修正轨迹】** 本节结论建立在「C2 的形式化触及范畴结构」这一假设上。R-b 机检（§10）证明 `DeviationBound` 的 import 闭包不含任何范畴模块，故「线性 ⟹ 预加范畴」只是语义推论，不是机检事实。结论以 §11 为准。

清点后，引力的约束力落在三处，但其中一处**不能算数**：

| 目标 | 强制来源 | 是否循环 | 结论 |
|:--|:--|:--|:--|
| F1 组合律 = 加法 | C2 `source_defect_linearity`（机证，不依赖谱交织） | 否 | **真·必要条件，注入点项被钉死** |
| F2 `timeLayerDim = 1` | C5 双法向（paper44 §5.3，不依赖谱交织） | 否 | **真·必要条件**（但仅在 `√g_00` 层严格） |
| F3 `T` 存在 / F4 谱交织 | C4 `m_i = m_g` | **是（且方向为充分条件）** | **零约束**：C4 形如 `T ⟹ m_i = m_g`，逆命题未证 |

**C4 的循环**：C4 本身的条件就是谱交织（`MassEquivalenceBridge` 的 6 个定理全部以 `intertwine` 为假设）。用 C4 去证明谱交织必要，等于用前提证明前提。因此上一轮「约束力全部指向 T 与谱交织」的说法**在这里被推翻**：不是指向那里，而是那个方向原本就测不到。

更准确地说：C4 的逻辑形式是 `intertwine ⟹ trace 相等`（**充分条件**）；其逆 `trace 相等 ⟹ ∃ intertwine` 未被证明。所以 C4 对「T 是否存在」的约束力**恰好为零**——它只说明「若有 T 则等质量」，不说明「等质量则必须有 T」。这也意味着 §8 的 R-c 不能做成「必要性骨架」，只能做成「充分性骨架」，否则会把充分条件误当必要条件。

**真正确定的结论只有一条，但很硬：**

> **「组合律 = 加法」不是指派，是被机证线性（`source_defect_linearity`，零 sorry）强制出来的必要条件。第 59 批定义的注入点两项里，这一项应当注销。**

`timeLayerDim = 1` 同理被 C5 强制，但 C5 的强度低一档：只有 [论文] 层级，且诚实边界写着「仅 `√g_00` 层严格」。所以它算「强提示」而非「钉死」。

**修正后的注入点口径**：由「两项 `{timeLayerDim = 1, 组合律 = 加法}`」变为——

- **`组合律 = 加法`：注销（由 C2 强制，不再是自由度）**
- **`timeLayerDim = 1`：保留，但降级为「被 C5 强提示」**
- 净效果：**注入点由两项降为一项，且这一项的强制来源弱一档**

**关于证伪通道**：C4 既然循环，就不能用它造通道。真正可用的通道来自 C2 的反面——但 C2 已机证，无法推翻。所以当前**没有**由引力数据给出的、针对 T 与谱交织的证伪通道。这条必须如实登记为「未获得」。

## 7. 对上一轮表述的修正

上一轮称「`n² = 2^n` 一元生成 3/4/5/15，是从物理层逆向推出的最底层」。本节审计否证了这句话的一半：

- `n² = 2^n` 的成立是**内部来源**（纯数论，框架自己给的），不是**逆向来源**。
- 引力约束完全不触及 F5–F8（全在核内）。逆向只能给结构，数值只能由框架内部给。

正确表述：**逆向给「必须有什么结构」，内部给「结构取什么数」。** 两者不可互相冒充。

1. C1–C6 的「⟹ 范畴必有 X」全部是 **[衔接]**：物理事实是硬的（C2/C3/C4 机检），但「所以范畴必须如此」这一步未证。

3. 6:6 覆盖度可能是口径产物，不作为结论使用。
4. 本审计不涉及静默逆向；两者不同域，不能互推。
5. §6 已就地剔除 C4 的强制力，`T` 与谱交织落回「循环区/未判定」。真正的出路是找到一条**不依赖谱交织**的物理约束来强制它——当前没有；在找到之前，这两项不得计入「必需」。

## 11. 逆向的死结（本轮最终结论）

补充审计：全库 **39 个模块** import 了这些常数所在模块，其中包含 `BlackHoleBounce`、`HawkingSpectrum`、`KerrFiber`、`SpectralBundle/QuantumGravity`、`SuperfluidStiffness`、`CuprateDistribution`。所以「物理侧整体不用这些常数」不成立。

于是二分成立：

| 定理类型 | 是否含常数 | 逆向约束力 |
|:--|:--|:--|
| 能不依赖常数独立机检（C2/C3/C4） | 不含 | **零**：删它不变 |
| 依赖常数机检（黑洞 / Kerr / 量子引力等） | 含，且以之为假设 | **被污染**：用前提证前提 |

**二分穷尽。** 所以「从物理层逆向推出范畴层抽象」在**当前依赖图结构下结构性不可能**——不是信息不足，不是能标截断，而是：任何一条物理定理，要么与范畴层不相交（无约束），要么以范畴层为前提（循环）。

**这同时推翻 §6**：`source_defect_linearity` 的形式化是纯矩阵线性（`DeviationBound` 闭包不含任何范畴模块），「线性 ⟹ 预加范畴」是语义层推论，不是机检事实。

**若要让逆向可行，唯一切实的第一步**：造一个**共享符号**的模块——把范畴层的某个常数真正写进物理侧定理的**陈述**（而非注释）。在此之前，一切「逆向」都只是语义层叙事。

## 12. 本轮累计结论（三次修正后）

1. 静默逆向 ≠ 引力逆向（用户指正，成立）。
2. C4 是充分条件 ⟹ 对 `T` 存在零约束（§6）。
3. C2/C3/C4 的证明项与范畴层常数零相交 ⟹ 连「加法被强制」也推翻（§10 / §11）。
4. 净结论：**逆向不可行，原因是依赖图的二分结构，不是信息量不足**。（§13 补充：该二分**未被解除**，但已被局部穿透——见下。）
5. 本轮**没有产出新定理**。唯一的确定结构事实是：物理侧与范畴侧对这三个锚而言是**互不相交的子图**；跨界的那 39 个模块全是「使用常数」，没有一个「被常数约束」。
6. 正确的下一步由第 5 条直接给出：先造共享符号模块，再谈伴随。

**结论：是非题的答案是「能」。** 常数可以进陈述，全部等式零 sorry。派生的三条事实：

1. `B = catOrder² − 1 = 2^catOrder − 1 = 15` 第一次被同一条定理串起。此前 `3 × 5` 与 `n² − 1` 是两套并行叙事，现在机检确认两者数值同一。
2. `K₄/m = B²/32` 是本库**第一条陈述里同时出现范畴层常数与物理侧量的定理**。迭代关系因此变了：此前是「物理定理不含常数」，现在至少有一条含。
3. 但**方向未变**：`catOrder → windowSteps → K₄/m`。R-b 的二分**没有被解除，只是被局部穿透**，且穿透点正好落在二分允许的那半边（让常数进陈述）。

**诚实边界**：

- 「窗口长度为什么是 4（从而等于 `catOrder`）」仍是公设。模块只证明「一旦取定 `catOrder`，所有相关等式成立」，没有证明「物理必须用范畴阶」。
- `B = catOrder² − 1` 是**数值合流**，不是导出：`B` 的定义仍走 `ActiveLayers.card * N_total`，其中 3 与 5 是两个独立读法。第 63 批的四口径（15 / 12 / 9 / 6）不受影响，本模块只钉住 `N_active × N_total` 这一支。
- **逆向唯一性仍是空白**。下一步真正该攻的不是「再写几条等式」，而是「给定 `K₄/m` 的读数，能否反定 `catOrder`」。按现有结构答案应为**否**：读数 `225/32` 只对应 `n = 4` 这一支，`n = 2` 给的是 `(4−1)²/8 = 9/8`，不同 `n` 给出不同读数，但读数本身不携带「来自哪一层」的信息。要把「不可反推」从判断变成机检结论，需要一条**多解显式化**定理：构造两个不同的范畴参数赋值，使物理读数完全相同。这是 §14 的入口。
