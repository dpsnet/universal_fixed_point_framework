# universal_fixed_point_framework

#### 介绍
本项目实现通用不动点范畴框架理论，实现谱去递归函子与原创谱静默机制。集成分形 RKHS、Clifford 谱、Kerr 黑洞、全息 CFT、BSM 新粒子、EFT 转化等模块，配套完整理论论文，全部数值实验可复现。
