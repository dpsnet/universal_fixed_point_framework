## 1. 背景与动机

四层静默（Four-Layer Silence）机制是 UFPF 框架的理论根基——它通过"高阶层态射幅度被权重压制"统一解释了质量层级、混合角、维度涌现、宇宙学常数等跨域现象。当前状态的强项与短板：

**已机器证明的根基事实**
- 定理 R1：递归压制率构成几何级数 S_k = s^k（范畴复合 k+l 步 = k 步 ⊗ l 步 ⇒ 半群同态 ⇒ 唯一解族；Lean `CoherenceToBranching.lean §10 suppression_geometric`）
- s = e⁻¹：规范固定（生成元匹配）+ 双重最优性（基数经济 E(b)=b/ln b 在 b=e 取极小；几何分布为固定均值最大熵分布）
- 规范不变量 d_H·ln(1/s) = ln 15（Moran 解唯一性机器证明）
- N_active = 3、B = 15、d_H = ln 15 + δ（机器证明）

**已知短板**
1. **分层值不一致**：多重静默方法论使用分层值 S₁=(Δλ_min/M_Pl)²、S₂=e^{-2π/α}、S₃=e^{-3}、S₄=e^{-d_H}，而定理 R1 给均匀几何级数 S_k=s^k——只有 S₃ 精确匹配均匀模式（e^{-3}=s³）。
2. **κ=1 概念缺口**：s=e⁻¹ 推导链中"为何 D 函子必须保持生成元（而非以 κ≠1 缩放）"未闭合，等价于"为何谱流参数 μ 以递归步为自然单位"。
3. **Z_i 推导失败（历史教训）**："四层静默猜测公式"不能复现 Z_i，已降级为"SM β 跑动 83% + 实验锚定 17%"。本轮统一推导链不得重蹈"猜测公式"覆辙——一切指数须有计数/结构来源。

## 2. 研究目标

建立四层静默的**统一母公式**与**推导链**：

- 从范畴结构计数统一导出 S₁–S₄ 各层具体形式（含非整数指数 e^{-d_H}、谱截断因子等）
- 闭合 κ=1 概念缺口（作为归一化条件自然进入）
- 数值验证全部推导步骤
- 诚实登记未闭合项（不使用"致命缺陷"表述，用"核心理论开放问题"）

## 3. 并行探索路线

### 阶段 0：数值基座（`scripts/paperX_silence_scan.py`）

- 精确盘点四层静默现状数值与来源表
- 建立"指数 = 结构计数"扫描框架：n_k = ln(S_k)/ln(s)（s=e⁻¹），检验 n_k 与候选范畴计数的匹配
- 候选计数库：N_active=3、N_total=5、B=15、Bott 塔 2³=8、能标比 ln(M_Pl/Λ)、SU(2) 表示维数等
- 注册 `run_all_tests.py`

### 阶段 1：路线 A — 有效指数统一

- 假说：S_k = s^{n_k}，n_k = 该层结构计数
- 已知匹配：n₃ = 3 = N_active；n₄ = d_H = ln B = ln 15（均机器证明）
- 待推导：n₁ ≈ 4.20（谱截断层）、n₂ = 2π/α（态射层）的计数来源
- 检验：统一的计数规则能否同时给出 n₁、n₂、n₃、n₄

### 阶段 2：路线 B — 统一变分原理

- 构造候选目标函数（最小描述长度 / 最大熵推广 / 基数经济变体）
- 检验：驻点是否同时给出 s=e⁻¹ 与各层指数 n_k
- 风险控制：目标函数自由度 ≤ 2，避免事后拟合

### 阶段 3：路线 C — κ=1 谱流生成元闭合

- 从 D ⊣ R 伴随自然性条件出发，论证谱流参数 μ 以递归步为自然单位 ⇒ κ=1
- 与规范不变量 d_H·ln(1/s) = ln 15 衔接
- 探索：κ≠1 时理论的自洽性损失（作为反证）

### 阶段 4：交叉验证与结论

- 三线一致判据：路线 A 的 n_k = 路线 B 的驻点指数 = 路线 C 的生成元秩 → 统一推导链成立
- 若某路线失败：记录失败模式（同样有价值，防止重复路径）
- 未闭合项按"核心理论开放问题"登记
