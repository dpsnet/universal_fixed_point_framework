## 1. 核心翻译：Lorentz 群 = 谱流生成元

$$[J_i, J_j] = \varepsilon_{ijk} J_k,\quad [J_i, K_j] = \varepsilon_{ijk} K_k,\quad [K_i, K_j] = -\varepsilon_{ijk} J_k$$

**定义 1.1**（Lorentz 谱生成元）。设物理可观测量 $A$ 在 $\mathbf{Spec}$ 中的谱像为 $D(A) = (\mathcal{H}, A, \sigma(A))$。Lorentz 变换 $\Lambda = \exp(\boldsymbol{\theta}\cdot\mathbf{J} + \boldsymbol{\varphi}\cdot\mathbf{K}) \in SO(1,3)$ 对应谱流：

$$\boxed{\frac{d}{d\tau} A_\tau = [G_{\text{Lor}}, A_\tau],\quad G_{\text{Lor}} = \boldsymbol{\theta}\cdot\mathbf{J} + \boldsymbol{\varphi}\cdot\mathbf{K}}$$

其中 $\tau$ 为谱流参数（旋转角 $\theta$ 或 rapidity $\varphi$，视生成元而定）。解为 $A_\tau = U_\tau A_0 U_\tau^{-1}$，$U_\tau = e^{\tau G_{\text{Lor}}}$。

### 2.3 关键发现：Carreau 流体与 Lorentz 因子的精确同构

Carreau 流体的本构方程
$$\eta/\eta_0 = [1 + (\lambda\dot\gamma)^2]^{(n-1)/2}$$
