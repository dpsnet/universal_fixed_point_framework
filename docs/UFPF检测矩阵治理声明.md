# 从"理论检测群"到可证伪的锚点网络：UFPF 对外治理声明

**声明日期**：2026-08-14
**关联**：本文为 UFPF（通用不动点范畴框架）就"路径×层次检测矩阵"协作提议的公开回应与治理立场声明；详细对接规格见仓库内《UFPF 检测矩阵对接对齐说明》。**"锚点必须可证伪"纪律源自外部学者回复《从"理论检测群"到可证伪的锚点网络》（docs/回复_王斌_理论检测群与外部锚点.md），本声明完整采纳并纳入 UFPF 对外治理。**

---

## 一、我们接受这个洞察与外部纪律

本框架发起人（王斌）在对外交流中提出的"理论检测群/外部锚点"洞察，是一个有价值的方法论升级：多路径推出同一组结论，不应被理解为冗余，而应理解为**冗余带来的检测能力**——同一个物理事实若能从不重叠的多条前提路线独立到达，任何新理论声称描述同一物理时，就自动获得多个可对表的外部参照系。

在此基础上，外部学者在回复《从"理论检测群"到可证伪的锚点网络》中为这个洞察补上了关键纪律，我们完全采纳：**锚点只有在可证伪时才有检测力。**

分歧必须区分两种：
- **表述层分歧**：语言不同、可观测后果完全一致——检测不到任何缺口，只是翻译手册没写完；
- **物理层分歧**：在某层次给出不同的可观测预言（不同的数、不同的符号、不同的定性行为）——只有这种分歧才能暴露理论缺口。

若不加这条区分，"交织网络"会退化成互相引用的同义反复：看起来检测力很强，实际上大量"锚点"只是同一结论的不同修辞。

## 二、可操作结构：一张"路径×层次"检测矩阵

行 = 多条已检验的解释路径（公设、几何、群论、因果、同步约定、热力学、量子参考系……）；列 = 理论层次（运动学、动力学、能量守恒、因果结构、量子接口）。每一格回答：**这条路径在这个层次上，能否独立推出一个可观测后果？**

- **✅ 格**：真锚点（独立可观测后果）；
- **⚠️ 格**：锚点存在但带条件，条件必须写进格子；
- **❌ 空格**：不是失败，是**理论缺口的候选登记处**——新理论声称在某格有内容而所有已检验路径在该格均空，则该声称须进入缺口登记。

矩阵每格必须附一个"分歧实验"字段：**设想一个观测，能区分"此格的 UFPF 版本"与"此格的主流版本"**。写不出分歧实验的格，一律降级为表述层分歧，不计入检测力。

## 三、治理形态：公共模板 + 各自副本 + 对外自报

工具不站队，只提供坐标系：

- **公共模板**（外部/社区维护）：矩阵 schema、proof_status 标注约定、盲登记格式。任何理论可 fork 后填自己的格子；模板演化同样走可证伪、可留痕的流程。
- **各理论副本**（自维护）：每个理论用自己的模板副本，自填格子、自标状态、自维护——**升降级、进攻（填格/挑战主流）、防守（保守标注）、妥协（协调表述）的原则因理论而异，公共层不统一规定**。
- **对外自报**：各理论用同一模板格式自报检测锚点状态——格式可比，内容自主，版本留痕保证可信。

## 四、权限边界：公共层只裁决当前，不裁决未来

这是本声明的核心治理条款：

1. **裁决权（唯一）——当前**：proof_status 现状判定、分歧实验存在性、盲登记冻结事实。这些是可核查的客观事实。
2. **无裁决权——未来**：任何理论的走向、优先级、攻守策略。未来不可核查，公共层不得裁决。
3. **建议权——未来**：仅限**从当前事实派生的建议**。建议的合法性来自它是当前裁决的自然推论。
4. **越权判定**：任何"应当/必须升级"类表述若不能回溯到当前事实判定，视为越权。

一句话：公共层回答"现在是什么状态"，各理论回答"我们打算怎么对待它"——两者分离，比较才有意义。

## 五、与 UFPF 现有治理的关系：不新增机制，只做形式化封装

上述治理工具并非为协作新建——UFPF 内部已长期执行同类机制（预言盲登记冻结、版本留痕、诚实边界与负结果登记、开放问题缺口登记）。对外矩阵只是把这套既有治理以标准化格式对外透明化。对接不改变 UFPF 任何实质内容，只要求"对外部锚点保持透明"。

## 六、邀请协作

- 公共模板的维护、行/列增删提案欢迎社区参与（增删须附带"该维度能区分两个原本不可区分的主张"的论证）；
- UFPF 侧将在项目内同步维护一份与公共模板格式对齐的登记实例；
- 任何分层理论都可以 fork 模板，把自己的缺口摊在同一盏灯下——不是某一个理论审判另一个理论，而是所有理论共用一套锚点登记坐标系。

**期待看到矩阵的各家版本。填格子时如果某一格让你犹豫了——那是检测群在工作。**
