# UFPF 就"路径×层次检测矩阵"协作提议的治理立场声明

**声明日期**：2026-08-14
**关联**：本文为 UFPF（通用不动点范畴框架）对一梦老师"路径×层次检测矩阵"协作提议（《回复_王斌_理论检测群与外部锚点》）的公开回应与治理立场声明；详细对接规格见仓库内《UFPF 检测矩阵对接对齐说明》（v0.2）。

---

## 一、接受一梦老师为"理论检测群"补上的纪律

"理论检测群/外部锚点"这一提法出自我在与一梦老师关于"解释路径"的讨论中提出的评论：多路径推出同一组结论，不应被理解为冗余，而应理解为**冗余带来的检测能力**——同一个物理事实若能从不重叠的多条前提路线独立到达，任何新理论声称描述同一物理时，就自动获得多个可对表的外部参照系。

一梦老师接住了这个洞察，并为我们补上一条硬纪律：**锚点只有在可证伪时才有检测力。**UFPF 接受这条纪律，并承诺在对外治理中执行。我们同时接受其标注纪律：proof_status **宁可标低不可标高**——矩阵的全部价值在于它的悲观可信。

由此，分歧必须区分两种（一梦老师《理论检测群》§一）：
- **表述层分歧**：语言不同、可观测后果完全一致——检测不到任何缺口，只是翻译手册没写完；
- **物理层分歧**：在某层次给出不同的可观测预言（不同的数、不同的符号、不同的定性行为）——只有这种分歧才能暴露理论缺口。

若不加这条区分，"交织网络"会退化成互相引用的同义反复：看起来检测力很强，实际上大量"锚点"只是同一结论的不同修辞。

## 二、可操作结构：一张"路径×层次"检测矩阵

一梦老师把上述纪律落成了可操作结构——一张"路径×层次"检测矩阵（《理论检测群》§二，v0.1 schema，七行五列）。

行 = 多条已检验的解释路径（公设、世界线/几何、群论、因果、同步约定、热力学、量子参考系）；列 = 理论层次（运动学、动力学、能量守恒、因果结构、量子接口）。每一格回答：**这条路径在这个层次上，能否独立推出一个可观测后果？**

- **✅ 格**：真锚点（独立可观测后果）；
- **⚠️ 格**：锚点存在但带条件，条件必须写进格子；
- **❌ 空格**：不是失败，是**理论缺口的候选登记处**——新理论声称在某格有内容而所有已检验路径在该格均空，则该声称须进入缺口登记。

矩阵每格必须附一个"分歧实验"字段：**设想一个观测，能区分"此格的 UFPF 版本"与"此格的主流版本"**。写不出分歧实验的格，一律降级为表述层分歧，不计入检测力。

## 三、治理形态：公共模板 + 各自副本 + 对外自报

工具不站队，只提供坐标系：

- **公共模板**（外部/社区维护）：矩阵 schema、proof_status 标注约定、盲登记格式。任何理论可 fork 后填自己的格子；模板演化同样走可证伪、可留痕的流程。
- **各理论副本**（自维护）：每个理论用自己的模板副本，自填格子、自标状态、自维护——**升降级、进攻（填格/挑战主流）、防守（保守标注）、妥协（协调表述）的原则因理论而异，公共层不统一规定**。
- **对外自报**：各理论用同一模板格式自报检测锚点状态——格式可比，内容自主，版本留痕保证可信。

## 四、权限边界：公共层只裁决当前，不裁决未来

这是本声明的核心治理条款：

1. **裁决权（唯一）——当前**：proof_status 现状判定、分歧实验存在性、盲登记冻结事实。这些是可核查的客观事实（证据指针可验证）。
2. **无裁决权——未来**：任何理论的走向、优先级、攻守策略。未来不可核查，公共层不得裁决。
3. **建议权——未来**：仅限**从当前事实派生的建议**（如"此格为孤桥——单路径可达，属当前事实；建议投入验证"）。建议的合法性来自它是当前裁决的自然推论。
4. **越权判定**：任何"应当/必须升级"类表述若不能回溯到当前事实判定，视为越权。

两点澄清，以消除"自维护"与"公共层裁决"的表面张力：

- 公共层的裁决对象是**对外自报的事实性**（自报与客观事实是否一致），不是主张的升降级策略——升降级归各理论自维护，公共层不统一规定；
- 各理论**内部治理权威不因对接而转移**：对 UFPF，内部权威仍以 `paper/RAP_盲登记协议.md` 为准，矩阵盲登记只是对外接口格式。

一句话：公共层回答"现在是什么状态"，各理论回答"我们打算怎么对待它"——两者分离，比较才有意义。

## 五、UFPF 侧对接：复用现有治理，显式处置四类干扰

对外矩阵并非为 UFPF 新建机制——UFPF 内部已长期执行同类治理，对接协议五条款（登记、有锚、缺口登记、翻译可还原、修订留痕）逐一映射到现有资产，UFPF 侧无新增负担：

| 治理资产 | 现状 | 对应条款 |
|:--|:--|:--|
| `paper/RAP_盲登记协议.md` | v0.38（登记表/冻结值/联动规则/版本哈希/修订史，与勘误 1:1 同步） | 条款 1（登记）、3（缺口登记） |
| `paper/RAP_勘误与立场声明.md` | 版本留痕/勘误惯例 | 条款 5（修订留痕） |
| `paper/UFPF体系总序.md` | v0.24 谱翻译可还原性条款 | 条款 2（有锚）、4（翻译可还原） |
| 论文层诚实边界/开放问题登记惯例 | 全库执行 | 条款 3（缺口登记）的既有形态 |

一梦老师提议将这类治理形式化为公共检测矩阵工具，UFPF 将其回收为对外接口（"外溢再回收"）：对接不改 UFPF 实质内容，只要求"对外部锚点保持透明"。**公共模板本身的创建与社区维护属于协作新增物，由外部/社区负责**——UFPF 不维护公共模板，只同步格式、自填内容。

针对对接可能产生的四类干扰，UFPF 承诺显式处置（详见《UFPF 检测矩阵对接对齐说明》§三）：

1. **防双轨标注**：proof_status（Proven/CLAIM/CONJECTURE）与 UFPF 既有三层级论证强度（预测检验/框架自洽/先验导出）是两个正交维度，同一主张二维标注，禁止只用一维标签造成歧义；
2. **防双权威**：矩阵工具盲登记 = 对外接口格式；内部权威 = RAP 盲登记协议。格式可对齐，权威不转移；
3. **防过度约束**：物理预言类主张必须写分歧实验；纯数学/框架自洽主张（Lean 机器证明、范畴结构、纯谱代数）豁免分歧实验字段，但须显式标注"纯结构主张，无实验分歧面"，不得默认豁免；
4. **防硬填**：矩阵是 UFPF 的**子集坐标**，不是全集映射——Rec/Sp 范畴纯结构、D 函子、静默机制等谱层内部内容不硬填七行五列，按条款 3 进缺口登记（盲登记 + 证伪条款）承载；落格率低不构成缺陷。

对接后 UFPF 的第一个作业，按一梦老师的建议落在**层次拼接点**上：对"递归层 → 谱层"与"谱层 → 物理层"两处接口，列出谱层每个可定义对象，问七条路径中哪一条能独立逼近它——只有谱层内部自指定义支撑的对象，登记为孤桥；声称有物理意义的谱量，落在 ✅ 格的与锚点对表，落在 ❌ 格的按条款 3 盲登记 + 证伪条款。

## 六、邀请协作

- 公共模板的维护、行/列增删提案欢迎社区参与（增删须附带"该维度能区分两个原本不可区分的主张"的论证）；
- UFPF 侧将在项目内同步维护一份与公共模板格式对齐的登记实例（`paper/RAP_盲登记协议.md` 为现成载体）；
- 检测矩阵与本仓库融合路线规划（`roadmap/u2f_fusion_roadmap.md`）共享同一路径集：融合路线定内容与方向，检测矩阵定对外标准化与治理，融合产物按五条款先盲登记再对表入矩阵，不重复建设；
- 任何分层理论都可以 fork 模板，把自己的缺口摊在同一盏灯下——不是某一个理论审判另一个理论，而是所有理论共用一套锚点登记坐标系。

**UFPF 将逐格填写自己的矩阵——从层次拼接点开始。填到某一格犹豫时，那是检测群在工作。**
